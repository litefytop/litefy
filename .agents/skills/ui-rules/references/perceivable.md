# 可感知（WCAG 1.1 / 1.2 / 1.3 / 1.4）

1. 文本替代：图标按钮的名字走 `aria-label`，装饰图标写 `aria-hidden="true"`；`Image` 的 `alt` 必填，装饰图给空串（`app/ui/components/image.tsx`）
2. 图形要有名字：图表 canvas 要 `role="img"` + `aria-label`（`app/ui/components/chart.tsx` 已接：`label` prop 优先，缺省取各系列 label 连接，全空回退 "Chart"），或外挂等价数据表
3. 对比下限：正文 4.5:1（1.4.3，AA）；大字号（≥24px = 18pt，或 ≥18.66px = 14pt 粗体）3:1；非文本件（控件边框、图标、状态图形）3:1（1.4.11）；比率不进位（4.499:1 不合格），暗档单独再核一遍
4. 文字色取与背景色配对的 `*-fg` 令牌：对比不达下限是令牌层的事，不在皮肤里就地调色
5. 颜色不单独传信：错误、选中、危险除变色外还要有属性、图标或文字差异之一
6. 结构不靠视觉：相邻关系、层级、分组要能从 `role`、`<th scope>`、列表标签读出，不能只靠缩进、边框或空白
7. 位置词不算说明：禁止只说「右侧的按钮」「红色那项」——方向与颜色要配一个不依赖感官的指代
8. 字号只用 rem 令牌：文本、行高、字距一律走 `@theme` 阶梯，禁 px 字面量与 `line-height` 无单位值以外的固定行高
9. 缩放不破相：浏览器文本放大到 200% 不许裁字、叠字；320px 视口宽度下不许横向滚动（固定宽度容器是首要破坏点）
10. 用户间距覆盖要活：行高 1.5、段后 2em、字距 0.12em、词距 0.16em（1.4.12，AA，四值均为字号的倍数）这类强制样式覆盖进来时不许破相——写死 `height` 的行盒与 `overflow: hidden` 是两条主要死因
11. 动效响应减弱偏好：`motion-safe:` 或 `useMotionPreference`（`banner` / `count-up` / `swipe-actions` 走 hook，`avatar` 走 `motion-safe:`）；不转不等于不加载，加载还要有文字或 `aria-busy`
12. 动画与 transition 默认只做变换与透明度；布局属性（width / height / top / left）动画按开销分流——对性能无影响的小范围布局动画可保留，开销大的不作默认、仅由消费者显式启用（细则见 delivery `references/motion.md` 7）
13. 不许闪：任何元素每秒闪烁不得多于 3 次；骨架屏的脉冲与进度条流光都算闪，减动效档必须整条停掉
14. 自动动效可控：自动播放、自动滚动、自动推进的件要有暂停/停止/隐藏入口，或时长由消费者控制
15. 媒体：本库暂无音视频件；接入时自带字幕、手语替代与独立音量控制，超 3 秒的自动声音必须能关
16. 外观可让位于消费者：正文对齐、缩进、间距不许用高特异性或 `!important` 锁死——覆盖通道永远比选择器硬拼干净
17. 强制颜色模式未接线：本库不回答 `forced-colors`，改外观不许假设系统高对比会兜底；真要接，焦点环、边框与状态图形都得走 `currentColor` 出路
18. 系统偏好现状：接管了 `color-scheme`（三案各自按档声明）与 `prefers-reduced-motion`；`prefers-contrast`、`prefers-reduced-transparency` 未回答——新增外观时先声明接管哪条，没接管就别装作兜住
19. 行宽上限（1.4.8，AAA）：连续阅读的正文每行不超过 80 个拉丁字符或 40 个中日韩字符，`max-w-[40em]` 让两者同时成立（车道与写法见 delivery `references/skin-rules.md` 16.1）；表格、代码块、图表不算正文列，不受此限，但超宽时要自己横向滚动而不是撑破页面
