# 组件优先

1. 写交互件先查组件库（`app/ui/skins/`）：有对应组件必须用组件；成品与零件二选一（皮肤通用外观律第 6 条），禁 Tabs 套 Tabs、Drawer 冒充侧栏
2. 链接观感是按钮：`Link`/`a` 引用 `buttonVariants` 既有形态再叠差异类（皮肤通用外观律第 11 条），禁止手写边框、阴影、位移按钮串；禁止 `Link` 内嵌 `Button`（嵌套交互）
3. 卡片分静态与可交互两态：静态卡禁 hover、光标与一切悬停动效（皮肤通用外观律第 7 条），库内形态是 Card；可点卡走 CardButton 或引 buttonVariants——动效由组件持有，页面不自贴 hover 串
4. 库里没有对应组件：先判断该形态是否值得进库（新增组件或变体走 delivery 的 ui-source 参考）；不值得进库才允许原生件，手写最小样式
5. 豁免：纯文字链接（无按钮观感）、教学演示画布（演示目标就是原始 utility 行为，如法则演示砖、app/demos/）
