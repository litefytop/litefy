# 装饰层通用律（渐变 / 光晕 / 噪点 / 着色器 / 动态背景）

1. 装饰可以存在，但必须被规范约束，不能浮在令牌系统之外。本文件约束一切非语义视觉层；语义色用法看 `skin-rules.md`，色板与填充契约看蓝图 `ui/schemes.md` 第 4 条，减动效契约看 `motion.md`——已有的律只引用不重复。
2. 六条边界，缺一即不合规：
   1. 位置：装饰不侵入内容可读区——正文与控件所在盒子的背景由色板令牌答，装饰只在留白区、页面级底层或明确的展示区；禁止把装饰铺在文字底下再靠文字阴影救回来
   2. 参数令牌化：强度、速度、颜色、尺寸全部出自令牌（渐变案的 `gradients:` YAML 与 `--fill-*` / `--text-fill-*` 机制值），禁在皮肤或页面里裸写角度、stop、时长与色值
   3. 可读性：装饰叠加后前景文字对比仍达 ui-rules `perceivable.md` 的下限；装饰与文字争对比时降装饰，不降文字
   4. 渐变质量：长距离渐变避免色带——在 oklab / oklch 插值，必要时加噪点打散；相邻 stop 明度差过大时补中间 stop
   5. 预算：装饰有渲染成本上限——着色器与画布限定作用域与分辨率、离屏即停、同屏只跑一处重量级装饰；能用 CSS 渐变表达的不启动画布
   6. 减少动态：动态装饰必须响应减动效契约（`prefers-reduced-motion` 与根 `data-motion`），退化为静态一帧而不是整体消失
3. 装饰不承担语义：状态、层级、选中与否一律由色板与形状表达，装饰不得成为唯一的信息通道。
4. 自检：把装饰层整体关掉，页面信息与可用操作应当完全不变——变了说明装饰在承担语义，退回第 3 条。
