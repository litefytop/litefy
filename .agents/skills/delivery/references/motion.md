# 动效通用律（时长 / 缓动 / 可打断 / 编排 / 预算）

1. 本文件只写方案无关的动效规律：时长与缓动取值看各方案 `design.md` Motion 与 `--duration-*` / `--ease-*`，减动效检测看 ui-rules `perceivable.md` 与 utils `useMotionPreference`，装饰层预算看 `decoration.md`——已有的律只引用不重复。
2. 时长按**位移量级**分档，不按组件名分档：微反馈（按压、悬停、开关指示）取最小档；小过渡（下拉、气泡、折叠、局部显隐）取中档；大过渡（抽屉、对话框、页面级切换、大元素进场）取最大档。新件先归量级再取档，禁逐场景现编时长——那是消灭一致性最快的方式。
3. 量级边界（**示例值**，只用于判断归哪一档，取值权威在各案 YAML）：微反馈约 100ms、小过渡约 200–300ms、大过渡约 300–450ms。本库现值 minimal 150 / 300 / 500ms、neo-brutalist 0 / 150 / 200ms，是方案自答，不是行业标准。
4. 缓动同样是令牌：进出场共用 `ease-frame`，需要弹性时由方案新增缓动令牌并写进 YAML；禁皮肤里裸写 `cubic-bezier(...)` 或 `ease-[...]`——裸时长与裸缓动同时绕过减动效契约。
5. 可打断：用户触发的动效必须能被新输入改向或中止，反向触发时从当前视觉位置接续，不排队、不锁到播完。实现上让目标值直接驱动 CSS 过渡（过渡天然从当前计算值接续），禁止「播完再处理下一次输入」的队列或 `isAnimating` 闸门。自动播放的装饰动画不受此条约束，但必须能被减动效与暂停开关停下。
6. 编排：多个元素同时进场用统一档加递进延迟表达先后，延迟总量不超过一档时长，禁逐个现编 delay；同一组元素的退场走同一档，不各自发挥。
7. 性能预算：默认只动 `transform` / `opacity` / 颜色（清单由各案 `--transition-frame-properties` 答）。布局属性动画按开销分流：对性能无影响的小范围布局动画（量具宽度过渡、单件高度收合、折叠高度的 grid-template-rows 技法）可保留；开销大的（大面积重排、持续布局动画）不作默认，仅由消费者显式选择性启用。持续动画只在可见时运行——离屏、`hidden`、折叠收起的分支不跑。
8. 自检四条：① 每处时长归得出量级；② 缓动出自令牌；③ 反向操作能立刻改向；④ 没有布局属性参与动画。只有时长表、没有缓动 / 可打断 / 预算三项的动效规范是半份。
