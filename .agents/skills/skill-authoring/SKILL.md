# 列表格式

1. 全部统一用数字列表（`1.` `2.` `3.`），不用 `-`，子项缩进后同样编号
2. 一条一段，不靠换行区分段落

# 形态分级

1. 查重先行：AGENTS.md 与既有技能已说明的内容不重复写入，需要时一句话引用；重复即删
2. 默认单文件：主题 < 3 个、总行数 ≤ 60、无任务路由 → 只写 SKILL.md
3. 出现任一信号即拆 `references/`：
   1. SKILL.md 超 50 行（理想）或 100 行（硬限）
   2. 内容分属不同领域
   3. 某部分只在特定场景需要（如故障排查）

# 主文件 = 路由器

SKILL.md 只留三样：

1. 高层工作流（80% 场景够用的内容）
2. 每个子文件一句话说明 + 明确的读取触发条件
3. 一个最小可运行示例

完整示例与参考细节一律进子文件，不留在主文件。

# 子文件与脚本

1. 子文件全放 `references/`，扁平一层，不建子目录
2. 技能自带的脚本放该技能文件夹内
3. 仓库根 `scripts/` 只收项目业务脚本（构建、生成、发布），禁止把技能脚本堆进去
