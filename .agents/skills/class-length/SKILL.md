# class-length

1. 范围只查 `app/ui/`（components、skins、utils），其余目录不查
2. 计量单位两类：每个 `cn()` 调用；每个类串常量定义（对象字面量按成员拆，函数与 JSX 初始化器不查）。长度按合并上界算——单元内直接书写的字面量 + 引用的静态常量（本地 / 跨文件 import / 对象成员）递归内联成完整串；同一常量被多处引用时各自计入所在单元（合并口径，不去重）
3. 超 300 字符即 WARN；WARN 当场清零——真正缩短合并串：用令牌替代长任意值、删冗余变体与重复类。拆成具名常量不减少合并长度（引用会被解析内联，挪常量躲不过计量），不带警告交付
4. cn 不可嵌套：任何 `cn(` 的参数范围内不得再出现 `cn(`——内层提为文件级常量或并回外层，NESTED 同 WARN 一样当场清零
5. className 透传参数与条件测试表达式不计入；三元 / `||` 两侧都计入（静态上界），`&&` 只算末段，`+` 按 JS 串接
6. 运行期值（props 透传、cva/tv/mergeSlots 等未知函数调用、动态键、模板插值）不计入长度，标注「未计入项」；槽映射对象（裸槽名键 + 类串值，如 slots / partClasses 别名）整体不是一条类串，记 SKIP、成员在定义处另计；整单元不可静态解析的记 SKIP——不算警告，但要在报告里盯住

# 工作流

1. 仓库根跑 `node .agents/skills/class-length/analyze-classes.mjs`；脚本自动以 `--all` 调用检查器，在 `temp/` 生成带时间戳的原始报告 `class-length-<时间戳>.txt` 与分析报告 `class-analysis-<时间戳>.txt`，文件名排序即时间顺序
2. 读分析报告查重复类串、重复片段与工具类用量；读原始报告查 WARN（>300，附完整合并串）、NESTED（含内外层位置）与 SKIP（只记录不算违规）
3. 修完复跑，直到 WARN 与 NESTED 归零；每次生成的新报告独立保留，不覆盖旧报告
4. 退出码沿用检查器：1 表示仍有 WARN 或 NESTED，0 表示干净
