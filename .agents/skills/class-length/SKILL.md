# class-length

1. 范围只查 `app/ui/`（components、skins、utils），其余目录不查
2. 计量单位两类，各只数单元内直接书写的类串字面量：每个 `cn()` 调用；每个类串常量定义（对象字面量按成员拆，函数与 JSX 初始化器不查）。被引用的常量只在定义处计量一次，引用点（含跨文件 import）记「未计入项」，不重复计数
3. 超 200 字符即 WARN；WARN 当场清零——把一整串按变体 / 条件态拆成具名常量再组装（不是挪进别的常量躲计量），不带警告交付
4. cn 不可嵌套：任何 `cn(` 的参数范围内不得再出现 `cn(`——内层提为文件级常量或并回外层，NESTED 同 WARN 一样当场清零
5. className 透传参数与条件测试表达式不计入；三元 / `||` 两侧都计入（静态上界），`&&` 只算末段，`+` 按 JS 串接
6. 常量引用与 props 等运行期值不计入长度，标注「未计入项」；未知函数调用、动态键访问、模板插值、深度超限的单元记 SKIP——不算警告，但要在报告里盯住

# 工作流

1. 仓库根跑 `node .agents/skills/class-length/check-class-length.mjs`
2. 读报告：WARN 行按长度降序，NESTED 行含内外两层位置，SKIP 行只记录不算违规；带 `--all` 可列出全部单元（含未计入标注）核对
3. 修完复跑，直到 WARN 与 NESTED 归零；需要留档时把输出重定向到 `temp/.tmp-result.txt`（临时文件用完即删）
4. 退出码 1 表示仍有 WARN 或 NESTED，0 表示干净
