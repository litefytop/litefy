# 组件 demo（app/demos/**）

1. 目录即正本：`app/demos/<name>/`，文档页经 `ComponentPreview name="<name>-<file>"` 挂载，示例墙按目录名匹配追加变体名（消费端归 `site/widgets/` 蓝图）。
2. 禁用态统一展示：实现了禁用态的交互组件一律配 `disabled.tsx`，只放一个禁用态实例，不与可用态对比（可用态归 basic）；条目级禁用的组件（无单控件形态或以列表为语义单元的，如 accordion、radio、segment、menu、tabs、tree、transfer、color-swatch、swipe-actions）在实例里整组禁用——组内所有条目全部禁用，禁止只禁其中一部分：有组级 disabled 的组件传组级 prop（Accordion 传组级 `disabled`，不逐项标注），其余逐条目标注 disabled；Calendar 通过 `isDateDisabled` 限制可选日期，限制之外的日期保留显示并禁用，不传整组件 `disabled`，日期格与正常态保持相同盒模型。禁用观感由组件各自的禁用变体与禁用状态自答，禁止用 `dim`、`inert` 或禁用用途的 `pointer-events: none` 包裹层兜底，禁用光标必须可见；包裹层只承担 basic 所需的宽度形态。原生控件传原生 `disabled`，组合控件传组级禁用；自定义可点击、可键盘激活或可导航条目由骨架或皮肤在 JavaScript 中阻断动作。清单（31）：accordion、button、calendar、cascader、checkbox、collapse、color-swatch、combobox、command、date-picker、date-range-picker、details、filter-combobox、input、input-otp、menu、multi-select、number-field、number-input、password、radio、segment、select、slider、swipe-actions、switch、tabs、toggle、transfer、upload、tree；未实现禁用态的组件不配。
3. 单控件 + 组条两形态并存的组件（checkbox、toggle）按 radix 式拆分：`basic.tsx` 只留单控件，组条拆入 `group.tsx`，`disabled.tsx` 只禁单控件；组条条目级禁用不单独配 demo（API 表已载 `option.disabled`）。示例出现多实例的一律以组形态承载——checkbox 删除线清单经 `CheckboxGroup` 的 `common.lineThrough` 统一开启，不堆裸多实例。
4. 相连堆叠的同族条目 demo（details 组、collapse 组等消费端自行成组的形态）条目不各自带阴影：整组投影只归外根容器（skin-rules 18），条目串剥阴影（`shadow-none`）、间以分隔线。
5. progress demo（`progress/basic`）根带 `w-full` 通栏承载——示例墙缩放内层列向 `items-center` 只居中不撑宽，无定宽根缩成 fit-content，根内 `w-full` 子件循环解析塌缩成内容宽（轨道空盒贡献 0，实测 2026-11-22）；按钮按阶段出：idle 只 `Start`；running 出 `Pause` / `Abort` / `Reset`；paused 首钮换 `Resume`、`Abort` / `Reset` 留守；complete / aborted 只余 `Reset`——终止后 Pause / Abort 无意义，回 idle 须经 Reset。
6. 文档挂载：各组件 zh.mdx 用法节末尾加 `### 禁用` 小节——一行概括 + `<ComponentPreview name="<name>-disabled" />`（doc-format 第 3 条「额外能力自成小节」）；checkbox、toggle 在禁用小节前加组条小节（`### 多选组` / `### 组条`）挂 `group.tsx`；英文攒批同步，slug 移出 `content/docs/sync.json` 白名单。
7. steps 额外配 `vertical.tsx`（用户定 2026-11-22）：纵向步骤内联每步 `content`，页脚导航按钮由使用方组合，终结态同 basic（走完 Next 隐去、Back 留守）——向导场景归 Steps 自答，不设独立向导组件。
8. demo 优先消费组件自带的语义宽度：字段不超过 320px，Card / Form / List / Chat / Transfer 使用各自默认档位，Banner / Callout / Accordion / Collapse / Details 与结构组件保持全宽；不重复给组件补默认最大宽度，也不添加桌面 75% 限制。只有展示内容宽度、固定形态或多实例排布时才在业务层显式给尺寸；优先直接渲染组件，必要时使用 `mx-auto min-w-0`，浮层触发组与固定形态控件按内容尺寸展示。
