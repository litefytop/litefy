# IconAdapterPlayground（app/components/icon-adapter-playground.tsx）

- 层：界面域·部件——headless 指南「适配器验证」节的动态演示件。
- 机制：全部官方适配器实现同时进站点包（默认面 + `packages/cli/adapters/` 各适配表文件逐一静态导入登记，新适配表同步登记），开关切换后网格逐格换字形；数据源 = 当前适配器的 `icons` 映射（普通对象，键即契约名；ES 模块命名空间属性不可枚举，禁止 `Object.entries(命名空间)`）。
- 标签 = 映射后的来源库名：取各适配器的 `sourceNames`（契约名 → 来源库名映射表，契约面一部分）；排序 = 契约顺序（默认适配器 `icons` 键序锚定），所有适配器同序；回退项显示 Lucide 名，与目标库名同屏可辨。
- 卡片放大、名字内联常显：卡片横排「图标 + 源库名」（`flex items-center`），全名直接可见——无 hover 浮层（划过屏幕会连环触发、触屏设备无从悬停）、不截断不折行；网格降到 1 / 2 / 3 列（sm、md 升档），卡片宽度由网格轨道定，内容变化不挤动轨道。
- 点击卡片复制源库名（`copyText` 契约）：复制成功后该卡片文字临时切换为「已复制 / Copied!」，2 秒后恢复源库名；列宽由轨道锁定，文字切换不位移布局。
- 数量一致性即验证信号：每个适配器必须导出**完全相同**的字形集合（契约面 = 骨架消费面，零预留件）——切到任一适配器网格数量与默认一致即通过，不一致即适配器面错误；一致性由 `scripts/check-icon-adapters.mjs` 门禁自动核对。
- 网格与文案零死值：网格项与顺序读默认适配器 `icons` 键序锚定的契约清单，说明文案的项数动态读同一来源的键数——新增字形后网格与数字全自动同步，无手写死值。
- 依赖：各官方适配器的图标库 npm 包进根 dependencies（站点演示与适配器类型检查共用）；适配器文件经根 tsconfig 类型检查。
