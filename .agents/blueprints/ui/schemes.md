# 方案令牌（app/ui/schemes/<slug>/index.css）

1. 色板每方案 22 枚、亮暗各一套：画布的背景与文字 `background` / `foreground`、次要容器的背景与文字 `surface` / `surface-fg`、强调背景与文字 `accent` / `accent-fg`、边框 `border`、品牌三件 `primary` / `primary-fg` / `primary-accent`、语义四族 `danger` / `info` / `success` / `warning` 各三件（背景色、`-fg` 前景色、`-accent` 悬停背景档）。色板之外不设颜色令牌；浮层背景与焦点环是方案机制值，由这 22 枚派生。焦点环全局唯一，写在 `index.css` 的 `--focus-*`：minimal 为 1px `primary` outline 加 3px `primary` 50% 透明的阴影，invalid / danger 组件转 `danger-fg` 及其 50% 透明的同形阴影；neo 无透明度，为 2px `foreground` outline；clinical 亦无阴影 glow，为 2px `primary` 实线 outline（offset 2px），invalid / danger 转 `danger-fg` 同形；neon-gradient 随档（第 16 条）：浅档 2px cyan-700 实线加同族柔影、danger 转 rose-700，暗档 2px cyan-400 实线加 cyan 光晕、danger 转 rose-400。
2. 后缀只有两枚：`-fg` 是前景色，`-accent` 是强调 / 悬停背景档；背景色一律不带后缀，`@theme` 同形（`--color-surface` / `--color-danger`）。画布例外用全写 `background` / `foreground`。
3. 语义四族成套取用：`<status>-fg` 是状态块上文字色，`<status>` 是状态静置背景色，`<status>-accent` 是强调 / 悬停背景档；取值归方案、成对取色板整数档（用户定则）：亮档 `<status>` 300 / `-accent` 200 / `-fg` 900，暗档 `<status>` 200 / `-accent` 300 / `-fg` 900（fg 亮暗同 900——语义块夜间翻为浅粉彩块配深字；minimal / neo / clinical 同构，neon-gradient 渐变案自答：浅档 700 / 800 配白字、暗档饱和实心对，见第 16 条）；块上文字 `-fg` 对 `<status>` 与 `-accent` 实测 5.24–7.50:1（AA 过）；填充对 `surface` 亮档不足 3:1（约 1.3–2.2:1）是既接受项——1.4.11 只约束理解内容所必需的视觉信息，进度 / 量具缺省尾随可见读数（值有文本替身）后填充即非必需图形，量具类不强制 1:3（用户定则）；独立语义文本（不落在语义块上的 `*-fg` 用法）夜间在暗画布上可读性记待定项。neon-gradient 随档自答（第 16 条）。皮肤按 `bg-<status>` + `text-<status>-fg` 成对写，状态色不开角色族。
4. `@theme` 的色彩映射只答这 22 枚（`--color-<令牌名>` 同形一一对应），其余颜色槽位（`panel` / `quiet` / `plain` / `active` / `block` / `field` / `note-*` / `shell-*` / `hover` / `paper` / `veil` / `black` / `white` …）缺省不设——确有必要时先修订本条把槽位纳回色板（枚数随实际开放数同步），恢复后即可正常取用，未恢复前的存量消费由整库重写处理；焦点轮廓（`--focus-outline-*`）与阴影档不是颜色变量，不在此律内；浮层背景机制值 `--color-surface-raised`（rule 1 派生，亮档同 `background`、minimal 暗档提亮一档读 `surface`）不属色板槽位；井底机制值 `--color-well`（组容器井的底色，minimal / clinical 读 `surface`、neo / neon 读 `background` 即关井色）同不属色板槽位。背景填充走全案同构 fill 契约，四案都声明同构 `bg-*` 家族（`bg-background`、`bg-surface`、`bg-primary` / `bg-primary-accent`、`bg-accent`、语义四族 `bg-<status>` / `bg-<status>-accent`），本体固定两行：`background-color: var(--color-<角色>)` 纯色兜底 + `background-image: var(--fill-<角色>, none)`。填充机制变量 `--fill-<角色>` 在各案 `:root` 答值：纯色案答 `none`（渲染与无填充一致），渐变案答整段 background-image——角度、stop 数、尺寸、流动动画都是值的一部分，渐变案 design.md 的 `gradients:` YAML 即其答值来源（rule 7 同律）。变体组合（`hover:` / `active:` / `has-[:checked]:` / `data-[…]:`）复用同一 utility 本体，全部状态自动同填充；悬停换档沿用 `-accent` 档 utility，渐变案要同图流动就答 `--fill-<角色>-accent: var(--fill-<角色>)`（图像同值、尺寸保留，position 滑动由案内 utility 追加行表达）。文字填充：组件需要渐变字时挂 `text-fill-<角色>` utility，本体固定三行——`background-image: var(--text-fill-<角色>)`、`background-clip: text`、`color: transparent`；文字填充没有 `none` 档，纯色案答同色渐变兜底；渐变字与 `text-shadow` 互斥，允许渐变字的角色由各案 design.md 自答。边框不设填充车道：边框与描边一律读纯色令牌，渐变边框需求出现时另立蓝图任务。令牌本体保持纯色：文字、描边、焦点环、阴影与派生仍读它。原生滚动条部件可加渐变 thumb 并去除原生箭头。
5. 运行期换色只重指向色板内令牌：`[data-brand]` 答品牌三件、`[data-surface]` 答次要容器背景与 `accent`；固定色方案不设梯。
6. 一个角色名只能属于一个 `@theme` 命名空间：`--color-x` 与 `--border-width-x` 同名时 `border-x` 同时生成宽与色两条规则，色档按源序抢掉写在它前面的 `border-border`。边框宽度档只有 `control` / `hair` / `frame`；例外：连续条 / 倒计时内条的前景细描边走原生 `outline-1`（1px、四案同值、画在盒外不占填充——hair 档随案 1–4px，且盒内 `border` 会吃掉 4px 内条的填充）。
7. 各套方案逐档同值：`index.css` 的 `@theme` 是该方案 `design.md` YAML 数值的实现，两边不一致时以 YAML 为准并报告冲突。
8. `index.css` 六块定序，一块一职责；`index.css` 是纯主题层，入口接线（`@import "tailwindcss"` 与扫描源 `@source`）归消费方 Tailwind 入口，不在方案文件内（分发模型 B，见 distribution/cli.md 第 13 条）：① `:root` / `.dark` 令牌与机制值，`--litefy-scheme` 只在此声明一次，组件运行期变量（cascader 深度/列宽这类）不进 `index.css`；② 运行期 ramp——minimal 的 `[data-brand]` / `[data-surface]`，neo 与 clinical 固定色不设；四案同构的紧凑档 ramp 见第 11 条；③ `@custom-variant`（`dark` / `quiet` / `plain` / `borderless` / `bordered` / `motion-safe`——双分支：OS `prefers-reduced-motion: no-preference` 或根元素 `data-motion="full"` 任一命中即动，站内「完整动态」对 CSS 呼吸类动画有覆盖权（动效指南契约）；独立消费方根元素无 `data-motion` 时退化为纯 OS 查询，行为不变）；④ `@theme`——色彩先 `--color-*: initial` 再只映射 22 枚与机制值 `--color-surface-raised` / `--color-well`，控制几何 `--height-control` / `--height-field` 同值 2.75rem（按钮与行控件同读控制令牌，按钮不骑数字乘道——乘道随 `--spacing` 逐案缩放会让 neo 按钮与 44px 控件车道断档），行控件反解 `--padding-tight` / `snug` / `loose` 三档，卡面内边距 `--padding-panel`（minimal / clinical 恒 1.5rem；neo 静置 1.5rem、48rem 起 2rem 随其尺寸宪法翻倍），组容器井框距 `--padding-well`（四案同答 0——minimal 曾答 0.25rem，现只关框距，井底与内阴影仍由各案自答）；⑤ `@utility` 角色类全家（`case-label` / `font-label` / `motion-frame` / `lift` / `crush` / `shadow-frame` 系 / `shadow-block` 系 / `shadow-surface` / `shadow-focus` / `shadow-checked` / `shadow-well` / `shadow-elevated`(neo；clinical 经 `@theme` 映射答 `none`) / `shadow-hint`(neo；minimal 经 `@theme` 映射答 elevated 同值，clinical 经 `@theme` 映射答 `none`) / `focus-ring` / `focus-ring-danger` / `thumb-hit` / `line-cap` / `line-join` / 排版单挂家族 `typo-h1`~`typo-h6` / `typo-body` / `typo-quote` / `typo-list` / `typo-code` / `typo-link`——约定见 schemes/typography.md 蓝图；键帽形态类 `kbd`——约定见 schemes/kbd.md 蓝图）；骨架脉冲不设自定义 utility——走核心模板 `animate-pulse`，minimal 与 clinical 用核心档，neo 在 `@theme` 重答 `--animate-pulse` 为硬切两档；⑥ `@layer base`——长文作用域、边框默认色、字体、禁用契约、`data-motion` 动效开关；`@property --litefy-cols` / `--litefy-percent` 随用随注册。按压反馈不设全局 `button:active`：按压由各皮肤显式挂 `active:` utilities（`crush` / `shadow-frame-active`），未挂即无按压。
9. 共享皮肤点名的角色每套方案都必须有值，禁止 `@utility` 读未声明变量：`--shadow-focus` minimal 答 `--focus-glow`、neo 答 `none`、neon-gradient 答 `--focus-glow`（霓虹焦点）、clinical 答 `none`（无阴影焦点）；`--shadow-hint` 是轻提示层（Tooltip / Toast 皮肤点名）——minimal 答 `--elevation-elevated` 同值，neo 答 `none`（轻提示不承重、不带阴影），clinical 答 `none`；`--shadow-checked`（选中双层环：画布色间隙 + 主色外环；运行期换环色经元素级内联覆盖该令牌注入，如 SwatchPicker 的同色环）四案同答；`--stroke-cap` / `--stroke-join` minimal 答 `round`、neo 与 clinical 答 `butt` / `miter`；`--shadow-faint` / `--shadow-subtle` minimal 经 `@theme` 映射 `--elevation-faint` / `--elevation-subtle`、neo 答 `--shadow-brutal-2`、clinical 经 `@theme` 映射答 `none`；控件标签声（`--text-label` / `--tracking-label`）是机制角色，与 YAML 阅读角色 `label` 同名不同物——minimal 答 0.875rem / 0em，neo 答 1rem / 0.1em，clinical 答 0.8125rem / 0.01em；标签字体档 `font-label` 是 `@utility` 角色类（`font-family: var(--font-mono)` + `font-weight: var(--font-weight-strong)`），全库标签文字统一挂它，不再设 `--font-weight-label` 令牌。井三角色：`--padding-well`（组容器井框距，`p-well` 由 `--padding-*` 命名空间生成）四案同答 0px（minimal 曾答 0.25rem，现只关框距）；`--color-well`（井底，`bg-well` 由 `@theme` 映射生成）minimal / clinical 答 `surface`、neo / neon 答 `background`；`--shadow-well`（井内阴影，单一光源左上一深一浅）minimal 亮暗各答双向内阴影（数值见各案 design.md YAML `well` 块）、clinical / neo / neon 答 `none`。条状件轨道（Meter / MeterGroup / Progress / Toast 倒计时条）一律读 `surface`，不设独立轨道机制值——与各案 design.md 轨道族「未填充底 surface」同源；Chart 画布不铺底色，底色由消费方背景承担；曾试中性-600/500 灰轨求填充 1:3，实践观感差已回退，量具类不强制 1:3（用户定则）。设计教训（用户定）：只有纯色背景、无图片纹理的面，不要为了对比度选灰暗底色，后续新面优先自然底色（surface / well）。逐件动画档（`--animate-lattice`）声明在 `@theme inline`，不写在 `@theme`：普通 `@theme` 在 `:root` 就把档内的 `var(--lattice-loop)` 代成兜底值，骨架内联在元素上的逐件时长再也读不进来。焦点环不设全局 `:focus-visible` 兜底：每个可聚焦件由皮肤显式挂 `focus-visible:focus-ring`（danger 件挂 `focus-ring-danger`，外壳洪泛 / `focus-within` 自答亦可）——内层件不挂即无环，无需 `outline: none` 压制。
10. 机制值单源：字体族只在 `@theme` 声明（值即 YAML typography），html / body 只引用；同一声明全文件只出现一次。
11. 紧凑档是三案同构的机制 ramp，不进 `@theme`、不入 design.md YAML：`@media (pointer: coarse), (width < 48rem)` 直答几何令牌，媒体列表任一命中即进紧凑，纯 CSS、无 JS、无偏好存储——手机与平板都是触摸屏，横竖屏同进紧凑；48rem 分界与全库口径一致（neo 尺寸宪法与滑杆 touch-adaptive 同判「窄于 48rem 或触屏」），窄视口（仿真调试、桌面窄窗）与移动端吃同一套紧凑值；`--height-control` 与 `--height-field` 同答 `calc(var(--spacing)*11)`（11 单位基准：minimal / neon-gradient / clinical 紧凑 33×33 成立 2.5.8 AA 硬底线上方、neo 44×44 仍达 2.5.5 AAA，紧凑档 44 车道由 11 倍数自答）、`--padding-control-x` 答 0.625rem、`--spacing` 基础值按案 ×0.75 后向下取整到整像素（minimal / neon-gradient / clinical 0.1875rem = 3px、neo-brutalist 0.25rem = 4px，间距整体收 1/4）；取整让紧凑档栅格落回整像素、倍数可反算，半步档（0.5）在 3px 基础值下产生 1.5px 属预期；命名间距档已废除（rule 12），全部间距走数字乘道，紧凑档整体收缩含卡面内边距；calc 派生档（`--padding-tight` / `snug` / `loose`、`--width-control` / `--size-control` / `--min-width-control`）与数字乘道 utilities 现场重算，文字档不动；细指针且视口不窄于 48rem 即舒适档，桌面恒 44 基准（触屏笔记本主指针仍是键鼠，不进紧凑；2 合 1 设备随系统当前主指针与当前视口走）。
12. 宽度、高度与间距全走 Tailwind 原生 `--spacing` 数字乘道，不自造刻度命名空间：间距只留单基础值 `--spacing`，逐案自答入 design.md YAML（minimal / neon-gradient / clinical 0.25rem、neo-brutalist 0.375rem，为默认案 1.5 倍）；数字乘道表达留白与节奏（padding / margin / gap / inset / translate / scroll-*）、盒子尺寸（`w` / `h` / `min-w` / `max-w` / `min-h` / `max-h`）、图标尺寸（`size-*`）与线宽轨道（`w-1` / `h-1` 发丝档），全部随 `--spacing` 逐案缩放（neo 1.5×）。`--container-*`（3xs 16rem / 2xs 18rem / xs 20rem / sm 24rem / md 28rem / lg 32rem / 2xl 42rem … 7xl 80rem）只任 `@container` 查询断点，不再当宽度 utility，不覆写也不新增命名档；媒体断点走 `--breakpoint-*`，两条断点都不含 `--spacing`，换案不动断点。控件几何读机制令牌（`--height-control` / `--height-field` / `--width-control` / `--size-control` / `--min-width-control`，2.75rem 常量不翻倍）；侧栏宽与正文让位同走数字乘道 `w-64` / `pl-64`（默认 16rem，随 `--spacing` 逐案缩放，neo 24rem），不设跨案恒定盒、不写 rem 定值。命名间距档 `--spacing-xs…2xl`、`:root` 的 `--space-*`、自造 `--width-*` 与高度发丝档 `--height-xs…xl` 一律不存在；语义→数字映射只作文档约定不进 CSS（`xs`≡1、`sm`≡2、`md`≡3、`lg`≡4、`xl`≡6、`2xl`≡8），neo 专属串与共享串同数字、不再为视觉对齐减半（随 1.5× 自然加粗）。arbitrary value 内禁空格：calc 的空格写 `_`（类名扫描按空格切词，含空格的串不生成任何 CSS，缩进与定位会静默失效）。共享同一元素的宽度只写一次：排版类常量不带宽度，宽度由消费处显式挂，避免同元素两枚 `max-w-*` 按源序互相覆盖。唯一 em 例外是正文行宽 `max-w-[40em]`——它要随字号走而不是随栅格走（中文 40 字 / 拉丁 80 字符，a11y 下限见 ui-rules `perceivable.md` 19）；定档件分两基：容器级（浮层 / 面板 / 页面块）一律 16n 单位，控件级小容器（步进器、值区、页码输入一类）一律 11 的倍数——`w-11` 是触控目标基准（默认案 44px，2.5.5 AAA），紧凑档随 `--spacing` 自答 33px（neo 44px），小容器不再另立第三档；浮层宽度对视口负责不对父格负责，车道与选道顺序的正本在 delivery `references/skin-rules.md` 第 16 条。浮层面板内边距含圆角补偿：`p = min(面板圆角档, --spacing×2)`——面板圆角的角部向内侵入约 0.29×半径（20–24px 圆角约 6–7px，经验规则），8px 档已覆盖；圆角答 0 的方案自然归零、维持贴边。补偿带正本 `panelPadClass`（popover.tsx 导出），菜单族面板（menu 子面板 / DropdownMenu / ContextMenu）与 Select / Combobox / MultiSelect / Cascader / FilterCombobox / FloatingToc 面板取用；popover 容器本体不取（零内边距由消费者自定的契约不变），command `p-2`（恰为补偿带同值）与日历 `p-3` 不取——避免双写。浮层内嵌列表律（用户定则）：圆角只归浮层面板，内嵌列表视口不设自身圆角、不继承面板圆角，行 hover 由面板补偿带兜住不被角部裁剪；圆角答 0 的方案列表自然贴边。
13. Paper 纸面机制值与 print 车道：`--paper-surface` / `--paper-ink` 各案 `:root` 同值恒亮（minimal 答 oklch 100%/0%、neo、neon-gradient 与 clinical 答 `#ffffff` / `#000000`——纸张白与墨黑是物理常量，非色板槽位，`paper` 本就在 rule 4 已删槽位名单内，机制值走 rule 9 同款先例）；各案文件尾声明 `@media print` 车道答 `color-scheme: light`（perceivable 18 的接管声明——打印不进暗档，方案打印恒白底黑字省碳粉）；全局令牌级亮色重映射另立任务不在此车道内。

14. 控件横向内边距含圆角补偿（光学修正，delivery `references/skin-rules.md` 第 17 条同律）：`px = 基础档 + min(本形态圆角令牌, var(--height-control)/2)`。有效圆角取 `min()` 钳位——pill（9999px）钳到半高，无圆角方案（neo 全档 0）补偿自然归零，不另立令牌。圆角档与 px 成对取：换圆角必同步换 px 算式；连体组内层 `rounded-none` 补偿为 0；纯图标件 `aspect-square + px-0` 豁免，补偿只落在有文字的横向内边距。minimal 的 `--padding-control-x` 答 `calc(var(--spacing)*3 + min(var(--radius-md), var(--height-control)/2))`（基础档 spacing×3 为经验规则），紧凑档不再另答定值——算式随 `--spacing` 与 `--height-control` 自缩；md 档字段族（select / picker / field / multi-select / command 触发件）读 `px-control-x` 即得补偿；pill 档按钮族（button / toggle / 特性胶囊 / 浮层触发钮）自写 `--radius-pill` 的同式算式，`rounded-pill` 与 px 成对取。其余方案暂答定值 `--padding-control-x`，补偿随各自修订接入。
