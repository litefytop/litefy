# SwipeActions 皮肤（app/ui/skins/swipe-actions.tsx）

1. 定位：行内操作滑动件的皮肤——行体铺画布背景色配前景文字色，加 `border-hair` 发丝描边（与画布同色，无边即隐形——checkbox 控制面的发丝边界先例）。动作配色走语义槽位、每色至多一次：次级钮按 `data-tone` 派语义对（`primary/info/success/warning` 底色配同系前景色，悬停转同系 accent 对）；danger 提交块恒 `danger` 对——Delete 这类破坏性动作恒 danger，提交钮悬停转 `danger-accent`。变体按语义自动派色、不设 prop；骨架仅在动作带图标时渲染图标位（空位不占格子，纵向居中不被 gap 顶偏）。
2. 布局：动作轨 `absolute inset-0` 覆盖排布，收起态由骨架 `inert` + `aria-hidden` 裁剪；次级语义钮绝对定位（`data-direction` 定左右，浅 → 深 = primary → info → success → warning，第 i 个偏移 i × 动作宽），danger 提交块满宽锚动作侧深端、提交钮 `var(--swipe-a)` 宽置于块的动作侧端；内容层 `relative z-10 flex h-full items-center gap-x-3 px-4` 吃满行宽；键盘胶囊平时视觉隐藏（clip-path），`focus-visible` 展开为胶囊（`bg-accent` 配 `accent-fg`）——桌面键盘用户的开合通路。
3. 几何：行高、动作宽、折叠时长读骨架内联变量 `--swipe-h` / `--swipe-a` / `--swipe-collapse`；圆角走具名令牌 `rounded-swipe`（`--radius-swipe` 三案 `@theme` 自答：minimal 答引用 `xl`、neo 答 0px 全直角、neon-gradient 答大圆角——Avatar `rounded-disc` 先例）；根折叠态 `[data-phase=collapsing]` 与长出态 `[data-phase=entering]` 同形（高度、外边距、透明度归 0），过渡走 `--swipe-collapse` + `ease-frame`，`motion-reduce:transition-none` 让减动效档直接落位。
4. 交互态：语义钮悬停转同系 accent 对；按压轻微缩放（减动效档不缩）；拖拽中内容 `select-none` 防选中文本；不设抓取光标——滑动提示箭头已承担可供性。
5. 提示箭头：内容层的流内尾随子项（`shrink-0` 不挤内容、`size-4` 槽内 `[&_svg]:size-full`；`direction=right` 时 `order-first` 翻到行首），`text-surface-fg` 弱化色，`data-open` / `data-dragging` / `data-disabled` 时隐藏；顿挫缓移提示可拖——`motion-safe:animate-swipe-hint`（令牌 `--animate-swipe-hint` 声明在三案 `@theme inline`，5s 一循环，往程与回程同构：起点中速位移 → 中途顿一下 → 尾段极缓近静止，循环接缝落在原点静止段，无位置跳变；字帧 `swipe-hint-nudge` 动 `translate` 不动 `transform`，中点位移为 `calc(var(--hint-nudge-x) / 2)`，方向经 `--hint-nudge-x` 随 `data-direction` 镜像），减动效档静止。
6. 折叠与阴影：根 `[data-phase=collapsing]` 与 `[data-phase=entering]` 高度过渡走 `--swipe-collapse` + `ease-frame`；行体承载面按各案可交互件律自答阴影；禁用（`data-disabled`）压暗禁指针。
7. 专属令牌：`--radius-swipe`（半径令牌）与 `--animate-swipe-hint`（提示缓移动画，声明在三案 `@theme inline`；配色全读 22 枚色板与机制值）。
