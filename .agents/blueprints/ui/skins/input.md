# Input 皮肤（app/ui/skins/input.tsx）

1. 字段壳（共享正本）：`fieldGroupBaseClasses` 提供 `min-h-control` 下限、`w-full min-w-0 max-w-[20rem]` 缺省宽度（字段车道，320px 设备适配常量，不随主题缩放）、`rounded-md` 圆角 + `border-frame` 描边 + `bg-surface-raised` 凸起档背景色配 `text-surface-raised-fg` 文字色（控件静置面归凸起，见 `ui/schemes/elevation.md`）+ `shadow-frame` + `motion-frame`；`fieldGroupClasses` 叠加 `cursor-text`、`borderless:border-0` 与焦点、禁用、无效状态（旧 `p-well` 框距令牌 `--padding-well` 随井档撤销，四案同答 0，删后无位移）。FilterCombobox 直接复用基础框并给输入条自己的内边距。禁用态：壳级按 `disabled` 选择独立禁用类串，使用禁用色、`cursor-not-allowed` 与 `select-none`；内层输入框原生禁用即整壳读作禁用，宿主（Input / Password / Number / Combobox / FilterCombobox）自动继承。
2. 焦点双通道（皮肤都声明、方案各自作答）：`focus-within` 换壳读法——一边由描边 + 阴影表达、一边真换背景色而边不动。
3. 无效态：挂 `field-invalid` 角色类（`data-invalid` / `aria-invalid` 双 hook 边转 `danger-fg`、focus-within 叠危险环，定义见 `ui/schemes.md` 第 9 条）。
4. 内层凹面（输入元素）：`bg-surface` 凹槽档 + `shadow-recess` 凹陷内阴影 + 端帽式圆角——圆角只落在壳的前后缀两端，贴插件一侧恒为直角：内层为壳内首件（无前缀插件）保留 start 侧两角、紧邻尾随插件（`data-field-trailing` 标记）时让出 end 侧两角、两侧皆有插件时四角归零，隐形浮件（聚焦提示卡等 absolute 垫底件）不计入几何；半径读 `--radius-field-inner` 派生令牌（同心内圆角，式见 delivery `references/skin-rules.md` 第 17 条），收编由 `field-seam` 角色类执行（`input` 非首子削 start 侧、紧跟 `[data-field-trailing]` 附件削 end 侧，定义见 `ui/schemes.md` 第 9 条）+ 无边框（`min-w-0 grow basis-0 self-stretch`、`px-3` 文字内边距），字号行高方案自答 + `font-field`；文字与占位符随档换配对——凹面读 `surface-fg`（成对律，schemes.md 第 19 / 24 条）；选区 `primary` 背景色 + `primary-fg` 文字色；禁用由壳级独立禁用类串替换正常焦点与颜色类，内层输入显式挂 `cursor-not-allowed`、`select-none` 与 `pointer-events-none`，指针命中禁用外壳而不进入输入框文本层。凹陷机制值逐案答案归蓝图 `ui/schemes.md` 第 9 条与 `ui/schemes/elevation.md`。
5. 前后置插件槽（leading / trailing）：`inline-flex` + `px-3` 呼吸 + `foreground` 文字色；槽的可见盒两轴下限 44×44（`min-h-11 min-w-11`），以 `-my-px` 出血到字段壳外缘而不撑高壳；内容自带尺寸，超出下限才撑宽。压缩链（窄容器优先级，固定）：后缀最先让位但仍守 44×44 下限（trailing `min-w-11 overflow-hidden`，只裁切内容）→ 内容区其次（`grow basis-0`，只吃后缀让完后的剩余空间）→ 前缀锁死（`shrink-0`，图标位不动）；外壳 `w-full min-w-0 max-w-[20rem]` 跟随父容器宽度并封顶 320px，在窄容器自动收敛。
6. 浮动提示（`fieldHintClasses`）：字段右上绝对定位的底色浮签——`surface-raised` 背景色 + 发丝边 + `text-xs` + label 两项（`tracking-label` / `case-label`）+ `shadow-subtle`，由 `peer-focus-visible` 显形，`pointer-events-none`。
7. 多行域（`fieldTextareaClasses`）：同字段框自承一盒、自身即凹面——`w-full min-w-0 max-w-[20rem]`、`min-h-20`、`resize-y`、`bg-surface` 凹槽档（自承一盒只有一枚 box-shadow：容器档 `shadow-frame` 浮起在位，凹陷内阴影让位——多行域的凹感只走凹槽底色与描边）、文字与占位符随档读 `surface-fg`、字号行高方案自答；焦点读法与壳一致；无效挂 `field-invalid`（`aria-invalid` 直挂自身）。
8. 组合导出：`fieldGroupBaseClasses` / `fieldGroupClasses` / `fieldInputClasses` / `fieldAddonClasses` / `fieldHintClasses` / `fieldTextareaClasses` / `inputPartClasses` 供 Password、Number、MultiSelect、FormItem、Command 等宿主装配。Input 成品封装在皮肤入口将 `className` 与 `classNames.group` 一起经 `mergeSlots` 合并；内层输入框以 `focus:outline-hidden` 隐藏原生描边并保留强制颜色模式焦点指示，常规颜色模式的视觉焦点只由字段壳承担。
9. 专属令牌：无。
