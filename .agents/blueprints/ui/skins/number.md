# NumberField / NumberInput 皮肤（app/ui/skins/number.tsx）

1. 双形态一枚内核：`NumberField` 自带步进壳（框、焦点与无效读法、↑↓ 提示都在壳上）；`NumberInput` 是 Input 组壳——整包复用共享字段框（`fieldGroupClasses`），只有自己的零件（suffix、↑↓ 指示）带数字专属工具类。
2. NumberField 壳：`w-fit max-w-full`——最小高在 `height-field` 基础上补 2px（旧 `p-well` 框距令牌 `--padding-well` 随井档撤销，四案同答 0，删后无位移）；总宽名义 3 格加框距与边框（两侧步进钮与值区各 1 格，`w-control` 基准），窄容器随 `max-w-full` 让位；`rounded-md` + `border-frame` 描边 + 底色方案自答 + `shadow-base` 浮起；焦点 `focus-within` 读法方案自答；无效挂 `field-invalid` 角色类（边转 `danger-fg` + focus-within 危险环，取代旧聚焦危险描边，定义见 `ui/schemes.md` 第 9 条），未聚焦时值文字转 `danger` 单轴自挂。
3. 步进钮：两端 `w-control` 竖条（`--width-control` 派生自 `--height-control`，11 单位两档自答）+ 自带完整描边（`border-control` 宽档方案自答 + `border-border`）+ 透明底（与壳同色，凹陷件的「前后缀同色」律），文字色继承壳；贴壳侧两角读 `--radius-field-inner` 派生令牌（start 侧 `rounded-s`、end 侧 `rounded-e`，贴值区一侧直角）；命中区即盒子（紧凑档随令牌收缩）；hover 吃 `accent` 背景档（并写它的配对前景 `accent-fg`），按下沿共享 `--translate-crush` 压平；± 字形自带尺寸（`size-4`）。
4. 值区走数字件车道（delivery `references/skin-rules.md` 第 16 条第 3 项）：`w-control` 与步进钮同宽、随令牌缩放——零运行期计算，输入框不随内容生长，超宽内容（千分位、改大的 max）在框内横向滚动；输入无边框，`bg-surface` 凹槽档 + `shadow-recess` 凹陷内阴影承凹，值区两侧恒贴步进钮（恒为中间件）——四角直角，端帽圆角只属步进钮贴壳侧；开发者改大 `max` 时自行经 `classNames.root` 加宽值区（如 `w-22`）。值文本挂 `tabular-nums`，等宽数字宽度可预期。
5. 共用零件：值输入透明居中（`text-sm` + `font-field`，placeholder `surface-fg`，选区 `primary` 背景色 + `primary-fg` 前景色）挂 `peer` 供提示卡显隐；字符串 suffix 由皮肤包进自有 span（`text-sm` + `font-field` + `foreground`），自定义节点直通；↑↓ 指示 `foreground`，双 chevron 负边距叠成一枚字形（`first:-mb-0.5`）；Input 组 trailing 双形态：字符串 / 自定义 suffix 走插件槽（附件 `px-3`，skin-rules 13.4），无 suffix 的 ↑↓ 指示走 `w-control` 正方形槽（`self-stretch` 拉满壳内高、图标居中，与步进钮同宽，同组合框后缀槽律）；indicator 关闭时的聚焦提示接共享 `fieldHintClasses`（右上角、`peer-focus-visible` 显隐），与 NumberField 提示同款（内容 `↑ ↓` 纯文本，无 kbd）；壳补 `relative` 锚定提示卡（skin-rules 10）。
6. NumberInput 壳：组律端角由 `field-seam` 角色类判定（`data-field-trailing` 标记，见 `ui/skins/input.md` 第 4 条）——提示卡等 absolute 垫底件不计入几何，无尾随插件时值区保留 end 侧端帽圆角；组内后代强制 `m-0`、无 gap；`data-[invalid=true]` 时值文字转 `danger`（输入根已有 `aria-invalid` 读法，壳不再重复后代选择器）；宽度走宿主车道（缺省 `w-full min-w-0`，父容器提供宽度）。
7. 专属令牌：无。
