# FilterCombobox 皮肤（app/ui/skins/filter-combobox.tsx）

1. `FilterCombobox` 包装 headless `FilterCombobox`，注入 `filterComboboxClasses` 与 `renderChip` / `renderOption` 两条缺省通道；复用 `fieldGroupBaseClasses`、`cn`、`mergeSlots`，不新写输入框框线；chip 编辑钮与四枚图标钮全部按成品 `Button` 的 text 变体类串着装，皮肤只提供尺寸、定位与截断差异，不手写背景、文字色或 hover 状态。
2. 根 `flex w-full min-w-0 max-w-[20rem] flex-col gap-y-1 @container`，无背景色、无卡片外壳；默认封顶 320px，窄容器允许收缩；皮肤将消费者 `className` 与 `classNames.root` 经 `cn` 合并后交给骨架，`styles.root` 与原生 `style` 合并后作用于字段根。
3. 输入条（`bar`）：字段基础框（`fieldGroupBaseClasses`，flex、items-center、焦点环与宿主宽度由它自带）+ `relative min-h-field flex-wrap gap-1 px-2 py-1 data-clear:pr-14`；行首搜索图标 `shrink-0` 固定头部、`text-foreground`；有已提交规则时骨架发 `data-clear`，条经 `data-clear:pr-14` 给右端钉住的清空钮预留空位；禁用观感由 `fieldGroupBaseClasses` 与独立的 `barDisabledClasses` 共同承担，不使用 `dim`。
4. 已提交 chip（`chip`）：`inline-flex h-7 max-w-full min-w-0 shrink-0 items-center rounded-md border-hair border-border bg-surface-raised px-1 text-sm`；值段（`chipLabel`）是点按重编辑的 `Button` text 变体（`min-w-0 flex-1`，可访问名带 `texts.editLabel`），文字经 `min-w-0 flex-1 truncate` 的内层 span 截断；移除钮（`chipRemove`）为同变体小图标钮（`size-7 shrink-0`，`X` 图标，可访问名带 `texts.removeLabel`）——chip 内两钮互不嵌套。chip 宽度受 bar 可用宽度封顶，超长标签在 chip 内截断，不移除关闭钮。截断标签复用 `useTooltipWiring` 与成品 `TooltipContent`：hover / focus 显示完整文本，触摸长按 450ms 显示并在松开后保留 2 秒，长按不触发编辑；按钮经 `aria-describedby` 关联提示，`Esc` 或失焦关闭。Tooltip 节点放在 chip span 之外，避免块级浮层破坏 phrasing 内容；不全局替换项目中的原生 `title`。
5. 草稿 chip（`draft`）：同实线 chip 尺寸与宽度封顶，边换 `border-dashed`、文字 `foreground`，`min-w-0 truncate` 截断超宽内容；紧贴输入框之前落入换行流，随阶段收缩（`value → operator → field`）。
6. 行内输入框（`input`）：`min-w-16 flex-[1_1_8rem] border-0 bg-transparent outline-none`，占位 `placeholder:text-foreground`——输入框是换行流最后一个伸缩件，光标始终跟在已有内容末尾；禁用由壳级 `disabled` 选择独立禁用类串并显式挂 `cursor-not-allowed`。
7. 草稿控制钮：提交钮（`submit`，`Check` 图标）与放弃钮（`cancel`，`X` 图标）均为 `Button` text 变体小图标钮（`size-7 shrink-0`，**禁止 primary**），在输入框与提示后方、跟随内容换行；正常类串取 `buttonVariants.text`，禁用类串取 `buttonVariants.disabledText`，只叠加尺寸；chip 流内小钮（`h-7`＝28px）达 24 硬底线即合规，属 token 流零件、不占 11 基；显隐由骨架裁决（提交钮仅值阶段草稿非空时出现，放弃钮在整段草稿态出现）。
8. 清空钮（`clear`）：钉在输入条右端（`absolute right-1 top-1/2 -translate-y-1/2`）的 `Button` text 变体图标钮（`size-control` 控制令牌车道，随字段框同高，`RotateCcw` 图标），垂直居中、不随换行流动；正常类串取 `buttonVariants.text`，禁用类串取 `buttonVariants.disabledText`，再叠加尺寸与定位，禁用后为 `text-disabled-fg` 与 `cursor-not-allowed`，不保留 hover 下划线。
9. 值阶段提示（`hint` / `hintKeys` / `hintKey`）：悬浮在输入条上方右端（`absolute -top-7 right-0 z-10`，不随输入流移动）的底色浮签——`bg-surface-raised` + `border-frame` + `text-xs` + label 两项（`tracking-label` / `case-label`）+ `shadow-subtle`，`pointer-events-none`；键帽直接引用 `kbd` 工具类（schemes/kbd.md 同源单一正本，与 Command 快捷键帽同源）。
10. 候选面板（`list`）：顶层浮层（定位与开合全由骨架的 floating-position 机制承担，皮肤只给外观）——`max-h-72 min-w-0 max-w-[min(20rem,calc(100vw_-_1rem))] overflow-y-auto` 自带浮层配方（`rounded-md` + `border-frame` + `bg-surface-raised text-foreground` + `shadow-elevated` + 圆角补偿 `p-[var(--radius-md)]`，律见 `ui/schemes.md` 第 12 条），宽度匹配锚点但受 320px 与视口边沟封顶；选项行（`option`）`h-control`（44，`px-3`）不带行级圆角——行 hover 由面板内边距兜住，`data-highlighted` 换 `bg-surface` 并同步 `text-surface-fg`；标签（`optionLabel`）`flex-1 truncate`、详情（`optionDetail`）`text-xs text-inherit` 随行切换；候选 `onMouseDown` preventDefault 防失焦（缺省渲染器即皮肤渲染器）。
11. 状态与错误：状态行（`status`）`text-sm text-foreground`（sr-only 播报由骨架承担，结果数不在输入条内显示）；错误（`error`）`text-danger-independent`。
12. 组合导出 `filterComboboxClasses`。
13. 专属令牌：无。
