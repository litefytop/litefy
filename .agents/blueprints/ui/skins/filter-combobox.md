# FilterCombobox 皮肤（app/ui/skins/filter-combobox.tsx）

1. `FilterCombobox` 包装 headless `FilterCombobox`，注入 `filterComboboxClasses` 与 `renderOption` 缺省通道（chip 渲染通道已废——条件行无 chip 外观）；复用 `fieldGroupBaseClasses`、`cn`、`mergeSlots`，不新写输入框框线；图标钮全部按成品 `Button` 的 text 变体类串着装，皮肤只提供尺寸、定位与换行差异，不手写背景、文字色或 hover 状态。
2. 根 `flex w-full min-w-0 max-w-[20rem] flex-col @container`，无背景色、无卡片外壳；默认封顶 320px，窄容器允许收缩；皮肤将消费者 `className` 与 `classNames.root` 经 `cn` 合并后交给骨架，`styles.root` 与原生 `style` 合并后作用于字段根。
3. Trigger（`trigger`）：字段基础框（`fieldGroupBaseClasses`，焦点环与宿主宽度自带）+ `flex w-full min-w-0 cursor-pointer items-center gap-x-1 rounded-md border-frame px-2 py-1 text-sm focus-visible:focus-ring` + `border-border bg-surface-raised text-surface-raised-fg shadow-frame`；文案（`triggerLabel`）`min-w-0 flex-1 truncate text-left`；禁用整串替换为 `bg-disabled text-disabled-fg cursor-not-allowed`。
4. 面板（`panel`）：直接沿用 `dialogPartClasses.content` 原串 + `flex h-[min(24rem,calc(100vh_-_3rem))] flex-col space-y-1`——宽度与外观完全继承 Dialog 内容卡（`max-w-[min(28rem,calc(100%_-_--spacing(8)))]`、`rounded-xl`、`p-4`、`shadow-elevated`），皮肤不自定宽度、不重复写边框背景；**高度固定**（flex 列 + 固定高），hint / 列表出现与否不改变面板高度，输入过程零跳变；骨架把面板渲染成受控 Dialog（与 Command 同一套），显隐由 showModal / close 驱动，皮肤向 headless 注入 Dialog 的 root / stage 类（`dialogClassNames`）。
5. 输入条（`bar`，input group 容器）：`min-h-field flex-wrap gap-1 rounded-md px-2 py-1`——**与 cmd 同款不带背景色**，透明融进面板（不铺 recessed 面、无独立文字色）；搜索图标前缀（`prefix`）`flex size-11 shrink-0 items-center justify-center -my-1 -ml-2`——**前后缀 addon 一律 11 基（44px 触控目标，schemes 第 12 条）**，负边距出血盖住 bar 内距、恰好填满 `min-h-field` 不撑高；禁用整串替换为 `bg-disabled text-disabled-fg cursor-not-allowed shadow-frame`，不用 `dim`。bar 内容只有搜索图标前缀、虚线草稿 chip、输入框、确认 / 放弃钮与后缀清空钮——已提交 chip 不进 bar（见骨架蓝图「列表区一物两用」）。
6. 条件行移除钮（`chipRemove`）：`size-7 shrink-0` 的 `Button` text 变体小图标钮（`X` 图标，可访问名带 `texts.removeLabel`）——条件行本体由骨架直接渲染为 `option` / `optionLabel` 普通列表行（**无 chip 外观、无 hover 下划线**），皮肤不再提供 chip / chipLabel 槽。
7. 草稿 chip（`draft`）：仍在单行输入流内，保持 `inline-flex h-7 max-w-full min-w-0 shrink-0 truncate whitespace-nowrap` + `border-dashed`，紧贴输入框之前、随阶段收缩；禁用整串替换。
8. 行内输入框（`input`）：`min-w-16 flex-[1_1_--spacing(32)] border-0 bg-transparent outline-none`，占位 `placeholder:text-foreground`；禁用由独立禁用类串显式挂 `cursor-not-allowed`。
9. 草稿控制钮：提交钮（`submit`，`Check`）与放弃钮（`cancel`，`X`）均为 `Button` text 变体小图标钮（`size-7 shrink-0`，**禁止 primary**，`pure-icon` 类直挂）——group 容器内只放这两枚；清空钮（`clear`）是 group 容器的**后缀段**：**`size-11` 触控目标（11 基，schemes 第 12 条）**，`-my-1 -mr-2 rounded-l-none rounded-r-md` 负边距出血盖住 bar 内距与右端圆角，背景 `bg-surface-raised text-surface-raised-fg`（**与面板同背景色**，视觉上从 recessed 输入条里分层出来），`RotateCcw` 图标；禁用后缀 `bg-disabled` 融入禁用输入条，去 hover 下划线。
10. 提示行（`footer` / `hint` / `hintKeys` / `hintKey`）：面板**最下方**单独一行，与 cmd footer 同款——`flex min-w-0 flex-wrap items-center justify-between gap-x-3 gap-y-1 border-t border-border pt-1`，触屏与窄屏整行不显形（`pointer-coarse:hidden max-sm:hidden`）；**溢出保护**：动态提示可能多条（条件态三组、日期区间两组），footer 允许换行、右侧提示组（`hint`）`min-w-0 flex-wrap justify-end` 可收缩换行、键帽组（`hintKeys`）`shrink-0` 不被压缩——面板固定高 + 列表 `flex-1`，footer 增高只压缩列表区，不撑破面板；左侧固定 ↑↓ 键帽（`aria-hidden`），右侧动态提示（`hint` 槽 `flex min-w-0 flex-wrap items-center justify-end gap-x-2 gap-y-1 text-xs text-foreground`，无底色浮签——旧 face 串已废）随阶段变化：条件列表态 ↵ 编辑 / Del 删除 / Space → 筛选列名、field / operator 阶段 ↵ 选择 / esc 取消、value 阶段 `resolveValueHint`（日期格式 + 分隔符键帽，文本无提示）；键帽引用 `kbd` 工具类（kbd.md 同源正本）；禁用不单独换装（装饰性行）。
11. 列表区（`list`，条件列表与候选列表共用同一槽，**骨架常驻渲染**——空态也占位，footer 恒钉面板底部）：`min-h-0 flex-1 min-w-0 overflow-y-auto p-1`——**与 cmd viewport 同款不带背景色**（透明融进面板，内嵌列表不设自身圆角，律见 `ui/schemes.md` 第 12 条浮层内嵌列表律），在固定高的面板内 `flex-1` 占满 bar / status / footer 之外的剩余空间，条件或候选超出即在列表区内滚动；条件列表（骨架 `rules-list`）在此槽内渲染第 6 条所述的普通列表行，候选列表渲染选项行。选项行（`option`）与 cmd item 同款：`flex min-h-control cursor-pointer select-none items-center gap-x-2 px-2 py-1.5 text-sm text-foreground` + 共享 `listOptionHoverClasses`（hover 与 `data-highlighted="true"` 换 accent 底 / accent 前景，条件行与候选行同一套高亮，**无下划线**）；标签（`optionLabel`）`flex-1 truncate`、详情（`optionDetail`）`text-xs text-inherit`；候选 `onMouseDown` preventDefault 防失焦。
12. 状态与错误：状态行（`status`）`min-h-5 px-2 text-sm text-foreground`（sr-only 播报由骨架承担）；错误（`error`）`text-danger-independent`；禁用整串替换。
13. `disabled` 组级禁用遵循 `ui/schemes.md` 第 8 条：`filterComboboxDisabledClasses` 以 `mergeSlots` 完整替换 trigger / bar / draft / input / submit / cancel / clear / status / error 禁用类串——保留布局与结构、移除 hover/focus/active 类并显式禁用色与 `cursor-not-allowed`。
14. 面板与面板内默认组件一律 `surface-raised`（用户定 2026-11-26）：面板沿用 Dialog 凸起底；输入条与列表区透明融进面板、读面板继承的前景色，不铺 `surface`；草稿 chip 与清空钮自带 `surface-raised` 面配 `surface-raised-fg`，与面板同档。
15. 组合导出 `filterComboboxClasses`；专属令牌：无。
