# Table 皮肤（app/ui/skins/table.tsx）

1. 条根：`@container` 容器查询载体 + `w-full min-w-0` + `overflow-x-auto`（唯一横向滚动容器）+ `overflow-y-hidden`（y 轴不滚）。`border-control` 边宽档 + `surface-raised` 背景色 + `foreground` 文字色 + `shadow-surface` 浮起；不设根固定最小宽，窄容器由根收缩、列宽总和超出时横向滚动；每列 64px 宽度下限由骨架内置在列宽与头/体容器 `min-width` 里。
2. 滚动容器分轴：表头 `overflow-hidden`，表体 `min-h` 12.5rem / `max-h` 16rem 档 + `overflow-y-auto` + `overflow-x-clip`（x 裁切不出横向滚动条）——max-h 取 16rem 使「表头 45px + 表体 256px + 舞台上下 32px 内距」合计 333px，塞进文档站 `aspect-video` demo 舞台（约 337px 起档）而不触发舞台滚动，滚动只发生在表格内部；滚动条律（用户定则）：全站滚动条外观由方案全局层统一定义（`schemes.md` 第 17 条）——骨架与皮肤禁止设置任何 scrollbar 样式（禁 `scrollbar-width` / `scrollbar-color` / `::-webkit-scrollbar` 定档、禁 `scrollbar-gutter` 预留、禁隐藏原生滚动条），每套方案各自的滚动条在方案内全局一致且常显可辨；组件只负责滚动分轴结构。
3. 表基：`w-full` + `border-collapse` + `text-sm` + 等宽数字；自带表格重置——reading scope 里的散文表规则（满边框、块外距）会被压制。移动端不换形：列宽按权重压缩、表头换行与单元格断词，表格语义原样保留（WCAG 1.4.10 数据表二维滚动豁免），同列对比不丢，筛选行与排序表头在移动端原样可用。
4. 表头：行 `bg-surface` 底 + `text-surface-fg` 文字色 + `border-b-hair` 分隔；头格 `h-control` 高、`px-3`、`text-sm` + `control-label` + `surface-fg` 文字色，对齐随 `data-align`；可排序（`data-[sortable]`）`cursor-pointer`，hover 与 `data-[drag-over]` 只换 `accent` 背景（表头文字保持 `surface-fg`）；排序图标 `size-3.5` 用 `text-inherit`，平时 40% 显，激活（`data-[active=true]`）全显并保持表头当前文字色。防溢出结构：`headLabel` `min-w-0 max-w-full`、排序图标 `shrink-0`——图标永不越过头格内距，表头文字不截断、窄列换行属预期；格间最小间距由 `px-3` 内置保证。
5. 行与格：行 `border-b-hair` 分隔（末行无线）+ `text-foreground`，hover 只换 `accent` 背景（并写它的配对前景 `accent-fg`）；格 `h-control`（44px 控件档命中区，可选表格行即交互件）+ `px-3`、对齐随 `data-align`、断词；实际行距 = 44px 行高 + 1px 行分隔，虚拟滚动 `rowHeight` 默认值须与此一致（45）。行点击选中（`data-[selectable]`）`cursor-pointer`；斑马纹 `data-[zebra=odd]:bg-surface` 配 `data-[zebra=odd]:text-surface-fg`，并配 `hover:data-[zebra=odd]:bg-accent hover:data-[zebra=odd]:text-accent-fg` 保 hover 在斑马行照常生效（悬停面整体转 `accent` 对，实测值见 `ui/schemes.md` 第 24 条）；折叠列单元格经 `cellCollapse` 槽——块级满宽、字色 / 字体 / 行高 / 对齐继承、`truncate` 单行省略、`cursor-pointer` + 焦点环，展开（`data-[expanded]`）转 `whitespace-normal` + 断词 + `cursor-default`。
6. 空态：居中 `foreground`。
7. 列拖动：头格 `data-[drag-over]` 换 `accent` 背景标落点；拖动手柄 `dragHandle` 槽——`shrink-0`、`border-0 bg-transparent p-0 text-inherit opacity-60` + `motion-frame` + hover / 拾起（`data-[grabbed]`）保持表头当前文字色并 `opacity-100` + `focus-visible:focus-ring`，图标随按钮 `size-3.5`。
8. 专属令牌：无。

批量行已废除：表格不出第二行，选中数回显与批量清空由消费方经 Pagination 的 `summary` 槽承载；复选框经 `checkbox` 槽整包装 Checkbox 零件（`checkboxPartClasses`，见第 5 条）。
