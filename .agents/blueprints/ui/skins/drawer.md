# Drawer 皮肤（app/ui/skins/drawer.tsx）

1. 壳（root）：dialog 元素即全视口透明滚动壳——`h-dvh w-full max-w-none max-h-none m-0 border-0 bg-transparent p-0 outline-none` + `overflow-y-auto overflow-x-hidden` + `overscroll-behavior: contain` 吃掉并断链滚轮/触摸（≥1px 可滚区间由 stage 提供），`[scrollbar-width:none]` 隐藏壳自身滚动条；`group/drawer` 标记承载业务 `data-duration` 档。backdrop 遮罩为平色蒙层，底色走 veil 档（方案自答）——不挂 backdrop-blur：引用未立卡变量的滤镜链会把 backdrop 推进异常合成层，丢掉其后 fixed 层（横幅背景被丢成透明、内容瓦片重影）。
2. 门控策略（用户定 2026-11-23）：prop 驱动的离散变体（placement / size / orientation）走 JS 选择（buttonVariants 式槽位表，合并串只含当前变体）；运行期状态（`data-static` 拖拽静止态、业务 `data-duration` 档）保留 CSS 门控免重渲染。禁动态修改令牌值：不写 `[--x:…]` 设值类，主轴语义尺寸直接使用固定 rem 档，不随主题 `--spacing` 缩放。
3. 定界层（stage）：`grid h-[calc(100dvh+1px)] w-full`（定值高度——面板与内容的高度链靠 `h-full` 逐层解析，定界层只给 min-height 时整条链失效；功能性 1px 常量保证壳恒有可滚区间）+ 按 placement JS 选择对齐——left `items-stretch justify-items-start`、right `items-stretch justify-items-end`、top `items-start justify-items-stretch`、bottom `items-end justify-items-stretch`；不声明 pointer-events（auto 为默认）——透明满幅 stage 即背景点击面，遮罩由原生 `::backdrop` 提供，背景关闭由骨架判 `target === stage`。
4. 面板（wrapper）：流内网格项（去 fixed/inset 定位），不声明 pointer-events；`@container flex min-w-0 min-h-0 overflow-hidden rounded-xl` + `border-frame border-border bg-surface-raised text-foreground shadow-elevated`；主轴按 placement 轴 × size JS 选择固定 rem 上限——横向 `w-full max-w-[20rem]`(sm)/`w-full max-w-[24rem]`(md)/`w-full max-w-[32rem]`(lg)，纵向 `h-full max-h-[20rem]`/`h-full max-h-[24rem]`/`h-full max-h-[32rem]`；交叉轴拉满 `h-full`(左右)/`w-full`(上下)。主轴先占满可用空间、再受固定 rem 上限约束，窄视口继续收缩，不设固定最小宽度；flex 方向随 placement JS 选择（left `flex-row-reverse`、right `flex-row`、top `flex-col-reverse`、bottom `flex-col`）把手贴外沿；位移动画由骨架 WAAPI 驱动；时长令牌 `data-[static]:duration-md data-[static]:ease-frame` + `group-data-[duration=sm|lg]:data-[static]:duration-sm!/lg!` 保留 CSS 门控（仅静止态），不挂 `transition-transform`。
5. 把手（drag）：`flex shrink-0 items-center justify-center before:content-[''] before:rounded-sm` + 按 orientation JS 选择——horizontal `h-full w-4 border-x-frame border-x-border before:h-12 before:w-1`、vertical `h-4 w-full border-y-frame border-y-border before:h-1 before:w-12`。
6. 内容：`flex min-h-0 min-w-0 flex-1 flex-col overflow-auto text-base leading-body`，不设内边距；vertical 时 JS 选择追加 `items-center`。
7. 焦点：面板是非交互容器，不挂任何焦点样式（禁 `group-focus-visible` 把焦点环洪泛到面板）；焦点可见性由 dialog 根内部的可聚焦件各自挂 `focus-visible:focus-ring` 自答。
8. 专属令牌：无（`--litefy-pane-size` 已废，主轴语义尺寸走固定 rem 档）。
