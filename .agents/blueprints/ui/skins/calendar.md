# Calendar 皮肤（app/ui/skins/calendar.tsx）

1. 框体：`rounded-lg` 圆角、`border` 描边、`background` 背景色 + `shadow-surface` 阴影、`foreground` 文字色，`p-3` 内边距、纵向紧贴节奏（禁纵向间距）；宽度占满宿主容器并按网格自然宽封顶（`w-full`，上限 `7 × --width-control + 6 × --spacing`，`6 × --spacing` 即 p-3 两侧内边距），窄容器随之收缩、不设横向最小宽；宿主已画框（DatePicker 面板）走无框变体，只留纵向排布与节奏，不套第二层框。
2. 头部：两端对齐；前后翻页钮复用按钮的框与 text 角色底（透明背景色），44 方格（`size-control`，方型与内距清零由 `pure-icon` utility 作答（骨架钩子只发射属性）），内置 chevron 16（`size-4`）。
3. 标题钮：同一按钮文字底，高度 `h-control` 与 `px-2` 由按钮帧自带，只叠 `text-sm` 最重字重；悬停吃 `accent` 背景档（并写它的配对前景 `accent-fg`），激活（`data-[active=true]`，展开了对应的年 / 月视图）换 `primary` 对。
4. 网格：一套网格类服务日 / 月 / 年三视图，不设 gap 也不设格间净距——零间隙网格（用户定 2026-11-20），格子经网格默认 stretch 占满 1fr 轨道（不写 `w-full`，grid item 拉伸同值，用户定 2026-11-24）、相邻相接，轨道宽即 `--width-control`，命中区恰为 44×44（2.5.5 AAA）；框宽按网格自然宽封顶；周历 `grid-cols-7` 均分，月 / 年层（`data-[cols=3]`）换 3 列。
5. 星期表头：`h-8` 居中，`text-xs` 加 label 声（`control-label`），`foreground` 文字色。
6. 日期格：44×44 命中区（`h-control` + 网格 stretch 占满轨道，桌面端轨道均分即正方形；移动端轨道压缩时格随轨道拉窄、高度保持 44）；零间隙相邻相接（用户定 2026-11-20，schemes.md 蓝图第 18 条）；共用布局为 `flex`、`h-control`、居中、`rounded-none`、`text-sm`、`font-field`、`tabular-nums`、`select-none` 与 `focus-visible:focus-ring-inset`。状态由槽位函数互斥选择：`disabled` 优先返回独立禁用类串（`rounded-none`、`bg-disabled`、`text-disabled-fg`、`cursor-not-allowed`，不挂载焦点环、hover、激活或月外类）；`active` 覆盖为非禁用的 `bg-primary` + `text-primary-fg`，单值选中与区间 `start` / `end` / `between` 外观完全一致，不挂载任何圆角类；`outsideMonth` 使用 `bg-surface` + `text-surface-fg`，保留焦点与选择行为，激活时由主色覆盖；其余正常格背景透明、文字色继承 `foreground`，悬停使用 `accent` 背景档（并写它的配对前景 `accent-fg`），激活格不挂 hover 类。所有日期格在任何方案下均无圆角，圆角只由日历外容器承担。键盘导航是骨架的 roving tabindex（真按钮 + `.focus()`）；焦点环与光晕同形内画（schemes.md 第 18 条机制档），聚焦足迹不超 44×44 控件盒，激活态上 `primary` 环压 `primary` 底不可见属可接受取舍。
7. 另导出 `calendarPopoverWidthClasses` / `calendarPanelWidthClasses` 两个共享宽度常量，供 `DatePicker` / `DateRangePicker` 的 top-layer 面板使用：按 `7 × --width-control + 6 × --spacing` 定宽、`max-w-[min(20rem,calc(100vw_-_1rem))] overflow-x-auto` 兜底，内部日历 `w-max min-w-[calc(7*var(--width-control))]`。这样日历浮层不跟随窄锚字段压缩，与「Calendar 独立使用时随容器收缩」互不冲突。
8. 专属令牌：无。
