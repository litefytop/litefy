# Button 皮肤（app/ui/skins/button.tsx）

1. 导出封装组件 `Button` 与 `buttonVariants`：复用骨架成品 `Button`，只供外观——变体串按 `data-variant` / `data-danger` 经 `buttonVariants` 选取（primary 默认 / outline / text / danger，见 3–6）；不自行组合零件。另导出 `buttonTextFieldClasses`、`buttonTextFaceClasses`、`buttonDisabledTextFaceClasses` 与 `buttonSquareFieldClasses`，供字段触发件和骨架渲染的 text 图标钮复用同一帧与外观。
2. 帧类基础流 `inline-flex items-center justify-center gap-x-2`：buttonVariants 须被裸 `<a>` 整串穿戴（display 决定 h-control 是否生效），流自足成串；status 配置后的网格切换归骨架 `data-[status]:inline-grid`（specificity 胜帧类 flex），帧类不双写。高度恒 `h-control`（控制几何令牌，不骑数字乘道——乘道随 `--spacing` 逐案缩放会让 neo 按钮与 44px 控件车道断档）；帧圆角 `rounded-pill`，px 读 `px-pill-x`（机制令牌 `--padding-pill-x` 答圆角补偿算式，见 `ui/schemes.md` 第 14 条）；纯图标形态的样式作答归四案同构 utility `pure-icon`（`&[data-pure-icon=true]` 答方型 + 两轴内距清零，见 `ui/schemes.md` 第 9 条），不进帧基类——帧被全文字形态穿戴，携带即死代码（用户定 2026-11-23）；骨架钩子只发射 `data-pure-icon` 属性、零样式；皮肤 `Button` 与 `FormSubmit` 在无 children 时补挂 `pure-icon` 类（与骨架自动属性同条件），图标形态皮肤串（popover / command 触发、calendar / pagination 翻页、filter-combobox 四钮、transfer 移动、chat 动作）模块层直写该类，链接型穿戴处挂类并直挂属性；`p-0` 两轴一并归零防任何来源的纵向内距渗入（帧水平内距经 flex `min-width:auto` 的 min-content 把按高换算的宽度钳大，不清零正方形必失效）；命中即盒（命中区不越出视觉框，相邻件的间隙归间隙，不设外扩）；裸 `<button>` 零件（DialogClose / BannerClose / picker trailingClose）无钩子不导入，内距自答。图标尺寸由按钮统一强制 `[&_svg]:size-4`（单一数字乘道，随 `--spacing` 逐案定值、全端不缩放，图标/控件比例恒定；用户定 2026-11-23），icon 与 status.icon 同尺寸由此保证原位换标零位移。帧不声明 text-decoration：preflight 的 `a` 继承 text-decoration 默认即无下划线，`no-underline` 是同值冗余；长文作用域内裸 `a` 按钮承 `typo-link` 下划线，要去线由消费方自挂 `no-underline` 覆盖（用户定 2026-11-23）。帧文字档 `control-text`（字号 / 行高 / 标签声整档捆绑，见 `ui/schemes.md` 第 9 条）；链接型图标钮（裸 `a` / `Link` 整串穿戴）直挂 `data-pure-icon="true"` 并挂 `pure-icon` 类复用同一纯图标契约，禁手写 `px-0` / `aspect-square` 复写与 after 外扩命中（命中即盒）。
3. primary（默认）：`primary` 背景色 + `primary-fg` 前景色 + `shadow-frame` 承重，hover 换 `primary-accent`；块状变体的抬升、悬停阴影、压平与按压阴影统一挂四案同构 utility `press-frame`，不再在皮肤串中展开四条状态类。
4. danger（`data-danger`）：`danger` 背景色 + `danger-fg` 前景色 + 发丝描边 + `shadow-frame` 承重（可交换按钮一律承重，text 例外），hover 换 `danger-accent`、文字保持 `danger-fg`（`-fg` 叠 `<status>` 与 `-accent` 两档背景实测均过 AA，见 schemes.md 规则 3），描边不随悬停换档，焦点环转 danger。
5. outline（`data-variant="outline"`）：`surface-raised` 背景色 + `surface-raised-fg` 前景色（控件静置面归凸起档，见 `ui/schemes/elevation.md`）+ 发丝描边，hover 换 `accent` 背景色；另导出 `buttonSquareFieldClasses`——与 outline 同外观，圆角答 `rounded-md` 且省略 `px-pill-x`，供 command 触发件改挂 `px-control-x`，避免同元素两套横向内距竞争与圆角相互取消。
6. text（`data-variant="text"`）：无背景色、无框、文字色恒为 `foreground` 不换——hover 加下划线（`underline-offset-4`；纯 icon 的 text 按钮无文字、线不可见，现行约定接受）；不挂抬升/压平动效，不声明按压——text 角色零按压反应（按压由皮肤显式挂 `active:` utilities，text 不挂）。
7. 禁用：`buttonVariants` 新增独立 `disabled` 与 `disabledText` 变体，`pickVariant` 在 `disabled` / `aria-disabled` 为真时直接选禁用变体，text 选 `disabledText`，不再从正常类串上叠加 `disabled:` 覆盖。块状禁用变体使用 `bg-disabled`、`text-disabled-fg`、`cursor-not-allowed` 与禁用阴影；文字禁用变体保持透明背景、透明边框和无阴影，只换文字与光标。两者都不挂 hover / active / crush，也不使用 `pointer-events: none`；保留 pill 圆角、控件高度与字号结构。`bg-disabled` 清空渐变填充；链接式按钮经 `aria-disabled` 与点击守卫达到同等阻断。
8. 专属令牌：无。
