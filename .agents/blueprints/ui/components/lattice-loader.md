# LatticeLoader 骨架（app/ui/components/lattice-loader.tsx）

1. 定位：AI 任务状态行——左侧 `grid × grid` 格阵以相位波逐格点亮，右侧动词 + 实时秒表；任务结束后格阵定格溶解成对勾（成功）或叉（失败），秒表停摆。
2. 定位补充：本组件是库的等待指示器（spin 等价物）；动词槽在文案为空时不渲染（组合宿主如 ThoughtLine 以指示器形态消费）。其余 Props：`status?: "working" | "done" | "error"`（默认 `"working"`；翻到 `done` / `error` 即定格）、`label` / `doneLabel` / `errorLabel`：`React.ReactNode` 动词槽，按 `status` 取其一直渲、空值不渲染，缺省动词由皮肤提供、`pattern?: LatticePattern | { cells: (number | null)[]; loop?: number; scale?: number }`（波形的每格延迟步数，`null` 为洞；默认 `"orbit"`——外圈顺时针环步，`3×3` 中心恒为洞格，亮窗内成弧段轮转，见 `../skins/lattice-loader.md`）、`grid?: 3 | 4`（默认 `3`）、`shape?: "square" | "round"`（默认 `"round"`，发 `data-shape` 给皮肤）、`step?: number`（相邻格点亮的毫秒间隔，默认 `90`，整圈时长随之缩放）、`showTimer?: boolean`（默认 `true`）、`elapsed?: number`（受控秒数，传入则内部时钟不跑）、`className` / `classNames`（`lattice` / `cell` / `mark` / `timer` 槽）/ `style`、其余 `div` 属性透传。`LatticePattern`：`3×3` 有 `arrow` / `dots` / `orbit` / `ripple` / `snake` / `spiral`，`4×4` 有 `sweep` / `spin` / `rain` / `pulse` / `orbit` / `snake`；未知名与尺寸不符时回落 `orbit`。
3. 结构：根 `div[data-status][data-shape]`（`role="status"` 播报动词与秒表变化）→ 格阵槽 `span`（内联 `grid-template-columns` 随 `grid` prop——行为几何必须由骨架表达）内按序渲染 `grid×grid` 枚 cell 槽 `span[data-hole]`（洞格照渲染占位，避免自动布局错位），每格内联 `--lattice-cell-delay`（波形延迟，运行期数据必须由内联样式表达）；mark 槽嵌于格阵槽内（成功内置 `Check` / 失败内置 `X`，`status` 为 working 时不渲染）→ 动词直渲 + timer 槽。
4. 行为：内部时钟 100ms 粒度累计秒数，仅 `status="working"` 时走；`status` 翻 `done` / `error` 时秒表冻结、`data-status` 交给皮肤做溶解；`status` 回 `"working"` 秒表归零重跑；命名波形 = 每格延迟步数矩阵（`step` 单位），自定义对象直接消费 `cells` / `loop` / `scale`。
5. 外观交给皮肤：格子明暗、点亮动画、溶解形态、成功 / 失败配色全由皮肤按 `data-status` 表达；mark 用库内置 `Check` / `X` 图标；骨架零样式 class，只发逻辑态与内联波形延迟。
