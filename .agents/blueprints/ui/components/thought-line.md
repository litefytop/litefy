# ThoughtLine 骨架（app/ui/components/thought-line.tsx）

1. 定位：AI 思考过程行——思考中是「呼吸图标 + 工作文案 + 实时秒表」，过程步骤在行下逐条附加；结束后整行一拍定格为「完成文案 + 冻结秒表」，步骤折叠收进行内。
2. Props：`working?: boolean`（默认 `true`；再次置 `true` 重开秒表并重新展开）、`label?: string`（工作文案，默认 `"Thinking…"`）、`doneLabel?: string`（完成文案，默认空——有秒表时补全为 `Thought for`，无秒表且为空时用 `Done thinking`）、`glyph?: "lattice" | "sparkle" | "dot" | "none" | React.ReactNode`（默认 `"lattice"`；`"lattice"` 组合 LatticeLoader——思考中渲染波形、定格渲染对勾，即 spin 等价物的宿主）、`latticeClassNames?: LatticeLoaderClassNames`（嵌套 LatticeLoader 的槽位包，直通其 `classNames`；`classNames.lattice` 只着装加载器根）、`steps?: string[]`（追加式轨迹：末条为进行中，其余为已完成）、`collapsible?: boolean`（默认 `true`，行成为轨迹的开关）、`collapseOnSettle?: boolean`（默认 `true`，定格时收起轨迹）、`settleAfter?: number`（秒；0 = 等 `working` 翻 `false`）、`elapsed?: number`（受控秒数，传入则内部时钟不跑）、`showTimer?: boolean`（默认 `true`）、`renderLabel?: (text: string, working: boolean) => React.ReactNode`（包一层的出口，行内内容）、`onSettle?: (seconds: number) => void`（每次定格回调一次，带冻结秒数）、`className` / `classNames`（`line` / `glyph` / `body` / `label` / `lattice` / `timer` / `chevron` / `steps` / `step` / `stepMarker` 槽）/ `style`、其余 `div` 属性透传。
3. 结构：根 `div[data-working][data-collapsible][data-open]` → 行件（`collapsible` 且有步骤时为 `button[type=button][aria-expanded][aria-controls]`，否则 `div`）内依序 glyph 槽、body 槽（`relative` 叠放锚——内含 label 槽（`aria-live="polite"`，文案变化播报）、完成文案直渲（皮肤经 `renderLabel` 包装成与 label 同格叠放交叉淡变的节点）、timer 槽）、chevron 槽（`collapsible` 且有步骤才渲染）→ 步骤列表 `ul[id][data-open]` > 折叠壳 `div` > `li`（`stepMarker` 槽 + 步骤文案；已完成步 marker 为内置 `Check`，进行中步 marker 为空 `span[data-current=true]`）。
4. 行为：内部时钟以 100ms 粒度累计秒数（`elapsed` 受控时不跑，计时仅在 `working` 时走）；定格触发 = `working` 翻 `false` 或 `settleAfter` 到点，`onSettle` 带冻结秒数回调一次；`collapseOnSettle` 时列表 `data-open` 翻 `false`；`collapsible` 时行件切换列表 `data-open`；`working` 重新为 `true` 时秒表归零重跑、列表重新展开。
5. 外观交给皮肤：呼吸、扫光、定格淡变、步骤显隐与折叠全由皮肤按 `data-working` / `data-open` 表达；骨架零样式 class，只发逻辑态；图标只用库内置图标（sparkle = 内置星形，chevron = 内置 ChevronDown）。
