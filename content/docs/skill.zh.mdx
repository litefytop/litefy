## 它是什么

Litefy UI 设计规范技能（`litefy-design`）是一个 `SKILL.md` 文件，教会 AI 编码助手——Claude Code、Codex、Cursor、Gemini CLI 以及一切支持 skills 格式的工具——正确使用 Litefy UI：语义 Token 体系、阴影/圆角分级、组件选型规则（成品与零件二选一）、反模式库和验证清单。

加载技能后，模型不再手写裸 HTML + Tailwind，而是用正确的 Token 组合 Litefy 组件——与本站文档教的规则一致，且始终在模型上下文里。

## 获取技能

  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm dlx litefy@latest skill
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bunx --bun litefy@latest skill
    ```
  </Tab>
</Tabs>

把 `SKILL.md`、配套 `CHANGELOG.md` 和随附的 `scripts/design-detect.mjs` 校验脚本一起装进当前项目的 `.claude/skills/litefy-design/` 目录。

**选项**

- `-d, --dir <path>`：目标技能目录（默认 `.claude/skills/litefy-design`）——指向你的工具实际扫描的目录，如 `.cursor/skills/litefy-design`
- `-o, --overwrite`：覆盖已存在的文件

### 单独下载源码

逐个下载文件、自行放置：

- **[litefy-design-skill.md](/litefy-design-skill.md)** —— 原始技能文件，构建时从仓库源文件自动同步，始终最新
- **[litefy-design-detect.mjs](/litefy-design-detect.mjs)** —— 可独立使用的校验脚本

两个文件也可以在 [GitHub](https://github.com/litefytop/litefy/tree/main/.agents/skills/litefy-design) 上查看。

## 放在哪里

- **Claude Code**：项目内 `.claude/skills/litefy-design/SKILL.md`（随仓库提交，团队全员共享），或 `~/.claude/skills/litefy-design/SKILL.md` 作为个人全局安装
- **其他支持 skills 的工具**：多数遵循同样的 `skills/<name>/SKILL.md` 约定（如 `~/.codex/skills/`、`.cursor/skills/`），把文件放进去即可
- **不支持 skills 的工具**：文件就是纯 Markdown——把内容粘贴进你的 `AGENTS.md`、`CLAUDE.md` 或 `.cursorrules`，效果相同

## 校验

对项目的源码目录运行随附脚本（`node .claude/skills/litefy-design/scripts/design-detect.mjs src`，单独下载则 `node litefy-design-detect.mjs src`）：硬编码色值、任意值阴影、手写焦点/禁用样式为 error（非零退出码，可接 CI）；阴影旧刻度名与结构坏味道（同标签三层以上嵌套、Tabs 触发条配手搓面板、Tabs 嵌套、滚动嵌套）为 warn。加 `--fix` 可自动改写唯一机械安全的规则——旧阴影刻度名到同值的语义名（`shadow-sm` → `shadow-subtle`，零视觉变化）；其余问题一律只报告。

## 内容一览

技能版本记录在 frontmatter 的 `metadata.version` 字段，附 changelog。当前包含：

- **工作流** —— 选组件 → 套 Token → 查反模式 → 验证闭环
- **Token 体系** —— Surface/品牌双色板、边框、焦点环、间距、四级阴影/圆角、动效规则
- **全局强制约束** —— 只用语义 Token、成品与零件二选一、WCAG 2.2 AA 基线
- **反模式库** —— 硬编码色值、ghost card、动布局属性等一票否决项
- **组件专项规范** —— Button 变体、Card 与 CardButton、Chip/Badge/Callout 划分、Table 列宽模型的设计 rationale
- **验证清单** —— 发布前的静态、可访问性与视觉检查
- **随附校验脚本** —— `design-detect.mjs` 确定性检查硬编码色值、任意值阴影、手写焦点/禁用样式（interactive.css 在场时），并对阴影旧刻度名与结构坏味道（同标签三层嵌套、Tabs 手搓面板/嵌套、滚动嵌套）给出 warn
