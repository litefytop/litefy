---

## 开放代码

所有组件源码直接交付到你的项目。没有黑盒，没有不可逆的封装层。需要修改组件行为？直接打开本地源文件编辑。

## 组合优先

组件提供两层使用模型，兼顾开发效率与定制自由度：

- **预置组合组件**：DOM 结构固化、API 极简，面向绝大多数业务场景，开箱即用，快速开发。
- **底层原子组件**：开放完整基础单元，支持自由拼装，可任意调整 DOM 结构、节点顺序、增删内部元素，完全掌控渲染逻辑。

当预置组件无法满足高度定制需求时，可使用原子组件自主组合；极致场景下，可直接修改本地组件源码二次改造。

所有组件遵循统一设计范式，接口行为可预测，降低学习与适配成本。

## 轻量分发

通过 CLI 一键初始化项目、安装组件、样式、Hooks。
所有资源源码本地化存储，**不存在远程黑盒依赖**。
无需锁定版本，无需担忧上游破坏性更新，你的 UI 完全由自己掌控。

## 原生优先

交互组件优先基于浏览器原生标准能力实现（popover、anchor‑position 等），不依赖重型第三方封装。

仅对非基线特性提供降级回退，**已进入 Web Baseline 的标准特性不做兼容 Polyfill**，保持代码轻量纯粹。
本库不针对老旧浏览器做兼容适配，如果项目需要兼容低版本环境，Litefy 可能并不适合。

## 全量资源 CLI 托管

组件、自定义 Hooks、样式文件全部支持 CLI 自动化管理：自动维护安装清单、自动生成聚合导出，支持修复丢失文件、清理无效配置、一键卸载重置，工程化体验完整闭环。
