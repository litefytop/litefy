title: 介绍
description: Litefy 是一套源码本地化的现代化 React UI 工具库。
---

**Litefy** 是一套**源码本地化**的现代化 React UI 工具库。无黑盒远程依赖，组件、Hooks、样式均可直接拷贝至项目，完全可控。

不同于主流 UI 库的组装思路，Litefy **完全自研底层、零第三方 UI 依赖**，并采用轻量化优先策略：纯展示视图使用 **CSS-only** 实现，规避冗余 JS 开销，仅交互组件提供 TSX 实现。

库提供双层组件模型，兼顾效率与定制：

- **预置成品组件**：内置完整无障碍能力，结构固化、开箱即用，适配绝大多数业务场景。
- **底层原子组件**：无默认样式，支持自由拼装，满足深度个性化定制需求。

**适配说明**：面向现代浏览器与 React 19+，遵循 Web 基线标准、不兼容老旧环境，更适合内部系统与可控浏览器场景使用。
