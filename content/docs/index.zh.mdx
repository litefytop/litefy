**Litefy** 是一套**源码本地化**的现代化 React UI 工具库：组件、Hooks 与样式经 CLI 直接拷入项目——没有黑盒远程依赖，交付的每一行都可读、可改。

不同于主流 UI 库的组装思路，Litefy **完全自研底层、零第三方 UI 依赖**。所有组件均为 **TSX 实现**、带完整 TypeScript 类型——并且全部**无样式**：语义化 DOM、无障碍与键盘交互内置，逻辑状态经 `data-*` 属性暴露，自身不挂任何外观。

外观来自**风格**：安装时选定的自持整包，负责全部颜色、圆角、阴影、动效与排版规则——见[样式](/zh/docs/styles)。组件不写死外观，风格不碰行为，两者只在每个组件暴露的 `className` / `classNames` 入口相遇。

组件有**封装组件**与**原子组件**两种形态，均为 headless 模式、可搭配不同皮肤：

- **封装组件**——`Dialog`、`Toaster`、`Select` 等开箱即用：焦点陷阱、定位、表单注册、校验全部内置。
- **原子组件**——`DialogRoot`、`DialogContent`、`Picker`、`List` 等，当封装组件的默认装配不合身时，自由拼装自己的弹层、字段与流程。

**适配说明**：面向现代浏览器与 React 19+，遵循 Web 基线标准、不兼容老旧环境，更适合内部系统与可控浏览器场景使用。
