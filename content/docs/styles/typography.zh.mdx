## 类名参考

| 类名                 | 描述                                     |
| :------------------- | :--------------------------------------- |
| `.heading-h1` ~ `.heading-h6` | 响应式标题，层级递减            |
| `.headline`          | 加粗的页面级大标题，带垂直间距           |
| `.description`       | 弱化的正文描述文本                       |
| `.heading-code`      | 标题内使用的行内代码样式                 |
| `.description-code`  | 正文内使用的行内代码样式                 |
