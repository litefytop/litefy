## Class Reference

| Class                | Description                                              |
| :------------------- | :------------------------------------------------------- |
| `.heading-h1` ~ `.heading-h6` | Responsive headings, decreasing size per level  |
| `.headline`          | Bold page-level headline with vertical spacing           |
| `.description`       | Muted body text                                          |
| `.heading-code`      | Inline code styled for headings                          |
| `.description-code`  | Inline code styled for body text                         |
