## Examples

### Basic

`.tag` is a pure CSS chip: rounded, single background color, no hover or focus states. Without a color utility it falls back to a muted surface.

<ComponentPreview name="tag-basic" />

### Coloring

The chip is one flat color — pass any Tailwind background utility plus a contrasting text color. Since there is no interaction logic, the same class works unchanged on `<span>` (display only), `<a>` (link) or `<button>` (action).

```html
<span class="tag">default</span>
<span class="tag bg-emerald-600 text-white">stable</span>
<a class="tag bg-violet-600 text-white" href="#">link tag</a>
<button class="tag bg-emerald-600 text-white">button tag</button>
```

## Notes

- `.tag` only defines shape and typography — radius follows `--radius`, and background/text color come entirely from utilities, so it never fights your theme.
- Combine with the [Capsule](/docs/styles/capsule) class to build shields-io style badges.
