## 用法

纯类名、无组件——单元素挂 `typo-*` 类取排版字符，或容器挂 `typography` 类，方案把域内的标题、段落、列表、引文、行内代码与链接统一排版。

### 阅读域

容器挂一个类，域内的标题、段落、列表、引文、行内代码与链接全部排版。

## 类名参考

| 类名                 | 答什么                                                       |
| -------------------- | ------------------------------------------------------------ |
| `typography`         | 阅读域——域内 h1–h6、p、ul/ol、blockquote、code、a 统一排版；子树挂 `not-typography` 退出 |
| `typo-h1` … `typo-h6` | 标题字符：字号、字重、行高，各方案自答声腔                   |
| `typo-headline`      | 展示级大字：首屏唯一的 hero 标题——字号随视口 clamp、字重、行高与字距；只单挂，不进阅读域 |
| `typo-kicker`        | headline 之上的黄金引导行：正文 × φ（1.625rem），大写、最宽字距；只单挂，不进阅读域 |
| `typo-body`          | 正文：字号、行高、文字色                                     |
| `typo-quote`         | 引文：行高、文字色、左侧边线与内边距                         |
| `typo-list`          | 列表：行高、缩进、符号（ul 圆点 / ol 数字）                  |
| `typo-code`          | 行内代码：等宽族、底色、边框                                 |
| `typo-link`          | 链接：主色、下划线                                           |
| `typo-overline`      | 眉标：小字号、大写、最宽字距；只单挂，不进阅读域             |

单挂类与阅读域给出同一套观感——块间距与行宽由使用方自答：节奏用 `gap-*` 列或站点自己的散文 margin，行宽挂 `max-w-[40em]`（随字号缩放，中文每行 40 字、拉丁每行 80 字符同时成立），排版域自身不带宽度。

字号越大相对行高越小、字距越紧，各档由方案自答，不是全局一个 line-height。中西文混排的自动间距由浏览器默认开启（`text-autospace` 初始值即 `normal`，无需声明），汉字与拉丁字母、数字之间自动补 1/8 em 间隙，标点挤压由浏览器默认承担；两条都是渐进增强，不支持的浏览器退化为默认排版，不改文本内容。
