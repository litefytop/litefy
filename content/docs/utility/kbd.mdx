## Usage

An inline keycap mark for keyboard key names; a pure styling class — write a native `kbd` element with the `kbd` class for the keycap form and key-name semantics, handling no interaction.

<ComponentPreview name="kbd-basic" />

The class ships with every scheme's style layer, no installation needed; the keycap aligns inline, ready for shortcut notes, tables and hints.
