Litefy 组件本身无样式。**风格**是一个自持整包：安装时选定一个，应用的全部颜色、圆角、阴影、动效与排版规则都由它决定。一个路由只加载一种风格的样式表，没有运行时切换，同一页面不混用。下面的面板按方案列出那一份文件：点开就能读到它的令牌阶梯、色板梯度与 `@theme` 映射。

<StyleStylesheets />

每个风格包只自带一份样式表（`index.css`：令牌、`@layer base` 区块、`@theme` 映射——只有从别的常量反解出来的维度才占一个命名空间（`--height-*` / `--width-*` / `--size-*` / `--padding-tight|snug|loose` / `--transition-duration-*`），所以 `h-control`、`py-snug`、`duration-sm` 是这样来的；留白没有名字，走数字间距刻度——再加本方案的 `@custom-variant` 档位与 `@utility` 原语；没有逐组件的文件）、亮色 + 暗色双方案（`<html>` 上的 `.dark` class 切换），以及设计语言文件 `design.md`（在线预览/下载，不随样式表安装）。

- **装到项目里**：命令与选项见[安装](/zh/docs/installation)。
- **读它的设计语言**：每种风格配一份 `design.md`（皮肤专属的设计语言文件，面向 AI 设计工具与编码助手），在下方预览或下载。

## 尺寸与留白

全部尺寸走同一枚间距基础值 `--spacing`（minimal、neon-gradient 与 flat-minimal 答 0.25rem = 4px，neo-brutalist 答 0.375rem = 6px），写成它的倍数——`w-112`、`p-4`、`gap-3` 都是倍数，不是像素。换风格时整库同步缩放，所以皮肤里不写 rem / px 定值。控件几何取 11 的倍数：`w-11` 即触控目标（默认案 44px），紧凑档把基础值 ×0.75 后向下取整到整像素（3px / 4px），`w-11` 随之收到 33px（neo 44px）。紧凑档自动生效——主指针为粗指针（触摸屏，手机与平板横竖屏同档）或视口窄于 48rem（桌面窄窗与仿真调试同档）即进紧凑；细指针且视口不窄于 48rem 才是舒适档，桌面恒 44 基准，无需任何设置。

留白有一条可判定的层级：**一组元素的内间距必须小于它与外部的间距**，层级差至少一档（4 单位）。组内 `gap-2`、组间 `mt-6` 读得出分组；两者相等就读不出，只写「4 的倍数」不构成约束。

## 宽度车道

宽度不靠逐个组件拍板，按顺序问六个问题，命中即停，同一元素不混写两条车道。

1. **是连续阅读的正文吗？** 挂 `max-w-[40em]`。这是唯一用 em 的车道——它要随字号走而不是随栅格走：中文每行 40 字、拉丁每行 80 字符同时成立（WCAG 1.4.8）。本站正文列就走这条。
2. **宽度由父格决定吗？** 输入框、密码框、文本域、下拉与多选触发件、数字输入根都自带缺省内在宽 `w-55`（220px：按前后缀各占一格 `w-11` 推得，最坏情形值区仍余 3 格）；表单布局里消费方给 `w-full` 接管，窄容器自动收敛。
3. **内容是定长可数的数值吗？** 数字件走静态 11 倍数：步进器值区恒 `w-11`（一格，超宽内容在框内横向滚动、零运行期计算），总宽名义 3 格（两侧步进钮与值区各 1 格）；改大 `max` 时自行加宽值区。区间输入单端 `min-w-11` 随格伸缩。
4. **要和同轴兄弟争余量吗？** 滑块轨道、进度条、图表画布这类伸缩件，本体写 `w-112 grow min-w-0 max-w-112`，控件根写 `min-w-[min(100%,--spacing(32))]`：余量不足时一路收缩，绝不挤掉兄弟。保底只能挂根——挂本体时百分比按整个容器算，兄弟占掉的空间它看不见。
5. **是脱离文档流的浮层吗？** 宽度对视口负责，不对父格负责。居中件（Dialog）写 `max-w-[min(100%_-_--spacing(8),--spacing(112))]`，两侧留 8 单位边沟、窄视口自动让位；贴边件（Drawer）主轴定档直接取 spacing 刻度（`w-96` / `h-96`，`size` 档换倍数），再用 `max-w-full` 封顶。
6. **以上都不是？** 从定档表按角色取。档位分两基：控件级小容器一律 **11 的倍数**（数字件值区、页码输入、内联小钮——`w-11` 即 44 触控基准）；容器级一律 **16 的倍数**：默认案 16 单位 = 4rem，想要 24rem 就写 `w-96`，换方案时整档跟着基础值缩放，不用重算。

定档表（单位数）：

- `11` 数字件值区与内联小钮的下限格
- `32` 伸缩件的保底根
- `48` 下拉菜单一族面板、上下抽屉保底
- `64` 左右抽屉保底
- `80` 行内窄选择件、`size="sm"` 抽屉
- `96` 抽屉默认档
- `112` Dialog 默认档、轻提示视口、伸缩轨道上限
- `128` 宽 Dialog（表单、双列内容）、`size="lg"` 抽屉

任意值里不能有空格：`calc` 与 `min()` 的空位写 `_`（类名扫描按空白切词，带空格的串静默不生成任何 CSS）。
