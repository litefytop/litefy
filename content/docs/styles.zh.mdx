Litefy 的样式是分层的 CSS 自定义属性，全部使用 OKLCH 并经 `@theme inline` 映射进 Tailwind——每个组件只读语义令牌（`bg-background`、`text-primary`、`border`…），因此换掉任意一层样式即可整体换肤，无需触碰组件代码。

| 层 | 文件 | 作用 |
|---|---|---|
| **Theme**（必需） | `theme.css` | 基础令牌集：亮色 + 暗色双方案，`@theme inline` 映射 |
| **Interactive** | `interactive.css` | 全局行为样式：禁用态、focus-visible、按压反馈 |
| **组件皮肤** | `preset/*.css` | 按组件拆分的皮肤：成品挂 `litefy-*` class，零件用 `data-slot`、状态用 `data-*` 选择 |

以上三层作为**一个整包 registry 条目——`preset`** 分发，`init` 会自动安装。单个 CSS 文件不提供分别下载：令牌层与组件皮肤只有成套在一起才是自洽的。各文件源码仍可在下方浏览。

## Theme

<Installation name="preset" />

`theme.css` 同时包含亮色与暗色方案——`<html>` 上的 `.dark` class 自动应用暗色模式。变量使用 OKLCH 颜色值，全部现代浏览器均支持。

### 阴影分级

阴影严格分为四个语义等级。亮色模式用黑色投影表达层级；暗色模式下深色画布会吞掉黑色投影（没有可再压暗的空间），因此暗色层级由三件套承担——**浮层表面提亮**（`--surface-raised`，画布亮度 +4.5%，浮层组件自带 `bg-surface-raised`）、**白色亮环**（阴影内置 1px 白圈，subtle 7% → elevated 14%）、**顶部白色内高光**（5–11%）；黑色投影降档兜底，仅在浮层盖住较亮内容（正文、表格）时起作用。禁止白色模糊外发光（与焦点环语义冲突）。Tailwind 默认阴影刻度已在 `theme.css` 映射到这四级——两套类名同值，任选其一：

| 刻度类 | 语义类 | 等级 | 用途 |
|--------|--------|------|------|
| `shadow-2xs` `shadow-xs` | `shadow-faint` | faint | 微小行内元素、极简占位 |
| `shadow-sm` | `shadow-subtle` | subtle | 小标签（Badge/Chip）、紧凑行内控件 |
| `shadow-md` | `shadow-base` | base | 按钮、输入框、标准卡片 |
| `shadow-lg` `shadow-xl` `shadow-2xl` | `shadow-elevated` | elevated | 弹窗、悬浮浮层、抽屉 |

圆角等级与阴影等级一一配对：`rounded-sm` 行内/标签、`rounded-md` 输入框/按钮、`rounded-lg` 区块卡片、`rounded-xl` 浮层外壳。

## Interactive 交互样式

`interactive.css` 不是主题——它是每个 Litefy 组件都依赖的全局行为层，包含四条 `@layer base` 规则：

- **禁用控件**（`:disabled`、`[inert]`、`[data-disabled]`）：整体 50% 透明度、中性底色、`not-allowed` 光标且不响应指针事件——含 `label:has(:disabled)` 这类包装层，组合复选框、上传控件会整体变暗。
- **Focus-visible**：`1px` 描边（`--color-outline`）加 `3px` 柔光环（`--color-ring`），仅键盘导航触发——鼠标点击不出现焦点环。
- **按钮按压**：`button:active` 内阴影 + `brightness(0.95)`，提供触觉反馈。

该层随 `preset` 整包分发。如果你想自行实现禁用/焦点/按压样式，从生成的 `styles/index.css` 里去掉 `./interactive.css` 导入即可——组件照常工作，反馈交由你负责。

## 风格模板

Litefy 的**风格**是独立模板，而非运行时切换：每个模板自带完整亮色 + 暗色令牌集（`theme.css`）、组件皮肤（`preset/*.css`）和成品组件示例页。风格之间不在同一页面共存，也不提供浏览器内换色——安装时选定一个模板，由它负责应用的全部外观。

组件文档的演示一律展示**默认方案**；其他风格各自提供示例页，而不是复制一套演示。点击模板卡片即可打开对应的完整示例页。
