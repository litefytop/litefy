## Prerequisites

Litefy is not a scaffolding tool. It assumes you already have an existing React + Tailwind CSS project.

Before you begin, make sure your project meets the following requirements:

- **React 19+** (Litefy uses React 19 features such as `props.ref`. Older versions will throw errors.)
- **Tailwind CSS 4** configured (Tailwind CSS 3 is untested and not guaranteed to work.)
- TypeScript enabled
- `@/` path alias configured (e.g. `@/ui` pointing to `src/ui`)

## Commands

### `init`

Initialize the Litefy configuration file.

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    ```bash 
    npx litefy@latest init
     ```
  </Tab>
  <Tab value="yarn">
  ```bash 
  yarn dlx litefy@latest init 
  ```
  </Tab>
  <Tab value="pnpm">
  ```bash 
  pnpm dlx litefy@latest init 
  ```
  </Tab>
  <Tab value="bun">
  ```bash 
  bunx --bun litefy@latest init 
  ```
  </Tab>
</Tabs>

> If you skip initialization, running add commands will initialize automatically.

- `-y, --yes`: Skip interactive prompts and use default configuration
- `--pm <npm|yarn|pnpm|bun>`: Explicitly set package manager, skip auto‑detection

---

### `add`

Download and add components to your local project.

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    ```bash 
    npx litefy@latest add <components...>
    ```
  </Tab>
  <Tab value="yarn">
  ```bash 
  yarn dlx litefy@latest add <components...>
  ```
  </Tab>
  <Tab value="pnpm">
  ```bash 
  pnpm dlx litefy@latest add <components...>
  ```
  </Tab>
  <Tab value="bun">
  ```bash 
  bunx --bun litefy@latest add <components...>
  ```
  </Tab>
</Tabs>

- `-o, --overwrite`: Force‑overwrite existing local component files

### `rm`

Remove installed components: delete local source files and update the installed list in config.

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    ```bash 
    npx litefy@latest rm <components...>
    ```
  </Tab>
  <Tab value="yarn">
  ```bash 
  yarn dlx litefy@latest rm <components...>
  ```
  </Tab>
  <Tab value="pnpm">
  ```bash 
  pnpm dlx litefy@latest rm <components...>
  ```
  </Tab>
  <Tab value="bun">
  ```bash 
  bunx --bun litefy@latest rm <components...>
  ```
  </Tab>
</Tabs>

## Theme Variables

Litefy does not inject theme variables automatically.
Head over to the <Link to="/docs/theming">Theming</Link> page, pick your desired color palette, and manually copy it into your global CSS file.
