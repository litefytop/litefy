Components ship as source — install them with the CLI tool, or by hand.

## Prerequisites

Litefy is not a project scaffold — use it inside an existing React app. The only hard requirements are:

- **React 19+** (components rely on React 19 features; older versions are incompatible)
- **TypeScript** enabled
- **Tailwind CSS 4** configured; Litefy stylesheets are theme layers and need your Tailwind entry to generate utilities

## CLI

### init

Initialize your project: generate the `litefy.json` config file, create the `ui/litefy` directory structure with its aggregate barrel files, and install the dependencies. `init` prepares headless skeletons only; select and install a skin with `add <component> -s <scheme>` or `add style <scheme>`. Running `add` before initialization triggers the initialization flow automatically.

> ⚠️ Do not manually modify the path fields in `litefy.json`. If you relocate these directories yourself, update your import paths to match; the CLI will not rewrite them for you.

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    ```bash
    npx litefy@latest init
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    yarn dlx litefy@latest init
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm dlx litefy@latest init
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bunx --bun litefy@latest init
    ```
  </Tab>
</Tabs>

**Options**

- `-y, --yes`: Skip interactive prompts and use all default configuration

### add

Download component skeletons, their matching skins, hooks and utils in batch, automatically resolve each entry's `dependence` (detected by scanning every template's relative imports at build time), install the resolved npm dependencies, and update the aggregate exports. Once a style scheme is picked (`-s`, or a previous `add style`), every `add` also re-syncs that scheme's complete stylesheet.

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    ```bash
    npx litefy@latest add <components...>
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    yarn dlx litefy@latest add <components...>
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm dlx litefy@latest add <components...>
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bunx --bun litefy@latest add <components...>
    ```
  </Tab>
</Tabs>

**Options**

- `-o, --overwrite`: Force overwrite existing files
- `-y, --yes`: Skip interactive prompts (auto-install npm dependencies)
- `-s, --style <scheme>`: Pick the style scheme; its complete stylesheet re-syncs on every add

### style

Install (or switch) a style scheme. `init` prepares skeletons only; `add style <scheme>` installs or switches the stylesheet, and the last-installed scheme is the only one wired into `styles/index.css`.

The installer writes the scheme's **single stylesheet** — `index.css`: tokens, the `@layer base` block, the `@theme` mapping, `@custom-variant` roles and `@utility` primitives — into the styles directory. That file is a pure theme layer, not a standalone entry: import it into your own Tailwind CSS entry after `@import "tailwindcss"`; your entry's scan generates the utilities. A scheme installs as a whole, with no per-component style entries. `add` installs each component's utility classes into `ui/litefy/skins/` alongside its skeleton, so you do not write them by hand.

## Manual installation

The library has two modes — headless skeletons and skins. When installing by hand, download the resources you need:

- **Skeleton**: component source ships without styles — structure and behavior only. Put the source and the `icons.tsx` adapter into `ui/litefy/components/`, then install the imported dependencies yourself. See [Headless](/en/docs/headless).
- **Skin**: put each component's matching skin source into `ui/litefy/skins/`. Each style also has one `index.css` (tokens, the base block and the `@theme` mapping). Review and copy it from the [Styles](/en/docs/styles) page and import it into your Tailwind CSS entry after `@import "tailwindcss"`.
