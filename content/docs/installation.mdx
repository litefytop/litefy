## Prerequisites

Litefy does not provide a full project scaffold. Use it in an existing React project.

Your project needs to meet the following requirements:

- **React 19+** (relies on new React 19 features; older versions are incompatible)
- TypeScript enabled
- Path alias `@/*` configured to point to the root of your source code

> Component templates import the `cn` utility from `@/lib` internally, so the alias must work properly. When using the CLI default paths, you only need to map `@` to your source directory; no extra special configuration is required. See your build tool's documentation for how to configure the alias.

## Commands

### init

Initialize your project: generate the `litefy.json` config file, create the `ui/litefy` directory structure, pull in `cn.ts`, and install the required dependencies. Running `add` before initialization triggers the initialization flow automatically.

> ⚠️ Do not manually modify the path fields in `litefy.json`. If you change the paths yourself, you must keep the project alias and import statements in sync; the CLI will not fix them automatically.

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    ```bash
    npx litefy@latest init
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    yarn dlx litefy@latest init
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm dlx litefy@latest init
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bunx --bun litefy@latest init
    ```
  </Tab>
</Tabs>

**Options**

- `-y, --yes`: Skip interactive prompts and use all default configuration

### add

Download and install components and their corresponding hooks in batch, and automatically update the aggregate export file.

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    ```bash
    npx litefy@latest add <components...>
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    yarn dlx litefy@latest add <components...>
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm dlx litefy@latest add <components...>
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bunx --bun litefy@latest add <components...>
    ```
  </Tab>
</Tabs>

**Options**

- `-o, --overwrite`: Force overwrite existing component files
