## 用法

将 `handlePointerDown` 绑定到拖拽手柄。hook 会捕获指针，在 document 上追踪移动，并通过回调上报偏移量。

<ComponentPreview
  name="use-drag-basic"
/>

```tsx
import { useDrag } from "@/ui";

function DraggableBox() {
  const [offset, setOffset] = useState({ x: 0, y: 0 });
  const startRef = useRef({ x: 0, y: 0 });

  const drag = useDrag({
    onDragStart: () => {
      startRef.current = offset;
    },
    onDragMove: ({ dx, dy }) => {
      setOffset({ x: startRef.current.x + dx, y: startRef.current.y + dy });
    },
  });

  return <div onPointerDown={drag.handlePointerDown} style={{ transform: `translate(${offset.x}px, ${offset.y}px)` }} />;
}
```

## API 参考

### useDrag

```ts
function useDrag(opts?: UseDragOptions): DragResult
```

#### UseDragOptions

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `disabled` | `boolean` | `false` | 为 true 时忽略指针按下事件 |
| `onDragStart` | `(e: React.PointerEvent<HTMLElement>) => void` | - | 拖拽手势开始时触发 |
| `onDragMove` | `(info: DragInfo) => void` | - | 拖拽过程中每次指针移动触发 |
| `onDragEnd` | `(info: DragInfo) => void` | - | 指针释放时触发 |

#### DragInfo

| 属性 | 类型 | 说明 |
|------|------|------|
| `dx` | `number` | 相对拖拽起点的水平偏移 |
| `dy` | `number` | 相对拖拽起点的垂直偏移 |
| `clientX` | `number` | 当前指针 client X |
| `clientY` | `number` | 当前指针 client Y |

#### DragResult

| 属性 | 类型 | 说明 |
|------|------|------|
| `isDragging` | `boolean` | 当前是否有拖拽手势进行中 |
| `handlePointerDown` | `(e: React.PointerEvent<HTMLElement>) => void` | 绑定到拖拽手柄的 `onPointerDown` |

**注意事项：**

- 偏移量相对指针起点计算，如何累积由调用方决定。
- 使用指针捕获，指针移出手柄后拖拽仍然持续追踪。
