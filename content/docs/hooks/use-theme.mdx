## Usage

A module-level store shared across components via `useSyncExternalStore`. Reads `brand` / `surface` / `theme` from localStorage on load, applies them to `document.documentElement` (`data-brand`, `data-surface`, `.dark`, `color-scheme`) and follows the system color scheme when `theme` is `"system"`.

<ComponentPreview
  name="use-theme-basic"
/>

```tsx
import { useTheme } from "@/ui";

function ThemeToggle() {
  const theme = useTheme();
  return <button onClick={theme.toggleTheme}>Toggle</button>;
}
```

## API Reference

### useTheme

```ts
function useTheme(): ThemeState
```

Returns a `ThemeState`:

| Property | Type | Description |
|------|------|-------------|
| `brand` | `string` | Current brand token, mapped to `data-brand` on the root element |
| `surface` | `string` | Current surface token, mapped to `data-surface` on the root element |
| `theme` | `'light' \| 'dark' \| 'system'` | Current color mode |
| `setBrand` | `(brand: string) => void` | Set the brand token, persists and applies it |
| `setSurface` | `(surface: string) => void` | Set the surface token, persists and applies it |
| `setTheme` | `(mode: ThemeMode) => void` | Set the color mode, persists and applies it |
| `toggleTheme` | `() => void` | Switch between light and dark (resolves system first) |

**Notes:**

- All state lives outside React; multiple components calling `useTheme` share one store and re-render together.
- Persisted under the `theme-storage` localStorage key.
- When `theme` is `"system"`, the stored value is kept and the applied mode follows `prefers-color-scheme` changes live.
