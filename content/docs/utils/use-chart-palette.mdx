## Usage

Picks 8 fixed colors by default: Tailwind 400-step tones, identical in light and dark mode, recalculated when the theme changes; beyond 8 series, extra colors are generated by continuing along the golden angle. The shade is the color — no contrast check against the surface. The first SSR frame already uses this fixed set; after mounting, colors are recalculated by the actual theme color.

```tsx
import { useChartPalette } from "@/ui";

function Swatches() {
  const palette = useChartPalette();

  return (
    <div className="flex gap-2">
      {palette.map((color) => (
        <div key={color} className="rounded-md" style={{ width: "2rem", height: "2rem", background: color }} />
      ))}
    </div>
  );
}
```

```tsx
const palette = useChartPalette({ mode: "mono" });

const series = [
  { label: "Returning", stroke: palette[0], fill: palette[0] },
  { label: "New", stroke: palette[1], fill: palette[1] },
];
```

## API Reference

### useChartPalette

```ts
function useChartPalette(options?: ChartPaletteOptions): string[]
```

Returns an array of `count` (default 8) colors whose elements are CSS color strings in the `oklch(L C H)` form.

#### ChartPaletteOptions

| Property | Type                 | Description                               |
| -------- | -------------------- | ----------------------------------------- |
| `mode`   | `"fixed" \| "mono"`  | Color picking mode, defaults to `"fixed"` |

#### Picking modes

| Mode      | Behavior                                                                                                                                                                                                                          |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `"fixed"` | The first 8 colors are picked in order from a fixed Tailwind palette interleaved by hue (red/green/blue/orange/cyan/violet/amber/pink, adjacent picks differing by 80°+ in hue) — unified 400-step tones in both light and dark; beyond 8 series, the extra colors are generated starting from the hue parsed from `--primary` and continuing along the golden angle; the shade is the color, with no contrast check against the surface |
| `"mono"`  | Locks the hue parsed from `--primary` and tells series apart through lightness steps and two saturation tiers, suited to bar/area charts that stay in step with the theme                                                                                                                         |
