## Usage

A module-level store shared across components via `useSyncExternalStore`. Reads `theme` from localStorage on load, applies it to `document.documentElement` (`.dark`, `color-scheme`) and follows the system color scheme when `theme` is `"system"`.

/>

Style templates do **not** switch at runtime — each template ships its own complete light + dark token set, chosen at install time. See [Styles](/docs/styles) and the [Default template preview](/templates/default). `useTheme` only drives the light / dark / system mode inside whichever template is installed.

## Color token families

The installed template defines two reusable palettes on `:root` / `.dark`:

### Surface (neutral)

| Token | Purpose |
|------|-------------|
| `--background` / `--foreground` | Containers that carry content, e.g. popover, sidebar, card, paper |
| `--muted` | Areas that should not draw attention, e.g. the app-level background; content containers are painted with the more prominent `--background`, so users focus on them against the muted backdrop |
| `--muted-foreground` | Description text, one step weaker than body text |
| `--accent` | Hover states and skeleton backgrounds |

### Brand

| Token | Purpose |
|------|-------------|
| `--primary` | The main brand color, used for emphasized actions and states |
| `--primary-accent` | The reinforced primary color, used for hover scenarios |
| `--ring` | Borders and focus outlines, also part of the brand color family |

## API Reference

### useTheme

```ts
function useTheme(): ThemeState
```

Returns a `ThemeState`:

| Property | Type | Description |
|------|------|-------------|
| `theme` | `'light' \| 'dark' \| 'system'` | Current color mode |
| `setTheme` | `(mode: ThemeMode) => void` | Set the color mode, persists and applies it |
| `toggleTheme` | `() => void` | Switch between light and dark (resolves system first) |

**Notes:**

- All state lives outside React; multiple components calling `useTheme` share one store and re-render together.
- Persisted under the `theme-storage` localStorage key.
- When `theme` is `"system"`, the stored value is kept and the applied mode follows `prefers-color-scheme` changes live.
