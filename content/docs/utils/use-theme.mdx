## API Reference

### useTheme

```ts
function useTheme(): ThemeState
```

Returns a `ThemeState`:

| Property | Type | Description |
|------|------|------|
| `theme` | `'light' \| 'dark' \| 'system'` | The current color mode |
| `setTheme` | `(mode: ThemeMode) => void` | Sets the color mode, persists and applies it |
| `toggleTheme` | `() => void` | Switches between light and dark (when `system`, resolves the system's actual mode first) |

**Notes:**

- All state lives outside React; multiple components calling `useTheme` share the same store and re-render together.
- Persisted under the `theme-storage` localStorage key.
- When `theme` is `"system"`, the stored value is kept and the applied mode follows `prefers-color-scheme` changes live.
