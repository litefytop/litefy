## API Reference

### useNavigator

A headless hook that manages filter values; pair it with the [Navigator](/docs/component/navigator) component or fully custom toolbars.

#### Options

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `fields` | `Record<string, unknown>` | - | Initial filter fields; each key maps to its default value. **Required** |
| `onValuesChange` | `(values: T) => void` | - | Fired with the next values whenever they change |

#### Returns

- `values`: Current filter values
- `setValue(key, value)`: Update a single field
- `setValues(patch)`: Merge multiple fields at once
- `reset()`: Restore every field back to its default
- `activeKeys`: Keys whose value differs from the default
- `activeCount`: Number of active (non-default) filters — handy for disabling reset or showing an active-filters badge
