## 用法

默认抽取 8 个固定颜色：日夜统一取 Tailwind 400 档，主题切换自动重算；系列数超过 8 时按黄金角续接生成。档位即档色，不做对底对比校验。SSR 首帧即用该固定色板，挂载后按实际主题色重算。

```tsx
import { useChartPalette } from "@/ui";

function Swatches() {
  const palette = useChartPalette();

  return (
    <div className="flex gap-2">
      {palette.map((color) => (
        <div key={color} className="rounded-md" style={{ width: "2rem", height: "2rem", background: color }} />
      ))}
    </div>
  );
}
```

```tsx
const palette = useChartPalette({ mode: "mono" });

const series = [
  { label: "Returning", stroke: palette[0], fill: palette[0] },
  { label: "New", stroke: palette[1], fill: palette[1] },
];
```

## API 参考

### useChartPalette

```ts
function useChartPalette(options?: ChartPaletteOptions): string[]
```

返回长度为 `count`（默认 8）的颜色数组，元素为 `oklch(L C H)` 形式的 CSS 颜色字符串。

#### ChartPaletteOptions

| 属性     | 类型                  | 说明                |
| ------ | ------------------- | ----------------- |
| `mode` | `"fixed" \| "mono"` | 取色模式，默认 `"fixed"` |

#### 取色模式

| 模式 | 行为 |
|------|------|
| `"fixed"` | 前 8 色从固定 Tailwind 色板交错排列按序抽取（red/green/blue/orange/cyan/violet/amber/pink，相邻抽取色相差 80°+）——日夜统一取 400 档；系列数超过 8 时，超出部分以 `--primary` 解析色相为起点按黄金角续接生成；档位即档色，不做对底对比校验 |
| `"mono"` | 锁定 `--primary` 解析色的色相，通过明度阶梯与两档饱和度区分系列，适合与主题保持一致的柱状/面积图 |
