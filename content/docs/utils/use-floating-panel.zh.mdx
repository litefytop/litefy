## 用法

`useFloatingPanel` 承担 `popover="manual"` 面板的完整生命周期：随 `open` 变化调用 `showPopover()` / `hidePopover()`，在面板外 `mousedown` 时关闭（可选择忽略锚点元素上的按下），打开时记录之前的焦点元素，关闭时若焦点将要丢失则恢复它。

它是 [PopoverContent](/docs/component/popover) 的 headless 对应物——[Popover](/docs/component/popover)、[Picker](/docs/component/picker) 和 [Select](/docs/component/select) 内部跑的就是这个 hook。当你用零件自行组装锚定面板时使用它：

```tsx
import { useRef, useState } from "react";
import { useFloatingPanel } from "@/ui";

function MyPanel() {
  const [open, setOpen] = useState(false);
  const panelRef = useRef<HTMLDivElement>(null);

  useFloatingPanel({
    open,
    panelRef,
    onOpenChange: setOpen,
    restoreFocus: true,
  });

  return (
    <div ref={panelRef} popover="manual" className="not-open:hidden">
      {/* 面板内容 */}
    </div>
  );
}
```

Escape 处理刻意留给调用方（通过 `onKeyDown`），因为不同面板对键盘的预期不同——输入框型选择器在输入框上响应 Escape，菜单在面板上响应。

## API 参考

### 选项（`UseFloatingPanelOptions`）

| Option         | Type                                    | Default | Description                                  |
| :------------- | :-------------------------------------- | :------ | :------------------------------------------- |
| `open`         | `boolean`                               | -       | 面板是否应当显示                              |
| `panelRef`     | `React.RefObject<HTMLElement \| null>`  | -       | 面板元素的 ref（即 `popover="manual"` 元素）  |
| `onOpenChange` | `(open: boolean) => void`               | -       | 外部按下请求关闭时以 `false` 回调             |
| `anchorRef`    | `React.RefObject<HTMLElement \| null>`  | -       | 该元素内的按下不算外部（例如触发器）          |
| `restoreFocus` | `boolean`                               | `false` | 关闭时若焦点丢失，恢复到打开前聚焦的元素      |
| `focusOnOpen`  | `boolean`                               | `false` | 打开时将焦点移入面板第一个可聚焦元素（或面板）|
