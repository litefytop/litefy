## 用法

通过 `useSyncExternalStore` 共享的模块级全局状态。加载时从 localStorage 读取 `theme`，应用到 `document.documentElement`（`.dark`、`color-scheme`），`theme` 为 `"system"` 时跟随系统配色。

风格模板**不做运行时切换**——每个模板自带完整的亮色 + 暗色令牌集，在安装时选定。详见[样式](/docs/styles)与[默认方案预览](/templates/default)。`useTheme` 只负责已安装模板内部的亮 / 暗 / 跟随系统模式。

## 颜色令牌家族

已安装的模板在 `:root` / `.dark` 上定义两组可复用色板：

### Surface（表面）

Surface 是用于容器的中性色系：

| Token | 用途 |
|------|------|
| `--background` / `--foreground` | 承载内容的容器，如 popover、sidebar、card、paper |
| `--muted` | 不需要过分关注的区域，比如应用的整体背景；容器使用更显眼的 `--background`，对比之下用户更容易关注承载内容的容器 |
| `--muted-foreground` | 描述类文字，比正文弱一级 |
| `--accent` | hover 色、骨架屏背景色 |

### Brand（品牌）

Brand 是主题色，除默认黑白主题外都是彩色的：

| Token | 用途 |
|------|------|
| `--primary` | 品牌主色，用于重点操作与强调状态 |
| `--primary-accent` | primary 的加强色，用于 hover 场景 |
| `--ring` | 用于 border 和外边框（焦点环），同属品牌色系 |

## API 参考

### useTheme

```ts
function useTheme(): ThemeState
```

返回 `ThemeState`：

| 属性 | 类型 | 说明 |
|------|------|------|
| `theme` | `'light' \| 'dark' \| 'system'` | 当前颜色模式 |
| `setTheme` | `(mode: ThemeMode) => void` | 设置颜色模式，持久化并应用 |
| `toggleTheme` | `() => void` | 在亮色与暗色之间切换（system 时先解析系统实际模式） |

**注意：**

- 全部状态存放在 React 之外；多个组件调用 `useTheme` 共享同一个 store，一起重渲染。
- 持久化在 `theme-storage` localStorage 键下。
- `theme` 为 `"system"` 时保留存储值，实际应用模式随 `prefers-color-scheme` 实时变化。
