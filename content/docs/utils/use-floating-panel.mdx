## Usage

The full lifecycle of a `popover="manual"` panel: show/hide, outside-press close and focus restore.

```tsx
import { useRef, useState } from "react";
import { useFloatingPanel } from "@/ui";

function MyPanel() {
  const [open, setOpen] = useState(false);
  const panelRef = useRef<HTMLDivElement>(null);

  useFloatingPanel({
    open,
    panelRef,
    onOpenChange: setOpen,
    restoreFocus: true,
  });

  return (
    <div ref={panelRef} popover="manual">
      
    </div>
  );
}
```

## API Reference

### Options (`UseFloatingPanelOptions`)

| Option         | Type                                    | Description                                                                                      |
| :------------- | :-------------------------------------- | :----------------------------------------------------------------------------------------------- |
| `open`         | `boolean`                               | Whether the panel should be shown                                                                |
| `panelRef`     | `React.RefObject<HTMLElement \| null>`  | Ref to the panel element (the `popover="manual"` element)                                        |
| `onOpenChange` | `(open: boolean) => void`               | Called with `false` when an outside press requests a close                                       |
| `anchorRef`    | `React.RefObject<HTMLElement \| null>`  | Presses inside this element do not count as outside (e.g. the trigger)                           |
| `restoreFocus` | `boolean`                               | On close, if focus was lost, restore it to the element focused before open, defaults to `false`  |
| `focusOnOpen`  | `boolean`                               | On open, move focus into the panel's first focusable element (or the panel), defaults to `false` |

### Float positioning (`data-float-*`)

`positionFloatingPanel` (publicly exported; `useFloatingPanel` calls it through `showFloatingPanel` on open) positions the panel by reading only the attributes on the panel itself. The anchor is the element whose `data-anchor-name` equals the panel's `data-float-anchor` — matched by two attributes in the DOM, no prop, no context, no registry. Component pages list only the values they each emit; this section is the source of truth for the mechanism.

| Attribute | Default | Behaviour |
| :-------- | :------ | :-------- |
| `data-float-anchor` | - | The anchor element's `data-anchor-name`; absent, or no element carries that name → the panel is never positioned |
| `data-float-x` + `data-float-y` | - | Both present → point anchor: a zero-size rect at that viewport point, taking precedence over `data-float-anchor` |
| `data-float-gap` | `4` | Pixels between the anchor edge and the panel edge |
| `data-float-side` | `bottom` | `top` / `bottom` / `left` / `right`; any other value falls back to `bottom` |
| `data-float-align` | `center` | `start` / `center` / `end` on the cross axis; any other value falls back to `center` |
| `data-float-match-width` | - | `"true"` → the anchor's width is written to the panel's inline `width` |

Placement runs in the order below and writes only the panel's own inline style:

1. Element anchor: when the requested side does not fit and the opposite side does, flip to the opposite; when neither fits, the request stands.
2. Element anchor: place the cross axis by `align` first, then clamp that coordinate into the viewport, so an over-long panel keeps its start edge on screen.
3. Point anchor: the panel docks at `bottom` / `start` off the point, flips to the other side of the point on overflow, and never matches width.
4. Writes `position: fixed` and the rounded `left` / `top`.
5. `showFloatingPanel` parks the panel at `-9999px` first and positions it after calling `showPopover()`, so the panel never paints a frame in the wrong place.

`useFloatingPosition(panelRef, watch)` repositions when the panel `toggle`s to open, then follows `scroll` and `resize` — both event types are coalesced through `requestAnimationFrame` before repositioning; nothing runs while the panel is closed. `watch` carries the panel's own placement values — change them and an open panel is repositioned.

The outside-press close reads the same pair of attributes: a press inside the element named by the panel's `data-float-anchor` is not an outside press.
