## 用法

`useLoadMore` 对本地（内存中）数据做分页：保留完整数组，只渲染 `items.slice(0, visibleCount)`，并把 `sentinelRef` 挂到列表后面的空元素上。当哨兵进入距视口 `rootMargin` 的范围时，自动展示下一页。观察器在每次增长后重新布防，因此较短的页面会持续自动加载，直到哨兵被推出触发范围。

```tsx
import { useLoadMore } from "@/ui";

function PhotoFeed({ photos }: { photos: Photo[] }) {
  const { visibleCount, hasMore, loadMore, sentinelRef } = useLoadMore({
    total: photos.length,
    pageSize: 12,
  });
  const visible = photos.slice(0, visibleCount);

  return (
    <>
      {visible.map((photo) => (
        <PhotoCard key={photo.id} photo={photo} />
      ))}
      {hasMore ? (
        <div ref={sentinelRef} aria-hidden className="h-px" />
      ) : (
        <p>已加载全部 {photos.length} 条</p>
      )}
    </>
  );
}
```

要在可滚动容器（而非页面）内加载，把容器作为 `root` 传入并相应缩小 `rootMargin`。与 [Masonry](/docs/component/masonry) 搭配即可实现滚动加载的瀑布流。

## API 参考

### 选项（`UseLoadMoreOptions`）

| Option         | Type                                        | Default   | Description                                       |
| :------------- | :------------------------------------------ | :-------- | :------------------------------------------------ |
| `total`        | `number`                                    | -         | 本地数据总量                                        |
| `pageSize`     | `number`                                    | `12`      | 每次展示的条数                                       |
| `initialCount` | `number`                                    | `pageSize`| 初始可见条数                                         |
| `onLoadMore`   | `(visibleCount: number) => void`            | -         | 可见条数增长后调用                                   |
| `rootMargin`   | `string`                                    | `"400px"` | 哨兵距根元素多远时触发                                |
| `enabled`      | `boolean`                                   | `true`    | 设为 `false` 暂停自动加载（改为手动调用 `loadMore`）    |
| `root`         | `React.RefObject<HTMLElement \| null>`      | viewport  | 观察根元素；传入可滚动元素可将加载限定在内部容器内       |

### 返回值（`UseLoadMoreReturn`）

| Member         | Type                                     | Description                                       |
| :------------- | :--------------------------------------- | :------------------------------------------------ |
| `visibleCount` | `number`                                 | 当前可见条数 —— 用 `items.slice(0, visibleCount)` 切片 |
| `hasMore`      | `boolean`                                | 是否还有未展示的数据                                 |
| `loadMore`     | `() => void`                             | 手动展示下一页                                       |
| `sentinelRef`  | `React.RefCallback<HTMLElement>`         | 挂到列表后方哨兵元素上                                |
