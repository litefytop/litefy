## Usage

A Popover + listbox multi-select control driven by `options`, with grouping support.

<ComponentPreview name="multi-select-basic" />

### Disabled

Group-level `disabled` natively disables the trigger and prevents the panel from opening; each option's `disabled` independently sets `aria-disabled`, and click and keyboard toggling are blocked by JavaScript. The trigger and options use `bg-disabled`, `text-disabled-fg` and `cursor-not-allowed`.

## API Reference

### High-level Components

Ready-to-use composite components.

#### MultiSelect

| Prop           | Type                                           | Description                                  |
| -------------- | ---------------------------------------------- | -------------------------------------------- |
| `options`      | `MultiSelectOption[]` **required**             | Options: label, value, group and disabled     |
| `value`        | `string[]`                                     | Controlled selected values                   |
| `defaultValue` | `string[]`                                     | Initial selected values (uncontrolled), defaults to `[]` |
| `onChange`     | `(values: string[]) => void`                   | The full selected values after each toggle   |
| `trigger`      | `React.ReactNode`                              | Custom trigger content; defaults to a placeholder-text button |
| `placeholder`  | `string`                                       | Placeholder text; also the panel's `aria-label`, defaults to `Select options` |
| `disabled`     | `boolean`                                      | Disables the trigger button, defaults to `false` |
| `className`    | `string`                                       | Custom class name for the trigger button; defaults to `w-full min-w-0 max-w-[20rem]` (maximum 20rem) |
| `classNames`   | `{ content?: string; list?: string; group?: string; option?: SlotClassName; check?: SlotClassName }` | `content` controls the options panel; `list` controls the inner list; `option` / `check` receive `({ disabled }) => string`; the remaining slots take fixed class names |
| `styles`       | `{ list?: React.CSSProperties; option?: React.CSSProperties }` | Inline styles for the inner list and options; there is no `content` style slot. The panel defaults to a maximum width of 20rem, limited by the viewport width minus 1rem |
| `...props`     | `React.ComponentProps<"button">`               | Supports native trigger-button props (except `children` and the like) |

### MultiSelectOption

| Property | Type | Description |
| ---- | ---- | ---- |
| `label` | `string` | The option label |
| `value` | `string` | The option value |
| `group` | `string` | Group name — when provided, a group header is rendered and the group's options are indented |
| `disabled` | `boolean` | Disables the option |

## Keyboard Interactions

| Key | Description |
| --- | --- |
| `↑` / `↓` | Move the highlight among options (wrapping) |
| `Enter` / `Space` | Toggle the highlighted option's selected state (the panel stays open) |
| `Escape` | Closes the panel and returns focus to the trigger button |

## Data Attributes

| Attribute | Description |
| --- | --- |
| `[data-selected]` | On an option — the option is selected |
| `[data-highlighted]` | On an option — the item the keyboard highlight sits on |
| `[data-disabled]` | On an option — present when the group or the option is disabled, together with `aria-disabled="true"` |
