MultiSelect is not a shipped component with source code. It is a composition of two primitives: [Popover](/docs/component/popover) provides the trigger and the floating panel, and [CheckboxGroup](/docs/component/checkbox) provides the option list with multi-select state. Assemble them directly in your page — the demo below is the complete implementation.

## Usage

### Basic Usage

Hold the selected values in your own state, put `CheckboxGroup` inside the Popover content, and show the selection count on the trigger.

<ComponentPreview
  name="multi-select-basic"
/>

Key points of the assembly:

- Popover's `open` / `onOpenChange` control the panel; `PopoverContent` already carries the panel look, so the checkbox list needs no extra container styling.
- Clicks inside the panel never close it — Popover only closes on outside mousedown or `Escape` — so users can toggle several checkboxes freely.
- `CheckboxGroup` is controlled (`value` / `onChange` with `string[]`); write the values back to your page state and derive the trigger label from them. Always render the count (e.g. `` `Categories (${values.length})` ``) instead of switching between different labels, so the trigger keeps a stable width and avoids layout shift.
- Focus lands on the first checkbox when the panel opens; `Tab` walks through checkboxes, `Space` toggles, and `Escape` closes the panel. Arrow keys cycle focus between options inside a `Checkbox.Group` (disabled options are skipped).

Refer to the [Popover API](/docs/component/popover) and [Checkbox API](/docs/component/checkbox) for the full prop tables of both parts.

### Grouped Usage

`CheckboxGroup`'s `options` also accepts the `{ group, options }` form, rendering a grouped list with headers.

/>

Grouping is purely presentational — every option's `value` still flows into the same `string[]` state, exactly like the basic usage.
