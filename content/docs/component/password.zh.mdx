## API 参考

### 高阶组件

开箱即用的组合组件。

#### Password

| 属性                | 类型                                                       | 描述                                                                                   |
| ----------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `value`           | `string`                                                 | 受控的密码值                                                                               |
| `visible`         | `boolean`                                                | 受控的可见性状态                                                                             |
| `defaultVisible`  | `boolean`                                                | 非受控模式下的默认可见性状态，默认 `false`                                                            |
| `onVisibleChange` | `(visible: boolean) => void`                             | 可见性状态变化时触发的回调函数                                                                      |
| `invalid`         | `boolean`                                                | 是否处于无效状态，默认 `false`                                                                  |
| `className`       | `string`                                                 | 自定义类名，作用于外壳容器                                                                        |
| `style`           | `React.CSSProperties`                                    | 内联样式，作用于外壳容器                                                                         |
| `classNames`      | `{ root?; toggle?; toggleIcon?; hint? }` —— 值均为 `string` | 内部输入框（`root`）、切换按钮、内置眼睛图标（`toggleIcon`）、以及 `⇧ Shift` 提示行（`hint`）的自定义类名               |
| `styles`          | `{ root?; toggle? }` —— 值均为 `React.CSSProperties`        | 内部输入框（`root`）与切换按钮的内联样式                                                              |
| `disabled`        | `boolean`                                                | 禁用输入框和切换按钮，默认 `false`                                                                |
| `...props`        | `React.ComponentProps<"input">`                          | 支持所有原生 input 属性（除 `type`、`className` 外），如 `placeholder`、`name`、`required`            |

### 可组合组件

#### PasswordGroup

输入框与切换按钮共用的外壳包装容器；`invalid` 时发出 `data-invalid`。

| 属性          | 类型                            | 描述                                            |
| ----------- | ----------------------------- | --------------------------------------------- |
| `invalid`   | `boolean`                     | 应用 `data-invalid` 和 `aria-invalid`，默认 `false` |
| `className` | `string`                      | 自定义 CSS 类                                     |
| `...props`  | `React.ComponentProps<"div">` | 支持所有原生 div 属性                                 |

#### PasswordRoot

在 `password` 和 `text` 类型之间切换的原生输入框。

| 属性          | 类型                              | 描述                                                            |
| ----------- | ------------------------------- | ------------------------------------------------------------- |
| `visible`   | `boolean`                       | 为 `true` 时渲染为 `type="text"`，否则为 `type="password"`，默认 `false`  |
| `className` | `string`                        | 自定义 CSS 类                                                     |
| `...props`  | `React.ComponentProps<"input">` | 支持所有原生 input 属性（除 `type`、`className` 外）                       |

#### PasswordToggle

带眼睛图标和 `aria-pressed` 状态的可见性切换按钮。

| 属性           | 类型                               | 描述                                                    |
| ------------ | -------------------------------- | ----------------------------------------------------- |
| `visible`    | `boolean`                        | 驱动 `aria-pressed`、`aria-label` 和默认图标，默认 `false`       |
| `className`  | `string`                         | 自定义 CSS 类                                             |
| `classNames` | `{ icon? }` —— 值均为 `string`      | 内置眼睛图标的类名；用 `children` 换掉图标时不带任何类名                    |
| `children`   | `React.ReactNode`                | 自定义图标内容，替换默认的眼睛图标                                     |
| `...props`   | `React.ComponentProps<"button">` | 支持所有原生 button 属性（除 `className` 外）                     |

## 键盘交互

| Key | Description |
| --- | --- |
| `Shift` | 输入框聚焦时单独按下再松开 `Shift` 即可切换可见性——切换按钮本身仅响应指针，不在 Tab 序列中 |

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-invalid]` | 位于外壳上——`invalid` 为 true 时存在 |
