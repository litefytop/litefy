## API 参考

### 高级组件

开箱即用的组合组件。

#### Password

| 属性              | 类型                                    | 默认值  | 描述                                                                                 |
| ----------------- | --------------------------------------- | ------- | ------------------------------------------------------------------------------------ |
| `value`           | `string`                                | -       | 受控的密码值                                                                         |
| `visible`         | `boolean`                               | -       | 受控的可见性状态                                                                     |
| `defaultVisible`  | `boolean`                               | `false` | 非受控模式下的默认可见性状态                                                         |
| `onVisibleChange` | `(visible: boolean) => void`            | -       | 可见性状态变化时触发的回调函数                                                       |
| `invalid`         | `boolean`                               | `false` | 是否处于无效状态                                                                     |
| `classNames`      | `{ group?, root?, toggle?: ClassNameValue }` | -  | 定制 group、输入框和切换按钮的自定义类名                                             |
| `styles`          | `{ group?, root?, toggle?: React.CSSProperties }` | - | 定制 group、输入框和切换按钮的内联样式                                        |
| `disabled`        | `boolean`                               | `false` | 禁用输入框和切换按钮                                                                 |
| `...props`        | `React.ComponentProps<"input">`         | -       | 支持所有原生 input 属性（除 `type`、`className` 外），如 `placeholder`、`name`、`required` |

### 可组合组件

#### PasswordGroup

承载边框、focus-within 环和无效状态样式的包装容器。

| 属性       | 类型                          | 默认值  | 描述                                        |
| ---------- | ----------------------------- | ------- | ------------------------------------------- |
| `invalid`  | `boolean`                     | `false` | 应用 `data-invalid` 和 `aria-invalid`       |
| `className` | `ClassNameValue`             | -       | 自定义 CSS 类                               |
| `...props` | `React.ComponentProps<"div">` | -       | 支持所有原生 div 属性                       |

#### PasswordRoot

在 `password` 和 `text` 类型之间切换的原生输入框。

| 属性       | 类型                            | 默认值  | 描述                                                          |
| ---------- | ------------------------------- | ------- | ------------------------------------------------------------- |
| `visible`  | `boolean`                       | `false` | 为 `true` 时渲染为 `type="text"`，否则为 `type="password"`    |
| `className` | `ClassNameValue`               | -       | 自定义 CSS 类                                                 |
| `...props` | `React.ComponentProps<"input">` | -       | 支持所有原生 input 属性（除 `type`、`className` 外）          |

#### PasswordToggle

带眼睛图标和 `aria-pressed` 状态的可见性切换按钮。

| 属性       | 类型                             | 默认值  | 描述                                                  |
| ---------- | -------------------------------- | ------- | ----------------------------------------------------- |
| `visible`  | `boolean`                        | `false` | 驱动 `aria-pressed`、`aria-label` 和默认图标          |
| `className` | `ClassNameValue`                | -       | 自定义 CSS 类                                         |
| `children` | `React.ReactNode`                | -       | 自定义图标内容，替换默认的眼睛图标                    |
| `...props` | `React.ComponentProps<"button">` | -       | 支持所有原生 button 属性（除 `className` 外）         |
