## API 参考

### 高阶组件

开箱即用的成品组件。

#### Input

带有插槽和验证支持的输入框组件。

| Prop         | Type                                              | Default  | Description                           |
| ------------ | ------------------------------------------------- | -------- | ------------------------------------- |
| `type`       | `'text' \| 'email' \| 'url' \| 'tel' \| 'search'` | -        | 输入类型                              |
| `leading`    | `ReactNode`                                       | -        | 前置插槽内容（如图标）                |
| `trailing`   | `ReactNode`                                       | -        | 后置插槽内容（如按钮、图标）          |
| `invalid`    | `boolean`                                         | -        | 输入框是否处于无效状态                |
| `className` | `ClassNameValue` | - | 自定义类名，作用于外壳容器 |
| `style` | `React.CSSProperties` | - | 内联样式，作用于外壳容器 |
| `classNames` | `{ leading?: ClassNameValue; trailing?: ClassNameValue; root?: ClassNameValue }` | - | 前后置插槽与内部输入框（`root`）的自定义类名 |
| `styles` | `{ leading?: React.CSSProperties; trailing?: React.CSSProperties; root?: React.CSSProperties }` | - | 前后置插槽与内部输入框（`root`）的内联样式 |
| `...props`   | `React.ComponentProps<"input">`                   | -        | 支持全部 input 原生属性（除 `type`、`className`） |
