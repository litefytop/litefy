## 注意

- DropdownMenu 内部由 [Popover](/docs/component/popover) 和 [Menu](/docs/component/menu) 组合而成——CLI 安装时会自动解析并安装这些依赖。
- 触发器默认使用 Button 的 primary 变体样式；可传入自定义 `trigger` 节点覆盖。
- `Menu` 接收 `autoFocus={open}`，每次打开面板时自动聚焦第一个可用项——方向键立即可用。
- 选中菜单项或按 Escape 关闭面板；焦点自动还给触发器（Popover 内置行为）。
- 子菜单的悬停展开、ArrowRight / ArrowLeft 导航、面板外 mousedown 关闭均由 Menu 内部处理。

## API 参考

### DropdownMenu

| 属性 | 类型 | 默认值 | 描述 |
| :--- | :--- | :----- | :--- |
| `trigger` | `React.ReactNode` | - | 触发器文案或节点 |
| `items` | `MenuConfig[]` | - | 菜单项（分组、子菜单、叶子项） |
| `onSelect` | `(item: MenuItemConfig) => void` | - | 点击叶子项时触发 |
| `alignX` | `"start" \| "end" \| "center"` | `"start"` | 面板相对触发器的对齐方式 |
| `className` | `ClassNameValue` | - | 触发器按钮的自定义类名 |
| `classNames` | `{ content? / item? / label? / sub? }` | - | 面板、菜单项、标签、子菜单的自定义类名 |
