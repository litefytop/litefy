## 用法

由 [Popover](/docs/component/popover) + [Menu](/docs/component/menu) 组合而成——CLI 安装时自动解析依赖。

<ComponentPreview
  name="dropdown-menu-basic"
/>

选中菜单项或按 Escape 关闭面板，焦点自动还给触发器；`autoFocus={open}` 使每次打开时自动聚焦第一个可用项。

## API 参考

### DropdownMenu

| 属性 | 类型 | 默认值 | 描述 |
| :--- | :--- | :----- | :--- |
| `trigger` | `React.ReactNode` | - | 触发器文案或节点 |
| `items` | `MenuConfig[]` | - | 菜单项（分组、子菜单、叶子项） |
| `onSelect` | `(item: MenuItemConfig) => void` | - | 点击叶子项时触发 |
| `alignX` | `"start" \| "end" \| "center"` | `"center"` | 面板相对触发器的对齐方式 |
| `className` | `ClassNameValue` | - | 触发器按钮的自定义类名 |
| `classNames` | `{ content? / item? / label? / sub? }` | - | 面板、菜单项、标签、子菜单的自定义类名 |
