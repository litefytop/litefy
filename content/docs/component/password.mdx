## API Reference

### High-level Components

Ready-to-use composite component.

#### Password

| Prop              | Type                                                     | Description                                                                                                                                |
| ----------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `value`           | `string`                                                 | Controlled password value                                                                                                                  |
| `visible`         | `boolean`                                                | Controlled visibility state                                                                                                                |
| `defaultVisible`  | `boolean`                                                | Default visibility state (uncontrolled), defaults to `false`                                                                               |
| `onVisibleChange` | `(visible: boolean) => void`                             | Callback fired when the visibility state changes                                                                                           |
| `invalid`         | `boolean`                                                | Whether the input is in an invalid state, defaults to `false`                                                                              |
| `className`       | `string`                                                 | Custom class names, applied to the shell container                                                                                         |
| `style`           | `React.CSSProperties`                                    | Inline styles, applied to the shell container                                                                                              |
| `classNames`      | `{ root?; toggle?; toggleIcon?; hint? }` — each `string` | Custom classes for the inner input (`root`), the toggle button, the built-in eye icon (`toggleIcon`), and the `⇧ Shift` hint line (`hint`) |
| `styles`          | `{ root?; toggle? }` — each `React.CSSProperties`        | Inline styles for the inner input (`root`) and the toggle button                                                                           |
| `disabled`        | `boolean`                                                | Disables the input and the toggle button, defaults to `false`                                                                              |
| `...props`        | `React.ComponentProps<"input">`                          | Supports all native input props (except `type`, `className`), such as `placeholder`, `name`, `required`                                    |

### Composable Components

#### PasswordGroup

The shell wrapper shared by the input and the toggle button; emits `data-invalid` when `invalid` is set.

| Prop        | Type                          | Description                                                    |
| ----------- | ----------------------------- | -------------------------------------------------------------- |
| `invalid`   | `boolean`                     | Applies `data-invalid` and `aria-invalid`, defaults to `false` |
| `className` | `string`                      | Custom CSS class                                               |
| `...props`  | `React.ComponentProps<"div">` | Supports all native div props                                  |

#### PasswordRoot

The native input switching between the `password` and `text` types.

| Prop        | Type                            | Description                                                                            |
| ----------- | ------------------------------- | -------------------------------------------------------------------------------------- |
| `visible`   | `boolean`                       | When `true` renders as `type="text"`, otherwise `type="password"`, defaults to `false` |
| `className` | `string`                        | Custom CSS class                                                                       |
| `...props`  | `React.ComponentProps<"input">` | Supports all native input props (except `type`, `className`)                           |

#### PasswordToggle

The visibility toggle button with eye icons and `aria-pressed` state.

| Prop         | Type                             | Description                                                                              |
| ------------ | -------------------------------- | ---------------------------------------------------------------------------------------- |
| `visible`    | `boolean`                        | Drives `aria-pressed`, `aria-label` and the default icon, defaults to `false`            |
| `className`  | `string`                         | Custom CSS class                                                                         |
| `classNames` | `{ icon? }` — each `string`      | Class for the built-in eye icon; when `children` replaces the icon it carries no classes |
| `children`   | `React.ReactNode`                | Custom icon content, replaces the default eye icons                                      |
| `...props`   | `React.ComponentProps<"button">` | Supports all native button props (except `className`)                                    |

## Keyboard Interactions

| Key | Description |
| --- | --- |
| `Shift` | Press and release `Shift` alone while the input is focused to toggle visibility — the toggle button itself responds only to pointer input and is not in the tab order |

## Data Attributes

| Attribute | Description |
| --- | --- |
| `[data-invalid]` | On the shell — present when `invalid` is true |
