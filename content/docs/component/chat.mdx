## Usage

A controlled conversation stream: pass `chats` and per-role metadata, and the list renders avatars, names, bubbles and an action row.

## API Reference

### Chat

| Prop                    | Type                                                                                                                           | Description                                                                                        |
| :---------------------- | :----------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------- |
| `chats`                 | `ChatMessage[]`                                                                                                                | Controlled message list                                                                            |
| `roleConfig`            | `Record<string, { name?, avatar? }>`                                                                                           | Per-role metadata, keyed by the message `role`                                                     |
| `align`                 | `"leftRight" \| "leftAlign"`                                                                                                   | `leftRight` mirrors user rows to the right; `leftAlign` stacks all left, defaults to `"leftRight"` |
| `mode`                  | `"bubble" \| "noBubble" \| "userBubble"`                                                                                       | Who gets a bubble, defaults to `"bubble"`                                                          |
| `hints`                 | `string[]`                                                                                                                     | Hint chips rendered after the list                                                                 |
| `onHintClick`           | `(hint: string) => void`                                                                                                       | Hint chip clicked                                                                                  |
| `onMessageCopy`         | `(message) => void`                                                                                                            | Fired after the copy button writes the clipboard                                                   |
| `onMessageGoodFeedback` | `(message) => void`                                                                                                            | Like toggled on                                                                                    |
| `onMessageBadFeedback`  | `(message) => void`                                                                                                            | Dislike toggled on                                                                                 |
| `onMessageReset`        | `(message) => void`                                                                                                            | Renders the regenerate button and fires on click                                                   |
| `renderMessageContent`  | `(message) => ReactNode`                                                                                                       | Full-content render override                                                                       |
| `className`             | `string`                                                                                                                       | Applied to the root `div`                                                                          |
| `classNames`            | `{ root?, list?, message?, main?, avatar?, name?, content?, contentItem?, actions?, action?, hints?, hint?, typing?: string }` | Custom classes on the slots                                                                        |
| `...props`              | `React.ComponentProps<"div">`                                                                                                  | Spread onto the root `div`                                                                         |

`ChatMessage`: `{ id, role, content?: string \| ContentItem[], status? }` with six statuses (`queued`, `in_progress`, `incomplete`, `completed`, `failed`, `cancelled`). `content` blocks support `text` / `input_text` / `output_text`, `input_image`, `input_file`, `reasoning` and `function_call` shapes out of the box.

## Keyboard Interactions

| Key | Description |
| :-- | :---------- |
| `Enter` / `Space` | Activates hint chips and action buttons — all native `button`s |

## Data Attributes

| Attribute | Description |
| :-------- | :---------- |
| `[data-align]` | On the root — the layout mode |
| `[data-mode]` | On the root — the bubble mode |
| `[data-user]` | On each message row — `"true"` for the user role |
| `[data-status]` | On each message row — the message status |
| `[data-active]` | On like / dislike buttons — local toggle state |
| `[data-typing]` | On the waiting-state dots |
