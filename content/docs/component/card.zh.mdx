## API 参考

### Card

玻璃拟态卡片表面，悬停上浮并伴随柔和阴影与渐入的氛围光晕。光晕颜色可通过 `--card-glow` CSS 变量自定义。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性 |
