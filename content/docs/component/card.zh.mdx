## API 参考

### Card

玻璃拟态**静态**卡片表面，固定 `shadow-base`（`rounded-lg`）——无 hover 抬升与动效，静态容器不伪装成可点击。需要卡片形态的交互组件请使用 [CardButton](#cardbutton)。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性 |
