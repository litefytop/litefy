## API 参考

### Card

玻璃拟态卡片表面，悬停上浮并伴随柔和阴影与渐入的氛围光晕。光晕是固定在左上角（`at 25% 25%`）的径向渐变遮罩，颜色为 `from-primary/15`——跟随主题主色，无法通过 CSS 变量自定义。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性 |
