## API Reference

### Kbd

A static keyboard key visual — non-interactive, with no hover or active states. Border uses the default border token; depth comes from the built-in `shadow-subtle`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | Custom CSS class |
| `...props` | `React.ComponentProps<"kbd">` | - | Supports all native kbd props |
