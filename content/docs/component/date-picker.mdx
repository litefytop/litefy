### Disabled

`disabled` natively disables both the input and the calendar controls; JavaScript blocks opening, input submission, date selection, and keyboard navigation. The disabled appearance uses `bg-disabled`, `text-disabled-fg`, and `cursor-not-allowed`.

## API Reference

### DatePicker

A controlled-or-uncontrolled date field; the visible month and panel open state are managed internally.

| Prop              | Type                                                 | Description                                                                                          |
| :---------------- | :--------------------------------------------------- | :--------------------------------------------------------------------------------------------------- |
| `value`           | `Date \| null`                                       | Controlled selected date                                                                             |
| `defaultValue`    | `Date \| null`                                       | Initial selected date (uncontrolled)                                                                 |
| `onValueChange`   | `(date: Date) => void`                               | Fired when a date is committed — picked from the panel, or `Enter` on a complete typed date          |
| `placeholder`     | `string`                                             | Input placeholder, defaults to `"Select or type a date"`                                             |
| `disabled`        | `boolean`                                            | Disables the input and the panel                                                                     |
| `invalid`         | `boolean`                                            | External invalid state — emits `aria-invalid` (also set internally when validation clears the input) |
| `firstDayOfWeek`  | `0 \| 1`                                             | First day of the calendar week (`0` = Sunday, `1` = Monday), defaults to `0`                         |
| `isDateDisabled`  | `(date: Date) => boolean`                            | Predicate disabling calendar dates                                                                   |
| `trailing`        | `React.ReactNode`                                    | Trailing decoration inside the input, defaults to `CalendarIcon`                                     |
| `onKeyDown`       | `React.KeyboardEventHandler<HTMLInputElement>`       | Runs before the built-in `Enter` commit; `preventDefault()` cancels it                               |
| `classNames`      | `{ root?: string; input?: string; trailing?: string; popover?: string; panel?: string; calendar?: CalendarClassNames }` | `root` controls the field root (20rem maximum by default), `input` the inner input, `popover` the floating layer (20rem maximum width by default, constrained by the viewport width minus 1rem), and `panel` the calendar panel |
| `styles`          | `{ input?; trailing? }` — each `React.CSSProperties` | Inline styles for the input and trailing decoration only; there are no root or popover style slots      |

While the panel is open, `ArrowDown` / `ArrowUp` move focus into the calendar's first / last control; `Escape` closes it and returns focus to the input.

## Keyboard Interactions

| Key | Description |
| --- | --- |
| `Enter` | Parses the typed text — commits a full valid date, or jumps to the month / year view for partial input |
| `Escape` | Closes the panel and re-applies the parse to the typed text |
| `ArrowDown` | Opens the panel from the input; while open, moves focus into the panel |

Typing a full valid date live-syncs the calendar selection without closing the panel.

## Data Attributes

| Attribute | Description |
| --- | --- |
| `[data-open]` | On the root — present while the panel is open |
| `[data-disabled]` | On the root — present when the entire date picker is disabled |
