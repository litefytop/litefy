## Usage

`Capsule` is a pill-shaped overflow-hidden container. Put two [Tag](/docs/component/tag) children inside — pass `rounded-none px-2.5 py-1` to each tag for badge proportions — and you get a shields-io style two-color badge in seconds.

<ComponentPreview name="capsule-badge" />

### Composition

The left tag acts as the label, the right one as the value. Colors are plain utilities on each tag. `Capsule` always renders a `div` — there is no `as` prop. For a clickable badge, nest a native `<a>` (or `button`) inside the container:

```tsx
<Capsule>
  <Tag className="rounded-none px-2.5 py-1 bg-neutral-600 text-white">build</Tag>
  <Tag className="rounded-none px-2.5 py-1 bg-emerald-600 text-white">passing</Tag>
</Capsule>

<Capsule>
  <Tag className="rounded-none px-2.5 py-1 bg-neutral-600 text-white">docs</Tag>
  <a href="#" className="rounded-none px-2.5 py-1 bg-violet-600 text-white">litefy.dev</a>
</Capsule>
```

## Notes

- `rounded-none px-2.5 py-1` on the tags neutralizes their radius and bumps padding for badge proportions.
- More than two tags work too: the container just clips whatever is inside.
- `Capsule.className` is the static base class string of the pill container — apply it to a native `a` / `button` when the capsule itself must carry the semantics.

## API Reference

### Capsule

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | Custom CSS class, merged with the base `Capsule.className` |
| `...props` | `React.ComponentProps<"div">` | - | Supports all native div props (except `className`) |

### Statics

| Member | Type | Description |
|--------|------|-------------|
| `Capsule.className` | `string` | Base class string of the pill container, for reuse on native elements |
