## 用法

经典数字输入框，可选 `prefix` / `suffix`，键盘与聚焦后滚轮步进。

<ComponentPreview name="number-input-basic" />

### 禁用

`disabled` 原生禁用输入框，输入外壳使用 `bg-disabled`、`text-disabled-fg` 与 `cursor-not-allowed`，键盘和滚轮输入随之阻断。

## API 参考

### NumberInput

| 属性                | 类型                                                                           | 描述                                                                 |
| ----------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `defaultValue`    | `number \| string`                                                           | 初始值（非受控模式）                                                         |
| `value`           | `number \| string \| undefined`                                              | 当前值（受控模式）                                                          |
| `onValueChange`   | `(value?: number) => void \| (value?: string) => void`                       | 值变化回调。`positiveInteger=true` 时为 `number \| undefined`，否则为 `string` |
| `invalid`         | `boolean`                                                                    | 输入框是否处于无效状态                                                        |
| `min`             | `number`                                                                     | 允许的最小值；需要负数下界时显式传入，默认 `0`                                          |
| `max`             | `number`                                                                     | 允许的最大值，默认 `99`                                                     |
| `step`            | `number`                                                                     | `ArrowUp` / `ArrowDown` 与聚焦后滚轮的步长，默认 `1`                |
| `positiveInteger` | `boolean`                                                                    | 仅允许正整数。值类型变为 `number \| undefined`，默认 `false`                      |
| `prefix`          | `React.ReactNode`                                                            | 渲染在数字前的内容（如货币符号）                                                   |
| `suffix`          | `React.ReactNode`                                                            | 渲染在数字后的内容 —— 设置时取代步进提示                                             |
| `thousands`       | `boolean`                                                                    | 未聚焦时整数部分按千分位分组显示；提交值始终不带分隔符，默认 `false`                             |
| `indicator`       | `boolean`                                                                    | 是否在尾部区域显示非交互的上下提示图标（设置 `suffix` 时不显示），默认 `true`；关闭时尾部不渲染指示。聚焦后所有实例都会在右上角显示 `↑` `↓` 键帽提示——移动端（触屏或窄屏）不显示 |
| `className`       | `string`                                                                     | 字段外壳自定义类名；默认 `w-full min-w-0 max-w-[20rem]`（最大 20rem） |
| `style`           | `React.CSSProperties`                                                        | 字段外壳内联样式                                                  |
| `classNames`      | `{ leading?: string; trailing?: string; root?: SlotClassName; indicator?: SlotClassName; indicatorIcon?: string; hint?: SlotClassName; hintKey?: string }` | `root`、`indicator`、`hint` 接收 `({ disabled }) => string` 状态函数；其余槽为固定类名（`hintKey` 是 `↑` `↓` 键帽的类名） |
| `styles`          | `{ leading?; trailing?; root?; indicator?; indicatorIcon?; hint?; hintKey? }` —— 值均为 `React.CSSProperties` | 前后缀插槽、内部输入框（`root`）、↑↓ 提示与聚焦提示键帽的内联样式            |
| `disabled`        | `boolean`                                                                    | 禁用整个字段，默认 `false`                                                  |
| `...props`        | `React.ComponentProps<"input">`                                              | 支持所有原生 input 属性（除 `type`、`className`），如 `onBlur`                   |

### 可组合组件

#### NumberRoot

NumberInput 与 NumberField 共用的裸数字输入框——它不带外壳，因此步进提示图标、千分位分隔与前后缀都是成品特性。需要完全自定义面板时，把 `NumberRoot` 放进普通 `div`（观感由你自己的类或方案皮肤提供），并用 `useNumberCore` 自管数值。

## 交互

| Key | Description |
| --- | --- |
| `ArrowUp` / `ArrowDown` | 按 `step` 步进数值，受 `min` / `max` 钳制 |
| `Wheel`（聚焦后） | 滚轮向上加、向下减，按 `step` 步进并阻断页面滚动，受 `min` / `max` 钳制 |
| `Blur` | 失焦时规范化编辑后的数值；开启 `thousands` 时，千分位分隔仅在未聚焦时显示 |

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-invalid]` | 位于外壳上——`invalid` 为 true 时存在 |
