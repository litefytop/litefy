## 用法

`FormItem` 按 `variant` 渲染成品控件，label、描述与校验开箱即用。

### 禁用状态

在字段上设置 `disabled` 可冻结该控件，表单其余部分照常工作。

<ComponentPreview
  name="form-item-disabled"
/>

### 校验

`validate` 返回**字符串**为硬错误，返回 **`{ message, invalid: false }`** 只显示文案、不标记控件（如必填项为空）。

## API 参考

### FormItem

以成品控件形式渲染的表单字段。

| 属性              | 类型                                                                                                                                                              | 默认值     | 描述                                                                                      |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | ----------------------------------------------------------------------------------------- |
| `variant`         | `"input" \| "textarea" \| "select" \| "password" \| "number-input"`                                                                                              | `"input"`  | 渲染哪种成品控件                                                                           |
| `name`            | `string`                                                                                                                                                          | -          | 字段名称，也是周围 `Form` 收集值时使用的键 **必填**                                       |
| `label`           | `React.ReactNode`                                                                                                                                                 | -          | 渲染在控件上方的标签                                                                      |
| `description`     | `React.ReactNode`                                                                                                                                                 | -          | 渲染在控件下方的辅助文字，校验失败时会被错误信息替代                                      |
| `required`        | `boolean`                                                                                                                                                         | -          | 标记标签必填并使控件变为 `required`                                                       |
| `validate`        | `(value: string) => string \| { message: string; invalid?: boolean } \| boolean \| null \| undefined \| Promise<...>`                                             | -          | 字符串是硬错误（文案 + 控件 `aria-invalid`）；`{ message, invalid: false }` 只显示文案、不标记控件；`false` 表示无效但不显示文案；`null`/`undefined`/`true` 表示通过 |
| `validateTrigger` | `"onChange" \| "onBlur"`                                                                                                                                          | `"onBlur"` | 校验触发时机。字段已处于无效状态时，每次变更也会重新校验                                  |
| `disabled`        | `boolean`                                                                                                                                                         | -          | 禁用控件                                                                                  |
| `className`       | `ClassNameValue`                                                                                                                                                  | -          | 根容器自定义样式                                                                          |
| `classNames`      | `{ label?; description?; error? }` —— 值均为 `ClassNameValue`                                                                                                      | -          | 标签、描述与错误行的自定义类名                                                            |
| `controlProps`    | 随 variant 变化，见下表                                                                                                                                           | `{}`       | 透传给底层控件的属性                                                                      |

`controlProps` 随 `variant` 的类型：

| Variant        | `controlProps` 类型                                                                                |
| -------------- | -------------------------------------------------------------------------------------------------- |
| `input`        | `Omit<InputProps, "ref">`                                                                          |
| `textarea`     | `Omit<TextareaProps, "ref">`                                                                       |
| `select`       | `Omit<SelectProps, "ref"> & { options: (SelectOption \| SelectOptionGroup)[] }`                    |
| `password`     | `Omit<PasswordProps, "ref">`                                                                       |
| `number-input` | `Omit<NumberInputProps, "ref">`                                                                   |

> `controlProps` 中自定义的 `onChange` / `onBlur` 会被包装而非替换；`select` variant 的值由隐藏 input 携带参与原生表单提交。
