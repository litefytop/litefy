## Usage

### Basic Usage

Compose a form using `Form`, `Form.Field`, `Form.Fieldset`, and `Form.Submit`. Fields and fieldsets expose a render prop with the underlying control attributes for full control.

  name="form-basic"
/>

### Validation

Use `validConfig` to add client-side validation. Validation runs on `onChange` or `onBlur` and renders the returned string as the error message. When `trigger` is `"onChange"`, validation can be debounced with `debounceMs`.

  name="form-validation"
/>

### Horizontal Layout

Set `direction="horizontal"` on a field for a side-by-side label/control layout. Combine with `classNames` to style the label.

### Parts Mode (useFieldValidity)

No wrapper components: keep a `useFieldValidity` store (built into the Form module), set/clear errors from your own handlers, pass `aria-invalid` into the control, and conditionally render the message. Every input control ships danger styling (`border-danger` / `text-danger` and a danger focus ring) that activates from the `aria-invalid` attribute alone.

<ComponentPreview 
  name="form-parts"
/>

### Invalid Control Styling

All field controls (Input, Textarea, Select, Password, NumberField, Picker, InputOtp) style themselves from the `aria-invalid` attribute — no extra props needed:

`aria-invalid:border-danger aria-invalid:text-danger` plus, when focused, `aria-invalid:focus-visible:outline-1 aria-invalid:focus-visible:outline-danger aria-invalid:focus-visible:ring-3 aria-invalid:focus-visible:ring-danger/50`. Composite wrappers (InputGroup, PasswordGroup) key the same treatment off their `data-invalid` state.

## API Reference

### High-level Components

Ready-to-use composite components.

#### Form

The root form component built on top of the native `<form>` element.

| Prop        | Type                                       | Default | Description                                                                                     |
| ----------- | ------------------------------------------ | ------- | ----------------------------------------------------------------------------------------------- |
| `onSubmit`  | `(values: FormValues) => Promise<boolean>` | -       | Async submit handler. Receives a preprocessed object where multi-value fields are arrays. Return `true` to mark success and trigger `autoReset` |
| `autoReset` | `boolean`                                  | `true`  | Reset the form when `onSubmit` resolves to `true`                                               |
| `onReset`   | `() => void`                               | -       | Called whenever the form resets — after a successful submit with `autoReset`, or via `ref.reset()` |
| `ref`       | `React.Ref<FormRef>`                       | -       | Imperative handle exposing `setValues`, `reset`, `submit`                                       |
| `children`  | `React.ReactNode`                          | -       | Form contents, typically `Form.Field`, `Form.Fieldset`, and `Form.Submit`                        |
| `...props`  | `React.ComponentProps<"form">`             | -       | Supports all native form props (except `onSubmit`, `ref`), spread onto the underlying form element |

#### FormRef

Imperative handle returned by the `ref` prop, where `FormValue = string | number | string[] | number[] | null`.

| Method      | Type                                          | Description                                                                    |
| ----------- | --------------------------------------------- | ------------------------------------------------------------------------------- |
| `setValues` | `(values: Record<string, FormValue>) => void` | Update one or more fields and dispatch a `change` event on each modified input   |
| `reset`     | `() => void`                                  | Reset the form and clear all registered inputs                                   |
| `submit`    | `() => void`                                  | Trigger a programmatic form submission                                           |

#### Form.Submit

A submit button that automatically reflects the pending state of the form. It is disabled while the form is submitting and can render a custom loading icon.

| Prop          | Type              | Default | Description                                                                      |
| ------------- | ----------------- | ------- | -------------------------------------------------------------------------------- |
| `loadingIcon` | `React.ReactNode` | -       | Custom icon rendered while the form is pending. Defaults to a spinning `Loader2` |
| `className`   | `string`          | -       | Custom CSS class, merged with the built-in button styles                         |
| `children`    | `React.ReactNode` | -       | Button label                                                                     |

All other native `<button>` props are supported; `type` is forced to `submit`.

#### Form.Field

Wraps a label, control, and helper text into a single accessible field. The control is provided through a render prop.

| Prop          | Type                                       | Default      | Description                                                                              |
| ------------- | ------------------------------------------ | ------------ | ---------------------------------------------------------------------------------------- |
| `name`        | `string`                                   | -            | Field name. Used to register the input with the form                                     |
| `label`       | `React.ReactNode`                          | -            | Label content rendered above the control                                                 |
| `description` | `React.ReactNode`                          | -            | Helper text shown below the control. Replaced by the error message when invalid          |
| `invalid`     | `React.ReactNode`                          | -            | Controlled error message. A string value is rendered as an error and sets `aria-invalid` |
| `direction`   | `"vertical" \| "horizontal"`               | `"vertical"` | Layout direction of label and control                                                    |
| `inputId`     | `string`                                   | -            | Custom id for the underlying control                                                     |
| `classNames`  | `{ root?: ClassNameValue; label?: ClassNameValue; hint?: ClassNameValue }` | - | Custom classes for the field container, label, and hint text |
| `styles`      | `{ root?: React.CSSProperties; label?: React.CSSProperties; hint?: React.CSSProperties }` | - | Inline styles for the field container, label, and hint text |
| `validConfig` | `{ validate?: (value: string) => string \| boolean \| null \| undefined \| Promise<string \| boolean \| null \| undefined>; trigger?: "onChange" \| "onBlur"; debounceMs?: number }` | - | Client-side validation configuration, see the table below |
| `children`    | `(field: FormFieldArg) => React.ReactNode` | -            | Render prop that receives the input props for the underlying control                     |
| `...props`    | `React.ComponentProps<"div">`              | -            | Supports all native div props (except `children`, `className`, `style`), spread onto the field container |

`validConfig` fields:

| Field        | Description                                                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| `validate`   | Validator receiving the field's current string value. Returning a string renders it as the error message; returning `true` marks the field invalid |
| `trigger`    | When to run the validator                                                                                                             |
| `debounceMs` | Debounce delay in milliseconds, applied when `trigger` is `"onChange"`                                                                |

#### FormFieldArg

Render prop provided to `Form.Field` children, where `FormElement = HTMLInputElement | HTMLSelectElement | HTMLTextAreaElement`.

| Prop               | Type                                                    | Description                                                            |
| ------------------ | -------------------------------------------------------- | ---------------------------------------------------------------------- |
| `id`               | `string`                                                 | Generated id for the underlying input. Forwarded to the control's `id` |
| `name`             | `string`                                                 | The field's `name`. Forwarded to the control's `name`                  |
| `ref`              | `(el: FormElement \| null) => void`                      | Ref callback to register the input with the form                       |
| `onChange`         | `(e: React.ChangeEvent<FormElement>) => void`            | Change handler. Triggers `validConfig` when `trigger` is `"onChange"`  |
| `onBlur`           | `(e: React.FocusEvent<HTMLElement>) => void`             | Blur handler. Triggers `validConfig` when `trigger` is `"onBlur"`      |
| `invalid`          | `boolean`                                                | Whether the field is currently invalid                                 |
| `aria-describedby` | `string`                                                 | Id of the description or error message, for accessibility              |

#### Form.Fieldset

Groups related controls — e.g. a checkbox or radio group — into a single registrable field. With `type="multi"` (default) the group value is a `string[]`; with `type="single"` it is a `string`.

| Prop          | Type                                            | Default   | Description                                                                             |
| ------------- | ----------------------------------------------- | --------- | ---------------------------------------------------------------------------------------- |
| `name`        | `string`                                        | -         | Group name. Used to register the fieldset value with the form                             |
| `type`        | `"single" \| "multi"`                           | `"multi"` | `"multi"` collects the value as `string[]`, `"single"` as `string`                        |
| `legend`      | `React.ReactNode`                               | -         | Legend content rendered in the fieldset's `<legend>`                                      |
| `description` | `React.ReactNode`                               | -         | Helper text shown below the group. Replaced by the error message when invalid             |
| `invalid`     | `React.ReactNode`                               | -         | Controlled error message. A string value is rendered as an error and sets `aria-invalid`  |
| `disabled`    | `boolean`                                       | `false`   | Disable every control inside the fieldset                                                 |
| `classNames`  | `{ root?: ClassNameValue; legend?: ClassNameValue; hint?: ClassNameValue }` | - | Custom classes for the fieldset, legend, and hint text |
| `styles`      | `{ root?: React.CSSProperties; legend?: React.CSSProperties; hint?: React.CSSProperties }` | - | Inline styles for the fieldset, legend, and hint text |
| `validConfig` | `{ validate?: (value: string[] \| string) => string \| boolean \| undefined \| Promise<string \| boolean \| undefined>; trigger?: "onChange" \| "onBlur"; debounceMs?: number }` | - | Client-side validation configuration, same shape as `Form.Field`'s, except `validate` receives the group value |
| `children`    | `(field: FieldsetRenderArg) => React.ReactNode` | -         | Render prop that receives the group value and handlers                                    |
| `...props`    | `React.ComponentPropsWithRef<"fieldset">`       | -         | Supports all native fieldset props (except `children`, `className`, `style`), spread onto the fieldset element |

The render prop receives:

| Prop               | Type                                          | Description                                                                         |
| ------------------ | ----------------------------------------------- | ------------------------------------------------------------------------------------ |
| `id`               | `string`                                        | Generated id of the fieldset                                                         |
| `name`             | `string`                                        | The fieldset's `name`                                                                |
| `value`            | `string[] \| string \| undefined`               | Current group value — `string[]` when `type="multi"`, `string` when `type="single"`  |
| `onValueChange`    | `(value: string[] \| string) => void`           | Update the group value. Triggers `validConfig` when `trigger` is `"onChange"`        |
| `onBlur`           | `(e: React.FocusEvent<HTMLElement>) => void`    | Blur handler. Triggers `validConfig` when `trigger` is `"onBlur"`                    |
| `invalid`          | `boolean`                                       | Whether the fieldset is currently invalid                                            |
| `aria-describedby` | `string`                                        | Id of the description or error message, for accessibility                            |

### Composable Components

#### FormLabel

The field label rendered as `<label>`.

| Prop        | Type             | Default | Description      |
| ----------- | ---------------- | ------- | ---------------- |
| `className` | `ClassNameValue` | -       | Custom CSS class |

Supports all native `<label>` attributes.

#### FormHint

The hint text rendered as `<small>`. Shows the description normally and the error message (with `role="alert"`) when the field is invalid.

| Prop        | Type             | Default | Description      |
| ----------- | ---------------- | ------- | ---------------- |
| `className` | `ClassNameValue` | -       | Custom CSS class |

Supports all native `<small>` attributes.
