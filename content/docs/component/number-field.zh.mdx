## 用法

步进器形态数字输入，前导 Minus / 尾部 Plus 按 `step` 步进。

<ComponentPreview name="number-field-basic" />

### 禁用

`disabled` 原生禁用输入框与两个步进按钮，使用 `bg-disabled`、`text-disabled-fg` 与 `cursor-not-allowed`；到达 `min` / `max` 时对应按钮单独禁用。

## API 参考

### 高阶组件

开箱即用的成品组件。

#### NumberField

| 属性                | 类型                                                     | 描述                                                                 |
| ----------------- | ------------------------------------------------------ | ------------------------------------------------------------------ |
| `defaultValue`    | `number \| string`                                     | 初始值（非受控模式）                                                         |
| `value`           | `number \| string \| undefined`                        | 当前值（受控模式）                                                          |
| `onValueChange`   | `(value?: number) => void \| (value?: string) => void` | 值变化回调。`positiveInteger=true` 时为 `number \| undefined`，否则为 `string` |
| `invalid`         | `boolean`                                              | 标记字段无效（校验未通过）                                                      |
| `min`             | `number`                                               | 允许的最小值——到达后 Minus 按钮禁用；需要负数下界时显式传入，默认 `0`                          |
| `max`             | `number`                                               | 允许的最大值——到达后 Plus 按钮禁用；步进件三字符缺省，改大界时自行确认值区可容，默认 `999`               |
| `step`            | `number`                                               | 步进按钮、`ArrowUp` / `ArrowDown` 与聚焦后滚轮的步长，默认 `1`      |
| `positiveInteger` | `boolean`                                              | 仅允许正整数。值类型变为 `number \| undefined`，默认 `false`                      |
| `thousands`       | `boolean`                                              | 未聚焦时整数部分按千分位分组显示；提交值始终不带分隔符，默认 `false`                             |
| `className`       | `string`                                               | 自定义类名，作用于外壳。外壳恒为名义 3 格宽，值区与步进钮同宽（见下方宽度）                            |
| `style`           | `React.CSSProperties`                                  | 内联样式，作用于外壳                                                         |
| `classNames`      | `{ root?: SlotClassName; stepper?: SlotClassName; stepperIcon?: string; hint?: SlotClassName }` | `root`、`stepper`、`hint` 接收 `({ disabled }) => string`；`stepper.disabled` 同时包含字段禁用与 `min` / `max` 导致的单按钮禁用 |
| `styles`          | `{ root?, stepper?, hint? }`                           | 上述各部分的自定义内联样式                                                      |
| `disabled`        | `boolean`                                              | 禁用字段与两个步进按钮，默认 `false`                                             |
| `incrementLabel`  | `string`                                               | 本组件自带的 `+` 步进按钮的可访问名称，默认 `'Increase'`                              |
| `decrementLabel`  | `string`                                               | 本组件自带的 `−` 步进按钮的可访问名称，默认 `'Decrease'`                              |
| `...props`        | `React.ComponentProps<"input">`                        | 支持所有原生 input 属性（除 `type`），如 `onBlur`                               |

### 可组合组件

#### NumberStepper

可点击的步进按钮——`direction="up"` 渲染 Plus 图标、`direction="down"` 渲染 Minus 图标；`children` 可覆盖图标。

| 属性          | 类型                | 描述                                          |
| ----------- | ----------------- | ------------------------------------------- |
| `direction` | `"up" \| "down"`  | 图标与无障碍标签（`Increase` / `Decrease`），默认 `"up"` |
| `className` | `string`          | 自定义类名                                       |
| `children`  | `React.ReactNode` | 自定义图标内容，替换默认图标                              |

支持所有原生 `<button>` 属性（`type` 除外）。

#### NumberRoot

裸的内部输入框。支持所有原生 `<input>` 属性（`className` 除外），另有 `className`。

尾部为非交互提示图标的形式请看 [NumberInput](/zh/docs/component/number-input)。

### 宽度

外壳恒为名义 3 格加 1px 内间距与描边（两侧步进钮与值区各 1 格，随 `--width-control` 令牌缩放——默认方案 136px，紧凑档同步收缩）：值区 `w-control` 与步进钮同宽，不做任何运行期宽度计算，输入与步进过程宽度不变；超宽内容（千分位、更大的 `max`）在值区内横向滚动，需要更宽值区时经 `classNames.root` 自行加宽（如 `w-22`）。

## 交互

| Key | Description |
| --- | --- |
| `ArrowUp` / `ArrowDown` | 按 `step` 步进数值，受 `min` / `max` 钳制 |
| `Wheel`（聚焦后） | 滚轮向上加、向下减，按 `step` 步进并阻断页面滚动，受 `min` / `max` 钳制 |
| `−` / `+` | 步进按钮仅响应指针——不进入 Tab 序列——并在 `min` / `max` 处自动禁用 |

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-invalid]` | 位于根节点上——`invalid` 为 true 时存在 |
