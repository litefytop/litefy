## API 参考

### 高阶组件

开箱即用的成品组件。

#### NumberField

带有内置增减按钮的数字输入字段。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `defaultValue` | `number \| string` | - | 初始值（非受控模式） |
| `value` | `number \| string \| undefined` | - | 当前值（受控模式） |
| `onValueChange` | `(value?: number) => void \| (value?: string) => void` | - | 值变化处理器。当 `positiveInteger=true` 时返回 `number \| undefined`，否则返回 `string` |
| `invalid` | `boolean` | - | 是否处于无效状态 |
| `min` | `number` | `0`（positiveInteger）或 `-Infinity` | 允许的最小值 |
| `max` | `number` | `Infinity` | 允许的最大值 |
| `step` | `number` | `1` | 增减步长 |
| `positiveInteger` | `boolean` | `false` | 限制为正整数。将值类型更改为 `number \| undefined` |
| `classNames` | `{ group?: ClassNameValue; decrement?: ClassNameValue; increment?: ClassNameValue; root?: ClassNameValue }` | - | 内部元素的自定义类名 |
| `styles` | `{ group?: React.CSSProperties; decrement?: React.CSSProperties; increment?: React.CSSProperties; root?: React.CSSProperties }` | - | 内部元素的内联样式 |
| `disabled` | `boolean` | `false` | 禁用整个字段 |
| `...props` | `React.ComponentProps<"input">` | - | 支持全部 input 原生属性（除 `type`、`className`），如 `onBlur` |

### 可组合组件

#### NumberGroup

外层容器，内置完整输入框样式：尺寸（`max-w-3xs w-full`）、圆角（rounded-full）、`focus-within` 焦点环；设置 `invalid` 时会添加 `data-invalid` 属性，但默认没有对应样式。

| Prop        | Type                          | Default | Description                               |
| ----------- | ----------------------------- | ------- | ----------------------------------------- |
| `className` | `ClassNameValue`              | -       | 自定义类名                                |
| `...props`  | `React.ComponentProps<"div">` | -       | 支持全部 div 原生属性（含 `data-*` 属性） |

#### NumberDecrement

减号按钮，内置左半圆样式与禁用态。

| Prop        | Type                             | Default | Description                                  |
| ----------- | -------------------------------- | ------- | -------------------------------------------- |
| `className` | `ClassNameValue`                 | -       | 自定义类名                                   |
| `children`  | `React.ReactNode`                | -       | 按钮内容                                     |
| `...props`  | `React.ComponentProps<"button">` | -       | 支持全部 button 原生属性（除 `className`）   |

#### NumberIncrement

加号按钮，内置右半圆样式与禁用态。

| Prop        | Type                             | Default | Description                                  |
| ----------- | -------------------------------- | ------- | -------------------------------------------- |
| `className` | `ClassNameValue`                 | -       | 自定义类名                                   |
| `children`  | `React.ReactNode`                | -       | 按钮内容                                     |
| `...props`  | `React.ComponentProps<"button">` | -       | 支持全部 button 原生属性（除 `className`）   |

#### NumberRoot

承载状态的文本输入框，内置居中数字排版样式。

| Prop        | Type                            | Default | Description                                                    |
| ----------- | ------------------------------- | ------- | -------------------------------------------------------------- |
| `className` | `ClassNameValue`                | -       | 自定义类名                                                     |
| `...props`  | `React.ComponentProps<"input">` | -       | 支持全部 input 原生属性（除 `className`），如 `value`、`onChange` 和 `role="spinbutton"` 相关 aria 属性 |
