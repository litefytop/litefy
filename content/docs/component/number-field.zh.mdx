## API 参考

### 高阶组件

即用型成品组件。

#### NumberField

支持键盘步进（`ArrowUp` / `ArrowDown`，无可点击按钮）、千分位显示与前后缀插槽的数字输入框。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `defaultValue` | `number \| string` | - | 初始值（非受控模式） |
| `value` | `number \| string \| undefined` | - | 当前值（受控模式） |
| `onValueChange` | `(value?: number) => void \| (value?: string) => void` | - | 值变化处理。`positiveInteger=true` 时返回 `number \| undefined`，否则返回 `string` |
| `invalid` | `boolean` | - | 是否处于无效状态 |
| `min` | `number` | `0`（positiveInteger）或 `-Infinity` | 允许的最小值 |
| `max` | `number` | `Infinity` | 允许的最大值 |
| `step` | `number` | `1` | `ArrowUp` / `ArrowDown` 的步长 |
| `positiveInteger` | `boolean` | `false` | 仅允许正整数。值类型变为 `number \| undefined` |
| `prefix` | `React.ReactNode` | - | 渲染在数字前的内容（如货币符号） |
| `suffix` | `React.ReactNode` | - | 渲染在数字后的内容 —— 设置时取代步进提示 |
| `thousands` | `boolean` | `false` | 未聚焦时整数部分按千分位分组显示；提交值始终不带分隔符 |
| `indicator` | `boolean` | `true` | 是否在尾部区域显示非交互的上下提示图标（设置 `suffix` 时不显示） |
| `classNames` | `{ group?; leading?; trailing?; root? }` —— 值均为 `ClassNameValue` | - | 各零件的自定义类名 |
| `styles` | `{ group?; leading?; trailing?; root? }` —— 值均为 `React.CSSProperties` | - | 各零件的内联样式 |
| `disabled` | `boolean` | `false` | 禁用整个字段 |
| `...props` | `React.ComponentProps<"input">` | - | 支持所有原生 input 属性（除 `type`、`className`），如 `onBlur` |

### 可组合组件

#### NumberRoot

承载数值的文本输入框，设计上无边框（边框与焦点环由外壳承担）。配合 `InputGroup` 用于自定义拼装。

| Prop        | Type                           | Default | Description                                            |
| ----------- | ------------------------------ | ------- | ------------------------------------------------------ |
| `className` | `ClassNameValue`               | -       | 自定义类名                                              |
| `...props`  | `React.ComponentProps<"input">` | -      | 支持所有原生 input 属性（除 `className`），如 `value`、`onChange` 与 `role="spinbutton"` 的 aria 属性 |

#### 自定义拼装

容器与插槽是共享的 [Input](/docs/component/input) 零件 —— `InputGroup`、`InputLeading`、`InputTrailing` 自带标准外壳样式（包括由 `data-invalid` / `aria-invalid` 驱动的 danger 效果）；把 `NumberRoot` 放在中间，用你自己的状态驱动数值即可。
