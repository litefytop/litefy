## 用法

`NumberField` 是步进器形态的数字输入组件：前导 Minus 与尾部 Plus 按钮按 `step` 步进数值（受 `min` / `max` 约束）。字段默认带边框；放在其他容器内部（工具栏、表格单元格、自定义外壳）时设置 `variant="embedded"` 去掉边框。数值到达某一侧边界后，该侧步进按钮自动禁用。输入框聚焦时依然支持键盘步进。

## API 参考

### NumberField

| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `defaultValue` | `number \| string` | - | 初始值（非受控模式） |
| `value` | `number \| string \| undefined` | - | 当前值（受控模式） |
| `onValueChange` | `(value?: number) => void \| (value?: string) => void` | - | 值变化回调。`positiveInteger=true` 时为 `number \| undefined`，否则为 `string` |
| `invalid` | `boolean` | - | 字段外围显示危险色边框；embedded 模式下切换文字为危险色 |
| `variant` | `"default" \| "embedded"` | `"default"` | `"default"` 自带边框，适合独立使用；`"embedded"` 无边框，适合嵌入其他容器 |
| `min` | `number` | `0`（positiveInteger）或 `-Infinity` | 允许的最小值——到达后 Minus 按钮禁用 |
| `max` | `number` | `Infinity` | 允许的最大值——到达后 Plus 按钮禁用 |
| `step` | `number` | `1` | 步进按钮与 `ArrowUp` / `ArrowDown` 的步长 |
| `positiveInteger` | `boolean` | `false` | 仅允许正整数。值类型变为 `number \| undefined` |
| `thousands` | `boolean` | `false` | 未聚焦时整数部分按千分位分组显示；提交值始终不带分隔符 |
| `className` | `ClassNameValue` | - | 自定义类名，作用于外壳 |
| `style` | `React.CSSProperties` | - | 内联样式，作用于外壳 |
| `classNames` | `{ root? }` | - | 内部输入框的自定义类名 |
| `styles` | `{ root? }` | - | 内部输入框的内联样式 |
| `disabled` | `boolean` | `false` | 禁用字段与两个步进按钮 |
| `...props` | `React.ComponentProps<"input">` | - | 支持所有原生 input 属性（除 `type`），如 `onBlur` |

### 可组合组件

#### NumberStepper

可点击的步进按钮——`direction="up"` 渲染 Plus 图标、`direction="down"` 渲染 Minus 图标；`children` 可覆盖图标。

| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `direction` | `"up" \| "down"` | `"up"` | 图标与无障碍标签（`Increase` / `Decrease`） |
| `className` | `ClassNameValue` | - | 自定义类名 |
| `children` | `React.ReactNode` | - | 自定义图标内容，替换默认图标 |

支持所有原生 `<button>` 属性（`type` 除外）。

#### NumberRoot

裸的内部输入框。支持所有原生 `<input>` 属性（`className` 除外），另有 `className`。

带边框、尾部为非交互提示图标的形式请看 [NumberInput](/zh/docs/component/number-input)。
