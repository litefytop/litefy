### Variants

`variant` switches the trigger style and defaults to `line` (the basic demo uses this form); `primary` gives the selected item a `primary` color pair.

### Disabled

Each tab's `disabled` independently and natively disables its trigger, and arrow keys skip it. The `trigger` uses `text-disabled-fg` and `cursor-not-allowed`, while the `primary` variant also uses `bg-disabled`.

## API Reference

### High-level Components

#### Tabs

An options-driven container that manages the active value and passes all state to `TabsList`, `TabsTrigger` and `TabsContent` as parameters — no context. One shape at every width: when labels overflow, the bar scrolls horizontally and the prev/next arrows indicate that it is draggable — adaptation changes size only, never layout.

| Prop | Type | Description |
| :--- | :--- | :--- |
| `options` | `TabsOptionConfig[]` | Tab definitions |
| `defaultValue` | `string` | Initial active tab value (uncontrolled mode). Falls back to the first option's value |
| `value` | `string` | Active tab value (controlled mode) |
| `onValueChange` | `(value: string) => void` | Callback when active tab changes |
| `orientation` | `'horizontal' \| 'vertical'` | Layout orientation, defaults to `'horizontal'` |
| `unmountOnHide` | `boolean` | Unmount a panel while its tab is inactive; `false` keeps it mounted and hides it — use it for panels that hold search, pagination or scroll state, defaults to `true` |
| `panelClassName` | `string` | Class applied to every panel this component renders |
| `className` | `string` | Custom CSS class, applied to the root; defaults to `w-full min-w-0` |
| `classNames` | `{ root?: string; list?: string; scroll?: SlotClassName; scroller?: string; trigger?: SlotClassName; content?: string }` | `trigger` / `scroll` accept `({ disabled }) => string`; `scroll.disabled` means the scroll direction has reached a boundary, and `content` applies to every tabpanel |
| `prevLabel` | `string` | Accessible name of the left scroll arrow this component renders, defaults to `'Scroll tabs left'` |
| `nextLabel` | `string` | Accessible name of the right scroll arrow this component renders, defaults to `'Scroll tabs right'` |
| `...props` | `React.ComponentProps<"div">` | Supports all native div props (except `className`) |

#### TabsOptionConfig

| Property | Type | Description |
| :--- | :--- | :--- |
| `value` | `string` | Unique identifier for the tab |
| `label` | `React.ReactNode` | Content of the tab trigger |
| `content` | `React.ReactNode` | Content of the tab panel |
| `disabled` | `boolean` | Disable the tab |

### Composable Components

#### TabsList

Container for the tab trigger buttons. Communicates only through parameters.

A horizontal list scrolls: its viewport renders prev/next buttons and reports `data-overflow="true"` on the shell when its triggers exceed the box it was given (in vertical orientation, when they exceed its height); a box hidden to 0 keeps the last reading rather than claiming it fits. Each trigger carries an inline `flex-shrink: 0`, so it is never shrunk. A vertical list is the tablist itself and scrolls along its own axis.

| Prop | Type | Description |
| :--- | :--- | :--- |
| `orientation` | `'horizontal' \| 'vertical'` | Layout orientation, defaults to `'horizontal'` |
| `activeValue` | `string` | Currently active value; scrolls the active trigger into view when it changes |
| `prevLabel` | `string` | Accessible name of the left scroll arrow this component renders, defaults to `'Scroll tabs left'` |
| `nextLabel` | `string` | Accessible name of the right scroll arrow this component renders, defaults to `'Scroll tabs right'` |
| `className` | `string` | Custom CSS class |
| `...props` | `React.ComponentProps<"div">` | Supports all native div props (except `className`); `ref` lands on the element that scrolls |

#### TabsTrigger

Individual tab button. Receives its active state and change callback purely as parameters.

| Prop | Type | Description |
| :--- | :--- | :--- |
| `value` | `string` | Unique identifier for the tab |
| `active` | `boolean` | Whether the tab is active, drives `data-state` and `aria-selected`, defaults to `false` |
| `uid` | `string` | Scope that derives the trigger id and the panel id it controls |
| `onValueChange` | `(value: string) => void` | Called with the tab's own `value` on click or Enter/Space |
| `disabled` | `boolean` | Disable the tab, defaults to `false` |
| `className` | `string` | Custom CSS class |
| `...props` | `React.ComponentProps<"button">` | Supports all native button props (except `className`) |

#### TabsContent

Panel rendered when `active` is true; returns `null` otherwise. Wrap content in `React.lazy()` to defer the import until the tab becomes active.

| Prop | Type | Description |
| :--- | :--- | :--- |
| `value` | `string` | Unique identifier, used to derive the panel id and `aria-labelledby` |
| `active` | `boolean` | Whether the panel is visible, defaults to `false` |
| `uid` | `string` | Scope that derives the panel id and the trigger id that labels it — pass the same value your triggers use |
| `unmountOnHide` | `boolean` | Return `null` while inactive; `false` keeps the panel mounted and hides it, defaults to `true` |
| `className` | `string` | Custom CSS class |
| `...props` | `React.ComponentProps<"div">` | Supports all native div props (except `className`) |

## Keyboard Interactions

| Key | Description |
| :--- | :--- |
| `ArrowRight` | Moves focus to the next enabled tab, wrapping past the last (horizontal lists) |
| `ArrowLeft` | Moves focus to the previous enabled tab, wrapping past the first (horizontal lists) |
| `ArrowDown` | Same as `ArrowRight` in vertical orientation |
| `ArrowUp` | Same as `ArrowLeft` in vertical orientation |
| `Home` | Moves focus to the first enabled tab |
| `End` | Moves focus to the last enabled tab |
| `Enter` / `Space` | Activates the focused tab |
| `Tab` | Reaches the left and right scroll arrows in turn; hidden (`display: none`) arrows leave the tab order |

## Data Attributes

| Attribute | Description |
| :--- | :--- |
| `[data-state]` | On each trigger and panel — `"active"` or `"inactive"` |
| `[data-overflow]` | On the list — `"true"` while its triggers are wider (vertical: taller) than the box it was given; drives the prev/next arrows' visibility |
| `[data-direction]` | On the scroll buttons of a horizontal list — `"prev"` or `"next"` |
| `[data-value]` | On each trigger — its own `value` |
