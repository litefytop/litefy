## Usage

`CardButton` is the interactive counterpart of [Card](/docs/component/card) — the same card surface as a real `button`, resting at `shadow-base` and lifting to `shadow-elevated` on hover.

<ComponentPreview name="card-button-basic" />

### Variants

`outline` is the default and is shown in Basic Usage; `primary` and `danger` tint the whole surface for strong emphasis, and `text` is flat at rest — no border, no shadow, only a background tint on hover — for lightweight card lists.

## API Reference

### CardButton

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"primary" \| "danger" \| "outline" \| "text"` | `"outline"` | Visual weight, mirrors Button |
| `className` | `ClassNameValue` | - | Custom CSS class |
| `...props` | `React.ComponentProps<"button">` | - | Supports all native button props |
