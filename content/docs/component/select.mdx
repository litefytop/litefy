### Variants

`data-variant="cell"` switches to the settings-row form — the trigger is the same width as `default`, with the label at the left start and the selected value and chevron grouped at the right; the whole row is the click target.

<ComponentPreview
  name="select-variants"
/>

### Disabled

`disabled` natively disables the trigger and forcibly closes a controlled `open` panel; opening, selection and keyboard handling are blocked by JavaScript. The trigger uses `bg-disabled`, `text-disabled-fg` and `cursor-not-allowed`.

## API Reference

### Select

A select built on the native popover API and a built-in JS positioning engine: the trigger button shows the selected item's text. Keyboard: `ArrowDown` / `ArrowUp` open the panel and move the highlight (wrapping), `Home` / `End` jump to the first / last option, `Enter` / `Space` select the highlighted option, `Escape` closes without selecting, `Tab` closes. Writing `tabIndex={-1}` on the trigger takes it out of tab order while its own listbox keys keep working once you focus it programmatically.

| Prop            | Type                                                                    | Description                                                                                                                                                                                                                                                                                                                                                              |
| --------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `options`       | `(SelectOption \| SelectOptionGroup)[]`                                 | Array of options or option groups to display                                                                                                                                                                                                                                                                                                                             |
| `value`         | `string`                                                                | Controlled selected value                                                                                                                                                                                                                                                                                                                                                |
| `defaultValue`  | `string`                                                                | Default selected value for uncontrolled state, defaults to `""`                                                                                                                                                                                                                                                                                                          |
| `onValueChange` | `(value: string) => void`                                               | Fired when an option is selected                                                                                                                                                                                                                                                                                                                                         |
| `open`          | `boolean`                                                               | Controls the panel from outside — for a popup you trigger somewhere else, such as a joined field's `Ctrl` + `↓`                                                                                                                                                                                                                                                          |
| `onOpenChange`  | `(open: boolean) => void`                                               | Fired on every open and close, including pick, `Escape` and outside clicks                                                                                                                                                                                                                                                                                               |
| `placeholder`     | `string`                                                                | Placeholder text shown when no option is selected                                                                                                                                                                                                                                                                                                                        |
| `label`           | `React.ReactNode`                                                       | Label placed at the start of the trigger (the leading row text in the settings-row form); it becomes part of the trigger content's accessible name                                                                                                                                                                                                                       |
| `description`     | `React.ReactNode`                                                       | Helper text rendered below the trigger; replaced by the error message when validation fails                                                                                                                                                                                                                                                                             |
| `validate`        | `(value: string) => FieldValidateResult`                                | Validation function; providing it enables field mode, gates submission and revalidates on change when an error already exists                                                                                                                                                                                                                                           |
| `validateTrigger` | `'submit' \| 'change' \| 'blur'`                                        | Validation timing, defaults to `'submit'`                                                                                                                                                                                                                                                                                                                               |
| `name`            | `string`                                                                | Renders a hidden input with this name so the value participates in native form submission; dispatches `change` on the hidden field when the value changes so [Field](/en/docs/component/field) can revalidate                                                                                                                                                                     |
| `data-variant`    | `'default' \| 'cell'`                                                   | Visual variant; `cell` is the settings-row form, defaulting to `'default'`                                                                                                                                                                                                                                                                                               |
| `disabled`        | `boolean`                                                               | Natively disables the trigger and forcibly closes the panel, defaults to `false`                                                                                                                                                                                                                                                                                        |
| `className`       | `string`                                                                | Custom class name for the trigger; defaults to `w-full min-w-0 max-w-[20rem]` (maximum width 20rem)                                                                                                                                                                                                                                                                     |
| `style`           | `React.CSSProperties`                                                   | Inline styles applied to the trigger                                                                                                                                                                                                                                                                                                                                  |
| `classNames`      | `{ panel?; label?; option?; value?; chevron?; empty? }` — each `string` | `panel` controls the panel; the others customize group labels, options, the value, the chevron and the empty state                                                                                                                                                                                                                                                        |
| `styles`          | `{ panel? }` — each `React.CSSProperties`                               | Inline styles for the panel; the panel's default maximum width is 20rem, limited by the viewport width minus 1rem                                                                                                                                                                                                                                                        |
| `...props`      | `React.ComponentProps<"button">`                                        | Remaining native button props spread on the trigger, such as `id`, `aria-describedby`, `aria-required` and `tabIndex` — there is no `required` prop; your own `aria-haspopup` also replaces the trigger's `listbox` default. `ref` points at the trigger, and your `onKeyDown` runs before the listbox keys, so `preventDefault()` takes the key away from the component |

### SelectOption

| Prop    | Type     | Description                      |
| ------- | -------- | -------------------------------- |
| `label` | `string` | Display text for the option      |
| `value` | `string` | Value associated with the option |

### SelectOptionGroup

| Prop      | Type             | Description                      |
| --------- | ---------------- | -------------------------------- |
| `group`   | `string`         | Group label text                 |
| `options` | `SelectOption[]` | Array of options in the group    |

## Keyboard Interactions

| Key | Description |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Opens the panel when closed; while open, moves the highlight (wrapping at the ends). Opening seeds the highlight to the selected option, or the first option when nothing is selected |
| `Enter` / `Space` | On the trigger — toggles the panel; while open — commits the highlighted option and closes the panel |
| `Escape` | Closes the panel without selecting |
| `Home` / `End` | Highlights the first / last option |
| `Tab` | Closes the panel and moves focus on |

## Data Attributes

| Attribute | Description |
| --- | --- |
| `[data-open]` | On the trigger and the chevron — present while the panel is open |
| `[data-placeholder-shown]` | On the trigger — present when no value is selected |
| `[data-highlighted]` | On the option under the keyboard highlight |
| `[data-selected]` | On the currently selected option |
| `[data-disabled]` | On every option — present when the whole select is disabled |
