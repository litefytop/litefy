## Usage

By default, items are balanced across equal-width columns by measured height; `layout="static"` switches to CSS multi-column layout and avoids item height measurement.

## API Reference

### High-level Components

#### Masonry

A data-driven masonry layout. In balanced mode, async content that grows taller after mount is not re-measured automatically, so give it a min-height close to its final size; static mode is laid out by the browser and does not measure item heights.

| Prop         | Type                                                    | Description                                                                                                                                                                                                                                               |
| :----------- | :------------------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `items`      | `T[]`                                                   | The data list                                                                                                                                                                                                                                             |
| `renderItem` | `(item: T, index: number) => React.ReactNode`           | Renders a single cell                                                                                                                                                                                                                                     |
| `getKey`     | `(item: T, index: number) => React.Key`                 | Stable key per item, defaults to index                                                                                                                                                                                                                   |
| `columns`    | `number \| { base?; sm?; md?; lg?; xl?; 2xl? }`         | Fixed column count, or breakpoint columns resolved from container width (sm 640 / md 768 / lg 1024 / xl 1280 / 2xl 1536), defaults to `{ base: 1, sm: 2, lg: 3, xl: 4 }`                                  |
| `layout`     | `"balanced" \| "static"`                               | `balanced` balances columns by measured height; `static` uses CSS multi-column layout without measuring heights, defaults to `balanced`                                                                                                                     |
| `className`  | `string`                                                | Custom class name for the root element; change spacing for a single instance via `styles.column` / `styles.item`                                                                                                                                           |
| `classNames` | `{ column?; item? }` — all values `string`              | Custom class names for each part                                                                                                                                                                                                                          |
| `styles`     | `{ column?; item? }` — all values `React.CSSProperties` | Inline styles for each part                                                                                                                                                                                                                               |

### Composable Components

#### MasonryColumn

The equal-width column container — the skeleton gives it inline `display: flex; flex-direction: column; flex: 1 1 0%; min-width: 0` with spacing `gap: var(--litefy-masonry-gap, 1rem)`, so the column layout holds even when the scheme misses its styles.

| Prop       | Type                          | Description             |
| :--------- | :---------------------------- | :---------------------- |
| `className`| `string`                      | Custom class name       |
| `...props` | `React.ComponentProps<"div">` | Supports all native div props |

#### MasonryItem

The cell wrapper each item renders into; the skeleton gives it inline `min-width: 0`, and static and nested lanes also add `margin-bottom: 1rem` and `break-inside: avoid`.

| Prop       | Type                          | Description             |
| :--------- | :---------------------------- | :---------------------- |
| `className`| `string`                      | Custom class name       |
| `...props` | `React.ComponentProps<"div">` | Supports all native div props |

## Keyboard Interactions

This component takes over no keys — no part attaches key handlers; focus and keys belong to whatever `renderItem` puts inside the cells.

## Data Attributes

| Attribute             | Description                                                                                                                                                         |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `[data-masonry-key]`  | On each item wrapper in the balanced lane — the item's key, i.e. the string result of `getKey(item, index)` or the index itself |
| `[data-masonry-index]` | On the same wrapper — the item's index in `items`; its `offsetHeight` is recorded into the height slot for that index             |

Static and nested lanes emit neither attribute because they do no height balancing; static fills one column in document order before moving to the next.
