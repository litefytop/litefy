## 注意

- MultiSelect 内部由 [Popover](/docs/component/popover) 和 [CheckboxGroup](/docs/component/checkbox) 组合而成——CLI 安装时会自动解析并安装这些依赖。
- 触发器始终显示选中数量（如 `Categories (3)`），保持宽度稳定，避免布局抖动。
- 面板内点击永远不会关闭它——只有面板外 mousedown 或 Escape 才会关闭——用户可以自由勾选。
- `ArrowDown` / `ArrowUp`（或 `ArrowRight` / `ArrowLeft`）在复选框间循环移动焦点（跳过禁用项）；`Space` 切换；`Escape` 关闭面板。

## API 参考

### MultiSelect

| 属性 | 类型 | 默认值 | 描述 |
| :--- | :--- | :----- | :--- |
| `options` | `(CheckboxOptionConfig \| CheckboxOptionGroup)[]` | - | 平铺或分组的复选框选项 |
| `value` / `defaultValue` | `string[]` | `[]` | 选中值（受控 / 非受控） |
| `onChange` | `(values: string[]) => void` | - | 选择变化时触发 |
| `trigger` | `React.ReactNode` | - | 自定义触发器节点（默认为 `placeholder (count)`） |
| `placeholder` | `string` | `"Select options"` | 未提供自定义 `trigger` 时显示的文案 |
| `className` | `ClassNameValue` | - | 触发器按钮的自定义类名 |
| `classNames` | `{ content? }` | - | 面板内容的自定义类名 |
