## API 参考

### Radio

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | - | 单选框内容 |
| `checked` | `boolean` | `false` | 受控选中状态 |
| `defaultChecked` | `boolean` | `false` | 非受控模式下的默认选中状态 |
| `onCheckedChange` | `(checked: boolean) => void` | - | 选中状态变化时的回调 |
| `indicator` | `(checked: boolean, wrapperClassName?: string) => React.ReactNode` | - | 自定义指示器渲染函数，包含包装器className |
| `invalid` | `boolean` | `false` | 标记为无效 |
| `className` | `ClassNameValue` | - | 自定义 CSS 类。仅支持字符串、数组及各类假值。 |
| `...props` | `React.ComponentProps<"input">` | - | 支持所有原生 input 属性（除 `type`、`className` 外），如 `name`、`value`、`disabled` |

### RadioOptionConfig

| Field | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | - | 选项显示文本 |
| `value` | `string` | - | 唯一标识值 |
| `disabled` | `boolean` | `false` | 禁用该选项 |
| `invalid` | `boolean` | `false` | 标记该选项为无效 |
| `indicator` | `(checked: boolean, wrapperClassName?: string) => React.ReactNode` | - | 自定义指示器，优先级高于 `common.indicator` |
| `className` | `ClassNameValue` | - | 自定义类名，优先级高于 `common.className` |

### Radio.Group

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `RadioOptionConfig[]` | - | 选项数据数组 |
| `value` | `string` | - | 受控选中值 |
| `defaultValue` | `string` | - | 非受控模式下的默认选中值 |
| `onValueChange` | `(value: string) => void` | - | 选中值变化时的回调 |
| `disabled` | `boolean` | `false` | 禁用所有选项 |
| `invalid` | `boolean` | `false` | 标记为无效 |
| `name` | `string` | - | 分组名称 |
| `className` | `ClassNameValue` | - | 自定义类名，应用于容器 |
| `common` | `{ className?, indicator? }` | - | 应用于所有选项的通用配置 |
