## API 参考

### Radio

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | - | 单选框内容 |
| `checked` | `boolean` | `false` | 受控选中状态 |
| `defaultChecked` | `boolean` | `false` | 非受控模式下的默认选中状态 |
| `onCheckedChange` | `(checked: boolean) => void` | - | 选中时的回调 |
| `indicator` | `React.ReactNode` | - | 自定义指示器内容，替换默认圆点 |
| `classNames` | `{ indicator?; label? }` | - | 指示器与标签的自定义类名 |
| `styles` | `{ indicator?; label? }` | - | 指示器与标签的内联样式 |
| `className` | `ClassNameValue` | - | 自定义类名，作用于标签 |
| `...props` | `React.ComponentProps<"input">` | - | 支持所有原生 input 属性（除 `type`、`className` 外），如 `name`、`value`、`disabled` |

### 可组合组件

#### RadioRoot

裸的 radio 输入框（`sr-only peer`）——选中态通过 `has-checked:` / `peer-checked:` 变体读取。

#### RadioIndicator

圆形指示器。内置焦点环（`has-focus-visible:`）与选中边框（`has-checked:`）。

#### RadioLabel

标签包装层（点击即可切换选中）。

### RadioOptionConfig

| Field | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | - | 选项显示文本 |
| `value` | `string` | - | 唯一标识值 |
| `disabled` | `boolean` | `false` | 禁用该选项 |
| `indicator` | `React.ReactNode` | - | 自定义指示器，优先级高于 `common.indicator` |
| `classNames` / `styles` | - | - | 每个选项的零件样式，优先级高于 `common` |

### Radio.Group

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `RadioOptionConfig[]` | - | 选项数据数组 |
| `value` | `string` | - | 受控选中值 |
| `defaultValue` | `string` | - | 非受控模式下的默认选中值 |
| `onValueChange` | `(value: string) => void` | - | 选中值变化时的回调 |
| `disabled` | `boolean` | `false` | 禁用所有选项 |
| `name` | `string` | - | 分组名称——同时启用选项间原生的方向键导航 |
| `className` | `ClassNameValue` | - | 自定义类名，应用于容器 |
| `aria-label` | `string` | - | 组的无障碍标签 |
| `common` | `{ classNames?, styles?, indicator? }` | - | 应用于所有选项的通用配置 |
