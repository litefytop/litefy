## 用法

默认按实测高度均衡分配到等宽列；`layout="static"` 改用 CSS 多列，避免条目高度测量。

## API 参考

### 高阶组件

#### Masonry

数据驱动的瀑布流布局；balanced 模式挂载后增高的异步内容不会自动重新测量，请为其设置接近最终尺寸的 min-height；static 模式由浏览器排版，不测量条目高度。

| Prop         | Type                                              | Description                                                                                                                      |
| :----------- | :------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------- |
| `items`      | `T[]`                                             | 数据列表                                                                                                                             |
| `renderItem` | `(item: T, index: number) => React.ReactNode`     | 渲染单个单元格                                                                                                                          |
| `getKey`     | `(item: T, index: number) => React.Key`           | 每项的稳定 key，默认 index                                                                                                                            |
| `columns`    | `number \| { base?; sm?; md?; lg?; xl?; 2xl? }`   | 固定列数，或按容器宽度解析的断点列数（sm 640 / md 768 / lg 1024 / xl 1280 / 2xl 1536），默认 `{ base: 1, sm: 2, lg: 3, xl: 4 }` |
| `layout`     | `"balanced" \| "static"`                          | `balanced` 按实测高度逐列均衡；`static` 使用 CSS 多列且不测量高度，默认 `balanced`                                                                      |
| `className`  | `string`                                          | 根元素自定义类名；单实例改间距走 `styles.column` / `styles.item`                                                                                       |
| `classNames` | `{ column?; item? }` —— 值均为 `string`              | 各零件的自定义类名                                                                                                                        |
| `styles`     | `{ column?; item? }` —— 值均为 `React.CSSProperties` | 各零件的内联样式                                                                                                                         |

### 可组合组件

#### MasonryColumn

等宽列容器——骨架给它内联 `display: flex; flex-direction: column; flex: 1 1 0%; min-width: 0`，间距 `gap: var(--litefy-masonry-gap, 1rem)`，方案漏写也拆不掉列布局。

| Prop       | Type                          | Description       |
| :--------- | :---------------------------- | :---------------- |
| `className`| `string`              | 自定义类名         |
| `...props` | `React.ComponentProps<"div">` | 支持所有原生 div 属性 |

#### MasonryItem

每个条目渲染进的单元格包装器；骨架给它内联 `min-width: 0`，static 与嵌套车道再补 `margin-bottom: 1rem` 与 `break-inside: avoid`。

| Prop       | Type                          | Description       |
| :--------- | :---------------------------- | :---------------- |
| `className`| `string`              | 自定义类名         |
| `...props` | `React.ComponentProps<"div">` | 支持所有原生 div 属性 |

## 键盘交互

本组件不接管任何按键——没有零件挂按键处理器，焦点与按键归 `renderItem` 放进单元格里的内容。

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-masonry-key]` | 位于 balanced 车道的每个条目包装器上——条目的键，即 `getKey(item, index)` 的字符串结果或索引本身 |
| `[data-masonry-index]` | 位于 balanced 车道的同一个包装器上——条目在 `items` 中的下标，其 `offsetHeight` 被记录进该下标对应的高度槽 |

static 与嵌套车道不发射这两个属性，因为它们不做高度配平；static 按文档顺序先填满一列再进入下一列。
