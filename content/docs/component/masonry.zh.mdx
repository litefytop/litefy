## 用法

条目均衡分配到等宽列；列数默认随容器宽度响应（`1 / sm:2 / lg:3 / xl:4`）。

## API 参考

### 高阶组件

#### Masonry

数据驱动的瀑布流布局；挂载后增高的异步内容不会自动重新测量——请为其设置接近最终尺寸的 min-height。

| Prop         | Type                                              | Description                                                                                                                      |
| :----------- | :------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------- |
| `items`      | `T[]`                                             | 数据列表                                                                                                                             |
| `renderItem` | `(item: T, index: number) => React.ReactNode`     | 渲染单个单元格                                                                                                                          |
| `getKey`     | `(item: T, index: number) => React.Key`           | 每项的稳定 key，同时驱动内部测量缓存，默认 index                                                                                                    |
| `columns`    | `number \| { base?; sm?; md?; lg?; xl?; 2xl? }`   | 固定列数，或按容器宽度解析的断点列数（JS 解析，sm 640 / md 768 / lg 1024 / xl 1280 / 2xl 1536）——均衡车道与嵌套车道读同一张断点表，默认 `{ base: 1, sm: 2, lg: 3, xl: 4 }` |
| `className`  | `string`                                          | 根元素自定义类名。间距不是类名：骨架按 `--litefy-masonry-gap` 写内联间距，该令牌由当前方案定义；单实例改间距走 `styles.column` / `styles.item`                              |
| `classNames` | `{ column?; item? }` —— 值均为 `string`              | 各零件的自定义类名                                                                                                                        |
| `styles`     | `{ column?; item? }` —— 值均为 `React.CSSProperties` | 各零件的内联样式                                                                                                                         |

---

### 可组合组件

#### MasonryColumn

等宽列容器——骨架给它内联 `display: flex; flex-direction: column; flex: 1 1 0%; min-width: 0`，间距 `gap: var(--litefy-masonry-gap, 1rem)`，方案漏写也拆不掉列布局。

| Prop       | Type                          | Description       |
| :--------- | :---------------------------- | :---------------- |
| `className`| `string`              | 自定义类名         |
| `...props` | `React.ComponentProps<"div">` | 支持所有原生 div 属性 |

#### MasonryItem

每个条目渲染进的单元格包装器；骨架给它内联 `min-width: 0`，静态（嵌套）车道再补 `margin-bottom: var(--litefy-masonry-gap, 1rem)` 与 `break-inside: avoid`。

| Prop       | Type                          | Description       |
| :--------- | :---------------------------- | :---------------- |
| `className`| `string`              | 自定义类名         |
| `...props` | `React.ComponentProps<"div">` | 支持所有原生 div 属性 |

## 键盘交互

本组件不接管任何按键——没有零件挂按键处理器，焦点与按键归 `renderItem` 放进单元格里的内容。

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-masonry-key]` | 位于测量车道的每个条目包装器上——条目的键，即 `getKey(item, index)` 的字符串结果或索引本身；分配高度的那一轮按它取条目 |
| `[data-masonry-index]` | 位于同一个包装器上——条目在 `items` 中的下标，其 `offsetHeight` 被记录进该下标对应的高度槽 |

静态车道（嵌在另一个 `Masonry` 内部的那一层）两个属性都不发射，因为它不做高度配平。
