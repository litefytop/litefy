## API 参考

### 高级组件

开箱即用的组合组件。

#### SegmentGroup

| 属性             | 类型                          | 默认值  | 描述                                       |
| ---------------- | ----------------------------- | ------- | ------------------------------------------ |
| `options`        | `SegmentOptionConfig[]`       | -       | 选项数据数组                               |
| `value`          | `string`                      | -       | 受控的选中值                               |
| `defaultValue`   | `string`                      | -       | 非受控模式下的默认选中值                   |
| `onValueChange`  | `(value: string) => void`     | -       | 选中值变化时触发的回调函数                 |
| `disabled`       | `boolean`                     | `false` | 禁用所有选项                               |
| `className`      | `ClassNameValue`              | -       | 自定义类名，应用于容器                     |
| `itemClassName`  | `ClassNameValue`              | -       | 自定义类名，应用于每个分段按钮             |

键盘：分组是带 roving tabindex 的单选组 —— `ArrowRight` / `ArrowDown` / `ArrowLeft` / `ArrowUp` 移动到（并选中）下一个/上一个可用选项，`Home` / `End` 跳到第一个/最后一个，`Enter` / `Space` 激活聚焦的选项。

### SegmentOptionConfig

| 字段        | 类型              | 默认值  | 描述                                        |
| ----------- | ----------------- | ------- | ------------------------------------------- |
| `label`     | `string`          | -       | 选项显示文本                                |
| `value`     | `string`          | -       | 唯一标识值                                  |
| `disabled`  | `boolean`         | `false` | 禁用该选项                                  |
| `className` | `ClassNameValue`  | -       | 自定义类名，优先级高于 `itemClassName`      |

### 可组合组件

#### Segment

单个分段零件，具有单选语义：选中后再次点击不会取消选中。它不持有内部状态，`checked` 状态必须由外部提供，因此只在 `SegmentGroup` 或手动拼装的分组容器中才有意义。

| 属性       | 类型                             | 默认值  | 描述                                                          |
| ---------- | -------------------------------- | ------- | ------------------------------------------------------------- |
| `children` | `React.ReactNode`                | -       | 分段按钮的内容                                                |
| `checked`  | `boolean`                        | `false` | 选中状态，驱动 `aria-checked` 和选中样式                      |
| `className` | `ClassNameValue`                | -       | 自定义类名                                                    |
| `...props` | `React.ComponentProps<"button">` | -       | 支持所有原生 button 属性（除 `type` 外），如 `onClick`、`disabled` |
