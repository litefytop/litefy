## 用法

数据驱动的分段控制器，用于单选，支持受控和非受控模式。

<ComponentPreview
  name="segment-basic"
/>

### 变体

`variant` 切换整体外观——缺省 `bordered` 描边壳（未选中为文字钮、选中转主题色块，外观与动效面板同款），`borderless` 无壳无边框、选中填主题色块，`well` 凹陷容器、选中项凸起为主题色块。

<ComponentPreview
  name="segment-variants"
/>

### 禁用

组级 `disabled` 与每个选项的 `disabled` 独立配置，最终按“任一为真”原生禁用该按钮；独立禁用类串使用 `text-disabled-fg` 与 `cursor-not-allowed`，`well` 变体另用 `bg-disabled`。

## API 参考

### 高阶组件

开箱即用的组合组件。

#### SegmentGroup

| 属性               | 类型                            | 描述                                                        |
| ---------------- | ----------------------------- | --------------------------------------------------------- |
| `options`        | `SegmentOptionConfig[]`       | 选项数据数组                                                    |
| `value`          | `string`                      | 受控的选中值                                                    |
| `defaultValue`   | `string`                      | 非受控模式下的默认选中值                                              |
| `onValueChange`  | `(value: string) => void`     | 选中值变化时触发的回调函数                                             |
| `variant`        | `"borderless" \| "bordered" \| "well"` | 选中态外观，默认 `bordered`：描边容器内未选中项为文字钮、选中项转主题色块；`borderless` 无壳无边框，选中项填主题色块，无 hover；`well` 凹陷容器，选中项凸起为主题色块 |
| `disabled`       | `boolean`                     | 禁用所有选项，默认 `false`                                         |
| `className`      | `string`                      | 自定义类名，应用于容器                                               |
| `itemClassName`  | `string`                      | 自定义类名，应用于每个分段按钮                                           |

键盘：带 roving tabindex 的单选组 —— 方向键移动并选中下一个 / 上一个可用选项，`Home` / `End` 跳到首尾，`Enter` / `Space` 激活。

### SegmentOptionConfig

| 字段          | 类型                | 描述                                          |
| ----------- | ----------------- | ------------------------------------------- |
| `label`     | `string`          | 选项显示文本                                      |
| `value`     | `string`          | 唯一标识值                                       |
| `disabled`  | `boolean`         | 禁用该选项，默认 `false`                            |
| `className` | `string`          | 自定义类名，优先级高于 `itemClassName`                 |

### 可组合组件

#### Segment

单个分段零件，具有单选语义；不持有内部状态——`checked` 必须由外部提供。

| 属性          | 类型                               | 描述                                                            |
| ----------- | -------------------------------- | ------------------------------------------------------------- |
| `children`  | `React.ReactNode`                | 分段按钮的内容                                                       |
| `checked`   | `boolean`                        | 选中状态，驱动 `aria-checked`，默认 `false`                             |
| `className` | `string`                         | 自定义类名                                                         |
| `...props`  | `React.ComponentProps<"button">` | 支持所有原生 button 属性（除 `type` 外），如 `onClick`、`disabled`           |

## 键盘交互

| Key | Description |
| --- | --- |
| `ArrowRight` / `ArrowDown` | 聚焦并选中下一个可用分段，到末尾循环 |
| `ArrowLeft` / `ArrowUp` | 聚焦并选中上一个可用分段，到开头循环 |
| `Home` | 跳到第一个可用分段 |
| `End` | 跳到最后一个可用分段 |
| `Enter` / `Space` | 激活当前聚焦的分段 |

采用 roving tabindex：仅选中的分段可被 Tab 聚焦。

## 数据属性

骨架不在本组件上发射任何 `data-*`。状态经每个按钮的 `aria-checked` 与 `tabIndex` 暴露。
