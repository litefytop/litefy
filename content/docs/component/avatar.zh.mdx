## API 参考

### 高阶组件

开箱即用的成品组件。

#### Avatar

自动管理图片预加载的头像组件，在骨架屏、图片和回退内容三种状态之间切换。

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `src` | `string` | - | 图片源地址，必填 |
| `skeleton` | `React.ReactNode` | - | 图片加载中时显示的内容 |
| `fallback` | `React.ReactNode` | - | 图片加载失败时显示的内容 |
| `classNames` | `{ root?: ClassNameValue; image?: ClassNameValue }` | - | 根容器和图片的自定义类名 |
| `styles` | `{ root?: React.CSSProperties; image?: React.CSSProperties }` | - | 根容器和图片的内联样式 |

支持所有原生 `<img>` 属性（如 `alt`），但不支持 `className` 和 `style`。

### 可组合组件

#### AvatarRoot

容器元素，渲染为默认 `size-12` 的正方形，内容居中且溢出隐藏。

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |

支持所有原生 `<div>` 属性。

#### AvatarImage

图片元素，默认启用懒加载和异步解码。

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `src` | `string` | - | 图片源地址，必填 |
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |

支持所有原生 `<img>` 属性。
