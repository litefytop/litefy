## 用法

### 基础用法

预加载图片并判断加载状态：加载中显示 `skeleton`，加载失败显示 `fallback`，成功后渲染图片。

<ComponentPreview 
  name="avatar-basic"
/>

### 自定义

当高层组件 `Avatar` 无法满足需求时，使用原子组件自行拼装头像：`AvatarRoot` + `AvatarImage` 配合自己的加载逻辑、环形描边、状态徽标等。

## API 参考

### 高阶组件

开箱即用的成品组件。

#### Avatar

预加载管理的头像组件，外层容器内置 `flex`、`aspect-square`、`overflow-hidden`、`items-center`、`justify-center`，并叠加 `bg-muted`、`border` 样式；图片以 `object-cover` 填充。

| Prop            | Type                                            | Default   | Description                                                                               |
| --------------- | ----------------------------------------------- | --------- | ----------------------------------------------------------------------------------------- |
| `src`           | `string`                                        | -（必填） | 图片源 URL                                                                                |
| `alt`           | `string`                                        | -         | 图片的替代文本                                                                            |
| `className`     | `ClassNameValue`                                | -         | 自定义 CSS 类名，作用于外层容器                                                           |
| `skeleton`      | `React.ReactNode`                               | -         | 加载中显示的占位元素                                                                      |
| `fallback`      | `React.ReactNode`                               | -         | 加载失败时显示的自定义回退元素                                                            |
| `slots.wrapper` | `Omit<React.ComponentProps<"div">, "children">` | -         | 外层容器属性，`className` 优先级高于 `className`                                          |
| `...props`      | `React.ComponentProps<"img">`                   | -         | 支持全部 img 原生属性（除 `className`、`src`），内置 `loading="lazy"`、`decoding="async"` |

---

### Headless 原子组件

> 以下为底层原子组件，**内置样式极少，样式需要通过 className 自行补充**。高层组合组件 `Avatar` 即由以下原子组件组合而成。

#### AvatarRoot

外层容器，内置 `flex`、`aspect-square`、`overflow-hidden`、`items-center`、`justify-center`。

| Prop        | Type                          | Default | Description           |
| ----------- | ----------------------------- | ------- | --------------------- |
| `className` | `ClassNameValue`              | -       | 自定义类名            |
| `...props`  | `React.ComponentProps<"div">` | -       | 支持全部 div 原生属性 |

#### AvatarImage

图片元素，内置 `w-full`、`h-full`。

| Prop        | Type                          | Default | Description           |
| ----------- | ----------------------------- | ------- | --------------------- |
| `className` | `ClassNameValue`              | -       | 自定义类名            |
| `...props`  | `React.ComponentProps<"img">` | -       | 支持全部 img 原生属性 |
