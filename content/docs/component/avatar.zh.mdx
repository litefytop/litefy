## API 参考

### 高阶组件

开箱即用的成品组件。

#### Avatar

自动管理图片预加载的头像组件，在骨架屏、图片和回退内容三种状态之间切换。

| 属性           | 类型                                | 描述                                                       |
| ------------ | --------------------------------- | -------------------------------------------------------- |
| `src`        | `string`                          | 图片源地址，必填                                                 |
| `skeleton`   | `React.ReactNode`                 | 图片加载中时显示的内容——传自带样式的节点可替换方案默认的加载占位块（背景色 + 脉冲动画）           |
| `fallback`   | `React.ReactNode`                 | 图片加载失败时显示的内容——字符串由方案包进文字格子，元素按原样渲染；不传时显示方案默认的空底格子（静态背景色） |
| `className`  | `string`                          | 自定义类名，作用于根容器                                             |
| `style`      | `React.CSSProperties`             | 内联样式，作用于根容器                                              |
| `classNames` | `{ image?: string }`              | 图片的自定义类名                                                 |
| `styles`     | `{ image?: React.CSSProperties }` | 图片的内联样式                                                  |

支持所有原生 `<img>` 属性（如 `alt`）；`className` 和 `style` 作用于根容器。

### 可组合组件

#### AvatarRoot

容器元素；尺寸与内部内容排布（居中、溢出裁切）由所加载的方案定义。

| 属性          | 类型       | 描述            |
| ----------- | -------- | ------------- |
| `className` | `string` | 自定义 CSS 类     |

支持所有原生 `<div>` 属性。

#### AvatarImage

图片元素，默认启用懒加载和异步解码。

| 属性          | 类型       | 描述            |
| ----------- | -------- | ------------- |
| `src`       | `string` | 图片源地址，必填      |
| `className` | `string` | 自定义 CSS 类     |

支持所有原生 `<img>` 属性。

## 键盘交互

本组件不接管任何按键。`AvatarRoot` 是 `<div>`，`AvatarImage` 是 `<img>`，两者都不进入 Tab 序。

## 数据属性

骨架不在本组件上发射任何 `data-*`。
