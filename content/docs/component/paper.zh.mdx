## 用法

固定真实纸张尺寸的排版面：屏显与打印恒白底黑字，不受夜间模式影响。正文排版交给 [Typography 排版类](/zh/docs/utility/typography)。

## API 参考

### Paper

| 属性          | 类型                            | 描述                                                                                                    |
| :---------- | :---------------------------- | :---------------------------------------------------------------------------------------------------- |
| `format`    | `"a5" \| "a4" \| "letter"`    | 纸张档——A5 `148mm × 210mm`、A4 `210mm × 297mm`、Letter `8.5in × 11in`；`min-height` 承内容增高，跨页分页归业务，默认 `"a4"` |
| `className` | `string`                      | 根元素自定义类                                                                                               |
| `...props`  | `React.ComponentProps<"div">` | 透传到根 `div`                                                                                            |

## 键盘交互

本组件不是控件，不接管任何按键。

## 数据属性

| 属性 | 描述 |
| :--- | :--- |
| `[data-format]` | 位于根元素——`"a5"`、`"a4"` 或 `"letter"` |
