## 用法

`SelectableTable` 在 [Table](/zh/docs/component/table) 的基础上内置一列复选框——全选只作用于当前页，并保留其他页的已选项。

<ComponentPreview name="selectable-table-basic" />

### 与 Pagination 组合分页

表格只渲染 `data` 里的内容——页状态交给 [usePagination](/zh/docs/utils/use-pagination)，在外部组合 [Pagination](/zh/docs/component/pagination)。

<ComponentPreview name="selectable-table-pagination" />

### 大数据量

行数多到无法一次性渲染时，把 [TableBody](#零件) 滚动容器与 [useVirtualScroll](/zh/docs/utils/use-virtual-scroll) 组合。

选择列占用内部列 key `__selection`——请避免数据里出现同名字段。

## API 参考

### SelectableTable&lt;T&gt;

| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `data` | `T[]` | - | 行数据（当前页） **必填** |
| `columns` | `TableColumn<T>[]` | - | 列配置，复选框列自动前置 **必填** |
| `rowKey` | `(row: T) => string` | - | 行 key 提取器，同时是选中值的单位 **必填** |
| `selected` | `string[]` | - | 受控选中集合（行 key 数组） |
| `defaultSelected` | `string[]` | `[]` | 非受控时的初始选中 |
| `onSelectionChange` | `(selected: string[]) => void` | - | 行勾选 / 全选变化时触发 |
| `loading` | `boolean` | `false` | 空数据默认文案变为 "Loading..." |
| `empty` | `React.ReactNode` | `"No data"` | 数据为空时渲染的内容 |
| `className` | `ClassNameValue` | - | 自定义类名，透传给内部 Table |
| `classNames` | Table 各插槽 | - | 各部分自定义类名 |
| `styles` | `{ wrapper?, table? }` | - | 透传给内部 Table |

其余 [Table](/zh/docs/component/table) 属性（`sort` / `onSortChange`、`getKey` 等）均被继承；`getKey` 由 `rowKey` 派生。
