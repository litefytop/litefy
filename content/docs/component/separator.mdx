## API Reference

### High-level Components

Ready-to-use composite components.

#### Separator

Renders a single line, or a line–text–line divider when `children` is passed.

| Prop          | Type                                    | Description                                              |
| ------------- | --------------------------------------- | -------------------------------------------------------- |
| `children`    | `React.ReactNode`                       | Text label rendered between two lines                    |
| `orientation` | `'horizontal' \| 'vertical'`            | Orientation of the separator, defaults to `'horizontal'` |
| `className`   | `string`                                | Custom class name; horizontal separators are full-width by default, and vertical separators stretch to the flex row's height |
| `classNames`  | `{ line?, text?: string }`              | Custom classes for the lines and the text label          |
| `styles`      | `{ line?, text?: React.CSSProperties }` | Inline styles for the lines and the text label           |

---

### Composable Components

#### SeparatorLine

The line part. Vertical lines stretch automatically to the flex row's height, or can be pinned with a fixed height.

| Prop          | Type                          | Description                                         |
| ------------- | ----------------------------- | --------------------------------------------------- |
| `orientation` | `'horizontal' \| 'vertical'`  | Orientation of the line, defaults to `'horizontal'` |
| `className`   | `string`                      | Custom CSS class                                    |
| `...props`    | `React.ComponentProps<"div">` | Supports all native div props, such as `role`       |

#### SeparatorText

The text label part, styled for sitting between two lines.

| Prop        | Type                           | Description                                        |
| ----------- | ------------------------------ | -------------------------------------------------- |
| `className` | `string`                       | Custom CSS class                                   |
| `...props`  | `React.ComponentProps<"span">` | Supports all native span props, such as `children` |

## Keyboard Interactions

This component handles no keys.
