## API 参考

### Donut

| 属性               | 类型                          | 说明                                         |
| :--------------- | :-------------------------- | :----------------------------------------- |
| `data`           | `DonutDatum[]`              | 扇形数据：`{ label, value, color? }`            |
| `variant`        | `"pie" \| "donut"`          | `pie` 关闭中孔并将读数移到图表下方，默认 `"donut"`          |
| `gap`            | `number`                    | 扇形之间的角度间隔（度），默认 `2`                        |
| `valueFormatter` | `(value: number) => string` | 读数的数值格式化，默认 `toLocaleString`               |
| `showLegend`     | `boolean`                   | 是否在图上方渲染可点击图例，默认 `true`                    |
| `className`      | `string`                    | 追加到根元素的类名；默认 `w-full min-w-0`                                  |
| `classNames`     | `DonutClassNames`           | 槽位覆盖：`root` / `svg` / `segment` / `legend` |
| `styles`         | `DonutStyles`               | 与 `classNames` 槽位对应的内联样式                   |

## 键盘交互

| Key | Description |
| --- | --- |
| `Enter` / `Space` | 图例项上按下——切换对应扇区的可见性 |

中心读数仅跟随指针在扇区上的悬停——悬停高亮没有键盘等价操作。

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-dimmed]` | 位于扇形路径上——悬停在其他扇区时存在 |
