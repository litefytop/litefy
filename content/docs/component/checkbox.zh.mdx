## API 参考

### 高阶组件

开箱即用的成品组件。

#### Checkbox

| 属性              | 类型                                                               | 默认值  | 描述                                                                                       |
| :---------------- | :----------------------------------------------------------------- | :------ | :----------------------------------------------------------------------------------------- |
| `children`        | `React.ReactNode`                                                  | -       | 复选框标签文本                                                                             |
| `checked`         | `boolean`                                                          | -       | 受控选中状态                                                                               |
| `defaultChecked`  | `boolean`                                                          | -       | 默认选中状态（非受控）                                                                     |
| `onChange`        | `(e: React.ChangeEvent<HTMLInputElement>) => void`                 | -       | 原生 change 回调                                                                           |
| `onCheckedChange` | `(checked: boolean) => void`                                       | -       | 选中状态变化回调                                                                           |
| `indicator`       | `React.ReactNode`                                                  | -       | 自定义指示器内容，替换默认图标                                                             |
| `classNames`      | `{ indicator?: ClassNameValue; label?: ClassNameValue }`           | -       | 指示器和 label 的自定义类名                                                                |
| `styles`          | `{ indicator?: React.CSSProperties; label?: React.CSSProperties }` | -       | 指示器和 label 的内联样式                                                                  |
| `disabled`        | `boolean`                                                          | `false` | 禁用复选框                                                                                 |
| `...props`        | `React.ComponentProps<"input">`                                    | -       | 支持全部 input 原生属性（除 `type`、`className`、`value`），如 `name`、`value`、`required` |

#### Checkbox.Group

| 属性           | 类型                                                                                                                                                                              | 默认值  | 描述                       |
| :------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------ | :------------------------- |
| `options`      | `CheckboxOptionConfig[]`                                                                                                                                                          | -       | 选项数据数组               |
| `value`        | `string[]`                                                                                                                                                                        | -       | 受控选中值                 |
| `defaultValue` | `string[]`                                                                                                                                                                        | `[]`    | 默认选中值（非受控）       |
| `onChange`     | `(values: string[]) => void`                                                                                                                                                      | -       | 值变化回调                 |
| `name`         | `string`                                                                                                                                                                          | -       | 分组名称，作用于每个 input |
| `disabled`     | `boolean`                                                                                                                                                                         | `false` | 禁用所有选项               |
| `className`    | `ClassNameValue`                                                                                                                                                                  | -       | 自定义类名，作用于容器     |
| `common`       | `{ classNames?: { indicator?: ClassNameValue; label?: ClassNameValue }; styles?: { indicator?: React.CSSProperties; label?: React.CSSProperties }; indicator?: React.ReactNode }` | -       | 统一应用到每个选项的配置   |

#### CheckboxOptionConfig

继承除 `children` 外的所有 `Checkbox` 属性。

| 字段        | 类型              | 默认值 | 描述             |
| :---------- | :---------------- | :----- | :--------------- |
| `label`     | `string`          | -      | 选项显示文本     |
| `value`     | `string`          | -      | 唯一标识值       |
| `indicator` | `React.ReactNode` | -      | 子项自定义指示器 |

### 可组合组件

#### CheckboxRoot

视觉上隐藏的原生 input（`sr-only`），承载状态、焦点和表单语义。

| 属性        | 类型                            | 默认值 | 描述                                                       |
| :---------- | :------------------------------ | :----- | :--------------------------------------------------------- |
| `className` | `ClassNameValue`                | -      | 自定义 CSS 类                                              |
| `...props`  | `React.ComponentProps<"input">` | -      | 支持全部 input 原生属性（除 `type`、`className`、`value`） |

#### CheckboxIndicator

视觉指示器，渲染为带 `role="checkbox"` 和 `aria-checked` 的 `span`，选中样式自动应用。

| 属性        | 类型                           | 默认值 | 描述                                 |
| :---------- | :----------------------------- | :----- | :----------------------------------- |
| `checked`   | `boolean`                      | -      | 驱动 `aria-checked` 和选中样式       |
| `className` | `ClassNameValue`               | -      | 自定义 CSS 类                        |
| `children`  | `React.ReactNode`              | -      | 指示器内容，组合组件中默认为对勾图标 |
| `...props`  | `React.ComponentProps<"span">` | -      | 支持全部 span 原生属性               |

#### CheckboxLabel

label 包装器，将 input 与指示器和文本关联起来。

| 属性        | 类型                            | 默认值 | 描述                    |
| :---------- | :------------------------------ | :----- | :---------------------- |
| `className` | `ClassNameValue`                | -      | 自定义 CSS 类           |
| `...props`  | `React.ComponentProps<"label">` | -      | 支持全部 label 原生属性 |
