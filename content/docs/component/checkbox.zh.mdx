## API 参考

### 高阶组件

开箱即用的成品组件。

#### Checkbox

| Prop              | Type                         | Default | Description                    |
| :---------------- | :--------------------------- | :------ | :----------------------------- |
| `children`        | `React.ReactNode`            | -       | 复选框标签文本                 |
| `checked`         | `boolean`                    | -       | 受控选中状态                   |
| `defaultChecked`  | `boolean`                    | -       | 默认选中状态（非受控）         |
| `onCheckedChange` | `(checked: boolean) => void` | -       | 选中状态变化回调               |
| `indicator`       | `React.ReactNode`            | -       | 自定义指示器内容，替换默认图标 |
| `value`           | `string`                     | -       | 分组模式下的标识值             |
| `disabled`        | `boolean`                    | `false` | 禁用复选框                     |
| `name`            | `string`                     | -       | input 的 name 属性             |
| `className`       | `ClassNameValue`             | -       | 自定义类名，作用于 label       |

#### Checkbox.Group

| Prop            | Type                         | Default | Description                    |
| :-------------- | :--------------------------- | :------ | :----------------------------- |
| `options`       | `CheckboxOptionConfig[]`     | -       | 选项数据数组                   |
| `value`         | `string[]`                   | -       | 受控选中值                     |
| `defaultValue`  | `string[]`                   | `[]`    | 默认选中值（非受控）           |
| `onChange`      | `(values: string[]) => void` | -       | 值变化回调                     |
| `disabled`      | `boolean`                    | `false` | 禁用所有选项                   |
| `name`          | `string`                     | -       | 分组名称                       |
| `className`     | `ClassNameValue`             | -       | 自定义类名，作用于容器         |
| `itemClassName` | `ClassNameValue`             | -       | 统一应用到每个子项的 className |
| `itemIndicator` | `CheckboxProps["indicator"]` | -       | 统一应用到每个子项的指示器     |

#### CheckboxOptionConfig

| Field       | Type                         | Default | Description      |
| :---------- | :--------------------------- | :------ | :--------------- |
| `label`     | `string`                     | -       | 选项显示文本     |
| `value`     | `string`                     | -       | 唯一标识值       |
| `disabled`  | `boolean`                    | `false` | 禁用单个选项     |
| `className` | `ClassNameValue`             | -       | 子项自定义类名   |
| `indicator` | `CheckboxProps["indicator"]` | -       | 子项自定义指示器 |

### Headless 原子组件

> 以下为底层原子组件，**无内置样式，样式需要通过 className 自行补充**。

#### CheckboxRoot

底层状态容器，用于高级自定义场景。

| Prop              | Type                            | Default | Description                                                   |
| :---------------- | :------------------------------ | :------ | :------------------------------------------------------------ |
| `checked`         | `boolean`                       | -       | 受控选中状态                                                  |
| `defaultChecked`  | `boolean`                       | -       | 默认选中状态（非受控）                                        |
| `onCheckedChange` | `(checked: boolean) => void`    | -       | 选中状态变化回调                                              |
| `value`           | `string`                        | -       | 分组模式下的标识值                                            |
| `disabled`        | `boolean`                       | `false` | 禁用                                                          |
| `name`            | `string`                        | -       | input 的 name 属性                                            |
| `className`       | `ClassNameValue`                | -       | 有 children 时作用于容器 span，无 children 时作用于原生 input |
| `children`        | `React.ReactNode`               | -       | 自定义指示器内容，传入后原生 input 自动隐藏                   |
| `...props`        | `React.ComponentProps<"input">` | -       | 支持全部 input 原生属性（除 `type`、`className`、`value`）    |
