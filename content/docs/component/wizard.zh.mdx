## 用法

### 基础用法

传入 `steps` 作为进度指示器，`children` 作为 Pager 内容——每个子元素对应一步。Wizard 内部管理 `index` 和 `maxIndex`；已到达的步骤可通过 Steps 指示器回退，未来步骤不能跳过。

## 注意

- Wizard 内部使用 [Steps](/docs/component/steps) 和 [Pager](/docs/component/pager)——CLI 安装时请一并添加：`litefy add wizard steps pager`。
- Pager 配置为 `gesture={false}` 和 `transition="view-transition"`，防止误滑提交并为步骤切换提供动画。
- `maxIndex` 记录已到达的最远步骤并传给 Steps——已到达步骤可点击回退，未来步骤锁定。
- 最后一步将 Next 按钮替换为 Submit，点击时触发 `onFinish`。

### 内联变体

`Wizard.Inline`（亦导出为 `InlineWizard`）用同一套状态机驱动纵向步骤手风琴：只有当前步骤展开显示内容与它自己的 Back / Continue 按钮，其余步骤折叠为标题行。点击已访问步骤即可回跳。

| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `steps` | `{ title?; description?; content: React.ReactNode }[]` | - | 步骤定义 **必填** |
| `defaultIndex` / `index` | `number` | `0` | 步骤索引（非受控 / 受控） |
| `onIndexChange` | `(index: number) => void` | - | 步骤变化回调 |
| `onFinish` | `() => void` | - | 最后一步的 Finish 按钮回调 |
| `maxIndex` | `number` | 最后一步 | 最远可达步骤 |
| `backLabel` / `nextLabel` / `finishLabel` | `React.ReactNode` | `"Back"` / `"Continue"` / `"Finish"` | 按钮文案 |
| `disabled` | `boolean` | `false` | 禁用导航 |
| `className` | `ClassNameValue` | - | 自定义类名，作用于列表 |
| `classNames` | `marker` / `title` / `description` / `connector` / `content` / `footer` / `button` / `primaryButton` | - | 各部分自定义类名 |

## API 参考

### useWizardNavigation

向导状态机（钳位导航 + 最远到达锁定）以 `useWizardNavigation({ count, defaultIndex?, index?, maxIndex?, onIndexChange? })` 导出——返回 `{ index, maxVisited, maxReachable, isFirst, isLast, isReachable, go }`。上方的分页式 Wizard 与下方的内联变体都由它驱动，你也可以用它构建自定义向导外壳。

### Wizard

向导组件，管理步骤导航状态，渲染 Steps 指示器、Pager 内容区和底部按钮。

| 属性        | 类型                | 默认值 | 描述                              |
| :---------- | :------------------ | :----- | :------------------------------- |
| `steps`     | `StepsItemConfig[]` | -      | 进度指示器的步骤配置              |
| `children`  | `React.ReactNode[]` | -      | 页面内容，每个子元素对应一步       |
| `onFinish`  | `() => void`        | -      | 点击 Submit 按钮时触发            |
| `className` | `ClassNameValue`    | -      | 自定义类名，应用于根元素          |
| `classNames`| `{ root? / steps? / pager? / footer? }` | - | 按插槽自定义类名 |
