## 用法

传入 `steps` 作为进度指示器、每个子元素对应一步——Wizard 内部管理索引状态。

<ComponentPreview
  name="wizard-basic"
/>

CLI 安装时需一并添加 `litefy add wizard steps pager`——Wizard 构建于 [Steps](/docs/component/steps) 与 [Pager](/docs/component/pager) 之上。

### 内联变体

`Wizard.Inline`（亦导出为 `InlineWizard`）以纵向步骤手风琴渲染同一套状态机——只有当前步骤展开。

<ComponentPreview name="wizard-inline" />

| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `steps` | `{ title?; description?; content: React.ReactNode }[]` | - | 步骤定义 **必填** |
| `defaultIndex` / `index` | `number` | `0` | 步骤索引（非受控 / 受控） |
| `onIndexChange` | `(index: number) => void` | - | 步骤变化回调 |
| `onFinish` | `() => void` | - | 最后一步的 Finish 按钮回调 |
| `maxIndex` | `number` | 最后一步 | 最远可达步骤 |
| `backLabel` / `nextLabel` / `finishLabel` | `React.ReactNode` | `"Back"` / `"Continue"` / `"Finish"` | 按钮文案 |
| `disabled` | `boolean` | `false` | 禁用导航 |
| `className` | `ClassNameValue` | - | 自定义类名，作用于列表 |
| `classNames` | `marker` / `title` / `description` / `connector` / `content` / `footer` / `button` / `primaryButton` | - | 各部分自定义类名 |

### 禁用状态

传入 `disabled` 冻结内联变体的 Back / Continue 按钮——例如异步提交进行中时。

## API 参考

### useWizardNavigation

导出的向导状态机，用于构建自定义向导外壳：`useWizardNavigation({ count, defaultIndex?, index?, maxIndex?, onIndexChange? })` 返回 `{ index, maxVisited, maxReachable, isFirst, isLast, isReachable, go }`。

### Wizard

向导组件，管理步骤导航状态，渲染 Steps 指示器、Pager 内容区和底部按钮。

| 属性        | 类型                | 默认值 | 描述                              |
| :---------- | :------------------ | :----- | :------------------------------- |
| `steps`     | `StepsItemConfig[]` | -      | 进度指示器的步骤配置              |
| `children`  | `React.ReactNode[]` | -      | 页面内容，每个子元素对应一步       |
| `onFinish`  | `() => void`        | -      | 点击 Submit 按钮时触发            |
| `className` | `ClassNameValue`    | -      | 自定义类名，应用于根元素          |
| `classNames`| `{ root? / steps? / pager? / footer? }` | - | 按插槽自定义类名 |
