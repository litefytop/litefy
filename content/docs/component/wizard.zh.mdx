## 用法

### 基础用法

传入 `steps` 作为进度指示器，`children` 作为 Pager 内容——每个子元素对应一步。Wizard 内部管理 `index` 和 `maxIndex`；已到达的步骤可通过 Steps 指示器回退，未来步骤不能跳过。

## 注意

- Wizard 内部使用 [Steps](/docs/component/steps) 和 [Pager](/docs/component/pager)——CLI 安装时请一并添加：`litefy add wizard steps pager`。
- Pager 配置为 `gesture={false}` 和 `transition="view-transition"`，防止误滑提交并为步骤切换提供动画。
- `maxIndex` 记录已到达的最远步骤并传给 Steps——已到达步骤可点击回退，未来步骤锁定。
- 最后一步将 Next 按钮替换为 Submit，点击时触发 `onFinish`。

## API 参考

### Wizard

向导组件，管理步骤导航状态，渲染 Steps 指示器、Pager 内容区和底部按钮。

| 属性        | 类型                | 默认值 | 描述                              |
| :---------- | :------------------ | :----- | :------------------------------- |
| `steps`     | `StepsItemConfig[]` | -      | 进度指示器的步骤配置              |
| `children`  | `React.ReactNode[]` | -      | 页面内容，每个子元素对应一步       |
| `onFinish`  | `() => void`        | -      | 点击 Submit 按钮时触发            |
| `className` | `ClassNameValue`    | -      | 自定义类名，应用于根元素          |
| `classNames`| `{ root? / steps? / pager? / footer? }` | - | 按插槽自定义类名 |
