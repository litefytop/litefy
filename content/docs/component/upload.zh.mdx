## 用法

### 基础用法

Upload 组件只处理选择、拖拽与本地校验——不发起网络请求，也不维护上传状态。搭配 [`useUploadMonitor`](/docs/utils/use-upload-monitor) hook 执行上传并跟踪进度。

### 校验限制

`accept`、`maxSize` 与 `maxCount` 在本地校验；被拒绝的文件通过 `onFilesRejected` 上报。

## API 参考

### 高级组件

#### Upload

由下方零件组合而成的拖拽上传区域，封装校验与文件条目生命周期。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `accept` | `string` | - | 接受的文件类型（MIME 类型、`image/*` 或 `.pdf` 等扩展名） |
| `multiple` | `boolean` | `false` | 允许选择多个文件 |
| `maxCount` | `number` | - | 同时接受的最大条目数量 |
| `maxSize` | `number` | - | 单个文件最大字节数 |
| `disabled` | `boolean` | `false` | 禁用点击、键盘与拖拽交互 |
| `invalid` | `boolean` | - | 在根节点设置 `data-invalid`，dropzone 设置 `aria-invalid` |
| `children` | `React.ReactNode` | - | 自定义 dropzone 内容；默认为提示文本 |
| `onFilesAccepted` | `(items: UploadItem[]) => void` | - | 校验通过时触发，每项包含 `{ uid, file, signal }` |
| `onFilesRejected` | `(rejects: UploadReject[]) => void` | - | 校验失败时触发，携带拒绝原因（`accept` / `maxSize` / `maxCount`） |
| `onFileRemove` | `(uid: string) => void` | - | `actionsRef.current.remove(uid)` 中止对应 controller 后触发 |
| `onDragEnter` | `(e: React.DragEvent) => void` | - | 文件拖入 dropzone 时触发 |
| `onDragLeave` | `(e: React.DragEvent) => void` | - | 文件拖出 dropzone 时触发 |
| `actionsRef` | `React.Ref<UploadActions>` | - | 命令式句柄，暴露 `remove(uid)` 与 `clear()`；`remove` 会先中止对应 controller 再触发 `onFileRemove` |
| `className` | `ClassNameValue` | - | 根节点自定义类 |
| `style` | `React.CSSProperties` | - | 根节点自定义内联样式 |
| `classNames` | `{ root?; dropzone?; hiddenInput? }` | - | 各零件自定义类 |
| `styles` | `{ root?; dropzone?; hiddenInput? }` | - | 各零件自定义内联样式 |

组件卸载时中止全部 controller。

### 可组合组件

纯展示零件，不内置状态与交互，供高级使用者自由拼装。

#### UploadRoot

最外层容器。

#### UploadDropzone

拖拽区域表面；渲染为 `role="button"` 的 div，事件与样式由使用者接入。

#### UploadHiddenInput

隐藏的原生 `input[type=file]`；`onChange` 与外部 `click()` 触发由使用者接入。
