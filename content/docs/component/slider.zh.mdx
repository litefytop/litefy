## 用法

### 基础用法

由 div 模拟的滑块（轨道、填充与滑块），支持指针拖拽与键盘方向键、Home、End 操作。

## API 参考

### 高级组件

#### Slider

由下方零件组合而成的模拟滑块，封装全部状态与交互逻辑。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | - | 当前值（受控） |
| `defaultValue` | `number` | `0` | 初始值（非受控） |
| `onChange` | `(val: number) => void` | - | 拖拽、点击轨道或键盘操作导致值变化时的回调 |
| `min` | `number` | `0` | 最小值 |
| `max` | `number` | `100` | 最大值 |
| `step` | `number` | `1` | 步长；根据步长精度保留小数 |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | 轨道方向；垂直方向完全由 JS 计算定位（最小值在底部） |
| `disabled` | `boolean` | `false` | 禁用指针与键盘交互 |
| `name` | `string` | - | 渲染 hidden input 用于表单提交 |
| `invalid` | `boolean` | `false` | 在根节点设置 `data-invalid`，滑块、填充与轨道显示错误色 |
| `aria-label` | `string` | - | 应用到滑块的无障碍标签 |
| `className` | `ClassNameValue` | - | 根节点自定义类 |
| `style` | `React.CSSProperties` | - | 根节点自定义内联样式 |
| `classNames` | `{ root?; track?; fill?; thumb? }` | - | 各零件自定义类 |
| `styles` | `{ root?; track?; fill?; thumb? }` | - | 各零件自定义内联样式 |

键盘操作遵循 WAI-ARIA slider：方向键、PageUp/PageDown、Home、End。

---

### 可组合组件

纯展示零件，不内置状态与交互，供高级使用者自由拼装。

#### SliderRoot

最外层容器。

#### SliderTrack

滑动轨道；尺寸与颜色由使用者指定（如 `h-2 w-3xs rounded-full bg-muted`）。

#### SliderFill

进度填充；定位完全由使用者的内联样式决定。

#### SliderThumb

滑块，渲染为 `<button>`；事件与 `role="slider"` aria 属性由使用者接入。
