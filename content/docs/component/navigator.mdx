## Usage

`Navigator` renders the standard opening layout for filter toolbars: a flex container that wraps automatically, with sibling controls vertically centered on the same row. Filter state comes from the [useNavigator](/docs/utils/use-navigator) hook.

<ComponentPreview name="navigator-basic" />

### Hook-only mode

The component is a pure layout shell. When the standard layout does not fit, skip it entirely and drive your own DOM with the [useNavigator](/docs/utils/use-navigator) hook:

<ComponentPreview name="use-navigator-basic" />

## Notes

- No pagination logic built in — pagination belongs to the Table suite. Compose `Navigator` and `Table` externally; never nest `Navigator` inside `Table`.
- Title text wraps automatically and never squeezes sibling controls.
- Pair with a `text` Button calling `reset()` and disable it via `activeCount === 0` for the standard "reset filters" affordance.

## API Reference

### Navigator

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `React.ReactNode` | - | Leading title text or label |
| `classNames` | `{ title?: ClassNameValue }` | - | Custom class names per slot |
| `styles` | `{ title?: React.CSSProperties }` | - | Custom styles per slot |
| `className` | `ClassNameValue` | - | Custom class names of the container |
| `...props` | `React.ComponentProps<"div">` | - | Native div props |
