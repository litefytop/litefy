## 用法

### 变体

变体是纯皮肤态，由皮肤层 JS 选择，不进骨架接口：`ChipGroup` 读组级 `data-variant`（`surface` / `primary` / `outline` / `success` / `warning` / `danger` / `info`，默认 `surface`）选一条配色发给所有标签。直接在任意元素上组合时，用皮肤导出的 `chipBase`（布局排版）配 `chipVariants.<变体>`（配色）经 `cn` 合并，如 `cn(chipBase, chipVariants.outline)`；默认标签串 `chipClasses` 等价 `cn(chipBase, chipVariants.surface)`。

## API 参考

### ChipGroup

| 属性                  | 类型                                            | 描述                                                                                              |
| :------------------ | :-------------------------------------------- | :---------------------------------------------------------------------------------------------- |
| `items`             | `ChipItem[]`                                  | 全部标签项                                                                                           |
| `onOverflowChange`  | `(hidden: ChipItem[]) => void`                | 折叠集合变化时回调，携带被隐藏的 items                                                                          |
| `renderMore`        | `(hidden: ChipItem[]) => React.ReactNode`     | 行内渲染自定义触发器，`hidden` 为被折叠的 items                                                                 |
| `className`         | `string`                                      | 自定义类名，应用于外层容器（在此设置 `max-width`）                                                                 |
| `style`             | `React.CSSProperties`                         | 外层容器的内联样式                                                                                       |
| `classNames`        | `row` / `chip` / `more` / `measure`           | 按插槽自定义类名（`row` 标签行 / `chip` 单个标签 / `more` 溢出触发器 / `measure` 隐藏测量行）；`chip` 同时落在可见那一行的标签与离屏的测量副本上 |

### ChipItem

| 字段      | 类型                | 描述         |
| :------ | :---------------- | :--------- |
| `value` | `string`          | 唯一标识       |
| `label` | `React.ReactNode` | 标签文本       |

## 键盘交互

本组件不接管任何按键。每个标签都是不可聚焦的 `<span>`，因此只有 `renderMore` 传入的内容进入 Tab 序。

## 数据属性

骨架不在本组件上发射任何 `data-*`。离屏的测量行携带 `aria-hidden`。皮肤层读组级 `data-variant` 作 JS 选键，不做 data 属性样式门控。
