## 用法

渲染 chip 并自动折叠溢出项；隐藏集合通过 `onOverflowChange` / `renderMore(hidden)` 传出，触发器行内挂载（Popover、Tooltip 或纯文本由你决定）。

## API 参考

### ChipGroup

| 属性                | 类型                                          | 默认值 | 描述                                   |
| :------------------ | :-------------------------------------------- | :----- | :------------------------------------- |
| `items`             | `ChipItem[]`                                  | -      | 全部标签项                             |
| `onOverflowChange`  | `(hidden: ChipItem[]) => void`                | -      | 折叠集合变化时回调，携带被隐藏的 items |
| `renderMore`        | `(hidden: ChipItem[]) => React.ReactNode`     | -      | 行内渲染自定义触发器，`hidden` 为被折叠的 items |
| `className`         | `ClassNameValue`                              | -      | 自定义类名，应用于外层容器（在此设置 `max-width`） |
| `classNames`        | `chip`                                        | -      | 按插槽自定义类名                       |

### ChipItem

| 字段    | 类型              | 默认值 | 描述       |
| :------ | :---------------- | :----- | :--------- |
| `value` | `string`          | -      | 唯一标识   |
| `label` | `React.ReactNode` | -      | 标签文本   |
