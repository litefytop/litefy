## 用法

## API 参考

### Group

横向控件组容器。子件原样透传——Group 不替它们渲染零件。

| 属性          | 类型                            | 描述                                     |
| ----------- | ----------------------------- | -------------------------------------- |
| `children`  | `React.ReactNode`             | 参与连接的兄弟控件                              |
| `className` | `string`                      | 容器自定义类名                                |
| `role`      | `string`                      | 容器角色，可覆盖，默认 `group`                    |
| `...props`  | `React.ComponentProps<"div">` | 支持全部 div 原生属性                          |

### GroupRoot

分组容器零件，行为与 `Group` 相同、不带皮肤连接外观。

| 属性       | 类型                          | 描述                     |
| ---------- | ----------------------------- | ------------------------ |
| `...props` | `React.ComponentProps<"div">` | 支持全部 div 原生属性    |

## 键盘交互

不接管任何按键——子件保持各自的键盘行为与焦点环。

## 数据属性

骨架不在本组件上发射任何 `data-*`。
