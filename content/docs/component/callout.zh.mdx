## API 参考

### Callout

纯样式组件——无骨架、无交互态，内容直接渲染在块内。

| 属性          | 类型                            | 描述                                                 |
| ----------- | ----------------------------- | -------------------------------------------------- |
| `role`      | `string`                      | 块的 ARIA 角色，可按语义改为 `alert` / `status` 等，默认 `"note"` |
| `children`  | `React.ReactNode`             | 提示内容                                               |
| `className` | `string`                      | 块的自定义类名；默认 `w-full min-w-0`                                            |
| `...props`  | `React.ComponentProps<"div">` | 支持全部 div 原生属性                                      |

## 键盘交互

本组件不接管任何按键，也不可聚焦——纯展示块；可交互内容只能来自 `children`。

## 数据属性

| Attribute        | Description                                                            |
| ---------------- | ---------------------------------------------------------------------- |
| `[data-variant]` | 语义变体：`success` / `warning` / `danger`，缺省 `info`；铺对应语义背景色档（300 / 200 档）为底，start 侧深色竖线，图标与标题取配对 `*-fg` |
