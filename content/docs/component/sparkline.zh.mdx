## API 参考

### Sparkline

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :----- | :--- |
| `data` | `number[]` | - | 原始数值，从左到右映射 |
| `variant` | `"line" \| "area" \| "bar"` | `"line"` | 迷你图形状 |
| `smooth` | `boolean` | `false` | line 与 area 的单调三次平滑 |
| `className` | `ClassNameValue` | - | 尺寸与颜色类，如 `h-8 w-32 text-primary` |
| `...props` | `React.ComponentProps<"svg">` | - | 透传到根 `svg` 元素 |
