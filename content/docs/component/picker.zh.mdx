## API 参考

### 高级组件

#### Picker

| 属性            | 类型                              | 默认值  | 描述                                                                |
| --------------- | --------------------------------- | ------- | ------------------------------------------------------------------- |
| `value`         | `string`                          | -       | 受控的输入值                                                        |
| `defaultValue`  | `string`                          | `""`    | 非受控模式下的默认输入值                                            |
| `onValueChange` | `(value: string) => void`         | -       | 输入值变化时触发                                                    |
| `open`          | `boolean`                         | -       | 受控的弹出面板打开状态                                              |
| `defaultOpen`   | `boolean`                         | `false` | 初始打开状态（非受控）                                              |
| `onOpenChange`  | `(open: boolean) => void`         | -       | 面板应当打开或关闭时触发（点击、点击外部、Escape）                  |
| `trailing`      | `React.ReactNode`                 | -       | 渲染在输入框尾部的图标                                              |
| `children`      | `React.ReactNode`                 | -       | 弹出面板内容                                                        |
| `panelRef`      | `React.Ref<HTMLDivElement>`       | -       | 接收面板元素，配合 [`usePanelFocus`](/docs/utils/use-panel-focus) 使用 |
| `className`     | `ClassNameValue`                  | -       | 自定义类名，作用于根容器                                           |
| `style`         | `React.CSSProperties`             | -       | 内联样式，作用于根容器                                             |
| `classNames`    | `PickerClassNames`                | -       | 分区类名覆盖：`input`、`trailing`、`popover`                |
| `styles`        | `PickerStyles`                    | -       | 分区样式覆盖：`input`、`trailing`、`popover`                |
| `...props`      | `React.ComponentProps<"input">`   | -       | 其余原生 input 属性，如 `placeholder`、`disabled`                   |

受控模式下父组件必须在每次输入时响应 `onValueChange` 更新 `value`，否则无法键入。

消费者传入的 `onKeyDown` / `onClick` 与内置的开关及 Escape 关闭组合调用，`preventDefault` 会跳过内置行为。

面板键盘用 hook 接线：高亮列表用 [`useCombobox`](/docs/utils/use-combobox)（面板打开期间输入框保持焦点），真实可聚焦控件构成的面板用 [`usePanelFocus`](/docs/utils/use-panel-focus) 配合 `panelRef`；面板关闭时焦点若即将丢失会自动交还给输入框。

面板定位由内置 JS 定位引擎完成，除 Popover API 外无其他浏览器特性要求。

### 可组合组件

#### PickerRoot

输入框的包裹容器，承载面板消费的锚点名称（`data-anchor-name` 属性）。

| 属性       | 类型                          | 默认值  | 描述                                       |
| ---------- | ----------------------------- | ------- | ------------------------------------------ |
| `anchorName`| `string`                     | -       | 将该元素注册为面板的锚点                   |
| `className`| `ClassNameValue`              | -       | 自定义类名                                 |
| `...props` | `React.ComponentProps<"div">` | -       | 原生 div 属性                              |

#### PickerInput

触发输入框。

| 属性       | 类型                           | 默认值  | 描述          |
| ---------- | ------------------------------ | ------- | ------------- |
| `className`| `ClassNameValue`               | -       | 自定义类名    |
| `...props` | `React.ComponentProps<"input">`| -       | 原生 input 属性|

#### PickerContent

弹出面板——原生 `popover="manual"` 元素；命令式调用 `showPopover()` / `hidePopover()`，并通过 `anchorName` 属性定位（内置 JS 引擎将其贴在锚点下方、宽度贴合锚点，视口溢出时翻到上方）。

| 属性       | 类型                          | 默认值  | 描述                                       |
| ---------- | ----------------------------- | ------- | ------------------------------------------ |
| `anchorName`| `string`                     | -       | 锚点元素的名称（其 `data-anchor-name`）    |
| `className`| `ClassNameValue`              | -       | 自定义类名                                 |
| `...props` | `React.ComponentProps<"div">` | -       | 原生 div 属性                              |
