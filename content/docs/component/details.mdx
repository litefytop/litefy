### Native Exclusive Grouping

Give several Details the same `name` to form an exclusive group: opening one closes the others, handled entirely by the browser (Chrome 126+, Safari 17.2+, Firefox 130+; older browsers fall back to independent panels).

## API Reference

### High-level Components

Ready-to-use composite components.

#### Details

A native `<details>` disclosure shell: open state, exclusivity, and keyboard activation are managed by the browser; `disabled` only cancels trigger-row activation and preserves the current state, does not take over `open` / `onToggle`, and leaves the content area interactive.

| Prop         | Type                                                                                        | Description                                                                       |
| ------------ | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `label`      | `React.ReactNode`                                                                           | Content shown on the header trigger                                               |
| `icon`       | `React.ReactNode`                                                                           | Expand/collapse icon; pass `null` to render no icon, defaults to `ChevronDown`    |
| `name`       | `string`                                                                                    | Exclusive group name, passed through natively to the `<details>` element          |
| `disabled`   | `boolean`                                                                                   | Prevents the trigger row from toggling and preserves the current open state, defaults to `false` |
| `className`  | `string`                                                                                    | Custom classes, applied to the root `<details>` element; defaults to `w-full min-w-0` |
| `classNames` | `{ summary?: string; icon?: string; body?: string }`                                        | Custom classes for the three slots: trigger row, icon box, content container      |
| `styles`     | `{ summary?: React.CSSProperties; icon?: React.CSSProperties; body?: React.CSSProperties }` | Inline styles for the same three slots                                            |
| `children`   | `React.ReactNode`                                                                           | Panel content                                                                     |
| `...props`   | `React.ComponentProps<"details">`                                                           | Supports all native details props (including `open` and `onToggle`)               |

## Keyboard Interactions

| Key | Description |
| --- | --- |
| `Enter` / `Space` | Activates the native `<summary>` to expand or collapse the current disclosure; activation is cancelled when disabled |
| `Tab` | Reaches the trigger row, including disabled items; disabled items remain focusable and announce `aria-disabled`. A collapsed disclosure keeps its content mounted in the DOM, so its focusable elements remain in the tab order |

## Data Attributes

| Attribute | Description |
| --- | --- |
| `[open]` | On the root `<details>` element, present while expanded — the skin uses it to drive icon rotation and hover tinting |
| `[data-disabled]` | On the root `<details>` element — present when `disabled` is `true` |
