## Usage

Configuring `status` turns the button into a grid: with `icon`, both cells stay in place and swap the icon in place; without `icon`, `active` shows the status icon before the text.

## Variants

Left to right: default (primary), outline, text, and danger.

<ComponentPreview name="button-variants" />

primary carries priority (submit, confirm); danger marks high-risk actions only; outline and text are for side-by-side actions of equal priority.

## Disabled

Native `disabled` or `aria-disabled` switches to a separate disabled class set: `bg-disabled`, `text-disabled-fg`, `shadow-frame-disabled`, and `cursor-not-allowed`; the text variant keeps its transparent background without a grayscale filter.

## API Reference

### Button

The button renders `icon` and `children` as the two cells of a grid; while `status.active` is true the icon cell swaps to `status.icon` in place. Passing only `icon` without `children` creates the icon-only form, which must include its own `aria-label` describing the action.

| Prop        | Type                                          | Description                                                                                                                                                                                                                                                                                                                                               |
| ----------- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `className` | `string`                                      | Custom CSS class.                                                                                                                                                                                                                                                                                                                                         |
| `icon`      | `React.ReactNode`                             | The icon cell, rendered before `children`; icons are sized by the button (`size-4`, scaling with the spacing scale across schemes and compact mode)                                                                                                                                                                                                                                              |
| `status`    | `{ icon: React.ReactNode; active: boolean }`  | Configuring it turns the button into a grid. With `icon`: both cells stay in place and the icon swaps in place; without `icon`: `active` shows `status.icon` before `children`. Display only — pass `disabled` / `aria-busy` yourself while waiting |
| `...props`  | `React.ComponentProps<"button">`              | Supports all native button props (except `className`), such as `type`, `disabled`                                                                                                                                                                                                                                                                         |

### Atomic Components

#### ButtonRoot

The `<button>` itself: children carry the content, and empty children emit `data-pure-icon`. It carries no styles and no layout — compose it into your own trigger with your own classes. Across all four schemes, the square shape and zero padding come from the `pure-icon` utility: `Button` adds it automatically when there are no children; other consumers (a bare `a`, `Link`, or `ButtonRoot`) must add both the class and the attribute for the square shape to apply.

## Keyboard Interactions

| Key | Description |
| --- | --- |
| `Enter` / `Space` | Activates the button through the native `<button>`; the skeleton handles no keys |
| `Tab` | Reaches the button; a `disabled` button leaves the tab order |

## Data Attributes

| Attribute | Description |
| --- | --- |
| `[data-variant]` | On the button — `outline` takes the outlined look, `text` the chrome-less inline look; absent means primary |
| `[data-danger]` | On the button — for dangerous actions; switches to the danger colors and danger focus ring |
| `[data-pure-icon]` | On the button — present when `children` is omitted; the `pure-icon` utility provides the square box (44×44 with zero padding), which `Button` adds automatically and other consumers must add directly |
| `[data-status]` | On the button — present while `status` is configured; switches the layout to grid |
