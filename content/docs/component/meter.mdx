## Usage

A read-only gauge — the indicator bar's width on a continuous track carries the reading, trailing the current value; the fill takes a semantic token tier, banding follows the native `<meter>` rules.

## API Reference

### Meter

| Prop        | Type     | Description                                                                                                                                                   |
| :---------- | :------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `value`     | `number` | Current reading, clamped to `[min, max]`                                                                                                                      |
| `min`       | `number` | Lower bound of the range, defaults to `0`                                                                                                                     |
| `max`       | `number` | Upper bound of the range, defaults to `100`                                                                                                                   |
| `low`       | `number` | Lower threshold of the default banding (defaults model a higher-is-better reading; override the whole set to fit yours), defaults to `20`                     |
| `high`      | `number` | Upper threshold of the default banding, defaults to `60`                                                                                                      |
| `optimum`   | `number` | Where the optimal value sits: below `low` favours the low band, above `high` favours the high band, inside `[low, high]` favours the middle, defaults to `80` |
| `hideValue` | `boolean` | Hides the trailing value readout; the readout is `aria-hidden` (it shows the raw value within the range), and the value is always expressed by `aria-valuenow`, defaults to `false` |
| `className` | `string` | Custom class for the root; defaults to `w-full min-w-0`                                                                                                        |

The remaining native `<div>` attributes (`aria-label`, `id`, inline `style`, …) are accepted and land on the root; the accessible name comes from `aria-label`.

Banding follows the HTML `<meter>` rules: an `optimum` below `low` favours the low band, above `high` favours the high band, and one inside the range favours the middle; a reading in the band containing the optimum is success, an adjacent band is warning, and the farthest band is danger. The fill takes the matching semantic resting background tier (the same value in light and dark); a pale fill under 3:1 against the light-mode `surface` groove track is an accepted item — the trailing readout already provides a text alternative, and 1.4.11 does not apply to non-essential graphics.
