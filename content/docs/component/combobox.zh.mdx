## 用法

### 基础用法

传入 `options` 作为本地字符串选项——键入文本即时过滤（不区分大小写），`ArrowDown` / `ArrowUp` 移动高亮，`Enter` 或点击行选中。

### 异步搜索

数据量大或来源为远程接口时，传入 `fetcher` 代替 `options`——关键词搜索自动防抖，列表滚动到底部时触发 `loadMore` 加载更多。

## 注意

- Combobox 内部由 [Picker](/docs/component/picker)、[List](/docs/component/list) 和 [useCombobox](/docs/utils/use-combobox) / [useRemotePagination](/docs/utils/use-remote-pagination) 工具组合而成——CLI 安装时会自动解析并安装这些依赖。
- 同时传入 `fetcher` 和 `options` 时，`fetcher` 优先。
- 异步模式在挂载时和每次键入（防抖）后发起搜索；请求进行中时空状态显示 "Loading..."。
- 焦点始终留在输入框：`ArrowDown` 打开面板，随后方向键驱动高亮、`Enter` 选中；选中、点击面板外或 `Escape` 关闭面板。
- 选中后输入框文本即所选选项——重新打开时列表会按它过滤；清空文本即可看到全部选项。

## API 参考

### Combobox

| 属性 | 类型 | 默认值 | 描述 |
| :--- | :--- | :----- | :--- |
| `options` | `string[]` | - | 本地选项，客户端过滤 |
| `fetcher` | `({ page, size, keyword }) => Promise<{ list: string[]; total: number }>` | - | 异步模式的远程请求函数 |
| `defaultValue` / `value` | `string` | `""` | 输入框文本（非受控 / 受控） |
| `onValueChange` | `(value: string) => void` | - | 键入和选中时触发 |
| `invalid` | `boolean` | `false` | 输入框无效态样式 |
| `empty` | `React.ReactNode` | `"No data"` / `"Loading..."` | 列表空状态节点 |
| `pageSize` | `number` | `20` | 异步分页大小 |
| `debounceMs` | `number` | `300` | 异步搜索防抖延迟 |
| `className` | `ClassNameValue` | - | 自定义类名，应用于输入框容器 |
| `classNames` | `{ panel? / item? }` | - | 面板与列表项的自定义类名 |
