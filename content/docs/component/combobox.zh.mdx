## API 参考

### Combobox

| 属性              | 类型                                                                        | 描述                                      |
| :-------------- | :------------------------------------------------------------------------ | :-------------------------------------- |
| `options`       | `string[]`                                                                | 本地选项，客户端过滤                              |
| `fetcher`       | `({ page, size, keyword }) => Promise<{ list: string[]; total: number }>` | 异步模式的远程请求函数                             |
| `defaultValue`  | `string`                                                                  | 初始输入框文本（非受控），默认 `""`                    |
| `value`         | `string`                                                                  | 受控输入框文本                                 |
| `onValueChange` | `(value: string) => void`                                                 | 键入和选中时触发                                |
| `invalid`       | `boolean`                                                                 | 输入框无效态，默认 `false`                       |
| `disabled`      | `boolean`                                                                 | 组级禁用：输入框原生禁用、容器挂 `inert`，候选面板不可打开，默认 `false` |
| `empty`         | `React.ReactNode`                                                         | 列表空状态节点，默认 `"No data"` / `"Loading..."` |
| `pageSize`      | `number`                                                                  | 异步分页大小，默认 `20`                          |
| `debounceMs`    | `number`                                                                  | 异步搜索防抖延迟，默认 `300`                       |
| `leading`       | `React.ReactNode`                                                         | 字段组内前缀节点，默认搜索图标；传 `null` 移除         |
| `className`     | `string`                                                                  | 自定义类名，应用于输入框容器                          |
| `classNames`    | `{ panel? / item? }`                                                      | 面板与列表项的自定义类名                            |

### 原子组件

#### Picker

Combobox 的底座：通用 input + popover 容器，用于拼装自定义拾取场景（CLI 随 `litefy add combobox` 一并安装）。

| 属性                       | 类型                                  | 描述                                                           |
| :----------------------- | :---------------------------------- | :----------------------------------------------------------- |
| `value` / `defaultValue` | `string`                            | 输入值（受控 / 非受控），默认 `""`                                        |
| `onValueChange`          | `(value: string) => void`           | 输入值变化时触发                                                     |
| `open` / `defaultOpen`   | `boolean`                           | 面板打开状态（受控 / 非受控），默认 `false`                                  |
| `onOpenChange`           | `(open: boolean) => void`           | 面板开合时触发（点击、点击外部、Escape）                                      |
| `trailing`               | `React.ReactNode`                   | 输入框尾部图标                                                      |
| `children`               | `React.ReactNode`                   | 弹出面板内容                                                       |
| `panelRef`               | `React.Ref<HTMLDivElement>`         | 接收面板元素，配合 [usePanelFocus](/zh/docs/utils/use-panel-focus) 使用 |
| `className` / `style`    | -                                   | 作用于根容器                                                       |
| `classNames` / `styles`  | `{ input? / trailing? / popover? }` | 分区覆盖                                                         |
| `...props`               | `React.ComponentProps<"input">`     | 其余原生 input 属性                                                |

面板键盘用 hook 接线：高亮列表用 [useCombobox](/zh/docs/utils/use-combobox)（面板打开期间输入框保持焦点），真实可聚焦控件构成的面板用 [usePanelFocus](/zh/docs/utils/use-panel-focus) 配合 `panelRef`；面板关闭时焦点若即将丢失会自动交还给输入框。

## 键盘交互

| Key | Description |
| --- | --- |
| `ArrowDown` / `ArrowUp` | 面板打开时移动高亮；面板关闭时按 `ArrowDown` 打开面板 |
| `Enter` | 提交当前高亮的选项 |
| `Escape` | 关闭面板 |

输入法组合输入期间，`onValueChange` 与远程搜索会被挂起，组合结束后才触发。

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-open]` | 位于根元素——面板打开期间存在（来自底层 Picker） |
