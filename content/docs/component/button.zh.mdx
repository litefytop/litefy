## API 参考

### Button

按钮组件。

| Prop            | Type                                                | Default     | Description                                               |
| --------------- | --------------------------------------------------- | ----------- | --------------------------------------------------------- |
| `variant`       | `'primary' \| 'danger' \| 'outline' \| 'text'` | `'primary'` | 按钮视觉变体                                              |
| `className`     | `ClassNameValue`                                    | -           | 自定义 CSS 类，接受字符串、数组以及所有假值（false、null、undefined、0、0n）；不支持 true 和对象。 |
| `loadingConfig` | `ButtonLoadingConfig`                               | -           | 加载状态配置                                              |
| `...props`      | `React.ComponentProps<"button">`                    | -           | 支持全部 button 原生属性（除 `className`），如 `type`、`disabled`                                                  |

### ButtonLoadingConfig

| Prop      | Type              | Default | Description          |
| --------- | ----------------- | ------- | -------------------- |
| `loading` | `boolean`         | `false` | 按钮是否处于加载状态 |
| `icon`    | `React.ReactNode` | -       | 自定义加载图标       |

### Button.className

静态 class 字符串，用于把完整的按钮外观套到非 button 元素上，例如把 `<a>` 链接样式化为按钮。每个键都是预拼接、冲突已解决的完整 class 串（base + 变体），可直接作为 `className` 使用，无需 `cn`：

```tsx
<Link to="/docs" className={Button.className.primary}>
  阅读文档
</Link>
```

| 键        | 等价外观                         |
| --------- | -------------------------------- |
| `primary` | `variant="primary"`（默认）外观  |
| `danger`  | `variant="danger"` 外观          |
| `outline` | `variant="outline"` 外观         |
| `text`    | `variant="text"` 外观            |
