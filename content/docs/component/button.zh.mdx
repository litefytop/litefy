## API 参考

### Button

按钮组件。

| Prop            | Type                                                | Default     | Description                                               |
| --------------- | --------------------------------------------------- | ----------- | --------------------------------------------------------- |
| `variant`       | `'primary' \| 'danger' \| 'outline' \| 'text'` | `'primary'` | 按钮视觉变体                                              |
| `className`     | `ClassNameValue`                                    | -           | 自定义 CSS 类，接受字符串、数组以及所有假值（false、null、undefined、0、0n）；不支持 true 和对象。 |
| `loadingConfig` | `ButtonLoadingConfig`                               | -           | 加载状态配置                                              |
| `...props`      | `React.ComponentProps<"button">`                    | -           | 支持全部 button 原生属性（除 `className`），如 `type`、`disabled`                                                  |

### ButtonLoadingConfig

| Prop      | Type              | Default | Description          |
| --------- | ----------------- | ------- | -------------------- |
| `loading` | `boolean`         | `false` | 按钮是否处于加载状态 |
| `icon`    | `React.ReactNode` | -       | 自定义加载图标       |

### 给非 button 元素套按钮外观

按钮外观就是 preset 皮肤（`preset/button.css`）里的成品 class——任何元素（`<a>` CTA 链接、`Link`）挂上同样的 class 即可获得完整按钮外观：

```tsx
<Link to="/docs" className="litefy-button litefy-button-primary">
  阅读文档
</Link>
```

| Class                                                | 作用                     |
| ---------------------------------------------------- | ------------------------ |
| `litefy-button`                                      | 基础布局/焦点/按压形态（必带） |
| `litefy-button-primary` / `-danger` / `-outline` / `-text` | 外观变体                 |
| `data-pure-icon="true"`                              | 可选状态属性：纯图标方形   |
