## 用法

### 数据驱动

简单场景直接用组合组件 `Breadcrumb`，按顺序渲染 `items`——最后一条渲染为当前页，其余渲染为链接：

<ComponentPreview
  name="breadcrumb-basic"
/>

```tsx
import { Breadcrumb } from "@/ui";

<Breadcrumb
  items={[
    { label: "Home", href: "/" },
    { label: "Project", href: "/project" },
    { label: "Current Page" },
  ]}
/>
```

### 零件组合

每一层都导出为零件——自由组合以完全掌控条目、图标与分隔符：

## API 参考

### Breadcrumb

| 属性         | 类型                                            | 默认值 | 描述                                           |
| :----------- | :---------------------------------------------- | :----- | :--------------------------------------------- |
| `items`      | `BreadcrumbDataItem[]`                          | -      | 路径条目，按层级顺序排列；最后一条渲染为当前页 |
| `classNames` | `root` / `list` / `link` / `page` / `separator` | -      | 按插槽自定义类名                               |
| `styles`     | `root` / `list` / `link` / `page` / `separator` | -      | 按插槽自定义样式                               |
| `...props`   | `React.ComponentProps<"nav">`                   | -      | 原生 nav 属性，展开到根元素                    |

### BreadcrumbDataItem

| 字段    | 类型              | 默认值 | 描述                             |
| :------ | :---------------- | :----- | :------------------------------- |
| `label` | `React.ReactNode` | -      | 条目文本                         |
| `href`  | `string`          | -      | 链接目标；配置后该条目渲染为链接 |

### 组合零件

零件继承原生 DOM 属性，内置 `className` 通过 `cn` 合并 —— 传入 `className` 是扩展默认值而非替换。

#### BreadcrumbRoot

外层 `<nav aria-label="breadcrumb">` 容器。

| 属性        | 类型                          | 默认值 | 描述          |
| :---------- | :---------------------------- | :----- | :------------ |
| `className` | `ClassNameValue`              | -      | 自定义类名    |
| `...props`  | `React.ComponentProps<"nav">` | -      | 原生 nav 属性 |

#### BreadcrumbList

内层 `<ol>`，flex 布局并允许换行。

| 属性        | 类型                         | 默认值 | 描述         |
| :---------- | :--------------------------- | :----- | :----------- |
| `className` | `ClassNameValue`             | -      | 自定义类名   |
| `...props`  | `React.ComponentProps<"ol">` | -      | 原生 ol 属性 |

#### BreadcrumbItem

单个 `<li>` 条目容器。

| 属性        | 类型                         | 默认值 | 描述         |
| :---------- | :--------------------------- | :----- | :----------- |
| `className` | `ClassNameValue`             | -      | 自定义类名   |
| `...props`  | `React.ComponentProps<"li">` | -      | 原生 li 属性 |

#### BreadcrumbLink

可点击路径链接（真实 `<a>`）。

| 属性        | 类型                        | 默认值 | 描述        |
| :---------- | :-------------------------- | :----- | :---------- |
| `className` | `ClassNameValue`            | -      | 自定义类名  |
| `...props`  | `React.ComponentProps<"a">` | -      | 原生 a 属性 |

#### BreadcrumbPage

当前页文本（不可点击，带 `aria-current="page"`）。

| 属性        | 类型                           | 默认值 | 描述           |
| :---------- | :----------------------------- | :----- | :------------- |
| `className` | `ClassNameValue`               | -      | 自定义类名     |
| `...props`  | `React.ComponentProps<"span">` | -      | 原生 span 属性 |

#### BreadcrumbSeparator

分隔符，默认渲染 `ChevronRight` 图标，可通过 `children` 替换。

| 属性        | 类型                         | 默认值 | 描述             |
| :---------- | :--------------------------- | :----- | :--------------- |
| `className` | `ClassNameValue`             | -      | 自定义类名       |
| `children`  | `React.ReactNode`            | -      | 自定义分隔符内容 |
| `...props`  | `React.ComponentProps<"li">` | -      | 原生 li 属性     |
