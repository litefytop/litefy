## Installation

<Installation name="calendar" />

> The component works with plain JavaScript `Date` values treated as calendar dates (no time-zone semantics). No date library is bundled and no polyfill is needed — it runs on every Baseline browser.

## API Reference

### High-level Components

Ready-to-use composite component.

#### Calendar

| Prop                   | Type                                            | Default  | Description                                                                             |
| :--------------------- | :---------------------------------------------- | :------- | :-------------------------------------------------------------------------------------- |
| `visibleMonth`         | `Date`                            | -        | Required. The month panel currently displayed                                           |
| `value`                | `Date \| null`                    | -        | Controlled selected date                                                                |
| `defaultValue`         | `Date \| null`                    | -        | Default selected date (uncontrolled)                                                    |
| `view`                 | `"days" \| "months" \| "years"`                 | -        | Controlled active panel                                                                 |
| `defaultView`          | `"days" \| "months" \| "years"`                 | `"days"` | Initial panel (uncontrolled)                                                            |
| `onChange`             | `(date: Date) => void`            | -        | Fired when clicking a valid date inside the visible month                               |
| `onVisibleMonthChange` | `(month: Date) => void`           | -        | Fired when the visible month changes (previous / next, panel pick, keyboard navigation) |
| `onViewChange`         | `(view: "days" \| "months" \| "years") => void` | -        | Fired when the active panel changes                                                     |
| `isDateDisabled`       | `(date: Date) => boolean`         | -        | Return `true` to disable the date                                                       |
| `firstDayOfWeek`       | `0 \| 1`                                        | `0`      | `0` starts the week on Sunday, `1` starts it on Monday                                  |
| `className`            | `ClassNameValue`                                | -        | Custom class names, applied to the root                                                 |

Dates are plain JavaScript `Date` values used as calendar dates. The component treats them as immutable — it never mutates the `Date` you pass in and always emits fresh `Date` objects (anchored at local noon to stay DST-safe) from `onVisibleMonthChange` / `onChange`. Month arithmetic clamps the day to the end of the target month: Jan 31 + 1 month becomes Feb 28/29.

`Calendar.calendarMonthLabels` is process-global — set it once at your app entry (it also affects [DatePicker](/docs/component/datepicker)); day-grid weekday abbreviations are fixed English.

```tsx
Calendar.calendarMonthLabels = ["一月", "二月", /* ... */];
```

### Composable Components

#### CalendarRoot

| Prop        | Type                          | Default | Description        |

#### CalendarHeader

Header shell: a flex row for the navigation buttons and the title buttons.

| Prop        | Type                             | Default | Description         |
| :---------- | :------------------------------- | :------ | :------------------ |
| `className` | `ClassNameValue`                 | -       | Custom class names  |
| `...props`  | `React.ComponentProps<"header">` | -       | Native header props |

#### CalendarNavButton

Chevron navigation button for the header.

| Prop        | Type                             | Default                 | Description                                          |
| :---------- | :------------------------------- | :---------------------- | :--------------------------------------------------- |
| `direction` | `"previous" \| "next"`           | -                       | Which chevron icon to render                         |
| `label`     | `string`                         | `"Previous"` / `"Next"` | Accessible name (`aria-label`)                       |
| `className` | `ClassNameValue`                 | -                       | Custom class names                                   |
| `...props`  | `React.ComponentProps<"button">` | -                       | Native button props (except `type` and `aria-label`) |

#### CalendarTitleButton

Text button for the header title area — typically rendered twice as the year and the month.

| Prop        | Type                             | Default | Description                                            |
| :---------- | :------------------------------- | :------ | :----------------------------------------------------- |
| `className` | `ClassNameValue`                 | -       | Custom class names                                     |
| `...props`  | `React.ComponentProps<"button">` | -       | Native button props (except `type`), such as `onClick` |

#### CalendarMonthGrid

3 × 4 month panel listing the 12 months of the visible year.

| Prop              | Type                                     | Default | Description                                                       |
| :---------------- | :--------------------------------------- | :------ | :---------------------------------------------------------------- |
| `visibleMonth`    | `Date`                     | -       | Source of the shown year; its month is the fallback tab stop      |
| `value`           | `Date \| null`             | -       | Selected date, highlights the cell of the same month              |
| `isMonthDisabled` | `(month: Date) => boolean` | -       | Receives the first day of each month; return `true` to disable it |
| `onSelect`        | `(month: Date) => void`    | -       | Fired with the first day of the picked month                      |
| `onNavigate`      | `(month: Date) => void`    | -       | Fired when arrowing out of the shown year with the target month   |
| `className`       | `ClassNameValue`                         | -       | Custom class names                                                |
| `...props`        | `React.ComponentProps<"div">`            | -       | Native div props                                                  |

#### CalendarYearGrid

3 × 4 year panel showing a 12-year window centered on the visible year.

| Prop             | Type                                    | Default | Description                                                    |
| :--------------- | :-------------------------------------- | :------ | :------------------------------------------------------------- |
| `visibleMonth`   | `Date`                    | -       | Centers the 12-year window; its year is the fallback tab stop  |
| `value`          | `Date \| null`            | -       | Selected date, highlights the cell of the same year            |
| `isYearDisabled` | `(year: Date) => boolean` | -       | Receives January 1st of each year; return `true` to disable it |
| `onSelect`       | `(year: Date) => void`    | -       | Fired with January 1st of the picked year                      |
| `onNavigate`     | `(year: Date) => void`    | -       | Fired when arrowing out of the window with the target year     |
| `className`      | `ClassNameValue`                        | -       | Custom class names                                             |
| `...props`       | `React.ComponentProps<"div">`           | -       | Native div props                                               |

#### CalendarGrid

Weekday header row plus the weeks body — pass a two-dimensional `weeks` array including previous/next-month padding dates.

| Prop             | Type                                    | Default | Description                                                   |
| :--------------- | :-------------------------------------- | :------ | :------------------------------------------------------------ |
| `weeks`          | `Date[][]`                | -       | Two-dimensional weeks array, 7 dates per row                  |
| `visibleMonth`   | `Date`                    | -       | Used to detect out-of-month cells                             |
| `value`          | `Date \| null`            | -       | Selected date, drives the highlighted cell                    |
| `isDateDisabled` | `(date: Date) => boolean` | -       | Return `true` to disable the date                             |
| `onSelect`       | `(date: Date) => void`    | -       | Fired on cell click; the composite filters out-of-month dates |
| `onNavigate`     | `(date: Date) => void`    | -       | Fired when arrowing to a date not present in the grid         |
| `firstDayOfWeek` | `0 \| 1`                                | `0`     | Weekday header order                                          |
| `className`      | `ClassNameValue`                        | -       | Custom class names                                            |
| `...props`       | `React.ComponentProps<"div">`           | -       | Native div props                                              |

#### CalendarGridRow

A single week row, usually rendered by `CalendarGrid`.

| Prop             | Type                                    | Default | Description                                                                                  |
| :--------------- | :-------------------------------------- | :------ | :------------------------------------------------------------------------------------------- |
| `week`           | `Date[]`                  | -       | The 7 dates of this week                                                                     |
| `visibleMonth`   | `Date`                    | -       | Used to detect out-of-month cells                                                            |
| `value`          | `Date \| null`            | -       | Selected date                                                                                |
| `isDateDisabled` | `(date: Date) => boolean` | -       | Return `true` to disable the date                                                            |
| `onSelect`       | `(date: Date) => void`    | -       | Fired on cell click                                                                          |
| `onNavigate`     | `(date: Date) => void`    | -       | Fired when arrowing to a date not present in the grid                                        |
| `tabStopDate`    | `string`                                | -       | ISO date string of the single tab stop in the grid; omit to keep all cells natively tabbable |
| `className`      | `ClassNameValue`                        | -       | Custom class names                                                                           |
| `...props`       | `React.ComponentProps<"div">`           | -       | Native div props                                                                             |

#### CalendarGridCell

A single date cell rendered as a button.

| Prop           | Type                             | Default | Description                                                                                |
| :------------- | :------------------------------- | :------ | :----------------------------------------------------------------------------------------- |
| `date`         | `Date`             | -       | The date this cell renders (shows `date.getDate()`)                                              |
| `outsideMonth` | `boolean`                        | `false` | Grays out cells not belonging to the visible month                                         |
| `selected`     | `boolean`                        | `false` | Highlights the cell as selected                                                            |
| `tabStop`      | `boolean`                        | -       | Roving tabindex: `true` makes the cell the only tab stop; omit to keep native tab behavior |
| `onNavigate`   | `(date: Date) => void` | -   | Fired when arrowing to a date not present in the grid                                       |
| `className`    | `ClassNameValue`                 | -       | Custom class names                                                                         |
| `...props`     | `React.ComponentProps<"button">` | -       | Native button props (except `type`), such as `disabled`                                    |
