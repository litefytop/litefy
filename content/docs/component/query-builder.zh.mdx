## 用法

以平铺树形列表展示字段行、嵌套 and/or 组与实时自然语言预览。

<ComponentPreview name="query-builder-basic" />

### 禁用状态

传入 `disabled` 让整棵树只读。

<ComponentPreview name="query-builder-disabled" />

### 枚举字段

`valueKind: "select"` 字段的选项常驻显示为复选框子行，勾选即直接增删条件。

### 自然语言预览

查询树的实时英文自然语言预览。

### 提交与重置

编辑只更新预览——**提交**以 `QueryGroup` 对象输出查询树，**重置**恢复 `defaultValue`。

## API 参考

### QueryBuilder

| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `fields` | `QueryFieldConfig[]` | - | 可用字段；每个字段渲染为一个唯一的字段行 **必填** |
| `defaultValue` | `QueryGroup` | 空 `and` 树 | 初始查询，也是重置的目标 |
| `onSubmit` | `(query: QueryGroup) => void` | - | 提交按钮触发 |
| `onQueryChange` | `(query: QueryGroup) => void` | - | `onSubmit` 的别名 |
| `onReset` | `() => void` | - | 重置按钮触发 |
| `showPreview` | `boolean` | `true` | 显示只读自然语言预览面板 |
| `maxDepth` | `number` | `2` | 最大组嵌套深度 |
| `disabled` | `boolean` | `false` | 禁用构建器 |
| `className` | `ClassNameValue` | - | 自定义类名，作用于根元素 |

### QueryFieldConfig

| 字段 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `name` | `string` | - | 写入查询的字段标识 **必填** |
| `label` | `string` | `name` | 字段行与预览中显示的标签 |
| `operators` | `string[]` | 按 `valueKind` | 子条件可用的操作符 |
| `valueKind` | `"text" \| "number" \| "date" \| "select"` | `"text"` | 值编辑器类型 |
| `options` | `{ label, value }[]` | - | `valueKind: "select"` 时的选项 |

### 安全：提交出去的是 JSON，不是 SQL

预览字符串切勿送后端执行——先按白名单校验 JSON，再在服务端生成参数化 SQL。

### 静态属性

| 属性 | 类型 | 描述 |
|------|------|------|
| `QueryBuilder.operatorLabels` | `Record<string, string>` | 操作符在下拉与自然语言预览中的显示文案。默认为英文自然语言短语（`=` → "is"、`>` → "is greater than"、`in` → "is one of" 等），赋值可部分覆盖（如中文）——未配置的键回退为原始操作符 |
