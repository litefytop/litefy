## Usage

### Basic Usage

Dropdown menu driven by the `items` config. Items can be grouped with labels, and any item can open a two-level submenu (max two levels).

### Alignment

Use `positionArea` (any valid CSS `position-area` value) for general placement, or `alignX` to attach the menu edge-to-edge beside the trigger for sidebar-style navigation.

## API Reference

### Dropdown

The main component. The root panel is a `popover="manual"` element positioned with `position-anchor` / `position-area`, with built-in collision detection (`position-try-fallbacks`).

| Prop            | Type                                    | Default             | Description                                                                                                        |
| --------------- | --------------------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `items`         | `DropdownItemConfig[]`                  | `[]`                | Menu item config, see [items](#items) below                                                                        |
| `children`      | `React.ReactNode`                       | -                   | Content of the trigger button                                                                                      |
| `itemClassName` | `ClassNameValue`                        | -                   | Class applied to every menu item button                                                                            |
| `positionArea`  | `string`                                | `'bottom span-all'` | Any valid CSS `position-area` value. Use `span-*` variants so collision detection works correctly                  |
| `alignX`        | `'start' \| 'end' \| 'center'`          | -                   | Sidebar mode: `start` attaches the menu's end edge to the trigger's start edge (opens left); `end` attaches the menu's start edge to the trigger's end edge (opens right); `center` centers it. Takes precedence over `positionArea` |
| `classNames`    | `{ trigger?: ClassNameValue; content?: ClassNameValue }` | -  | Custom classes for the trigger button and root panel                                                               |
| `styles`        | `{ trigger?: React.CSSProperties; content?: React.CSSProperties }` | - | Inline styles for the trigger button and root panel; `styles.content` merges with the built-in positioning styles |
| `...props`      | `React.ComponentProps<"div">`           | -                   | Supports all native div props on the root panel                                                                    |

#### items

```ts
type DropdownGroup = {
  group: React.ReactNode;
  items: DropdownMenuItem[];
};

type DropdownMenuItem = {
  label: React.ReactNode;
  disabled?: boolean;
  className?: ClassNameValue;
  onClick?: React.MouseEventHandler<HTMLButtonElement>;
  children?: Omit<DropdownMenuItem, "children">[];
};

type DropdownItemConfig = DropdownGroup | DropdownMenuItem;
```

#### Keyboard Navigation

| Key          | Behavior                                          |
| ------------ | -------------------------------------------------- |
| `Space` / `Enter` | Open the menu and focus the first item       |
| `ArrowDown` / `ArrowUp` | Move between items (wraps around)      |
| `ArrowRight` | Open the submenu of the current item              |
| `ArrowLeft`  | Close the submenu and return to the parent item   |
| `Escape`     | Close the menu and refocus the trigger            |

### Composable Components

#### DropdownTrigger

The trigger button with built-in `type="button"` and `aria-haspopup="menu"`. The high-level `Dropdown` sets `anchor-name` on it via inline style.

| Prop        | Type                            | Default | Description                     |
| ----------- | -------------------------------- | ------- | -------------------------------- |
| `className` | `ClassNameValue`                 | -       | Custom class name                |
| `...props`  | `React.ComponentProps<"button">` | -       | Supports all native button props |

#### DropdownContent

Popover panel container rendered as a `popover="manual"` div with built-in panel styles (`bg-popover`, `min-w-32`, `max-h-96`, `overflow-auto`, `rounded-md`, `border`, `p-1`, `shadow-md`). The composite `Dropdown` renders both its root panel and submenu with it.

| Prop        | Type                          | Default | Description                  |
| ----------- | ------------------------------ | ------- | ------------------------------ |
| `className` | `ClassNameValue`               | -       | Custom class name              |
| `...props`  | `React.ComponentProps<"div">`  | -       | Supports all native div props  |

#### DropdownSubContent

Submenu panel container based on `DropdownContent`, with built-in submenu positioning styles (`position-area: right span-bottom` and flip fallbacks). Anchor it to the parent menu item via `positionAnchor` (each item's `anchor-name` is `--dropdown-sub-{entryId}`).

| Prop             | Type                          | Default | Description                          |
| ---------------- | ------------------------------ | ------- | -------------------------------------- |
| `positionAnchor` | `string`                       | -       | `anchor-name` of the parent menu item  |
| `className`      | `ClassNameValue`               | -       | Custom class name                      |
| `...props`       | `React.ComponentProps<"div">`  | -       | Supports all native div props          |

#### DropdownItem

Menu item wrapper (`li`) with built-in `m-0`.

| Prop        | Type                         | Default | Description                 |
| ----------- | ----------------------------- | ------- | ----------------------------- |
| `className` | `ClassNameValue`              | -       | Custom class name             |
| `...props`  | `React.ComponentProps<"li">`  | -       | Supports all native li props  |
