## API 参考

### 高阶组件

开箱即用的成品组件。

#### Watermark

组合式水印：root 容器（外观走 `classNames.root`）、平铺的 canvas 覆盖层以及你的内容。

| 属性           | 类型                                                         | 描述                                                         |
| :----------- | :--------------------------------------------------------- | :--------------------------------------------------------- |
| `text`       | `string`                                                   | 水印文本内容                                                     |
| `fontSize`   | `number`                                                   | 水印文字字号（px），默认 `16`                                         |
| `color`      | `WatermarkColor`                                           | 水印文字颜色，默认 `"surface-fg"`                                   |
| `fontFamily` | `string`                                                   | 水印文字字体，默认 `"sans-serif"`                                   |
| `rotate`     | `number`                                                   | 旋转角度（度），默认 `-30`                                           |
| `gap`        | `number`                                                   | 相邻水印块之间的最小间距（px），默认 `100`                                  |
| `padding`    | `number`                                                   | 每个水印块四周的额外内边距（px），默认 `20`                                  |
| `opacity`    | `number`                                                   | 水印透明度（0–1），默认 `0.3`                                        |
| `children`   | `React.ReactNode`                                          | 被水印覆盖的内容                                                   |
| `className`  | `string`                                                   | 自定义类名，作用于 root                                             |
| `style`      | `React.CSSProperties`                                      | 内联样式，作用于 root                                              |
| `classNames` | `{ canvas?: string }`                                      | canvas 的自定义类名                                              |
| `styles`     | `{ canvas?: React.CSSProperties }`                         | canvas 的内联样式                                               |
| `...props`   | `React.ComponentProps<"div">`                              | 支持全部 div 原生属性（除 `className`、`style`），透传给 root              |

`WatermarkColor` 支持语义 token `"surface" \| "surface-fg" \| "primary" \| "primary-fg" \| "secondary" \| "secondary-foreground" \| "accent"` 或任意自定义 CSS 颜色字符串。

### 可组合组件

#### WatermarkRoot

水印容器，为 canvas 提供其填满所需的定位上下文。

| 属性          | 类型                            | 描述                     |
| :---------- | :---------------------------- | :--------------------- |
| `className` | `string`                      | 自定义 CSS 类              |
| `...props`  | `React.ComponentProps<"div">` | 支持全部 div 原生属性          |

#### WatermarkCanvas

绘制平铺水印文字的 `canvas`；父元素应为定位元素，如 `WatermarkRoot`。

| 属性           | 类型                                                | 描述                                                         |
| :----------- | :------------------------------------------------ | :--------------------------------------------------------- |
| `text`       | `string`                                          | 水印文本内容                                                     |
| `fontSize`   | `number`                                          | 水印文字字号（px），默认 `16`                                         |
| `color`      | `WatermarkColor`                                  | 水印文字颜色，默认 `"surface-fg"`                                   |
| `fontFamily` | `string`                                          | 水印文字字体，默认 `"sans-serif"`                                   |
| `rotate`     | `number`                                          | 旋转角度（度），默认 `-30`                                           |
| `gap`        | `number`                                          | 相邻水印块之间的最小间距（px），默认 `100`                                  |
| `padding`    | `number`                                          | 每个水印块四周的额外内边距（px），默认 `20`                                  |
| `opacity`    | `number`                                          | 水印透明度（0–1），默认 `0.3`                                        |
| `className`  | `string`                                          | 自定义 CSS 类；画布由组件内置铺满父容器、不拦截指针、不可选中，尺寸随容器变化                  |
| `...props`   | `React.ComponentProps<"canvas">`                  | 支持全部 canvas 原生属性（除 `className`、`ref`）                      |

## 键盘交互

本组件不接管任何按键。canvas 不可聚焦，且带 `pointer-events: none`，既不接收键盘也不接收指针输入；所有按键都归水印下方的内容。

## 数据属性

骨架不在本组件上发射任何 `data-*`。
