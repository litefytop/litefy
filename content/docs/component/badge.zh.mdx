## 用法

### 基础用法

`Badge` 是一个固定尺寸的承载面（默认 `size-12` 的 muted 方块），角标是独立的叠加标记 span——传 `label` 即可在右上角挂上数字或文本标记。

<ComponentPreview
  name="badge-basic"
/>

### 尺寸

承载面的形状完全来自工具类，用 `className` 即可改造——角标会自动重新锚定：

<ComponentPreview
  name="badge-sizing"
/>

### 角标配色

`label` 渲染为标记层，用 `label` 插槽以同样的方式着色：

<ComponentPreview
  name="badge-marker-color"
/>

## 注意

- 角标是独立的叠加标记 span，而非 [Chip](/docs/component/chip)——附属标记与行内状态标签刻意分离。`Badge` 无任何依赖。

## API 参考

### Badge

| 属性       | 类型                              | 默认值 | 描述                                       |
| :--------- | :-------------------------------- | :----- | :----------------------------------------- |
| `children` | `React.ReactNode`                 | -      | 承载面内容，通常放图标                     |
| `label`    | `React.ReactNode`                 | -      | 角标内容，以叠加标记渲染在右上角            |
| `classNames`| `{ label?: ClassNameValue }`     | -      | 按插槽自定义类名                           |
| `styles`   | `{ label?: React.CSSProperties }` | -      | 按插槽自定义样式                           |
| `className`| `ClassNameValue`                  | -      | 承载面的自定义类名                         |
| `...props` | `React.ComponentProps<"div">`     | -      | 原生 div 属性                              |
