## 用法

`children` 承载主体内容，`label` 在右上角叠加角标，可省略。

## API 参考

### Badge

| 属性           | 类型                                | 描述                                         |
| :----------- | :-------------------------------- | :----------------------------------------- |
| `children`   | `React.ReactNode`                 | 承载面内容，通常放图标                                |
| `label`      | `React.ReactNode`                 | 角标内容，渲染在右上角；可省略，省略或空串时为圆点                  |
| `classNames` | `{ label?: string }`              | 按插槽自定义类名                                   |
| `styles`     | `{ label?: React.CSSProperties }` | 按插槽自定义样式                                   |
| `className`  | `string`                          | 承载面的自定义类名                                  |
| `...props`   | `React.ComponentProps<"div">`     | 原生 div 属性                                  |

## 键盘交互

本组件不接管任何按键。两层都是不可聚焦的元素（`<div>` 承载面、`<span>` 角标）；可交互内容只能来自 `children` 或 `label`。

## 数据属性

骨架不在本组件上发射任何 `data-*`。
