## 用法

`Table` 是数据驱动的：传入 `data` 与 `columns` 配置即可；`sortable: true` 让表头可点击排序。

<ComponentPreview name="table-basic" />

### 远程排序（数据库）

传入受控的 `sort` + `onSortChange` 即进入**远程模式**——排序交给数据库；搭配 [useRemoteSort](/zh/docs/utils/use-remote-sort) 管理状态并生成查询。

<ComponentPreview name="table-remote" />

### 表头固定 + 表体滚动

表头固定、表体在独立容器内滚动——内置表体高度可通过 `classNames.body` 覆盖。

<ComponentPreview name="table-scroll" />

### 可组装零件

`Table` 由四个原子组装而成——自定义表格复用同一套骨架，两个表格中的 `<colgroup>` 必须保持一致。

## API 参考

### Table

| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `data` | `T[]` | - | 行数据 **必填** |
| `columns` | `TableColumn<T>[]` | - | 列配置 **必填** |
| `getKey` | `(row: T, index: number) => React.Key` | index | 行 key 提取器 |
| `sort` | `SortState<T> \| null` | - | 受控排序状态；传入即进入远程模式 |
| `onSortChange` | `(sort: SortState<T>) => void` | - | 表头点击回调（两种模式均触发） |
| `initialSortDirection` | `"asc" \| "desc"` | `"asc"` | 首次点击某列使用的方向 |
| `empty` | `React.ReactNode` | `"No data"` | 数据为空时渲染的内容 |
| `className` | `ClassNameValue` | - | 自定义类名，作用于外层框架 |
| `classNames` | `wrapper` / `table` / `head` / `headRow` / `headCell` / `body` / `row` / `cell` | - | 各部分自定义类名（`head` / `body` 分别作用于表头条与表体滚动容器） |
| `styles` | `{ wrapper?, table? }` | - | 外层容器与两个 table 的内联样式 |

### TableColumn&lt;T&gt;

| 字段 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `key` | `keyof T & string` | - | 展示的行字段 **必填** |
| `header` | `React.ReactNode` | `key` | 表头文案 |
| `render` | `(row: T) => React.ReactNode` | 原始值 | 自定义单元格渲染 |
| `sortable` | `boolean` | `false` | 表头可点击排序 |
| `compare` | `(a: T, b: T) => number` | `<` / `>` | 本地排序使用的自定义比较器 |
| `align` | `"left" \| "right" \| "center"` | `"left"` | 单元格对齐；设计规范约定列统一 start（控件列可用 center） |
| `width` | `string` | - | 列的 CSS 宽度（`"8rem"`、`"25%"`、`"20ch"`），作用于 `<col>`；未设置的列平分剩余宽度 |
| `className` | `ClassNameValue` | - | 同时作用于该列表头单元格与表体单元格的自定义类名（如长文本列用 `max-w-*`） |

### 零件

| 零件 | 元素 | 内置类 | 描述 |
|------|------|--------|------|
| `TableRoot` | `<div>` | `w-full overflow-hidden rounded-lg border` | 外层框架 |
| `TableHead` | `<div>` | `overflow-hidden` | 表头条，永不滚动 |
| `TableBody` | `<div>` | `h-96 overflow-y-auto` | 表体滚动容器 |
| `TableBase` | `<table>` | `w-full table-fixed border-collapse text-sm` | 共享的 table 元素 |

所有零件均接受原生元素属性与 `className`。

### SortState&lt;T&gt;

`{ key: keyof T & string; direction: "asc" | "desc" } | null`
