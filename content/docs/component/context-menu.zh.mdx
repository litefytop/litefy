## 用法

### 基础用法

右键点击目标区域，菜单会在指针位置打开；选中菜单项后自动关闭。菜单已打开时再次右键，会重新锚定到新的光标位置。

### 自定义拼装

手动拼装零件以获得完全控制：自定义样式的触发区域、自拟的锚点名称，以及自定义宽度和类名的面板。传给 `ContextMenuAnchor` 和 `ContextMenuContent` 的 `anchorName` 必须一致 —— 它是面板定位所依赖的链接。

## API 参考

### 高阶组件

#### ContextMenu

数据驱动的右键菜单。渲染你提供的触发区域，右键时记录指针位置，并把菜单面板锚定到光标处。点击外部与 `Escape` 会关闭面板；面板内部的右键会被屏蔽，不会弹出浏览器菜单。

| Prop         | Type                                   | Default | Description                                                                 |
| :----------- | :------------------------------------- | :------ | :-------------------------------------------------------------------------- |
| `children`   | `React.ReactNode`                      | -       | 触发区域，右键点击它打开菜单                                                 |
| `items`      | `MenuConfig[]`                         | -       | 菜单项，扁平或分组 —— 与 [Menu](/docs/component/menu) 组件的形状一致          |
| `disabled`   | `boolean`                              | -       | 禁用自定义菜单，此时显示浏览器原生菜单                                        |
| `onSelect`   | `(item: MenuItemConfig) => void`       | -       | 菜单项激活时触发，随后菜单关闭                                                |
| `classNames` | `{ content?: ClassNameValue }`         | -       | 面板的自定义类名                                                              |
| `styles`     | `{ content?: React.CSSProperties }`    | -       | 面板的内联样式；锚点定位属性由组件内部管理                                    |

#### 静态属性

| Static                | Type                  | Description        |
| :-------------------- | :-------------------- | :----------------- |
| `ContextMenu.Trigger` | `ContextMenuTrigger`  | 右键触发区域零件    |
| `ContextMenu.Anchor`  | `ContextMenuAnchor`   | 零尺寸指针锚点零件  |
| `ContextMenu.Content` | `ContextMenuContent`  | 浮动菜单面板零件    |

### 可组合组件

#### ContextMenuTrigger

只承载行为的包装器：右键点击时先执行 `e.preventDefault()`，再通过 `onOpenMenu` 上报指针位置。渲染普通的 `div`，不内置任何样式。

| Prop          | Type                                            | Default | Description                                                                                     |
| :------------ | :---------------------------------------------- | :------ | :---------------------------------------------------------------------------------------------- |
| `disabled`    | `boolean`                                       | -       | 为 true 时右键无响应（显示浏览器原生菜单）                                                        |
| `onOpenMenu`  | `(position: { x: number; y: number }) => void`  | -       | 右键点击区域时以光标坐标调用                                                                      |
| `className`   | `ClassNameValue`                                | -       | 自定义类名                                                                                       |
| `...props`    | `React.ComponentProps<"div">`                   | -       | 支持所有原生 div 属性；你自己的 `onContextMenu` 会先执行，可以 `preventDefault()` 阻止打开菜单     |

#### ContextMenuAnchor

放置在指针位置的零尺寸 `fixed` div —— 面板通过 CSS 锚点定位依附于它。

| Prop        | Type                            | Default | Description                                        |
| :---------- | :------------------------------ | :------ | :------------------------------------------------- |
| `position`  | `{ x: number; y: number }`      | -       | 锚点点的视口坐标                                    |
| `anchorName`| `string`                        | -       | 必填。CSS 锚点名称；最后写入，不会被 `style` 覆盖    |
| `className` | `ClassNameValue`                | -       | 自定义类名                                          |
| `...props`  | `React.ComponentProps<"div">`   | -       | 支持所有原生 div 属性                                |

#### ContextMenuContent

浮动面板，基于 `PopoverContent` 以 `popover="manual"` 构建。面板左上角贴合锚点并带少量偏移，靠近视口边缘时通过 `positionTryFallbacks` 自动翻转。点击外部 `mousedown` 与 `Escape` 时关闭。

| Prop           | Type                           | Default | Description                                                                        |
| :------------- | :----------------------------- | :------ | :--------------------------------------------------------------------------------- |
| `open`         | `boolean`                      | -       | 受控的面板状态                                                                       |
| `onOpenChange` | `(open: boolean) => void`      | -       | 面板打开或关闭时触发                                                                  |
| `anchorName`   | `string`                       | -       | 必填。定位所依赖的锚点；最后写入，不会被 `style` 覆盖                                 |
| `className`    | `ClassNameValue`               | -       | 自定义类名（默认 `w-48`）                                                            |
| `...props`     | `React.ComponentProps<"div">`  | -       | 支持所有原生 div 属性，透传到面板上                                                   |

菜单项本身（分组、子菜单、键盘导航）由 [Menu](/docs/component/menu) 组件提供 —— `MenuConfig` 与 `MenuItemConfig` 请参阅其 API。
