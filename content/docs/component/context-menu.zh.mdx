## 用法

### 基础用法

先挂载一次 `<ContextMenuHost />`，然后在任意元素的 `onContextMenu` 里调用 `ContextMenu.open()` —— 不需要包裹组件，也不需要锚点布线。菜单在指针位置打开；选中菜单项后自动关闭；菜单已打开时再次右键，会重新锚定到新的光标位置。

### 自定义样式

通过 `open()` 的 `classNames.content` / `styles.content` 定制面板。菜单项本身（分组、子菜单、键盘导航）由 [Menu](/docs/component/menu) 组件提供 —— `MenuConfig` 与 `MenuItemConfig` 请参阅其 API。

## API 参考

### ContextMenuHost

`ContextMenu.open()` 激活期间渲染浮动菜单面板。在应用根挂载一次即可——没有菜单打开时它不渲染任何内容。点击外部与 `Escape` 自动关闭；面板内右键被屏蔽，不会弹出浏览器菜单。

| Prop        | Type              | Default | Description              |
| :---------- | :---------------- | :------ | :----------------------- |
| `className` | `ClassNameValue`  | -       | 锚点包装层的自定义类名    |

### 静态方法

#### ContextMenu.open

```ts
ContextMenu.open(options: ContextMenuOpenOptions): void
```

在给定视口坐标处打开菜单。

| 选项           | 类型                                   | 默认值  | 描述                                                                 |
| :------------- | :------------------------------------- | :------ | :------------------------------------------------------------------- |
| `x`            | `number`                               | -       | 视口 x 坐标（通常是 `e.clientX`）**必填**                             |
| `y`            | `number`                               | -       | 视口 y 坐标（通常是 `e.clientY`）**必填**                             |
| `items`        | `MenuConfig[]`                         | -       | 菜单项，扁平或分组 —— 与 [Menu](/docs/component/menu) 组件的形状一致 **必填** |
| `onSelect`     | `(item: MenuItemConfig) => void`       | -       | 菜单项激活时触发，随后菜单关闭                                        |
| `classNames`   | `{ content?: ClassNameValue }`         | -       | 面板的自定义类名                                                      |
| `styles`       | `{ content?: React.CSSProperties }`    | -       | 面板的内联样式；锚点定位属性由组件内部管理                            |

#### ContextMenu.dismiss

```ts
ContextMenu.dismiss(): void
```

以编程方式关闭菜单。

### 说明

- 面板锚定在指针位置的一个零尺寸元素上，靠近视口边缘时通过 `positionTryFallbacks` 自动翻转——两者均为内部实现细节。
- 由于没有包裹层，触发源可以是任意元素或事件：表格行、canvas、树节点，甚至非右键手势。
