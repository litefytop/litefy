## 用法

先挂载一次 `<ContextMenuHost />`，然后在任意元素的 `onContextMenu` 里调用 `ContextMenu.open()`——不需要包裹组件。

### 自定义样式

通过 `open()` 的 `classNames.content` / `styles.content` 定制面板；菜单项能力由 [Menu](/docs/component/menu) 组件提供。

## API 参考

### ContextMenuHost

`ContextMenu.open()` 激活期间渲染浮动菜单面板；在应用根挂载一次即可——没有菜单打开时它不渲染任何内容。它不接受任何属性；面板由内置 JS 定位引擎按 `ContextMenu.open()` 传入的 `x` / `y` 坐标定位。

### 静态方法

#### ContextMenu.open

```ts
ContextMenu.open(options: ContextMenuOpenOptions): void
```

在给定视口坐标处打开菜单。

| 选项           | 类型                                   | 默认值  | 描述                                                                 |
| :------------- | :------------------------------------- | :------ | :------------------------------------------------------------------- |
| `x`            | `number`                               | -       | 视口 x 坐标（通常是 `e.clientX`）**必填**                             |
| `y`            | `number`                               | -       | 视口 y 坐标（通常是 `e.clientY`）**必填**                             |
| `items`        | `MenuConfig[]`                         | -       | 菜单项，扁平或分组 —— 与 [Menu](/docs/component/menu) 组件的形状一致 **必填** |
| `onSelect`     | `(item: MenuItemConfig) => void`       | -       | 菜单项激活时触发，随后菜单关闭                                        |
| `classNames`   | `{ content?: ClassNameValue }`         | -       | 面板的自定义类名                                                      |
| `styles`       | `{ content?: React.CSSProperties }`    | -       | 面板的内联样式；定位属性由组件内部管理                              |

#### ContextMenu.dismiss

```ts
ContextMenu.dismiss(): void
```

以编程方式关闭菜单。
