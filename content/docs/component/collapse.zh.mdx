## API 参考

### 高阶组件

开箱即用的成品组件。

#### Collapse

单体折叠面板，内置触发器与折叠动画面板。

| 属性             | 类型                                                                                                                       | 描述                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------ |
| `label`        | `React.ReactNode \| ((open: boolean) => React.ReactNode)`                                                                | 头部触发器显示内容，支持函数接收 open 状态                   |
| `icon`         | `React.ReactNode \| ((open: boolean) => React.ReactNode)`                                                                | 展开收起图标，支持函数接收 open 状态，默认 `ChevronDown`     |
| `open`         | `boolean`                                                                                                                | 受控展开状态                                     |
| `defaultOpen`  | `boolean`                                                                                                                | 初始展开状态（非受控），默认 `false`                     |
| `onOpenChange` | `(open: boolean) => void`                                                                                                | 展开状态变化回调                                   |
| `itemKey`      | `string`                                                                                                                 | 触发器与面板 id 的后缀，用于无障碍关联                      |
| `className`    | `string`                                                                                                                 | 自定义类名，作用于根容器                               |
| `style`        | `React.CSSProperties`                                                                                                    | 内联样式，作用于根容器                                |
| `classNames`   | `{ trigger?: string; icon?: string; panel?: string; body?: string }`                                                     | 触发器、箭头、动画外壳、面板内容四个插槽的自定义类名                 |
| `styles`       | `{ trigger?: React.CSSProperties; icon?: React.CSSProperties; panel?: React.CSSProperties; body?: React.CSSProperties }` | 同上四个插槽的内联样式                                |
| `children`     | `React.ReactNode`                                                                                                        | 面板内容                                       |
| `...props`     | `React.ComponentProps<"div">`                                                                                            | 支持全部 div 原生属性                              |

### 可组合组件

#### CollapseRoot

面板的外层 `<div>` 容器。

| 属性          | 类型                            | 描述                    |
| ----------- | ----------------------------- | --------------------- |
| `className` | `string`                      | 自定义样式                 |
| `...props`  | `React.ComponentProps<"div">` | 支持全部 div 原生属性         |

#### CollapseTrigger

触发器按钮；独立使用时传入 `open` 并通过 `onClick` 自行控制。

| 属性          | 类型                               | 描述                       |
| ----------- | -------------------------------- | ------------------------ |
| `open`      | `boolean`                        | 驱动 `aria-expanded`       |
| `className` | `string`                         | 自定义样式                    |
| `...props`  | `React.ComponentProps<"button">` | 支持全部 button 原生属性         |

#### CollapsePanel

折叠面板：外层 `<section>` 是动画网格裁切层，`className` / `style` 落在它上面；`classNames.body` / `styles.body` 指向内层内容容器。

| 属性           | 类型                                                            | 描述                                    |
| ------------ | ------------------------------------------------------------- | ------------------------------------- |
| `open`       | `boolean`                                                     | 是否展开，驱动折叠动画                           |
| `className`  | `string`                                                      | 自定义样式，作用于动画外壳 `<section>`             |
| `classNames` | `{ panel?: string; body?: string }`                           | 动画外壳与内容容器的自定义类名                       |
| `styles`     | `{ panel?: React.CSSProperties; body?: React.CSSProperties }` | 同上两个插槽的内联样式                           |
| `...props`   | `React.ComponentProps<"section">`                             | section 原生属性，用于无障碍、data-\*            |

## 键盘交互

| Key | Description |
| --- | --- |
| `Enter` / `Space` | 由原生 `<button>` 激活当前聚焦的触发器；骨架不接管任何按键 |
| `Tab` | 按 DOM 顺序依次到达各触发器。收起的面板仍然挂载——`<section>` 只裁切高度——其内可聚焦元素保持在 Tab 序中；是否移出由加载的方案决定 |

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-open]` | 位于面板上——取值 `"true"` 或 `"false"`，驱动展开/收起动画；默认折叠图标上同样携带 |
