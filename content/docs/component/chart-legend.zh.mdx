ChartLegend 是 [Chart](/zh/docs/component/chart)、[Donut](/zh/docs/component/donut) 和 [Radar](/zh/docs/component/radar) 共用的图例，以独立组件形式发布，自定义图表也可以直接复用。每个条目是一个按钮：点击隐藏或恢复对应下标的系列；指针移入/移出时触发 `onHover`。命中 `hidden` 的条目发出 `data-hidden`。

色块有两种形状——`"line"` 适配系列型图表（线段），`"square"` 适配分类型图表（饼图/环形图的扇区）。

## API 参考

### ChartLegend

| Prop        | Type                                        | Description                                                |
| :---------- | :------------------------------------------ | :--------------------------------------------------------- |
| `items`     | `{ label: string; color: string }[]`        | 每个系列一个条目，顺序与图表的系列一致                                        |
| `hidden`    | `ReadonlySet<number>`                       | 当前隐藏的下标集合；命中的条目发出 `data-hidden`                            |
| `swatch`    | `"line" \| "square"`                        | 色块形状——系列型用线段，分类数据用方块，默认 `"line"`                           |
| `onToggle`  | `(index: number) => void`                   | 条目被点击时回调                                                   |
| `onHover`   | `(index: number \| null) => void`           | 条目 mouse enter 时回调下标，mouse leave 时回调 `null`                |
| `className` | `string`                                    | 合并到容器上                                                     |
| `style`     | `React.CSSProperties`                       | 容器内联样式                                                     |

## 键盘交互

| Key | Description |
| --- | --- |
| `Enter` / `Space` | 切换该系列的可见性 |

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-hidden]` | 位于图例项上——对应系列隐藏时存在 |
| `[data-shape]` | 位于色块上——取值 `"line"` 或 `"square"` |
