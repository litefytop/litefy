## Usage

### Basic Usage

`Badge` is a fixed-size surface (a `size-12` muted square by default) whose corner marker is a standalone overlay span — pass `label` to attach a numeric or text marker at the top-right corner.

<ComponentPreview
  name="badge-basic"
/>

### Sizing

The surface shape comes entirely from utilities, so reshape it with `className` — the marker re-anchors itself automatically:

<ComponentPreview
  name="badge-sizing"
/>

### Marker coloring

`label` renders as a marker — color it the same way, via the `label` slot:

<ComponentPreview
  name="badge-marker-color"
/>

## Notes

- The marker is a standalone overlay span, not a [Chip](/docs/component/chip) — attached markers and inline status labels are deliberately separate components. `Badge` ships with no dependencies.

## API Reference

### Badge

| Prop        | Type                              | Default | Description                                              |
| :---------- | :-------------------------------- | :------ | :------------------------------------------------------- |
| `children`  | `React.ReactNode`                 | -       | Surface content, typically an icon                       |
| `label`     | `React.ReactNode`                 | -       | Corner marker content, rendered as an overlay at the top-right |
| `classNames`| `{ label?: ClassNameValue }`      | -       | Custom class names per slot                              |
| `styles`    | `{ label?: React.CSSProperties }` | -       | Custom styles per slot                                   |
| `className` | `ClassNameValue`                  | -       | Custom class names of the surface                        |
| `...props`  | `React.ComponentProps<"div">`     | -       | Native div props                                         |
