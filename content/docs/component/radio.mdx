## API Reference

### Radio

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | - | The radio content |
| `checked` | `boolean` | `false` | Controlled checked state |
| `defaultChecked` | `boolean` | `false` | Default checked state (uncontrolled) |
| `onCheckedChange` | `(checked: boolean) => void` | - | Callback when checked state changes |
| `indicator` | `(checked: boolean, wrapperClassName?: string) => React.ReactNode` | - | Custom indicator render function with wrapper className |
| `invalid` | `boolean` | `false` | Mark as invalid |
| `className` | `ClassNameValue` | - | Accepts strings, arrays, and all falsy values (false, null, undefined, 0, 0n). True and objects are not supported. |
| `...props` | `React.ComponentProps<"input">` | - | Supports all native input props (except `type`, `className`), such as `name`, `value`, `disabled` |

### RadioOptionConfig

| Field | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | - | Option display text |
| `value` | `string` | - | Unique identifier value |
| `disabled` | `boolean` | `false` | Disable the option |
| `invalid` | `boolean` | `false` | Mark the option as invalid |
| `indicator` | `(checked: boolean, wrapperClassName?: string) => React.ReactNode` | - | Custom indicator, overrides `common.indicator` |
| `className` | `ClassNameValue` | - | Custom class names, overrides `common.className` |

### Radio.Group

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `RadioOptionConfig[]` | - | Options data array |
| `value` | `string` | - | Controlled selected value |
| `defaultValue` | `string` | - | Default selected value (uncontrolled) |
| `onValueChange` | `(value: string) => void` | - | Callback when the selected value changes |
| `disabled` | `boolean` | `false` | Disable all options |
| `invalid` | `boolean` | `false` | Mark as invalid |
| `name` | `string` | - | Group name |
| `className` | `ClassNameValue` | - | Custom class names, applied to the container |
| `common` | `{ className?, indicator? }` | - | Common config applied to all options |
