## API 参考

### Skeleton

带脉冲动画的占位块，默认填满容器（`size-full`），通过 `className` 调整形状。基色跟随 `--color-neutral` 主题 token。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | 自定义 CSS 类，如 `h-4 w-1/2 rounded-full` |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性 |
