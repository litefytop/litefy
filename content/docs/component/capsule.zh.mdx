## 用法

`Capsule` 是胶囊形 overflow-hidden 容器，将任意子元素拼接为一个整体胶囊；子元素通过 `*:rounded-none *:px-2 *:py-1` 统一样式。

<ComponentPreview name="capsule-badge" />

### 组合

当整个胶囊需要可点击时，应将 `<Capsule>` 包在原生 `<a>`（或 `button`）里，让所有子元素共享同一个点击目标，而不是把链接只嵌在某个子元素上：

## API 参考

### Capsule

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | 自定义 CSS 类，与基础 `Capsule.className` 合并 |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性（`className` 除外） |

### Statics

| Member | Type | Description |
|--------|------|-------------|
| `Capsule.className` | `string` | 胶囊容器的基础类名字符串，可在原生元素上复用 |
