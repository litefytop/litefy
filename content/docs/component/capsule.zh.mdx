## 用法

`Capsule` 是胶囊形 overflow-hidden 容器：放入的任意内容都会被拼接、裁剪为一个整体胶囊。容器通过 `*:rounded-none *:px-2 *:py-1` 统一子元素样式，像 [Tag](/docs/component/tag) 这类典型子元素只需写颜色工具类。

<ComponentPreview name="capsule-badge" />

### 组合

`Capsule` 就是一个普通容器——始终渲染为 `div`，没有 `as` 属性。里面放什么都可以：两个标签可以拼成徽章，toggle 组、segment 组或任意其他内容同样适用。当整个胶囊需要可点击时，应将 `<Capsule>` 包在原生 `<a>`（或 `button`）里，让所有子元素共享同一个点击目标，而不是把链接只嵌在某个子元素上：

## 注意

- 容器通过 `*:rounded-none *:px-2 *:py-1` 对所有子元素统一处理圆角与内边距，典型子元素只需写颜色工具类即可。
- 子元素数量不限：容器会裁剪任意内容。
- `Capsule.className` 是胶囊容器的静态基础类名字符串，可用于样式化包裹元素或在其他地方复用胶囊外观。

## API 参考

### Capsule

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | 自定义 CSS 类，与基础 `Capsule.className` 合并 |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性（`className` 除外） |

### Statics

| Member | Type | Description |
|--------|------|-------------|
| `Capsule.className` | `string` | 胶囊容器的基础类名字符串，可在原生元素上复用 |
