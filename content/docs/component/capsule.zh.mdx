## 用法

`Capsule` 是胶囊形 overflow-hidden 容器。放入两个 [Tag](/docs/component/tag) 子元素——给每个标签传 `rounded-none px-2.5 py-1` 获得徽章比例——即可快速拼出 shields-io 风格双色徽章。

<ComponentPreview name="capsule-badge" />

### 组合

左侧标签作为标签名，右侧作为值。颜色是每个标签上的普通工具类。`Capsule` 始终渲染为 `div`——没有 `as` 属性。需要可点击徽章时，在容器内嵌套原生 `<a>`（或 `button`）：

```tsx
<Capsule>
  <Tag className="rounded-none px-2.5 py-1 bg-neutral-600 text-white">build</Tag>
  <Tag className="rounded-none px-2.5 py-1 bg-emerald-600 text-white">passing</Tag>
</Capsule>

<Capsule>
  <Tag className="rounded-none px-2.5 py-1 bg-neutral-600 text-white">docs</Tag>
  <a href="#" className="rounded-none px-2.5 py-1 bg-violet-600 text-white">litefy.dev</a>
</Capsule>
```

## 注意

- 标签上的 `rounded-none px-2.5 py-1` 会去掉其圆角并增大内边距，形成徽章比例。
- 支持两个以上标签：容器会裁剪任意内容。
- `Capsule.className` 是胶囊容器的静态基础类名字符串——当胶囊本身需要承载语义时，可将其应用到原生 `a` / `button` 上。

## API 参考

### Capsule

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | 自定义 CSS 类，与基础 `Capsule.className` 合并 |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性（`className` 除外） |

### Statics

| Member | Type | Description |
|--------|------|-------------|
| `Capsule.className` | `string` | 胶囊容器的基础类名字符串，可在原生元素上复用 |
