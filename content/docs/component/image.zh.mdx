## API 参考

### 高阶组件

开箱即用的成品组件。

#### Image

预加载管理的图片组件，外层容器内置 `relative`、`overflow-hidden` 样式。

| Prop          | Type                                            | Default   | Description                                                             |
| ------------- | ----------------------------------------------- | --------- | ------------------------------------------------------------------------ |
| `src`         | `string`                                        | -（必填） | 图片源 URL                                                               |
| `alt`         | `string`                                        | -         | 图片的替代文本                                                           |
| `fallback`    | `React.ReactNode`                               | -         | 图片加载失败时显示的自定义回退元素                                       |
| `loadingNode` | `React.ReactNode`                               | -         | 加载中显示的占位元素，可用于渐进式模糊缩略图                             |
| `className` | `ClassNameValue` | - | 自定义类名，作用于根容器 |
| `style` | `React.CSSProperties` | - | 内联样式，作用于根容器 |
| `classNames` | `{ image?: ClassNameValue }` | - | 图片的自定义类名 |
| `styles` | `{ image?: React.CSSProperties }` | - | 图片的内联样式 |

### 可组合组件

#### ImageRoot

外层容器，内置 `relative`、`overflow-hidden`。

| Prop        | Type                          | Default | Description           |
| ----------- | ----------------------------- | ------- | --------------------- |
| `className` | `ClassNameValue`              | -       | 自定义类名            |
| `...props`  | `React.ComponentProps<"div">` | -       | 支持全部 div 原生属性 |

#### ImageImage

图片元素，内置 `size-full`、`object-cover`、`loading="lazy"` 和 `decoding="async"`。

| Prop        | Type                          | Default | Description           |
| ----------- | ----------------------------- | ------- | --------------------- |
| `className` | `ClassNameValue`              | -       | 自定义类名            |
| `...props`  | `React.ComponentProps<"img">` | -       | 支持全部 img 原生属性 |
