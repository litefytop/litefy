## API 参考

### 高阶组件

开箱即用的成品组件。

#### Image

预加载管理的图片组件，外层容器内置 `relative`、`overflow-hidden` 样式。

| Prop            | Type                                            | Default   | Description                                                                                                   |
| --------------- | ----------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------- |
| `src`           | `string`                                        | -（必填） | 图片源 URL                                                                                                    |
| `alt`           | `string`                                        | -         | 图片的替代文本                                                                                                |
| `className`     | `ClassNameValue`                                | -         | 自定义 CSS 类名，作用于外层容器                                                                               |
| `fallback`      | `React.ReactNode`                               | -         | 图片加载失败时显示的自定义回退元素                                                                            |
| `loadingNode`   | `React.ReactNode`                               | -         | 加载中显示的占位元素，可用于渐进式模糊缩略图                                                                  |
| `slots.wrapper` | `Omit<React.ComponentProps<"div">, "children">` | -         | 外层容器属性，`className` 优先级高于 `className`                                                              |
| `...props`      | `React.ComponentProps<"img">`                   | -         | 支持全部 img 原生属性（除 `className`），内置 `loading="lazy"`、`decoding="async"`、`contentVisibility: auto` |

---

### Headless 原子组件

> 以下为底层原子组件，**内置样式极少，样式需要通过 className 自行补充**。高层组合组件 `Image` 即由以下原子组件组合而成。

#### ImageRoot

外层容器，内置 `relative`、`overflow-hidden`。

| Prop        | Type                          | Default | Description           |
| ----------- | ----------------------------- | ------- | --------------------- |
| `className` | `ClassNameValue`              | -       | 自定义类名            |
| `...props`  | `React.ComponentProps<"div">` | -       | 支持全部 div 原生属性 |

#### ImageImage

图片元素，内置 `w-full`、`h-full`、`object-cover`。

| Prop        | Type                          | Default | Description           |
| ----------- | ----------------------------- | ------- | --------------------- |
| `className` | `ClassNameValue`              | -       | 自定义类名            |
| `...props`  | `React.ComponentProps<"img">` | -       | 支持全部 img 原生属性 |
