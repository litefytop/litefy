## 用法

### 基础用法

通过 `items` 配置驱动菜单。支持分组标签，任意菜单项可以展开二级子菜单（最多两级）。

<ComponentPreview 
  name="dropdown-basic"
/>

### 对齐方式

使用 `positionArea`（任意合法的 CSS `position-area` 值）控制常规定位；或使用 `alignX` 将菜单边对边贴靠在 trigger 旁，适配侧边栏导航场景。

## API 参考

### Dropdown

主组件。根面板是 `popover="manual"` 元素，通过 `position-anchor` / `position-area` 定位，内置碰撞检测（`position-try-fallbacks`）。

| Prop            | Type                                    | Default             | Description                                                 |
| --------------- | --------------------------------------- | ------------------- | ------------------------------------------------------------ |
| `items`         | `DropdownItemConfig[]`                  | `[]`                | 菜单项配置，见下方 [items](#items)                           |
| `children`      | `React.ReactNode`                       | -                   | 触发按钮内容                                                 |
| `itemClassName` | `ClassNameValue`                        | -                   | 应用到每个菜单项按钮的类名                                   |
| `positionArea`  | `string`                                | `'bottom span-all'` | 任意合法的 CSS `position-area` 值。建议使用 `span-*` 系列，碰撞检测才能正常工作 |
| `alignX`        | `'start' \| 'end' \| 'center'`          | -                   | 侧边栏模式：`start` 表示菜单的 end 边贴靠 trigger 的 start 边（向左展开）；`end` 表示菜单的 start 边贴靠 trigger 的 end 边（向右展开）；`center` 居中。优先级高于 `positionArea` |
| `classNames`    | `{ trigger?: ClassNameValue; content?: ClassNameValue }` | -  | 触发按钮与根面板的自定义类名                                 |
| `styles`        | `{ trigger?: React.CSSProperties; content?: React.CSSProperties }` | - | 触发按钮与根面板的内联样式；`styles.content` 会与内置定位样式合并 |
| `...props`      | `React.ComponentProps<"div">`           | -                   | 支持根面板的全部 div 原生属性                                |

#### items

```ts
type DropdownGroup = {
  group: React.ReactNode;
  items: DropdownMenuItem[];
};

type DropdownMenuItem = {
  label: React.ReactNode;
  disabled?: boolean;
  className?: ClassNameValue;
  onClick?: React.MouseEventHandler<HTMLButtonElement>;
  children?: Omit<DropdownMenuItem, "children">[];
};

type DropdownItemConfig = DropdownGroup | DropdownMenuItem;
```

#### 键盘导航

| 按键               | 行为                                 |
| ------------------ | ------------------------------------- |
| `Space` / `Enter`  | 打开菜单并聚焦第一个菜单项            |
| `ArrowDown` / `ArrowUp` | 在菜单项之间移动（循环）         |
| `ArrowRight`       | 打开当前菜单项的子菜单                |
| `ArrowLeft`        | 关闭子菜单并回到父级菜单项            |
| `Escape`           | 关闭菜单并重新聚焦 trigger            |

### 可组合组件

#### DropdownTrigger

触发按钮，内置 `type="button"` 和 `aria-haspopup="menu"`。高层组件 `Dropdown` 通过内联 style 为其设置 `anchor-name`。

| Prop        | Type                            | Default | Description           |
| ----------- | -------------------------------- | ------- | ----------------------- |
| `className` | `ClassNameValue`                 | -       | 自定义类名              |
| `...props`  | `React.ComponentProps<"button">` | -       | 支持全部 button 原生属性 |

#### DropdownContent

Popover 面板容器，渲染为 `popover="manual"` 的 div，内置面板样式（`bg-popover`、`min-w-32`、`max-h-96`、`overflow-auto`、`rounded-md`、`border`、`p-1`、`shadow-md`）。高层组件 `Dropdown` 的根面板与子菜单均由它渲染。

| Prop        | Type                          | Default | Description           |
| ----------- | ------------------------------ | ------- | ----------------------- |
| `className` | `ClassNameValue`               | -       | 自定义类名              |
| `...props`  | `React.ComponentProps<"div">`  | -       | 支持全部 div 原生属性   |

#### DropdownSubContent

子菜单面板容器，基于 `DropdownContent`，内置子菜单定位样式（`position-area: right span-bottom` 与翻转回退），通过 `positionAnchor` 锚定到父菜单项（每个菜单项的 `anchor-name` 为 `--dropdown-sub-{entryId}`）。

| Prop             | Type                          | Default | Description                    |
| ---------------- | ------------------------------ | ------- | -------------------------------- |
| `positionAnchor` | `string`                       | -       | 锚定的父菜单项 `anchor-name`     |
| `className`      | `ClassNameValue`               | -       | 自定义类名                       |
| `...props`       | `React.ComponentProps<"div">`  | -       | 支持全部 div 原生属性            |

#### DropdownItem

菜单项包装元素（`li`），内置 `m-0`。

| Prop        | Type                         | Default | Description          |
| ----------- | ----------------------------- | ------- | ---------------------- |
| `className` | `ClassNameValue`              | -       | 自定义类名             |
| `...props`  | `React.ComponentProps<"li">`  | -       | 支持全部 li 原生属性   |
