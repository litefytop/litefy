## API Reference

### High-level Components

Ready-to-use composite components.

#### NumberField

A numeric input field with built-in increment and decrement buttons.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `defaultValue` | `number \| string` | - | Initial value (uncontrolled mode) |
| `value` | `number \| string \| undefined` | - | Current value (controlled mode) |
| `onValueChange` | `(value?: number) => void \| (value?: string) => void` | - | Value change handler. Returns `number \| undefined` when `positiveInteger=true`, otherwise `string` |
| `invalid` | `boolean` | - | Whether the field is in an invalid state |
| `min` | `number` | `0` (positiveInteger) or `-Infinity` | Minimum allowed value |
| `max` | `number` | `Infinity` | Maximum allowed value |
| `step` | `number` | `1` | Increment/decrement step size |
| `positiveInteger` | `boolean` | `false` | Restrict to positive integers only. Changes value type to `number \| undefined` |
| `classNames` | `{ group?: ClassNameValue; decrement?: ClassNameValue; increment?: ClassNameValue; root?: ClassNameValue }` | - | Custom classes for the internal elements |
| `styles` | `{ group?: React.CSSProperties; decrement?: React.CSSProperties; increment?: React.CSSProperties; root?: React.CSSProperties }` | - | Inline styles for the internal elements |
| `disabled` | `boolean` | `false` | Disable the entire field |
| `...props` | `React.ComponentProps<"input">` | - | Supports all native input props (except `type`, `className`), such as `onBlur` |

### Composable Components

#### NumberGroup

Outer container with the complete input styles built in: size (`max-w-3xs w-full`), rounded-full shape, and the `focus-within` focus ring; `data-invalid` is set when invalid but has no built-in styling.

| Prop        | Type                          | Default | Description                                                   |
| ----------- | ----------------------------- | ------- | ------------------------------------------------------------- |
| `className` | `ClassNameValue`              | -       | Custom class name                                             |
| `...props`  | `React.ComponentProps<"div">` | -       | Supports all native div props (including `data-*` attributes) |

#### NumberDecrement

The decrement button with built-in left semicircle styling and disabled state.

| Prop        | Type                             | Default | Description                                     |
| ----------- | -------------------------------- | ------- | ----------------------------------------------- |
| `className` | `ClassNameValue`                 | -       | Custom class name                               |
| `children`  | `React.ReactNode`                | -       | Button content                                  |
| `...props`  | `React.ComponentProps<"button">` | -       | Supports all native button props (except `className`) |

#### NumberIncrement

The increment button with built-in right semicircle styling and disabled state.

| Prop        | Type                             | Default | Description                                     |
| ----------- | -------------------------------- | ------- | ----------------------------------------------- |
| `className` | `ClassNameValue`                 | -       | Custom class name                               |
| `children`  | `React.ReactNode`                | -       | Button content                                  |
| `...props`  | `React.ComponentProps<"button">` | -       | Supports all native button props (except `className`) |

#### NumberRoot

The state-carrying text input with centered numeric styling built in.

| Prop        | Type                           | Default | Description                                            |
| ----------- | ------------------------------ | ------- | ------------------------------------------------------ |
| `className` | `ClassNameValue`               | -       | Custom class name                                      |
| `...props`  | `React.ComponentProps<"input">` | -      | Supports all native input props (except `className`), such as `value`, `onChange` and `role="spinbutton"` aria attributes |
