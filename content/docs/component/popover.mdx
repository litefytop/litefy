## API Reference

### High-level Components

#### Popover

Renders a native trigger button (`type="button"`, `aria-haspopup`, `aria-expanded`) plus the floating panel, positioned by the built-in JS positioning engine.

| Prop           | Type                                                                              | Default  | Description                                                                                 |
| :------------- | :-------------------------------------------------------------------------------- | :------- | :------------------------------------------------------------------------------------------ |
| `trigger`      | `React.ReactNode`                                                                 | -        | Content of the trigger button                                                                |
| `children`     | `React.ReactNode`                                                                 | -        | Panel content                                                                                |
| `open`         | `boolean`                                                                         | -        | Controlled panel state                                                                       |
| `defaultOpen`  | `boolean`                                                                         | `false`  | Initial panel state (uncontrolled)                                                           |
| `onOpenChange` | `(open: boolean) => void`                                                         | -        | Fired whenever the panel opens or closes                                                     |
| `alignX`       | `"start" \| "end" \| "center"`                                                    | `center` | Horizontal alignment of the panel relative to the trigger                                    |
| `placement`    | `{ side?; align?; gap?; matchWidth? }`                                            | -        | Overrides the docking derived from `alignX` (built-in JS positioning)                        |
| `mode`         | `"click" \| "hover"`                                                              | `click`  | Trigger interaction mode; `hover` opens on pointer enter / trigger focus and closes after a delayed pointer leave |
| `classNames`   | `{ trigger?: ClassNameValue; content?: ClassNameValue }`                          | -        | Custom class names per slot — the trigger is a bare `<button>` (part); give it preset finished classes (e.g. `litefy-button litefy-button-primary`) to style it |
| `styles`       | `{ trigger?: React.CSSProperties; content?: React.CSSProperties }`                | -        | Inline styles per slot (positioning itself is managed internally)                            |

### Hooks

#### usePopoverTrigger

Wires a custom trigger element and panel to the popover state; spread `triggerProps` onto the trigger (it carries the `data-anchor-name` attribute) and pass the returned `anchorName` to `PopoverContent`'s `anchorName` prop for alignment.

Options (`UsePopoverTriggerOptions`):

| Option            | Type                   | Default | Description                                            |
| :---------------- | :--------------------- | :------ | :----------------------------------------------------- |
| `open`            | `boolean`              | -       | Current panel state                                    |
| `onOpenChange`    | `(v: boolean) => void` | -       | State updater the hook calls to open or close          |
| `mode`            | `"click" \| "hover"`   | `click` | Interaction mode                                       |
| `hoverDelayOpen`  | `number`               | `0`     | Delay in ms before opening after pointer enter (hover) |
| `hoverDelayClose` | `number`               | `200`   | Delay in ms before closing after the pointer leaves    |

Returns:

| Member          | Type         | Description                                                                                        |
| :-------------- | :----------- | :------------------------------------------------------------------------------------------------- |
| `triggerProps`  | `object`     | Spread on the trigger element: `aria-haspopup`, `aria-expanded`, the `data-anchor-name` attribute, and click / hover / focus / keyboard handlers |
| `contentProps`  | `object`     | Spread on the panel: cancels the pending close timer on pointer enter and schedules it on pointer leave (hover mode) |
| `clearTimer`    | `() => void` | Cancels any pending hover open/close timer                                                          |
| `scheduleOpen`  | `() => void` | Opens the panel, honoring `hoverDelayOpen`                                                          |
| `scheduleClose` | `() => void` | Closes the panel after `hoverDelayClose` ms                                                         |
| `anchorName`    | `string`     | Generated anchor name (e.g. `--popover-trigger-abc123`); pass it to the panel's `anchorName` prop   |

### Composable Components

#### PopoverContent

The floating panel: a `popover="manual"` div with pre-wired panel look; a consumer `onKeyDown` composes with the built-in `Escape` handling — call `preventDefault()` to skip it.

| Prop           | Type                             | Default  | Description                                                                               |
| :------------- | :------------------------------- | :------- | :---------------------------------------------------------------------------------------- |
| `open`         | `boolean`                        | -        | Controls the panel; `true` calls `showPopover()`, `false` calls `hidePopover()`           |
| `onOpenChange` | `(open: boolean) => void`        | -        | Called when `Escape` is pressed inside the panel or a `mousedown` lands outside it        |
| `alignX`       | `"start" \| "end" \| "center"`   | `center` | Docking preset: `start` attaches the panel to the trigger's left, `end` to its right, `center` below it |
| `anchorName`   | `string`                         | -        | Name of the anchor element (its `data-anchor-name`) to position against                                   |
| `anchorPoint`  | `{ x: number; y: number }`       | -        | Viewport point anchor (e.g. mouse coordinates); takes precedence over `anchorName`                        |
| `placement`    | `{ side?; align?; gap?; matchWidth? }` | -    | Overrides the docking derived from `alignX`                                                               |
| `className`    | `ClassNameValue`                 | -        | Custom class names                                                                                        |
| `style`        | `React.CSSProperties`            | -        | Custom inline styles; positioning itself is managed by the built-in JS engine (side flip + cross-axis clamping) |
| `ref`          | `React.Ref<HTMLDivElement>`      | -        | Forwards to the panel div                                                                 |
| `...props`     | `React.ComponentProps<"div">`    | -        | Supports all native div props (except `className`), such as `role`, `id`, `onKeyDown`     |
