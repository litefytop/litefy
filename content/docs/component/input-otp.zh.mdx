### 禁用

`disabled` 原生禁用全部格子，根元素标记 `aria-disabled`，输入、粘贴、焦点移动与指针处理停止；格子使用 `bg-disabled`、`text-disabled-fg` 与 `cursor-not-allowed`。

## API 参考

### 高阶组件

#### InputOtp

由下方零件组合而成的验证码输入框，封装值状态与交互逻辑。

| Prop            | Type                      | Description                                |
| --------------- | ------------------------- | ------------------------------------------ |
| `length`        | `number`                  | 格子数量，默认 `6`                                |
| `value`         | `string`                  | 当前值（受控）                                    |
| `defaultValue`  | `string`                  | 初始值（非受控），默认 `""`                           |
| `onValueChange` | `(value: string) => void` | 值变化时的回调                                    |
| `disabled`      | `boolean`                 | 禁用所有格子，默认 `false`                          |
| `invalid`       | `boolean`                 | 在容器设置 `data-invalid`，每个格子设置 `aria-invalid` |
| `mask`          | `boolean`                 | 将格子渲染为密码输入，默认 `false`                      |
| `name`          | `string`                  | 渲染 hidden input 用于表单提交                     |
| `aria-label`    | `string`                  | 无障碍标签，每个格子会附加序号后缀                          |
| `className`     | `string`                  | 容器自定义类；默认 `w-full min-w-0 max-w-[20rem]`（最大 20rem） |
| `style`         | `React.CSSProperties`     | 容器自定义内联样式                                  |
| `classNames`    | `{ slot? }`               | 单元格的自定义类                                   |
| `styles`        | `{ slot? }`               | 单元格的内联样式                                   |

### 可组合组件

纯展示零件，不内置状态与交互，供高级使用者自由拼装。

#### InputOtpGroup

最外层容器，渲染为朴素 `div`；格子间的排列与间距来自 `classNames.group`，由所加载方案的皮肤填写。

| Prop        | Type                          | Description                             |
| ----------- | ----------------------------- | --------------------------------------- |
| `className` | `string`                      | 自定义类名                                   |
| `...props`  | `React.ComponentProps<"div">` | 支持全部 div 原生属性（除 `className`）            |

#### InputOtpSlot

单个格子，渲染为 `<input>`；值、事件、焦点移动与粘贴处理均由使用者接入。

| Prop        | Type                            | Description                                      |
| ----------- | ------------------------------- | ------------------------------------------------ |
| `className` | `string`                        | 自定义类名                                            |
| `ref`       | `React.Ref<HTMLInputElement>`   | 转发到原生 input 元素                                   |
| `...props`  | `React.ComponentProps<"input">` | 支持全部 input 原生属性（除 `className`、`ref`）             |

## 键盘交互

| Key | Description |
| --- | --- |
| `Typing` | 将输入的字符写入当前格子，并自动跳到下一格 |
| `ArrowLeft` / `ArrowRight` | 在格子之间移动 |
| `Backspace` | 在空格子上按下时清除并回到上一格 |
| `Paste` | 粘贴文本（Ctrl+V）时从当前位置起依次填入各格子 |

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-invalid]` | 位于外壳上——`invalid` 为 true 时存在 |
| `[data-disabled]` | 位于外壳上——所有格子禁用时存在 |
