### 基础用法

### 无效状态

设置 `invalid` 会在组上标记 `data-invalid`、在每个格子标记 `aria-invalid`——危险色边框与文字自动生效。填满后校验，修正后清除标记。

## API 参考

### 高级组件

#### InputOtp

由下方零件组合而成的验证码输入框，封装值状态与交互逻辑。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `length` | `number` | `6` | 格子数量 |
| `value` | `string` | - | 当前值（受控） |
| `defaultValue` | `string` | `""` | 初始值（非受控） |
| `onValueChange` | `(value: string) => void` | - | 值变化时的回调 |
| `disabled` | `boolean` | `false` | 禁用所有格子 |
| `invalid` | `boolean` | - | 在容器设置 `data-invalid`，每个格子设置 `aria-invalid` |
| `mask` | `boolean` | `false` | 将格子渲染为密码输入 |
| `name` | `string` | - | 渲染 hidden input 用于表单提交 |
| `aria-label` | `string` | - | 无障碍标签，每个格子会附加序号后缀 |
| `className` | `ClassNameValue` | - | 容器自定义类 |
| `style` | `React.CSSProperties` | - | 容器自定义内联样式 |
| `classNames` | `{ slot? }` | - | 单元格的自定义类 |
| `styles` | `{ slot? }` | - | 单元格的内联样式 |

输入后自动跳到下一格，空格子按 `Backspace` 回退并删除上一格，方向键在格子间移动，粘贴从当前格起填充。首个格子使用 `autoComplete='one-time-code'`。

### 可组合组件

纯展示零件，不内置状态与交互，供高级使用者自由拼装。

#### InputOtpGroup

最外层容器，渲染为 `div`，内置 `flex items-center gap-2`。

| Prop        | Type                          | Default | Description                             |
| ----------- | ----------------------------- | ------- | --------------------------------------- |
| `className` | `ClassNameValue`              | -       | 自定义类名                              |
| `...props`  | `React.ComponentProps<"div">` | -       | 支持全部 div 原生属性（除 `className`） |

#### InputOtpSlot

单个格子，渲染为 `<input>`；值、事件与 aria 属性由使用者接入。

| Prop        | Type                            | Default | Description                                      |
| ----------- | ------------------------------- | ------- | ------------------------------------------------ |
| `className` | `ClassNameValue`                | -       | 自定义类名                                       |
| `ref`       | `React.Ref<HTMLInputElement>`   | -       | 转发到原生 input 元素                            |
| `...props`  | `React.ComponentProps<"input">` | -       | 支持全部 input 原生属性（除 `className`、`ref`） |
