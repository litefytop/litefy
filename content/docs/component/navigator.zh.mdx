## 用法

`Navigator` 提供筛选工具栏的标准开箱布局：flex 容器自动换行，同行控件垂直居中对齐。筛选状态由 [useNavigator](/docs/utils/use-navigator) Hook 管理。

<ComponentPreview name="navigator-basic" />

### 仅 Hook 模式

组件只是纯布局外壳。标准布局不满足时，可以完全跳过组件，用 [useNavigator](/docs/utils/use-navigator) Hook 驱动自己的 DOM 结构：

<ComponentPreview name="use-navigator-basic" />

## 注意

- 不内置分页逻辑——分页属于 Table 复合套件。`Navigator` 与 `Table` 只做外部组合，禁止嵌套进 `Table` 内部。
- 标题文本自动换行，不会挤压同行控件。
- 标准的"重置筛选"组合：`text` Button 调用 `reset()`，用 `activeCount === 0` 控制禁用。

## API 参考

### Navigator

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `React.ReactNode` | - | 前置标题文本或标签 |
| `classNames` | `{ title?: ClassNameValue }` | - | 按插槽自定义类名 |
| `styles` | `{ title?: React.CSSProperties }` | - | 按插槽自定义样式 |
| `className` | `ClassNameValue` | - | 容器的自定义类名 |
| `...props` | `React.ComponentProps<"div">` | - | 原生 div 属性 |
