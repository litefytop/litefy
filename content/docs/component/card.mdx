## API Reference

### Card

A glassmorphic **static** surface with a fixed `shadow-base` (`rounded-lg`) — no hover lift or effects, so static containers never masquerade as clickable. For an interactive card, use [CardButton](#cardbutton).

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | Custom CSS class |
| `...props` | `React.ComponentProps<"div">` | - | Supports all native div props |
