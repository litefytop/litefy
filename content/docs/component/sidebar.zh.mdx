## 用法

以 `aside` 元素渲染、与内容并排的侧边栏；关闭时收起为零宽度，通过 `ref` 命令式控制（`toggle` / `open` / `close` / `isOpen`）。

## API 参考

### 高级组件

#### Sidebar

内部维护展开状态的 `aside` 元素，通过 `data-close` 属性收起。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `ref` | `React.Ref<SidebarHandle>` | - | 命令式句柄，包含 `toggle`、`open`、`close` 和 `isOpen`，用于外部控制 |
| `defaultOpen` | `boolean` | `true` | 初始展开状态 |
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `...props` | `React.ComponentProps<"aside">` | - | 支持所有原生 aside 属性（除 `className`、`ref` 外） |

#### SidebarHandle

挂载到 `ref` 上的命令式句柄。

| Property | Type | Description |
|----------|------|-------------|
| `toggle` | `() => void` | 切换展开状态 |
| `open` | `() => void` | 展开侧边栏 |
| `close` | `() => void` | 收起侧边栏 |
| `isOpen` | `boolean` | 当前展开状态 |
