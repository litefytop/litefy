## API Reference

### Callout

A pure-style component — no skeleton, no interactive states; content renders directly inside the block.

| Prop        | Type                          | Description                                                                                            |
| ----------- | ----------------------------- | ------------------------------------------------------------------------------------------------------ |
| `role`      | `string`                      | ARIA role of the block; switch to `alert` / `status` etc. to match the semantics, defaults to `"note"` |
| `children`  | `React.ReactNode`             | Callout content                                                                                        |
| `className` | `string`                      | Custom class names of the block; defaults to `w-full min-w-0`                                                                        |
| `...props`  | `React.ComponentProps<"div">` | Supports all native div props                                                                          |

## Keyboard Interactions

The component handles no keys and is not focusable — a pure display block; interactive content can only come from `children`.

## Data Attributes

| Attribute        | Description                                                            |
| ---------------- | ---------------------------------------------------------------------- |
| `[data-variant]` | Semantic variant: `success` / `warning` / `danger`; unset means `info`; lays the matching semantic resting background tier (the same value in light and dark) as the background, a dark vertical line on the start side, and the icon and title take the paired `*-fg` |
