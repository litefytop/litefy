## Usage

`Callout` is a static, block-level feedback container. It renders a soft tinted background with matching semantic text color, so feedback stays gentle and consistent.

<ComponentPreview name="callout-basic" />

- `info` (default) — neutral notices and descriptions
- `success` — positive results
- `warning` — cautionary hints
- `danger` — failures and danger feedback

## Notes

- `Callout` is for block-level feedback only — for short inline state marks use [Chip](/docs/component/chip), for inline actions use a `text` [Button](/docs/component/button).
- It is a static container: no hover, focus or other interaction states.
- Compose arbitrary content inside — a title can be a `<p>` with `font-medium`, or use any icon.
- Validation feedback below a form control is a `Callout` too: `variant="danger"` with `role="alert"`. `Form` / `FormItem` render their error line this way internally.

## API Reference

### Callout

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"info" \| "success" \| "warning" \| "danger"` | `"info"` | Semantic color of the block |
| `className` | `ClassNameValue` | - | Custom CSS class, overrides variant colors |
| `...props` | `React.ComponentProps<"div">` | - | Supports all native div props |
