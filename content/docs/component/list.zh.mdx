## 用法

由 `items` 驱动的滚动容器，行内容通过 `renderItem` 渲染，支持键盘导航。

## API 参考

### 高阶组件

#### List

支持滚动与键盘导航的列表；默认最大宽度 28rem。

| Prop                | Type                                                                | Description                                             |
| ------------------- | ------------------------------------------------------------------- | ------------------------------------------------------- |
| `items`             | `T[]`                                                               | 要渲染的数据数组                                                |
| `renderItem`        | `(item: T, index: number) => ReactNode`                             | 行内容渲染函数                                                 |
| `getKey`            | `(item: T, index: number) => Key`                                   | 行 key 提取函数；默认使用索引                                       |
| `empty`             | `React.ReactNode`                                                   | `items` 为空时渲染的内容                                        |
| `highlightIndex`    | `number \| null`                                                    | 受控高亮索引；省略时使用内部键盘导航                                      |
| `onHighlightChange` | `(index: number \| null) => void`                                   | 高亮变化时触发                                                 |
| `getGroup`          | `(item: T, index: number) => string`                                | 分组标签提取函数；仅当 `getGroup` 与 `renderGroupHeader` 同时提供时启用分组  |
| `renderGroupHeader` | `(groupName: string) => ReactNode`                                  | 组标题渲染函数；仅当 `getGroup` 与 `renderGroupHeader` 同时提供时启用分组   |
| `onSelect`          | `(item: T, index: number) => void`                                  | 点击行或键盘导航期间按下 `Enter` 确认时触发                              |
| `onScrollBottom`    | `() => void`                                                        | 列表滚动到底部 16px 以内时触发，用于加载更多场景                             |
| `onItemMouseMove`   | `(item: T, index: number) => void`                                  | 指针在行上移动时触发——把它接到 `setHighlightIndex` 可让 hover 与键盘共享同一高亮 |
| `isItemDisabled`    | `(item: T, index: number) => boolean`                               | 逐项判断禁用；禁用行不响应点击或悬停，键盘高亮与选择也会跳过，默认所有项可用 |
| `size`               | `"sm" \| "md" \| "lg" \| "xl"`                                                               | 外层滚动视口最大宽度依次为 20、24、28、32rem，默认 `"lg"`                    |
| `ref`               | `React.Ref<HTMLDivElement>`                                                                   | 外层滚动视口 ref，例如用于把焦点移入列表                                   |
| `className`         | `string`                                                                            | 外层滚动视口自定义类；默认 `w-full min-w-0`                              |
| `style`             | `React.CSSProperties`                                                                   | 外层滚动视口内联样式                                                |
| `classNames`        | `{ root?: string; viewport?: string; empty?: string; groups?: string; item?: SlotClassName; groupHeader?: string }` | `root` 控制内层 `ul` 或分组 `div`；`viewport` 控制外层滚动视口；`item` 接收 `({ disabled }) => string` |
| `styles`            | `{ root?: React.CSSProperties; empty?: React.CSSProperties; groups?: React.CSSProperties; item?: React.CSSProperties; groupHeader?: React.CSSProperties }` | `root` 控制内层列表，`empty` 控制空态，`groups` 控制分组容器；`item` 与 `groupHeader` 控制行与组标题 |

禁用行使用 `bg-disabled`、`text-disabled-fg` 与 `cursor-not-allowed`，不叠加透明度或灰度滤镜。行分隔由方案决定（组件不强制）；需要滚动边缘阴影时自行搭配 [ScrollShadow](/zh/docs/component/scroll-shadow)。

#### Order

有序列表变体，列表元素渲染为 `<ol>` 并发出 `data-ordered`，十进制编号由所加载的方案提供。它接受除分组 API（`getGroup` / `renderGroupHeader`）外的所有 `List` 属性，`ref` 类型为 `React.Ref<HTMLDivElement>`，指向外层滚动视口。序号通过 `::marker` 渲染，要求行保持 `display: list-item`——改变行的 display（例如改成 flex）会使序号消失，行内容布局应放在 `renderItem` 内部。

| Prop                | Type                                                                | Description                             |
| ------------------- | ------------------------------------------------------------------- | --------------------------------------- |
| `items`             | `T[]`                                                               | 要渲染的数据数组                                |
| `renderItem`        | `(item: T, index: number) => ReactNode`                             | 行内容渲染函数                                 |
| `getKey`            | `(item: T, index: number) => Key`                                   | 行 key 提取函数；默认使用索引                       |
| `empty`             | `React.ReactNode`                                                   | `items` 为空时渲染的内容                        |
| `highlightIndex`    | `number \| null`                                                    | 受控高亮索引；省略时使用内部键盘导航                      |
| `onHighlightChange` | `(index: number \| null) => void`                                   | 高亮变化时触发                                 |
| `onSelect`          | `(item: T, index: number) => void`                                  | 点击行或键盘导航期间按下 `Enter` 确认时触发              |
| `onScrollBottom`    | `() => void`                                                        | 列表滚动到底部 16px 以内时触发，用于加载更多场景             |
| `onItemMouseMove`   | `(item: T, index: number) => void`                                  | 指针在行上移动时触发                              |
| `isItemDisabled`    | `(item: T, index: number) => boolean`                               | 逐项判断禁用，与 `List` 相同                    |
| `size`               | `"sm" \| "md" \| "lg" \| "xl"`                                                               | 外层滚动视口最大宽度依次为 20、24、28、32rem，默认 `"lg"`                    |
| `ref`               | `React.Ref<HTMLDivElement>`                                                                   | 外层滚动视口 ref                                                            |
| `className`         | `string`                                                                            | 外层滚动视口自定义类；默认 `w-full min-w-0`                              |
| `style`             | `React.CSSProperties`                                                                   | 外层滚动视口内联样式                                                |
| `classNames`        | `{ root?: string; viewport?: string; empty?: string; item?: SlotClassName; groupHeader?: string }` | `root` 控制内层 `ol`；`viewport` 控制外层滚动视口；`item` 接收 `({ disabled }) => string`；`Order` 不使用 `groupHeader` |
| `styles`            | `{ root?: React.CSSProperties; empty?: React.CSSProperties; item?: React.CSSProperties; groupHeader?: React.CSSProperties }` | `root` 控制内层 `ol`，`empty` 控制空态；`Order` 不使用 `groups` 与 `groupHeader` |

## 键盘交互

| Key | Description |
| --- | --- |
| `ArrowDown` | 高亮移动到下一项——无高亮时移到第一项；高亮项会自动滚动到可视区域 |
| `ArrowUp` | 高亮移动到上一项——无高亮时移到最后一项；高亮项会自动滚动到可视区域 |
| `Enter` / `Space` | 选中当前高亮项 |

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-highlighted]` | 位于每个条目上——键盘高亮落在该项上时存在 |
| `[data-disabled]` | 位于禁用条目上——该行同时带 `aria-disabled="true"` |
| `[data-ordered]` | 位于根元素上——列表有序时存在 |
