## 用法

由 `items` 驱动的滚动容器，行内容通过 `renderItem` 渲染；分页场景搭配 [`usePagination`](/docs/utils/use-pagination) hook。

<ComponentPreview
  name="list-basic"
/>

### 有序列表

`Order` 把同样的列表渲染为带十进制编号的 `<ol>`——用于顺序本身有含义的序列。

<ComponentPreview
  name="list-order"
/>

序号通过 `::marker` 渲染，要求行保持 `display: list-item`——在 `classNames.item` 上加 display 工具类（如 `flex`）会使序号消失，行内容布局应放在 `renderItem` 内部。

### 分组

提供 `getGroup` / `renderGroupHeader` 渲染组标题——组标题是普通行，键盘导航不会高亮或选中它们。

## API 参考

### 高级组件

#### List

支持滚动与键盘导航的列表；尺寸完全由使用者指定（如 `h-40 rounded-md border`）。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `T[]` | - | 要渲染的数据数组 |
| `renderItem` | `(item: T, index: number) => ReactNode` | - | 行内容渲染函数 |
| `getKey` | `(item: T, index: number) => Key` | - | 行 key 提取函数；默认使用索引 |
| `empty` | `React.ReactNode` | - | `items` 为空时渲染的内容 |
| `highlightIndex` | `number \| null` | - | 受控高亮索引；省略时使用内部键盘导航 |
| `onHighlightChange` | `(index: number \| null) => void` | - | 高亮变化时触发 |
| `getGroup` | `(item: T, index: number) => string` | - | 分组标签提取函数；仅当 `getGroup` 与 `renderGroupHeader` 同时提供时启用分组 |
| `renderGroupHeader` | `(groupName: string) => ReactNode` | - | 组标题渲染函数；仅当 `getGroup` 与 `renderGroupHeader` 同时提供时启用分组 |
| `onSelect` | `(item: T, index: number) => void` | - | 点击行或键盘导航期间按下 `Enter` 确认时触发 |
| `onScrollBottom` | `() => void` | - | 列表滚动到底部 16px 以内时触发，用于加载更多场景 |
| `onItemMouseMove` | `(item: T, index: number) => void` | - | 指针在行上移动时触发——把它接到 `setHighlightIndex` 可让 hover 与键盘共享同一高亮 |
| `ref` | `React.Ref<HTMLUListElement \| HTMLDivElement>` | - | 根元素 ref —— 平铺模式为 `ul`，分组模式为 `div`，例如用于把焦点移入列表 |
| `className` | `ClassNameValue` | - | 根节点自定义类 |
| `style` | `React.CSSProperties` | - | 根节点自定义内联样式 |
| `classNames` | `{ item?: ClassNameValue; groupHeader?: ClassNameValue }` | - | 行与组标题的自定义类 |
| `styles` | `{ item?: React.CSSProperties; groupHeader?: React.CSSProperties }` | - | 行与组标题的内联样式 |

默认不带分隔线与边缘阴影——需要时加 `divide-y` 类，并自行搭配 [ScrollShadow](/docs/component/scroll-shadow)。

#### Order

有序列表变体，根节点渲染为带十进制编号（`list-decimal pl-6`）的 `<ol>`。它接受除分组 API（`getGroup` / `renderGroupHeader`）外的所有 `List` 属性，`ref` 类型为 `React.Ref<HTMLOListElement>`。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `T[]` | - | 要渲染的数据数组 |
| `renderItem` | `(item: T, index: number) => ReactNode` | - | 行内容渲染函数 |
| `getKey` | `(item: T, index: number) => Key` | - | 行 key 提取函数；默认使用索引 |
| `empty` | `React.ReactNode` | - | `items` 为空时渲染的内容 |
| `highlightIndex` | `number \| null` | - | 受控高亮索引；省略时使用内部键盘导航 |
| `onHighlightChange` | `(index: number \| null) => void` | - | 高亮变化时触发 |
| `onSelect` | `(item: T, index: number) => void` | - | 点击行或键盘导航期间按下 `Enter` 确认时触发 |
| `onScrollBottom` | `() => void` | - | 列表滚动到底部 16px 以内时触发，用于加载更多场景 |
| `onItemMouseMove` | `(item: T, index: number) => void` | - | 指针在行上移动时触发 |
| `ref` | `React.Ref<HTMLOListElement>` | - | 根 `<ol>` 元素的 ref |
| `className` | `ClassNameValue` | - | 根节点自定义类 |
| `style` | `React.CSSProperties` | - | 根节点自定义内联样式 |
| `classNames` | `{ item?: ClassNameValue; groupHeader?: ClassNameValue }` | - | 各部分自定义类（`Order` 中不会用到 `groupHeader`） |
| `styles` | `{ item?: React.CSSProperties; groupHeader?: React.CSSProperties }` | - | 各部分自定义内联样式（`Order` 中不会用到 `groupHeader`） |
