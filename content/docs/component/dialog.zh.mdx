## API 参考

### 高阶组件

开箱即用的成品组件。

#### Dialog

基于原生 HTML `dialog` 元素的模态对话框组件，内置焦点圈定、Esc 关闭处理和过渡动画。

| Prop           | Type                                               | Default   | Description                                                                   |
| -------------- | -------------------------------------------------- | --------- | ----------------------------------------------------------------------------- |
| `open`         | `boolean`                                          | -（必填） | 受控打开状态，内部通过原生 `showModal()` / `close()` 同步                     |
| `onOpenChange` | `(open: boolean) => void`                          | -         | 打开状态变化回调，Esc、关闭按钮点击、原生 `cancel` / `close` 时触发           |
| `className`    | `ClassNameValue`                                   | -         | 自定义 CSS 类名，作用于原生 dialog 元素                                       |
| `ref`          | `React.Ref<HTMLDialogElement>`                     | -         | 转发到原生 dialog 元素                                                        |
| `children`     | `React.ReactNode`                                  | -         | 对话框内容                                                                    |
| `onClick`      | `(e: React.MouseEvent<HTMLDialogElement>) => void` | -         | 点击 Backdrop 时触发的事件回调，可自行实现点击遮罩关闭                        |
| `...props`     | `React.ComponentProps<"dialog">`                   | -         | 支持全部 dialog 原生属性（`onKeyDown`、`onCancel`、`onClose` 由组件内部接管） |

---

### 可组合组件

> 以下组件可自由拼装。`DialogClose` 内置与组合组件 `Dialog` 关闭按钮相同的默认样式，可通过 `className` 覆盖；`DialogRoot` 为无样式与行为的原生 `dialog`。

#### DialogRoot

dialog 元素，渲染为无内置样式与行为的原生 `dialog`。

| Prop        | Type                             | Default | Description                                  |
| ----------- | -------------------------------- | ------- | -------------------------------------------- |
| `className` | `ClassNameValue`                 | -       | 自定义类名，作用于原生 dialog 元素           |
| `...props`  | `React.ComponentProps<"dialog">` | -       | 支持全部 dialog 原生属性（除 `className`）   |

#### DialogClose

关闭按钮，内置样式，绝对定位于最近的定位祖先（即 dialog 元素）的右上角。

| Prop        | Type                             | Default | Description                                |
| ----------- | -------------------------------- | ------- | ------------------------------------------ |
| `className` | `ClassNameValue`                 | -       | 自定义类名                                 |
| `children`  | `React.ReactNode`                | -       | 按钮内容                                   |
| `...props`  | `React.ComponentProps<"button">` | -       | 支持全部 button 原生属性（除 `className`） |

#### dialog

命令式触发方法，动态创建对话框并在关闭后自动销毁。

| Method    | Type                                   | Description    |
| --------- | -------------------------------------- | -------------- |
| `success` | `(opts: DialogCommandOptions) => void` | 打开命令对话框 |
| `error`   | `(opts: DialogCommandOptions) => void` | 打开命令对话框 |
| `warning` | `(opts: DialogCommandOptions) => void` | 打开命令对话框 |
| `info`    | `(opts: DialogCommandOptions) => void` | 打开命令对话框 |

> 四个方法为语义化快捷方式，行为一致。
> 浏览器限制：模态 dialog（`showModal()`）同一时间只能打开一个，重复打开会被浏览器拦截，而非排队等待。

#### DialogCommandOptions

| Field      | Type              | Description          |
| ---------- | ----------------- | -------------------- |
| `title`    | `React.ReactNode` | 对话框标题           |
| `children` | `React.ReactNode` | 对话框内容           |
| `props`    | `DialogProps`     | 透传给 Dialog 的属性 |
