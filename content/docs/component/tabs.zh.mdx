## API 参考

### 高级组件

#### Tabs

options 驱动的容器组件，管理活动值并以参数形式向 `TabsList`、`TabsTrigger` 和 `TabsContent` 传递全部状态，不使用 context。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `TabsOptionConfig[]` | - | 标签定义 |
| `defaultValue` | `string` | - | 初始活动标签值（非受控模式），缺省时取第一个选项的值 |
| `value` | `string` | - | 活动标签值（受控模式） |
| `onValueChange` | `(value: string) => void` | - | 活动标签变化时的回调 |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | 布局方向 |
| `variant` | `'button' \| 'line'` | `'line'` | 视觉样式变体 |
| `className` | `ClassNameValue` | - | 自定义 CSS 类，作用于根元素 |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性（除 `className` 外） |

#### TabsOptionConfig

| Property | Type | Description |
|----------|------|-------------|
| `value` | `string` | 标签的唯一标识符 |
| `label` | `React.ReactNode` | 标签触发器的内容 |
| `content` | `React.ReactNode` | 标签面板的内容 |
| `disabled` | `boolean` | 禁用该标签 |

---

### 可组合组件

#### TabsList

标签触发按钮的容器，仅通过参数通信。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | 布局方向 |
| `autoScroll` | `boolean` | `false` | 渲染左右滚动按钮并隐藏滚动条（仅水平方向） |
| `activeValue` | `string` | - | 当前活动值；变化时将活动触发器滚动到可视区域 |
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性（除 `className` 外） |

#### TabsTrigger

单个标签按钮。激活状态与回调完全通过参数传入。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | - | 标签的唯一标识符 |
| `active` | `boolean` | `false` | 是否激活，驱动 `data-state` 和 `aria-selected` |
| `onValueChange` | `(value: string) => void` | - | 点击或按 Enter/Space 时以自身 `value` 调用 |
| `variant` | `'button' \| 'line'` | `'line'` | 视觉样式变体 |
| `disabled` | `boolean` | `false` | 禁用该标签 |
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `...props` | `React.ComponentProps<"button">` | - | 支持所有原生 button 属性（除 `className` 外） |

#### TabsContent

`active` 为 true 时渲染的面板，否则返回 `null`。配合 `React.lazy()` 包裹内容，可在标签被激活前延迟加载。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | - | 唯一标识符，用于派生面板 id 和 `aria-labelledby` |
| `active` | `boolean` | `false` | 面板是否可见 |
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性（除 `className` 外） |

## 懒加载

`TabsContent` 在非激活时返回 `null`，因此用 `lazy()` 包裹内容可以延迟 import：

```tsx
import { lazy, Suspense } from "react";
import { Tabs } from "@/ui";

const LazySettings = lazy(() => import("./settings"));

<Tabs
  defaultValue="profile"
  options={[
    { value: "profile", label: "个人资料", content: "个人资料内容" },
    {
      value: "settings",
      label: "设置",
      content: (
        <Suspense fallback={null}>
          <LazySettings />
        </Suspense>
      ),
    },
  ]}
/>
```
