## 用法

带渐变阴影指示器的可滚动容器——`edges` 指定边缘，`classNames.edge` 覆盖内置的 `h-16` / `w-16` 渐变尺寸。

## API 参考

### ScrollShadow

带有渐变阴影指示器的可滚动容器。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | - | 可滚动内容 |
| `edges` | `'top' \| 'bottom' \| 'left' \| 'right' \| Array<'top' \| 'bottom' \| 'left' \| 'right'>` | `'bottom'` | 显示阴影指示器的边缘（可传单个或数组） |
| `onScroll` | `React.UIEventHandler<HTMLDivElement>` | - | 绑定到滚动视口——例如用于无限滚动触发 |
| `className` | `ClassNameValue` | - | 自定义类名，作用于根容器 |
| `style` | `React.CSSProperties` | - | 内联样式，作用于根容器 |
| `classNames` | `{ viewport?, edge? }` | - | 滚动视口与阴影覆盖层的自定义类（在此覆盖内置的 `h-16` / `w-16` 边缘尺寸） |
| `styles` | `{ viewport?, edge? }` | - | 滚动视口与阴影覆盖层的内联样式 |

### 组合零件

#### ScrollShadowRoot

外层容器，负责裁剪溢出内容并作为阴影覆盖层的定位锚点。

| Prop        | Type             | Default | Description      |
| ----------- | ---------------- | ------- | ---------------- |
| `className` | `ClassNameValue` | -       | 自定义 CSS 类 |

支持所有原生 `<div>` 属性。

#### ScrollShadowViewport

填满根容器的滚动视口。

| Prop        | Type             | Default | Description      |
| ----------- | ---------------- | ------- | ---------------- |
| `className` | `ClassNameValue` | -       | 自定义 CSS 类 |

支持所有原生 `<div>` 属性（含 `ref`）。

#### ScrollShadowEdge

单个边缘的渐变阴影覆盖层。

| Prop        | Type             | Default     | Description      |
| ----------- | ---------------- | ----------- | ---------------- |
| `edge`      | `'top' \| 'bottom' \| 'left' \| 'right'` | `'bottom'` | 渐变起始的边缘 |
| `className` | `ClassNameValue` | -           | 自定义 CSS 类（内置尺寸为 `h-16` / `w-16`） |

支持所有原生 `<div>` 属性；可见性由组合组件 `ScrollShadow` 根据滚动位置控制。
