## 用法

`ChatInput` 替你管理文字与粘贴图片的状态：粘贴进文本域的截图自动生成缩略图条（内部处理 `URL.createObjectURL`），发送按钮通过 `onSend` 把收集到的内容整包发出，并自动清空输入。

能力开关放在 `actions` 插槽里——用 [Toggle](/zh/docs/component/toggle) 自行组合。

### 移动端适配

- **回车行为**：精确指针（鼠标）下 Enter 发送、Shift+Enter 换行；粗糙指针（触摸）下 Enter 始终换行——发送只通过按钮，虚拟键盘不会误触发送。可用 `enterToSend: "auto" | boolean` 控制。
- **聚焦不缩放**：小屏下文本域字号为 16px（iOS Safari 会缩放聚焦时字号小于该值的输入框）。
- **附件按钮**：设置 `attach` 显示图片选择按钮（`accept="image/*"`），移动端会唤起相机/相册选择器。

## API 参考

### ChatInput

| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `value` | `string` | - | 受控文字 |
| `defaultValue` | `string` | `""` | 初始文字（非受控） |
| `onValueChange` | `(text: string) => void` | - | 文字变化回调 |
| `onSend` | `(payload: { text: string; images: File[] }) => void` | - | 发送回调；发送后组件自动清空 |
| `placeholder` | `string` | - | 文本域占位文案 |
| `disabled` | `boolean` | `false` | 禁用整个输入框 |
| `autoPaste` | `boolean` | `true` | 粘贴的图片转为缩略图 |
| `attach` | `boolean` | `false` | 显示图片附件按钮 |
| `enterToSend` | `"auto" \| boolean` | `"auto"` | 回车发送行为 |
| `actions` | `React.ReactNode` | - | 操作栏左侧插槽 |
| `className` | `ClassNameValue` | - | 自定义类名，作用于容器 |
| `classNames` | `container` / `textarea` / `images` / `actions` / `send` | - | 各部分自定义类名 |
| `styles` | `{ container?, textarea?, actions?, send? }` | - | 各部分内联样式 |
