## Usage

Typing filters the local options; matching ignores case and spaces, and focus stays in the input.

### Async search

Pass `fetcher` instead of `options` for large datasets or remote APIs; when both are provided, `fetcher` wins.

### Disabled

`disabled` natively disables the input and marks the root with `aria-disabled`; opening, typing, and selection handling stop. The disabled appearance uses `bg-disabled`, `text-disabled-fg`, and `cursor-not-allowed`.

## API Reference

### Combobox

| Prop             | Type                                                                      | Description                                                               |
| :--------------- | :------------------------------------------------------------------------ | :------------------------------------------------------------------------ |
| `options`        | `string[]`                                                                | Local options, filtered client-side                                       |
| `fetcher`        | `({ page, size, keyword }) => Promise<{ list: string[]; total: number }>` | Remote request function for async mode                                    |
| `defaultValue`   | `string`                                                                  | Initial input text (uncontrolled), defaults to `""`                       |
| `value`          | `string`                                                                  | Controlled input text                                                     |
| `onValueChange`  | `(value: string) => void`                                                 | Fires on typing and on selection                                          |
| `invalid`        | `boolean`                                                                 | Invalid state of the input, defaults to `false`                           |
| `disabled`       | `boolean`                                                                 | Disables the group: the input is natively disabled, the root is marked `aria-disabled`, and the candidate panel cannot open; defaults to `false` |
| `empty`          | `React.ReactNode`                                                         | Node for the list's empty state, defaults to `"No data"` / `"Loading..."` |
| `pageSize`       | `number`                                                                  | Page size for async pagination, defaults to `20`                          |
| `debounceMs`     | `number`                                                                  | Debounce delay for async search, defaults to `300`                        |
| `leading`        | `React.ReactNode`                                                         | Leading node inside the field group, defaults to a search icon; pass `null` to remove |
| `className`      | `string`                                                                  | Custom class name on the field root container; defaults to `w-full min-w-0 max-w-[20rem]` (maximum width 20rem) |
| `style`          | `React.CSSProperties`                                                    | Inline styles on the field root container                                 |
| `classNames`     | `{ panel?; item?; input?; leading?; trailing?; list?: ListClassNames }` | `input` controls the inner input, `panel` the candidate panel, and `list` the internal list and its slots |
| `styles`         | `{ panel?: React.CSSProperties; item?: React.CSSProperties; leading?: React.CSSProperties }` | Inline styles for the panel, list items, and leading slot; there are no root or input style slots. The panel defaults to a maximum width of 20rem and is constrained by the viewport width minus 1rem |

### Atoms

#### Picker

The foundation of Combobox: a generic input + popover container for assembling custom picker scenarios (the CLI installs it along with `litefy add combobox`).

| Prop                     | Type                                | Description                                                                                    |
| :----------------------- | :---------------------------------- | :--------------------------------------------------------------------------------------------- |
| `value` / `defaultValue` | `string`                            | Input value (controlled / uncontrolled), defaults to `""`                                      |
| `onValueChange`          | `(value: string) => void`           | Fires when the input value changes                                                             |
| `open` / `defaultOpen`   | `boolean`                           | Panel open state (controlled / uncontrolled), defaults to `false`                              |
| `onOpenChange`           | `(open: boolean) => void`           | Fires when the panel opens or closes (click, outside click, Escape)                            |
| `trailing`               | `React.ReactNode`                   | Trailing icon of the input                                                                     |
| `disabled`               | `boolean`                          | Natively disables the input and closes the panel, defaults to `false`                         |
| `children`               | `React.ReactNode`                   | Popover panel content                                                                          |
| `panelRef`               | `React.Ref<HTMLDivElement>`         | Receives the panel element; use together with [usePanelFocus](/en/docs/utils/use-panel-focus) |
| `className` / `style`    | -                                   | Applied to the root container                                                                  |
| `classNames` / `styles`  | `{ input? / trailing? / popover? }` | Per-part overrides                                                                             |
| `...props`               | `React.ComponentProps<"input">`     | Remaining native input props                                                                   |

Panel keyboard behavior is wired up with hooks: use [useCombobox](/en/docs/utils/use-combobox) for highlight lists (the input keeps focus while the panel is open), and [usePanelFocus](/en/docs/utils/use-panel-focus) with `panelRef` for panels made of real focusable controls; if focus would be lost when the panel closes, it is handed back to the input automatically.

## Keyboard Interactions

| Key                    | Description                                                                                    |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| `ArrowDown` / `ArrowUp` | Moves the highlight while the panel is open; when the panel is closed, `ArrowDown` opens it    |
| `Enter`                | Commits the currently highlighted option                                                       |
| `Escape`               | Closes the panel                                                                               |

During IME composition, `onValueChange` and the remote search are suspended and only fire after the composition ends.

## Data Attributes

| Attribute    | Description                                                                          |
| ------------ | ------------------------------------------------------------------------------------ |
| `[data-open]` | On the root element — present while the panel is open (from the underlying Picker)  |
| `[data-disabled]` | On the root element — present when the entire combobox is disabled |
