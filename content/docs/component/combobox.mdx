Combobox is not a shipped component with source code. It is a composition of two primitives: [Picker](/docs/component/picker) provides the input trigger and the popover panel, and [List](/docs/component/list) provides the keyboard-navigable option list with highlight support. Assemble them directly in your page — the demos below are the complete implementations.

## Usage

### Basic Usage

Client-side filtering lives in your own state: `onValueChange` mirrors the typed text, the options are filtered from it, and `List`'s built-in keyboard navigation takes over once the list is focused.

/>

Key points of the assembly:

- Focus never leaves the input. `ArrowDown` opens the panel (built into Picker), then `ArrowDown` / `ArrowUp` drive the highlight through `List`'s controlled `highlightIndex`, so typing and arrow-key navigation coexist.
- `List` renders the highlight with `data-highlighted` and scrolls it into view automatically; `Enter` in the input (or a click on a row) selects through `onSelect`.
- `onSelect` writes the chosen option back into the input text and closes the panel via `onOpenChange`; closing also clears the highlight.
- The `empty` node renders when the filtered options are exhausted.

### Async Search

For large or remote datasets, call `remote.search` from `onValueChange` and page through results with `onScrollBottom` as the list is scrolled to the bottom — the [`useRemotePagination`](/docs/utils/use-remote-pagination) hook provides the debounced fetching, data and load-more controls.
