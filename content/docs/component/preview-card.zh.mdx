## 注意

- PreviewCard 内部由 [Card](/docs/component/card)、[Image](/docs/component/image) 和 [Tooltip](/docs/component/tooltip) 组合而成——CLI 安装时会自动解析并安装这些依赖。
- Card 的 `overflow-hidden rounded-lg` 会自动裁出顶部图片的圆角。
- 传入 `trigger` 时，卡片作为 Tooltip 内容渲染（宽度 `w-72`）；不传 `trigger` 时，作为独立卡片渲染（`max-w-sm`）。
- Image 的 `className` 控制图片区域高度（默认 `h-40`）。

## API 参考

### PreviewCard

| 属性 | 类型 | 默认值 | 描述 |
| :--- | :--- | :----- | :--- |
| `src` | `string` | - | 图片地址 |
| `alt` | `string` | - | 图片 alt 文本 |
| `title` | `React.ReactNode` | - | 卡片标题 |
| `description` | `React.ReactNode` | - | 卡片描述 |
| `trigger` | `React.ReactNode` | - | 传入时作为链接的悬停 Tooltip 展示 |
| `href` | `string` | `"#"` | 链接地址（仅在传入 `trigger` 时生效） |
| `delay` | `number` | `200` | Tooltip 显示延迟（毫秒，仅与 `trigger` 配合） |
| `className` | `ClassNameValue` | - | 卡片的自定义类名 |
| `classNames` | `{ image? / body? / title? / description? }` | - | 子区域的自定义类名 |
