## API 参考

### 高阶组件

#### Banner

数据驱动的跑马灯横幅。

| Prop           | Type                                   | Default | Description                                                                              |
| :------------- | :------------------------------------- | :------ | :--------------------------------------------------------------------------------------- |
| `items`        | `BannerItem[]`                         | -       | 滚动的内容；每项渲染在一个 `BannerItem` 内                                                 |
| `speed`        | `number`                               | `30`    | 循环一周（轨道位移 `-50%`）所需的秒数                                                      |
| `direction`    | `"left" \| "right"`                    | `left`  | 滚动方向                                                                                   |
| `pauseOnHover` | `boolean`                              | `true`  | 指针悬停在横幅上时暂停动画                                                                  |
| `className`    | `ClassNameValue`                       | -       | 视口的自定义类名                                                                            |
| `style`        | `React.CSSProperties`                  | -       | 视口的内联样式                                                                              |
| `classNames`   | `{ track?; item? }` —— 值均为 `ClassNameValue` | - | 轨道与条目的自定义类名                                          |
| `styles`       | `{ track?; item? }` —— 值均为 `React.CSSProperties` | - | 轨道与条目的内联样式                                            |
| `...props`     | `React.ComponentProps<"div">`          | -       | 原生 div 属性透传到视口（不含 `children`）；你自己的 `onMouseEnter` / `onMouseLeave` 会与悬停暂停组合 |

#### BannerItem

单个滚动条目。

| Field     | Type                 | Description   |
| :-------- | :------------------- | :------------ |
| `key`     | `string \| number`   | 可选 React key |
| `content` | `React.ReactNode`    | 渲染的内容     |

#### 静态属性

| Static             | Type              | Description      |
| :----------------- | :---------------- | :--------------- |
| `Banner.Viewport`  | `BannerViewport`  | 裁剪容器零件      |
| `Banner.Track`     | `BannerTrack`     | 动画轨道零件      |
| `Banner.Item`      | `BannerItem`      | 单个条目零件      |

### 可组合组件

#### BannerViewport

裁剪容器。

| Prop       | Type                          | Description       |
| :--------- | :---------------------------- | :---------------- |
| `className`| `ClassNameValue`              | 自定义类名         |
| `...props` | `React.ComponentProps<"div">` | 支持所有原生 div 属性 |

#### BannerTrack

动画轨道；无缝循环要求轨道包含完全相同的两半（对应 `-50%` 位移）。

| Prop        | Type                          | Default | Description                                              |
| :---------- | :---------------------------- | :------ | :------------------------------------------------------- |
| `duration`  | `number`                      | `30`    | 循环一周所需的秒数                                        |
| `direction` | `"left" \| "right"`           | `left`  | 滚动方向                                                   |
| `playing`   | `boolean`                     | `true`  | 播放或暂停动画                                             |
| `className` | `ClassNameValue`              | -       | 自定义类名（内置 `flex w-max`）                             |
| `...props`  | `React.ComponentProps<"div">` | -       | 支持所有原生 div 属性                                       |

#### BannerItem

单个条目单元（内置 `flex shrink-0 items-center`）。

| Prop       | Type                          | Description       |
| :--------- | :---------------------------- | :---------------- |
| `className`| `ClassNameValue`              | 自定义类名         |
| `...props` | `React.ComponentProps<"div">` | 支持所有原生 div 属性 |
