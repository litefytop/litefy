## API Reference

### High-level Components

Ready-to-use composite components.

#### Image

An image component with preload state management; the outer container has built-in `relative` and `overflow-hidden` styles.

| Prop            | Type                                            | Default      | Description                                                         |
| --------------- | ----------------------------------------------- | ------------ | -------------------------------------------------------------------- |
| `src`           | `string`                                        | - (required) | Image source URL                                                    |
| `alt`           | `string`                                        | -            | Alternative text for the image                                      |
| `className`     | `ClassNameValue`                                | -            | Custom CSS class name, applied to the outer container               |
| `fallback`      | `React.ReactNode`                               | -            | Custom fallback element shown when the image fails to load          |
| `loadingNode`   | `React.ReactNode`                               | -            | Placeholder element shown while loading, commonly used for progressive blurred thumbnails |
| `slots.wrapper` | `Omit<React.ComponentProps<"div">, "children">` | -            | Props for the outer container; its `className` takes precedence over `className` |
| `...props`      | `React.ComponentProps<"img">`                   | -            | Supports all native img props (except `className`), with built-in `loading="lazy"`, `decoding="async"` and `contentVisibility: auto` |

### Headless Atomic Components

> The following are low-level atomic components with **minimal built-in styles; styles should be added via className**. The high-level composite component `Image` is composed of these atomic components.

#### ImageRoot

Outer container with built-in `relative` and `overflow-hidden`.

| Prop        | Type                          | Default | Description                    |
| ----------- | ------------------------------ | ------- | -------------------------------- |
| `className` | `ClassNameValue`               | -       | Custom class name                |
| `...props`  | `React.ComponentProps<"div">`  | -       | Supports all native div props    |

#### ImageImage

The image element with built-in `w-full`, `h-full` and `object-cover`.

| Prop        | Type                          | Default | Description                    |
| ----------- | ------------------------------ | ------- | -------------------------------- |
| `className` | `ClassNameValue`               | -       | Custom class name                |
| `...props`  | `React.ComponentProps<"img">`  | -       | Supports all native img props    |
