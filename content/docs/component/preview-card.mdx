## API Reference

### PreviewCard

| Prop          | Type                                         | Description                                                             |
| :------------ | :------------------------------------------- | :---------------------------------------------------------------------- |
| `src`         | `string`                                     | The image URL                                                           |
| `alt`         | `string`                                     | The image alt text                                                      |
| `title`       | `React.ReactNode`                            | The card title                                                          |
| `description` | `React.ReactNode`                            | The card description                                                    |
| `trigger`     | `React.ReactNode`                            | When provided, the card renders as a hover Tooltip on a link            |
| `href`        | `string`                                     | The link href (only used when `trigger` is provided), defaults to `"#"` |
| `delay`       | `number`                                     | Tooltip show delay in ms (only used with `trigger`), defaults to `200`  |
| `size`        | `"sm" \| "md" \| "lg" \| "xl"`         | Inline card maximum widths are 20, 24, 28 and 32rem respectively, defaulting to `"md"`; the floating card maximum width is the smaller of 20rem and the viewport width minus 1rem |
| `className`   | `string`                                     | Custom class name on the card root; `data-[floating=true]:max-w-*` can override the floating card's default maximum |
| `classNames`  | `{ root? / image? / body? / title? / description? }` | `root` controls the card root and is merged with `className`; the others customize the sub-parts |

## Keyboard Interactions

| Key | Description |
| --- | --- |
| `Tab` | Moving focus onto the trigger link shows the card |
| Focus out | Focus leaving the trigger link hides the card |

## Data Attributes

| Attribute | Description |
| --- | --- |
| `[data-floating]` | On the card — present only when rendered with a `trigger` (floating mode) |
