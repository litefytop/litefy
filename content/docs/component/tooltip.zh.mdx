## 用法

### 基础用法

在悬停或聚焦时显示的基础提示框。`Tooltip` 是接线容器：生成内容 id、锚点名称与延迟，经 context 提供给 `TooltipTrigger` / `TooltipContent` —— 不克隆任何元素，触发器永远是显式的 `TooltipTrigger`。

### 命令式控制

手动拼装零件并匹配 `id` 和 `anchorName`，在引导步骤等高级场景中使用命令式 API 控制弹出层。

## API 参考

### 高级组件

开箱即用的组合组件。

#### Tooltip

接线容器：生成内容 id 与锚点名称，连同 `delay` 经 context 提供给 `TooltipTrigger` / `TooltipContent`。自身不渲染任何元素，也不克隆 children。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | - | 一对 `TooltipTrigger` 与 `TooltipContent` |
| `delay` | `number` | `100` | 隐藏提示框前的延迟时间（毫秒） |

---

### 可组合组件

#### TooltipTrigger

带有内置悬停和焦点显隐逻辑的触发按钮。在 `Tooltip` 内经 context 继承接线；独立使用时显式传入 `popoverId` / `anchorName`。任何元素都可以改用零件自行拼装 —— `TooltipTrigger` 只是现成的按钮。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `popoverId` | `string` | - | 要显隐的内容元素 id；缺省回退到 `Tooltip` context |
| `anchorName` | `string` | - | 设置在触发元素上的 CSS 锚点名称，与内容的 `positionAnchor` 匹配；缺省回退到 `Tooltip` context |
| `delay` | `number` | `100` | 隐藏延迟时间（毫秒）；缺省回退到 `Tooltip` context |
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `style` | `React.CSSProperties` | - | 自定义内联样式，与锚点名称合并 |
| `...props` | `React.ComponentProps<"button">` | - | 支持所有原生 button 属性（除 `className`、`style` 外） |

#### TooltipContent

内联渲染的提示气泡，带 `popover="manual"`（top layer 不受祖先 `overflow` 裁剪）和锚点定位。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `id` | `string` | - | 供触发元素 `popoverId` 引用的元素 id；缺省回退到 `Tooltip` context |
| `anchorName` | `string` | - | 触发元素的锚点名称，应用为 `positionAnchor`；缺省回退到 `Tooltip` context |
| `delay` | `number` | `100` | 指针交互的隐藏延迟时间（毫秒）；缺省回退到 `Tooltip` context |
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `style` | `React.CSSProperties` | - | 自定义内联样式，与锚点样式合并 |
| `ref` | `React.Ref<HTMLDivElement>` | - | 指向弹出层元素的 ref，用于命令式 `showPopover()` 和 `hidePopover()` 调用 |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性（除 `className`、`style`、`id` 外） |

## 注意事项

- 基于原生 Popover API 和 CSS 锚点定位（`anchor-name` / `position-anchor` / `position-area`）构建，无手动定位回退。
- 默认锚定在触发元素上方，通过 `position-try-fallbacks: flip-block, flip-inline` 自动处理溢出翻转，无需方向属性。
- 指针悬停在提示内容上时保持显示；对已打开的弹出层调用 `showPopover()` 不会重复打开。
- `hidePopover()` 会立即关闭，不受隐藏延迟影响。
