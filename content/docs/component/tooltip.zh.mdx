## API 参考

### 高阶组件

开箱即用的组合组件。

#### Tooltip

接线容器：生成内容 id 与锚点名称，连同 `delay` 经 context 提供给 `TooltipTrigger` / `TooltipContent`。自身不渲染任何元素，也不克隆 children。

| Prop       | Type              | Description                            |
| ---------- | ----------------- | -------------------------------------- |
| `children` | `React.ReactNode` | 一对 `TooltipTrigger` 与 `TooltipContent` |
| `delay`    | `number`          | 隐藏提示框前的延迟时间（毫秒），默认 `100`               |

---

### 可组合组件

#### TooltipTrigger

带有内置悬停和焦点显隐逻辑的触发按钮。在 `Tooltip` 内经 context 继承接线；独立使用时显式传入 `popoverId` / `anchorName`。任何元素都可以改用零件自行拼装 —— `TooltipTrigger` 只是现成的按钮。

| Prop         | Type                             | Description                                                                           |
| ------------ | -------------------------------- | ------------------------------------------------------------------------------------- |
| `popoverId`  | `string`                         | 要显隐的内容元素 id；缺省回退到 `Tooltip` context                                                   |
| `anchorName` | `string`                         | 设置在触发元素上的锚点名称（渲染为 `data-anchor-name` 属性），与内容的 `anchorName` 匹配；缺省回退到 `Tooltip` context |
| `delay`      | `number`                         | 隐藏延迟时间（毫秒）；缺省回退到 `Tooltip` context，默认 `100`                                           |
| `className`  | `string`                         | 自定义 CSS 类                                                                             |
| `style`      | `React.CSSProperties`            | 自定义内联样式                                                                               |
| `...props`   | `React.ComponentProps<"button">` | 支持所有原生 button 属性（除 `className`、`style` 外）                                             |

#### TooltipContent

内联渲染的提示气泡，带 `popover="manual"`（top layer 不受祖先 `overflow` 裁剪），由内置 JS 定位引擎定位——机制见[浮动定位](/zh/docs/utils/use-floating-panel)。

| Prop         | Type                          | Description                                                            |
| ------------ | ----------------------------- | ---------------------------------------------------------------------- |
| `id`         | `string`                      | 供触发元素 `popoverId` 引用的元素 id；缺省回退到 `Tooltip` context                     |
| `anchorName` | `string`                      | 触发元素的锚点名称（其 `data-anchor-name` 属性），供内置 JS 定位匹配；缺省回退到 `Tooltip` context |
| `delay`      | `number`                      | 指针交互的隐藏延迟时间（毫秒）；缺省回退到 `Tooltip` context，默认 `100`                       |
| `className`  | `string`                      | 提示气泡自定义类名；默认 `w-max min-w-0`，最大宽度为 20rem 与视口宽度减 1rem 的较小值 |
| `style`      | `React.CSSProperties`         | 提示气泡自定义内联样式，可覆盖宽度；定位本身由内置 JS 引擎管理                                                |
| `ref`        | `React.Ref<HTMLDivElement>`   | 指向弹出层元素的 ref，用于命令式 `showPopover()` 和 `hidePopover()` 调用                |
| `...props`   | `React.ComponentProps<"div">` | 支持所有原生 div 属性（除 `className`、`style`、`id` 外）                            |

## 键盘交互

| Key | Description |
| --- | --- |
| `Tab` | 聚焦触发器时显示提示框 |
| Focus out | 焦点离开触发器时隐藏 |

没有 `Escape` 处理——焦点离开触发器或指针移开时提示框隐藏。

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-anchor-name]` | 位于触发按钮上——解析后的 `anchorName`；未设置时不存在 |
| `[data-float-anchor]` | 位于内容上——同一个锚点名称，定位引擎据此查找触发元素 |
| `[data-float-side]` | 位于内容上——取值 `"top"`，由骨架写成常量 |
| `[data-float-align]` | 位于内容上——取值 `"center"`，由骨架写成常量 |
| `[data-float-gap]` | 位于内容上——取值 `4`，由骨架写成常量 |

视口溢出时换边发生在定位计算内部，这些属性不会被改写。
