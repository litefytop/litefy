## 用法

### 基础用法

在悬停或聚焦时显示的基础提示框。组合组件接收单个触发元素作为 `children`，并通过 `content` 属性传入提示内容。

## API 参考

### 高级组件

开箱即用的组合组件。

#### Tooltip

克隆单个触发子元素并注入锚点关联与悬停/焦点处理器，通过 portal 渲染提示内容。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactElement` | - | 触发元素，会被克隆并注入 `popoverTarget`、`anchorName` 样式和悬停/焦点处理器 |
| `content` | `React.ReactNode` | - | 提示内容 |
| `delay` | `number` | `100` | 隐藏提示框前的延迟时间（毫秒） |

---

### 可组合组件

#### TooltipTrigger

带有内置悬停和焦点显隐逻辑的触发按钮。通过 DOM id 和锚点名称与内容组件解耦通信。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `popoverId` | `string` | - | 要显隐的内容元素 id |
| `anchorName` | `string` | - | 设置在触发元素上的 CSS 锚点名称，与内容的 `positionAnchor` 匹配 |
| `delay` | `number` | `100` | 隐藏延迟时间（毫秒） |
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `style` | `React.CSSProperties` | - | 自定义内联样式，与锚点名称合并 |
| `...props` | `React.ComponentProps<"button">` | - | 支持所有原生 button 属性（除 `className`、`style` 外） |

#### TooltipContent

通过 portal 渲染的提示气泡，带 `popover="manual"` 和锚点定位。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `id` | `string` | - | 供触发元素 `popoverId` 引用的元素 id |
| `anchorName` | `string` | - | 触发元素的锚点名称，应用为 `positionAnchor` |
| `delay` | `number` | `100` | 指针交互的隐藏延迟时间（毫秒） |
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `style` | `React.CSSProperties` | - | 自定义内联样式，与锚点样式合并 |
| `ref` | `React.Ref<HTMLDivElement>` | - | 指向弹出层元素的 ref，用于命令式 `showPopover()` 和 `hidePopover()` 调用 |
| `...props` | `React.ComponentProps<"div">` | - | 支持所有原生 div 属性（除 `className`、`style`、`id` 外） |

## 命令式 API

在引导步骤或全局事件联动等高级场景中，手动拼装零件并使用命令式方式控制弹出层：

```tsx
import { useRef } from 'react';
import { TooltipContent, TooltipTrigger } from "@/ui";

function MyComponent() {
  const contentRef = useRef<HTMLDivElement>(null);

  return (
    <>
      <TooltipTrigger popoverId="my-tip" anchorName="--my-tip">
        悬停触发
      </TooltipTrigger>
      <TooltipContent id="my-tip" anchorName="--my-tip" ref={contentRef}>
        提示内容
      </TooltipContent>
      <button type="button" onClick={() => contentRef.current?.showPopover()}>
        手动打开
      </button>
      <button type="button" onClick={() => contentRef.current?.hidePopover()}>
        手动关闭
      </button>
    </>
  );
}
```

**注意事项：**

- 基于原生 Popover API 和 CSS 锚点定位（`anchor-name` / `position-anchor` / `position-area`）构建，无手动定位回退。
- 默认锚定在触发元素上方，通过 `position-try-fallbacks: flip-block, flip-inline` 自动处理溢出翻转，无需方向属性。
- 指针悬停在提示内容上时保持显示；对已打开的弹出层调用 `showPopover()` 不会重复打开。
- `hidePopover()` 会立即关闭，不受隐藏延迟影响。
