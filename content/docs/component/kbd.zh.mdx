## API 参考

### Kbd

静态键盘按键视觉元素——非交互控件，无 hover / active 状态。边框使用默认边框 token，层次感来自内置的 `shadow-subtle`。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `...props` | `React.ComponentProps<"kbd">` | - | 支持所有原生 kbd 属性 |
