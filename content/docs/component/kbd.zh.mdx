## API 参考

### Kbd

键盘按键视觉元素。圆角跟随 `--radius`，边框与阴影颜色来自 `--color-neutral` 与 `--color-ring` 主题 token。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `ClassNameValue` | - | 自定义 CSS 类 |
| `...props` | `React.ComponentProps<"kbd">` | - | 支持所有原生 kbd 属性 |
