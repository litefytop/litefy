## Usage

A data-driven segmented control for single-select, with controlled and uncontrolled modes.

<ComponentPreview
  name="segment-basic"
/>

### Variants

The `variant` prop switches the overall look — the default `bordered` is an outlined shell (unchecked items are text buttons and checked items become theme-colored blocks, with the same appearance and motion as the panel); `borderless` has no shell or border and fills the checked item with a theme-colored block; `well` is a recessed container where the checked item rises as a theme-colored block.

<ComponentPreview
  name="segment-variants"
/>

### Disabled

Group-level `disabled` and each option's `disabled` are configured independently; the button is natively disabled when either is true. The standalone disabled classes use `text-disabled-fg` and `cursor-not-allowed`; the `well` variant also uses `bg-disabled`.

## API Reference

### High-level Components

Ready-to-use composite components.

#### SegmentGroup

| Prop             | Type                          | Description                                                                                                                                                                                     |
| ---------------- | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `options`        | `SegmentOptionConfig[]`       | The options data array                                                                                                                                                                          |
| `value`          | `string`                      | Controlled selected value                                                                                                                                                                       |
| `defaultValue`   | `string`                      | Default selected value in uncontrolled mode                                                                                                                                                     |
| `onValueChange`  | `(value: string) => void`     | Called when the selected value changes                                                                                                                                                          |
| `variant`        | `"borderless" \| "bordered" \| "well"` | Checked look, defaulting to `bordered`: unchecked items are text buttons and checked items become theme-colored blocks inside an outlined container; `borderless` has no shell or border, fills the checked item with a theme-colored block, and has no hover; `well` is a recessed container where the checked item rises as a theme-colored block |
| `disabled`       | `boolean`                     | Disables all options, defaults to `false`                                                                                                                                                       |
| `className`      | `string`                      | Custom class name, applied to the container                                                                                                                                                     |
| `itemClassName`  | `string`                      | Custom class name, applied to each segment button                                                                                                                                               |

Keyboard: a radiogroup with roving tabindex — the arrow keys move to and select the next / previous enabled option, `Home` / `End` jump to the ends, `Enter` / `Space` activate.

### SegmentOptionConfig

| Field       | Type              | Description                                              |
| ----------- | ----------------- | -------------------------------------------------------- |
| `label`     | `string`          | Option display text                                      |
| `value`     | `string`          | Unique identifying value                                 |
| `disabled`  | `boolean`         | Disables the option, defaults to `false`                 |
| `className` | `string`          | Custom class name; takes precedence over `itemClassName` |

### Composable Components

#### Segment

A single segment part with radio semantics; it holds no internal state — `checked` must be provided from outside.

| Prop        | Type                             | Description                                                                     |
| ----------- | -------------------------------- | ------------------------------------------------------------------------------- |
| `children`  | `React.ReactNode`                | The segment button's content                                                    |
| `checked`   | `boolean`                        | Checked state, drives `aria-checked`, defaults to `false`                       |
| `className` | `string`                         | Custom class name                                                               |
| `...props`  | `React.ComponentProps<"button">` | Supports all native button props (except `type`), such as `onClick`, `disabled` |

## Keyboard Interactions

| Key | Description |
| --- | --- |
| `ArrowRight` / `ArrowDown` | Focuses and checks the next enabled segment, wrapping at the end |
| `ArrowLeft` / `ArrowUp` | Focuses and checks the previous enabled segment, wrapping at the start |
| `Home` | Jumps to the first enabled segment |
| `End` | Jumps to the last enabled segment |
| `Enter` / `Space` | Activates the focused segment |

Uses roving tabindex: only the checked segment is reachable by `Tab`.

## Data Attributes

The skeleton emits no `data-*` on this component. State is exposed through each button's `aria-checked` and `tabIndex`.
