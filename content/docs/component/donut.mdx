## API Reference

### Donut

| Prop             | Type                        | Description                                                                               |
| :--------------- | :-------------------------- | :---------------------------------------------------------------------------------------- |
| `data`           | `DonutDatum[]`              | Slice data: `{ label, value, color? }`                                                    |
| `variant`        | `"pie" \| "donut"`          | `pie` closes the center hole and moves the readout below the chart, defaults to `"donut"` |
| `gap`            | `number`                    | Angular gap between slices (degrees), defaults to `2`                                     |
| `valueFormatter` | `(value: number) => string` | Number formatting for the readout, defaults to `toLocaleString`                           |
| `showLegend`     | `boolean`                   | Whether to render the clickable legend above the chart, defaults to `true`                |
| `className`      | `string`                    | Class names appended to the root element                                                  |
| `classNames`     | `DonutClassNames`           | Slot overrides: `root` / `svg` / `segment` / `legend`                                     |
| `styles`         | `DonutStyles`               | Inline styles matching the `classNames` slots                                             |

## Keyboard Interactions

| Key | Description |
| --- | --- |
| `Enter` / `Space` | Pressed on a legend item — toggles the visibility of the matching segment |

The center readout follows pointer hover on the segments only — hover highlighting has no keyboard equivalent.

## Data Attributes

| Attribute | Description |
| --- | --- |
| `[data-dimmed]` | On a segment path — present while a different segment is hovered |
