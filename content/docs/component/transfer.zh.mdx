Transfer 不是发布组件 —— 它是 `Checkbox` 加普通标记的组合。从示例（View Code）复制完整实现到项目中，自由调整。

> 前置依赖：先安装 `Checkbox`（`npx shadcn@latest add checkbox` 或 `litefy@latest add checkbox`）。

## 用法

### 基础用法

完全受控的 `value`：数组保存当前位于目标面板的条目值。禁用条目会留在来源面板且无法移动。`renderItem` 非必需 —— 普通条目直接渲染 `label` 文本。

实现要点：

- `value` / `defaultValue` / `onChange` 遵循受控/非受控惯例：`value` 保存当前位于目标面板的条目值，`onChange` 在任一方向移动后触发，顺序保持 `dataSource` 稳定序。
- 每个面板独立维护勾选状态（`Set`）。移动按钮应用勾选项并清空该面板的勾选状态；面板没有勾选项时对应方向按钮禁用。
- 行用 `Checkbox` 复合组件渲染 —— 原生 `input` 免费获得键盘访问（Tab + Space），`disabled` 条目无法勾选或移动。
- `titles` / `renderItem` / `classNames`（root / panel / header / body / item / actions）用于自定义。

## API 参考

### Transfer

| 属性           | 类型                                            | 默认值              | 描述                                          |
| :------------- | :---------------------------------------------- | :------------------ | :-------------------------------------------- |
| `dataSource`   | `TransferItemConfig[]`                          | -                   | 所有可用条目                                  |
| `value`        | `string[]`                                      | -                   | 受控值 —— 当前位于目标面板的条目值            |
| `defaultValue` | `string[]`                                      | `[]`                | 默认目标值（非受控）                          |
| `onChange`     | `(value: string[]) => void`                     | -                   | 任一方向移动条目后触发                        |
| `titles`       | `[React.ReactNode, React.ReactNode]`            | `Source` / `Target` | 来源与目标面板的标题                          |
| `renderItem`   | `(item: TransferItemConfig) => React.ReactNode` | -                   | 自定义条目渲染，两个面板同时生效              |
| `className`    | `string`                                        | -                   | 自定义类名，应用于根元素                      |
| `classNames`   | `root` / `panel` / `header` / `body` / `item` / `actions` | -         | 按插槽自定义类名                              |

### TransferItemConfig

| 字段       | 类型              | 默认值  | 描述                                                    |
| :--------- | :---------------- | :------ | :------------------------------------------------------ |
| `label`    | `React.ReactNode` | -       | 条目显示内容                                            |
| `value`    | `string`          | -       | 唯一标识值                                              |
| `disabled` | `boolean`         | `false` | 禁用条目 —— 留在来源面板，无法勾选或移动                |

### 结构

- 两个边框面板，各含标题栏（`title` + `count` 计数如 `1/3`）和可滚动内容区（`max-h-64 overflow-auto`）
- 中间操作列包含两个移动按钮（`ArrowRight` / `ArrowLeft`），对应面板没有勾选项时禁用
- 行是全宽可点击的 `Checkbox` 复合组件；空面板渲染弱化的 `No data` 文本
