## API Reference

### High-level Components

Ready-to-use composite components.

#### Input

The input component with slot and validation support.

| Prop         | Type                                              | Default  | Description                                               |
| ------------ | ------------------------------------------------- | -------- | --------------------------------------------------------- |
| `type`       | `'text' \| 'email' \| 'url' \| 'tel' \| 'search'` | `'text'` | Input type                                                |
| `leading`    | `ReactNode`                                       | -        | Leading slot content (e.g., icons)                        |
| `trailing`   | `ReactNode`                                       | -        | Trailing slot content (e.g., buttons, icons)              |
| `invalid`    | `boolean`                                         | `false`  | Whether the input is in an invalid state                  |
| `classNames` | `{ root?: ClassNameValue; leading?: ClassNameValue; trailing?: ClassNameValue; input?: ClassNameValue }` | - | Custom classes for the internal elements |
| `styles` | `{ root?: React.CSSProperties; leading?: React.CSSProperties; trailing?: React.CSSProperties; input?: React.CSSProperties }` | - | Inline styles for the internal elements |
| `...props`   | `React.ComponentProps<"input">`                   | -        | Supports all native input props (except `type`, `className`) |

---

### Composable Components

#### InputGroup

Outer container with the complete input styles built in: size (`h-9 w-sm`), rounded border, background, `focus-within` focus ring, and the `data-invalid` invalid state styles.

| Prop        | Type                          | Default | Description                                                   |
| ----------- | ----------------------------- | ------- | ------------------------------------------------------------- |
| `className` | `ClassNameValue`              | -       | Custom class name                                             |
| `...props`  | `React.ComponentProps<"div">` | -       | Supports all native div props (including `data-*` attributes) |

#### InputLeading

Leading slot container rendered as a `span`, with built-in `shrink-0`, icon sizing and padding.

| Prop        | Type                           | Default | Description                                                    |
| ----------- | ------------------------------ | ------- | -------------------------------------------------------------- |
| `className` | `ClassNameValue`               | -       | Custom class name                                              |
| `...props`  | `React.ComponentProps<"span">` | -       | Supports all native span props (including `data-*` attributes) |

#### InputTrailing

Trailing slot container rendered as a `span`, with built-in `shrink-0`, icon sizing and padding.

| Prop        | Type                           | Default | Description                                                    |
| ----------- | ------------------------------ | ------- | -------------------------------------------------------------- |
| `className` | `ClassNameValue`               | -       | Custom class name                                              |
| `...props`  | `React.ComponentProps<"span">` | -       | Supports all native span props (including `data-*` attributes) |
