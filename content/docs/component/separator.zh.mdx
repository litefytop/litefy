## API 参考

### 高阶组件

开箱即用的组合组件。

#### Separator

渲染单条分割线；传入 `children` 时渲染"线 - 文本 - 线"结构。

| 属性            | 类型                                      | 描述                      |
| ------------- | --------------------------------------- | ----------------------- |
| `children`    | `React.ReactNode`                       | 渲染在两条线之间的文本标签           |
| `orientation` | `'horizontal' \| 'vertical'`            | 分隔符方向，默认 `'horizontal'` |
| `className`   | `string`                                | 自定义类名，应用于分割线或包装容器       |
| `classNames`  | `{ line?, text?: string }`              | 定制分割线和文本标签的自定义类名        |
| `styles`      | `{ line?, text?: React.CSSProperties }` | 定制分割线和文本标签的内联样式         |

---

### 可组合组件

#### SeparatorLine

自带 `data-orientation` 尺寸的分割线零件。垂直线随 flex 行高自动拉伸，也可用固定高度钉住。

| 属性            | 类型                            | 描述                      |
| ------------- | ----------------------------- | ----------------------- |
| `orientation` | `'horizontal' \| 'vertical'`  | 分割线方向，默认 `'horizontal'` |
| `className`   | `string`                      | 自定义 CSS 类               |
| `...props`    | `React.ComponentProps<"div">` | 支持所有原生 div 属性，如 `role`  |

#### SeparatorText

文本标签零件，为嵌在两条线之间而设计。

| 属性          | 类型                             | 描述                          |
| ----------- | ------------------------------ | --------------------------- |
| `className` | `string`                       | 自定义 CSS 类                   |
| `...props`  | `React.ComponentProps<"span">` | 支持所有原生 span 属性，如 `children` |

## 键盘交互

本组件不接管任何按键。

## 数据属性

| Attribute | Description |
| --- | --- |
| `[data-orientation]` | 位于分割线与组合根节点上——取 `"horizontal"` 或 `"vertical"`，与 `orientation` 属性一致 |
