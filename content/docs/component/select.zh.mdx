## API 参考

### 高阶组件

#### Select

基于原生 popover API 与 CSS 锚点定位的选择器：触发按钮显示选中项的文本，listbox 面板跟随主题配色。键盘：`ArrowDown` / `ArrowUp` 打开面板并移动高亮（首尾环绕），`Home` / `End` 跳到第一个 / 最后一个选项，`Enter` / `Space` 选中高亮项，`Escape` 不选择直接关闭，`Tab` 关闭。

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `(SelectOption \| SelectOptionGroup)[]` | - | 要展示的选项或选项分组数组 |
| `value` | `string` | - | 受控的选中值 |
| `defaultValue` | `string` | `""` | 非受控模式的默认选中值 |
| `onValueChange` | `(value: string) => void` | - | 选中选项时触发 |
| `placeholder` | `string` | - | 未选中任何选项时显示的占位文本 |
| `required` | `boolean` | - | 在触发器上设置 `aria-required` |
| `name` | `string` | - | 渲染携带该 name 的隐藏 input，使值参与原生表单提交 |
| `disabled` | `boolean` | - | 禁用触发器 |
| `className` | `ClassNameValue` | - | 自定义类名，作用于触发器 |
| `style` | `React.CSSProperties` | - | 内联样式，作用于触发器 |
| `classNames` | `{ panel?; label?; option? }` —— 值均为 `ClassNameValue` | - | 面板、分组标签与选项的自定义类名 |
| `styles` | `{ panel? }` —— 值均为 `React.CSSProperties` | - | 面板的内联样式 |
| `...props` | `React.ComponentProps<"button">` | - | 其余原生 button 属性透传到触发器上，如 `id`、`aria-describedby` |

行为说明：

- 选中选项后面板关闭、值更新、焦点回到触发器。
- 面板通过 top layer 逃逸祖先的 `overflow` 裁剪，靠近视口边缘时通过 `positionTryFallbacks` 自动翻转，并以 `min-width: anchor-size(width)` 匹配触发器宽度。
- 面板打开时，高亮从当前选中的选项开始。

### SelectOption

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | - | 选项的显示文本 |
| `value` | `string` | - | 选项关联的值 |

### SelectOptionGroup

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `group` | `string` | - | 分组标签文本 |
| `options` | `SelectOption[]` | - | 分组内的选项数组 |
