## Usage

Renders chips, collapses the overflow, and hands the hidden items to `renderMore(hidden)`.

<ComponentPreview
  name="chip-group-basic"

### Variants

Variants are pure skin states selected by skin-layer JavaScript, not part of the skeleton API: `ChipGroup` reads the group-level `data-variant` (`surface` / `primary` / `outline` / `success` / `warning` / `danger` / `info`, defaulting to `surface`) to choose one color treatment for all chips. When composing on any element directly, merge the skin's `chipBase` (layout and typography) with `chipVariants.<variant>` (colors) through `cn`, as in `cn(chipBase, chipVariants.outline)`; the default `chipClasses` string is equivalent to `cn(chipBase, chipVariants.surface)`.

## API Reference

### ChipGroup

| Prop               | Type                                          | Description                                                                                                                                                                                               |
| :----------------- | :-------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `items`            | `ChipItem[]`                                  | All chip items                                                                                                                                                                                            |
| `onOverflowChange` | `(hidden: ChipItem[]) => void`                | Fired when the hidden set changes, carrying the hidden items                                                                                                                                              |
| `renderMore`       | `(hidden: ChipItem[]) => React.ReactNode`     | Renders a custom trigger inline; `hidden` is the collapsed items                                                                                                                                          |
| `className`        | `string`                                      | Custom class names, applied to the outer container (set `max-width` here)                                                                                                                                 |
| `style`            | `React.CSSProperties`                         | Inline styles on the outer container                                                                                                                                                                      |
| `classNames`       | `row` / `chip` / `more` / `measure`           | Custom class names per slot (`row` chip row / `chip` one chip / `more` overflow trigger / `measure` hidden measure row); `chip` lands on both the visible row's chips and the off-screen measurement copy |

### ChipItem

| Field   | Type              | Description                      |
| :------ | :---------------- | :------------------------------- |
| `value` | `string`          | Unique identity                  |
| `label` | `React.ReactNode` | Chip text                        |

## Keyboard Interactions

The skeleton handles no keys. Each chip is a non-focusable `<span>`, so only the content you pass to `renderMore` joins the tab order.

## Data Attributes

The skeleton emits no `data-*` on this component. The off-screen measurement row carries `aria-hidden`. The skin layer reads the group-level `data-variant` as a JavaScript lookup key; it does not gate styles on data attributes.
