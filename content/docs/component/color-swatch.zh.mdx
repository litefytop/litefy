## 用法

单选色样组，`color` 传 CSS 颜色值，当前项带同色外环，悬停经 `title` 显示色名。

### 禁用

组级 `disabled` 与每个色样的 `disabled` 独立配置，最终按“任一为真”原生禁用该按钮；禁用色样使用 `bg-disabled`、`--color-disabled` 与 `cursor-not-allowed`，方向键跳过。

## API 参考

### ColorSwatch

| 属性              | 类型                                                        | 描述                                         |
| --------------- | --------------------------------------------------------- | ------------------------------------------ |
| `options`       | `{ value; label; color; disabled?; attrs? }[]` **必填**     | 色样配置：值、无障碍名（同源作悬停 `title`）、颜色字面值与逐项数据属性                   |
| `value`         | `string`                                                  | 当前选中值（受控）                                  |
| `defaultValue`  | `string`                                                  | 初始选中值（非受控）                                 |
| `onValueChange` | `(value: string) => void`                                 | 选中变化回调；再点已选项不重复触发                          |
| `disabled`      | `boolean`                                                 | 禁用整组                                       |
| `className`     | `string`                                                  | 容器自定义类名                                    |

`options.attrs` 是逐项 data-* 属性通道——锚定某个选项到固定的 ramp 档（如 `data-brand="default"`），让它的预览不随当前选择漂移；其中 `title` 可按项覆盖默认悬停名。

## 键盘交互

| Key | Description |
| --- | --- |
| `ArrowRight` / `ArrowDown` | 焦点与选中前进一项，循环 |
| `ArrowLeft` / `ArrowUp` | 焦点与选中后退一项，循环 |
| `Home` / `End` | 跳到首 / 末个可用项 |

## 数据属性

选中态由色样上的 `aria-checked="true"` 表达（驱动同色外环），禁用为原生 `disabled` 属性——骨架不发射 `data-*`。
