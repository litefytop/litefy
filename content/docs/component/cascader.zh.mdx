## 用法

传递树形数据给 `tree`，点击某一级打开对应面板，点击叶子节点完成选择。

需要 Chrome 125+ 以支持 CSS 锚点定位。

## API 参考

### 高阶组件

开箱即用的成品组件。

#### Cascader

由树形数据驱动的多级级联选择器；面板默认宽度 `18rem`（经 `styles.panel`），内部管理的锚点属性始终优先于 `styles`。

| 属性         | 类型                                                                     | 默认值                   | 描述                                                                                           |
| :----------- | :----------------------------------------------------------------------- | :----------------------- | :--------------------------------------------------------------------------------------------- |
| `tree`       | `CascaderNode[]`                                                         | -                        | 驱动级联选择的树形数据                                                                         |
| `placeholder` | `string`                                                                | `"Select your location"` | 未选择任何项时触发器显示的占位文本                                                             |
| `className`  | `ClassNameValue`                                                         | -                        | 根容器的自定义类名                                                                             |
| `classNames` | `{ trigger?: ClassNameValue; panel?: ClassNameValue }`                   | -                        | 触发器与面板的自定义类名                                                                       |
| `styles`     | `{ trigger?: React.CSSProperties; panel?: React.CSSProperties }`         | -                        | 触发器与面板的内联样式                                                                         |
| `...props`   | `React.ComponentProps<"div">`                                            | -                        | 支持全部 div 原生属性（除 `children`、`className` 外），展开到根容器                            |

#### CascaderNode

级联选择器树节点的数据结构。

| 字段     | 类型              | 默认值 | 描述                      |
| :-------- | :---------------- | :----- | :----------------------- |
| `value`   | `string`          | -      | 节点的唯一值              |
| `label`   | `string`          | -      | 节点的显示文本            |
| `children` | `CascaderNode[]` | -      | 下一级的子节点数组        |

---

### 可组合组件

#### CascaderTrigger

面包屑样式的触发器按钮；组合组件会为每一级渲染一个。

| 属性        | 类型                              | 默认值 | 描述                    |
| :--------- | :-------------------------------- | :----- | :----------------------- |
| `className` | `ClassNameValue`                 | -      | 自定义 CSS 类            |
| `...props` | `React.ComponentProps<"button">`  | -      | 支持全部 button 原生属性 |
