## 用法

传递树形数据给 `tree`，点击某一级打开对应面板，点击叶子节点完成选择。

<ComponentPreview
  name="cascader-basic"

### 禁用

`disabled` 原生禁用所有面包屑触发器，根元素标记 `aria-disabled`，选择、展开与键盘处理停止；外观使用 `bg-disabled`、`text-disabled-fg` 与 `cursor-not-allowed`。

## API 参考

### 高阶组件

开箱即用的成品组件。

#### Cascader

由树形数据驱动的多级级联选择器；面板宽度由所加载的方案提供，可用 `classNames.menu` / `styles.menu` 覆盖；内部管理的定位属性（锚点 + 方位）始终优先于 `styles`。

| 属性            | 类型                                                                                          | 描述                                                                                             |
| :------------ | :------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------- |
| `tree`        | `CascaderNode[]`                                                                            | 驱动级联选择的树形数据                                                                                    |
| `disabled`    | `boolean`                                                                                   | 组级禁用：所有触发器原生禁用、根容器标记 `aria-disabled`，面板不可展开，默认 `false`                                        |
| `placeholder` | `string`                                                                                    | 未选择任何项时触发器显示的占位文本，默认 `"Select your location"`                                                  |
| `width`       | `string \| number`                                                                          | 可选的显式最大宽度（CSS 值，数字按 px）；省略时字段根节点默认最大宽度 20rem，面板与字段等宽                                  |
| `className`   | `string`                                                                                    | 根容器自定义类名，与 `classNames.root` 合并；默认 `w-full min-w-0 max-w-[20rem]`                                               |
| `style`       | `React.CSSProperties`                                                                       | 根容器内联样式，与 `styles.root` 合并                                                                                          |
| `classNames`  | `{ root?; breadcrumb?; trigger?; chevron?; menu?; option?; list?: ListClassNames }`         | 各部分自定义类名：根容器、面包屑行、各级触发器、箭头图标、级别面板、选项行，以及面板内的 `List`                                            |
| `styles`      | `{ root?: React.CSSProperties; trigger?: React.CSSProperties; menu?: React.CSSProperties }` | 根容器、触发器与级别面板内联样式；面板默认最大宽度 20rem，并受视口宽度减 1rem 限制                                      |
| `...props`    | `React.ComponentProps<"div">`                                                               | 支持全部 div 原生属性（除 `children`、`className` 外），展开到根容器                                               |

#### CascaderNode

级联选择器树节点的数据结构。

| 字段         | 类型                | 描述                       |
| :--------- | :---------------- | :----------------------- |
| `value`    | `string`          | 节点的唯一值                   |
| `label`    | `string`          | 节点的显示文本                  |
| `children` | `CascaderNode[]`  | 下一级的子节点数组                |

---

### 可组合组件

#### CascaderTrigger

面包屑样式的触发器按钮；组合组件会为每一级渲染一个。

| 属性          | 类型                                | 描述                       |
| :---------- | :-------------------------------- | :----------------------- |
| `className` | `string`                          | 自定义 CSS 类                |
| `...props`  | `React.ComponentProps<"button">`  | 支持全部 button 原生属性         |

## 键盘交互

| Key | Description |
| --- | --- |
| `ArrowDown` / `ArrowUp` | 在打开的面板中移动选项高亮 |
| `Enter` / `Space` | 选中高亮项；位于面包屑触发器上时为原生按钮激活 |
| `Escape` | 关闭当前打开的面板 |

## 数据属性

| Attribute | Description |
| --- | --- |
| `[aria-expanded]` | 位于触发器按钮上——该层面板打开期间为 `true` |
| `[aria-current="step"]` | 位于显示已选叶子节点的触发器按钮上 |
| `[data-disabled]` | 位于根元素上——整个级联选择器禁用时存在 |
