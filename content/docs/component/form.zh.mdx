## 用法

### 基础用法

用 `Form` + [FormItem](/zh/docs/component/form-item) + `Form.Submit` 组合表单。不带包装的分组控件（复选/单选组）原生提交即可——给它们 `name` 属性，值会自动进入提交数据。

  name="form-basic"
/>

### 校验

包装字段通过 `FormItem` 的 `validate` / `validateTrigger` 做校验。校验在 `onChange` 或 `onBlur` 时执行，返回的字符串渲染为输入框下方的错误信息。

  name="form-validation"
/>

### 命令式控制

通过 `ref` 获取表单实例，从外部调用 `setValues`、`reset` 和 `submit`。

### 表单项

`FormItem` 组件用法已拆分为独立页面：[Form Item 表单项](/zh/docs/component/form-item)。

### 零件用法（useFieldValidity）

不使用任何包装组件：自持一个 `useFieldValidity` 状态（内置于 Form 模块），在自己的处理器里设置/清除错误，把 `aria-invalid` 传给控件，并条件渲染错误信息。所有输入类控件都内置危险样式（`border-danger` / `text-danger` 与危险焦点环），仅凭 `aria-invalid` 属性即可生效。

<ComponentPreview 
  name="form-parts"
/>

### 控件校验样式

所有字段控件（Input、Textarea、Select、Password、NumberField、Picker、InputOtp）直接由 `aria-invalid` 属性驱动样式 —— 无需额外属性：

`aria-invalid:border-danger aria-invalid:text-danger`，聚焦时叠加 `aria-invalid:focus-visible:outline-1 aria-invalid:focus-visible:outline-danger aria-invalid:focus-visible:ring-3 aria-invalid:focus-visible:ring-danger/50`。组合包装器（InputGroup、PasswordGroup）通过自身的 `data-invalid` 状态应用同样的效果。

## API 参考

### 高阶组件

开箱即用的成品组件。

#### Form

构建在原生 `<form>` 元素之上的根表单组件。

| 属性        | 类型                                       | 默认值 | 描述                                                                                       |
| ----------- | ------------------------------------------ | ------ | ------------------------------------------------------------------------------------------ |
| `onSubmit`  | `(values: FormValues) => Promise<boolean>` | -      | 异步提交处理器。接收已预处理的对象，多值字段为数组。返回 `true` 表示成功并触发 `autoReset` |
| `autoReset` | `boolean`                                  | `true` | 当 `onSubmit` 解析为 `true` 时自动重置表单                                                 |
| `onReset`   | `() => void`                               | -      | 表单重置时触发 —— 包括 `autoReset` 在提交成功后的重置，以及通过 `ref.reset()` 触发的重置    |
| `ref`       | `React.Ref<FormRef>`                       | -      | 暴露 `setValues`、`reset`、`submit` 的命令式句柄                                           |
| `children`  | `React.ReactNode`                          | -      | 表单内容，通常为 `FormItem` 与 `Form.Submit`                            |
| `...props`  | `React.ComponentProps<"form">`             | -      | 支持全部 form 原生属性（除 `onSubmit`、`ref` 外），展开到底层 form 元素                     |

#### FormRef

通过 `ref` 属性获取的命令式句柄，其中 `FormValue = string | number | string[] | number[] | null`。

| 方法        | 类型                                          | 描述                                                             |
| ----------- | --------------------------------------------- | ------------------------------------------------------------------ |
| `setValues` | `(values: Record<string, FormValue>) => void` | 更新一个或多个字段的值，并在每个被修改的输入上派发 `change` 事件 |
| `reset`     | `() => void`                                  | 重置表单并清空所有已注册的输入                                     |
| `submit`    | `() => void`                                  | 触发一次程序化表单提交                                             |

#### Form.Submit

自动反映表单提交状态的提交按钮。在表单提交过程中会被禁用，并可渲染自定义加载图标。

| 属性          | 类型              | 默认值 | 描述                                               |
| ------------- | ----------------- | ------ | -------------------------------------------------- |
| `loadingIcon` | `React.ReactNode` | -      | 表单提交时显示的自定义图标，默认为旋转的 `Loader2` |
| `className`   | `string`          | -      | 自定义 CSS 类，与内置按钮样式合并                  |
| `children`    | `React.ReactNode` | -      | 按钮文案                                           |

支持其余所有原生 `<button>` 属性；`type` 被强制为 `submit`。

### 可组合组件

#### FormLabel

字段标签，渲染为 `<label>`。

| 属性        | 类型             | 默认值 | 描述          |
| ----------- | ---------------- | ------ | ------------- |
| `className` | `ClassNameValue` | -      | 自定义 CSS 类 |

支持所有原生 `<label>` 属性。

#### FormHint

提示文字，渲染为 `<small>`。正常时显示描述文字，字段无效时显示错误信息（带 `role="alert"`）。

| 属性        | 类型             | 默认值 | 描述          |
| ----------- | ---------------- | ------ | ------------- |
| `className` | `ClassNameValue` | -      | 自定义 CSS 类 |

支持所有原生 `<small>` 属性。
