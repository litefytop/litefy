## 用法

用 `Form` + `FormSubmit` 组合表单，字段控件以 `name` / `label` / `validate` 直接接入，校验在提交时统一门禁。

## API 参考

### 高阶组件

开箱即用的成品组件。

#### Form

构建在原生 `<form>` 元素之上的根表单组件。

| 属性          | 类型                                         | 描述                                                                                         |
| ----------- | ------------------------------------------ | ------------------------------------------------------------------------------------------ |
| `size`       | `"sm" \| "md" \| "lg" \| "xl"`                 | 表单最大宽度依次为 20、24、28、32rem，默认 `"lg"`                                                       |
| `className`  | `string`                                         | 根表单自定义类名；默认 `w-full min-w-0`                                                                   |
| `style`      | `React.CSSProperties`                             | 根表单内联样式                                                                                             |
| `onSubmit`  | `(values: FormValues) => Promise<boolean>` | 异步提交处理器。接收已预处理的对象，多值字段为数组。返回 `true` 表示成功并触发 `autoReset`；返回 `false` 或抛错时保留当前输入值             |
| `autoReset` | `boolean`                                  | 当 `onSubmit` 解析为 `true` 时自动重置表单，默认 `true`                                                  |
| `onReset`   | `() => void`                               | 表单重置时触发 —— 包括 `autoReset` 在提交成功后的重置，以及通过 `ref.reset()` 触发的重置                               |
| `ref`       | `React.Ref<FormRef>`                       | 暴露 `setValues`、`reset`、`submit` 的命令式句柄                                                     |
| `children`  | `React.ReactNode`                          | 表单内容，通常为带 `name` 的字段控件与 `FormSubmit`                                                       |
| `...props`  | `React.ComponentProps<"form">`             | 支持全部 form 原生属性（除 `action`、`onSubmit`、`ref` 外），展开到底层 form 元素                                |

#### FormRef

通过 `ref` 属性获取的命令式句柄，其中 `FormValue = string | number | string[] | number[] | null`。

| 方法        | 类型                                          | 描述                                                             |
| ----------- | --------------------------------------------- | ------------------------------------------------------------------ |
| `setValues` | `(values: Record<string, FormValue>) => void` | 更新一个或多个字段，并按 React 监听的方式逐个通知被修改的控件 —— 文本框与下拉派发 `input` + `change`，勾选/单选派发一次 `click` —— 使用者的 `onChange` 与字段校验都会看到新值。禁用控件与未变化的字段不动 |
| `reset`     | `() => void`                                  | 重置表单并清空所有已注册的输入                                     |
| `submit`    | `() => void`                                  | 触发一次程序化表单提交                                             |

### 可组合组件

#### FormSubmit

自动反映表单提交状态的提交按钮。提交中或显式 `disabled` 时使用 Button 禁用变体，呈现 `bg-disabled`、`text-disabled-fg` 与 `cursor-not-allowed`；提交中默认原生禁用按钮并标记 `aria-busy`。

| 属性            | 类型                | 描述                                                 |
| ------------- | ----------------- | -------------------------------------------------- |
| `loadingIcon` | `React.ReactNode` | 表单提交时显示的自定义图标，默认为旋转的 `Loader2`                     |
| `className`   | `string`          | 自定义 CSS 类，作用于提交按钮                                  |
| `children`    | `React.ReactNode` | 按钮文案                                               |

支持其余所有原生 `<button>` 属性；`type` 被强制为 `submit`。内部渲染一个 [Button](/zh/docs/component/button)——从方案包引入时，该方案皮肤会把自身的按钮外观通过 `className` 复合上去（无头版本不发出任何外观钩子）。

## 键盘交互

骨架在 `Form` 与 `FormSubmit` 里都不挂按键处理器——下列行为是原生 `<form>` 与 `<button>` 自带的。

| Key | Description |
| --- | --- |
| `Enter` | 原生 `<form>` 的隐式提交，走的 `onSubmit` 与点击提交是同一条 |
| `Enter` / `Space` | 原生激活当前聚焦的按钮，`FormSubmit` 也不例外 |
| 其余按键 | 归当前聚焦的控件，见该控件的文档 |

## 数据属性

`<form>` 元素本身不带 `data-*`。

| Attribute | Description |
| --- | --- |
| `[data-pure-icon]` | 位于 `FormSubmit` 上——其子内容只有一个图标、不含文字时存在（来自 [Button](/zh/docs/component/button)） |
