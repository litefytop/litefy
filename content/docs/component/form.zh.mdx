## 用法

### 基础用法

使用 `Form`、`Form.Field`、`Form.Fieldset` 和 `Form.Submit` 组合出一个表单。字段与字段集通过 render prop 暴露底层控件属性，便于完全控制。

<ComponentPreview 
  name="form-basic"
/>

### 校验

通过 `validConfig` 添加客户端校验。校验在 `onChange` 或 `onBlur` 触发，返回的字符串会作为错误信息渲染。当 `trigger` 为 `"onChange"` 时，可通过 `debounceMs` 进行防抖。

<ComponentPreview 
  name="form-validation"
/>

### 横向布局

将字段的 `direction` 设为 `"horizontal"`，即可让标签与控件并排显示。结合 `classNames` 可以进一步定制标签样式。

<ComponentPreview 
  name="form-horizontal"
/>

### 命令式控制

通过 `ref` 获取表单实例，从外部调用 `setValues`、`reset` 和 `submit`。

### 表单项

`FormItem` 组件用法已拆分为独立页面：[Form Item 表单项](/zh/docs/component/form-item)。

### 零件用法（useFieldValidity）

不使用任何包装组件：自持一个 `useFieldValidity` 状态（内置于 Form 模块），在自己的处理器里设置/清除错误，把 `aria-invalid` 传给控件，并条件渲染错误信息。所有输入类控件都内置危险样式（`border-danger` / `text-danger` 与危险焦点环），仅凭 `aria-invalid` 属性即可生效。

<ComponentPreview 
  name="form-parts"
/>

### 控件校验样式

所有字段控件（Input、Textarea、Select、Password、NumberField、Picker、InputOtp）直接由 `aria-invalid` 属性驱动样式 —— 无需额外属性：

`aria-invalid:border-danger aria-invalid:text-danger`，聚焦时叠加 `aria-invalid:focus-visible:outline-1 aria-invalid:focus-visible:outline-danger aria-invalid:focus-visible:ring-3 aria-invalid:focus-visible:ring-danger/50`。组合包装器（InputGroup、PasswordGroup）通过自身的 `data-invalid` 状态应用同样的效果。

## API 参考

### 高阶组件

开箱即用的成品组件。

#### Form

构建在原生 `<form>` 元素之上的根表单组件。

| 属性        | 类型                                       | 默认值 | 描述                                                                                       |
| ----------- | ------------------------------------------ | ------ | ------------------------------------------------------------------------------------------ |
| `onSubmit`  | `(values: FormValues) => Promise<boolean>` | -      | 异步提交处理器。接收已预处理的对象，多值字段为数组。返回 `true` 表示成功并触发 `autoReset` |
| `autoReset` | `boolean`                                  | `true` | 当 `onSubmit` 解析为 `true` 时自动重置表单                                                 |
| `onReset`   | `() => void`                               | -      | 表单重置时触发 —— 包括 `autoReset` 在提交成功后的重置，以及通过 `ref.reset()` 触发的重置    |
| `ref`       | `React.Ref<FormRef>`                       | -      | 暴露 `setValues`、`reset`、`submit` 的命令式句柄                                           |
| `children`  | `React.ReactNode`                          | -      | 表单内容，通常为 `Form.Field`、`Form.Fieldset` 与 `Form.Submit`                            |
| `...props`  | `React.ComponentProps<"form">`             | -      | 支持全部 form 原生属性（除 `onSubmit`、`ref` 外），展开到底层 form 元素                     |

#### FormRef

通过 `ref` 属性获取的命令式句柄，其中 `FormValue = string | number | string[] | number[] | null`。

| 方法        | 类型                                          | 描述                                                             |
| ----------- | --------------------------------------------- | ------------------------------------------------------------------ |
| `setValues` | `(values: Record<string, FormValue>) => void` | 更新一个或多个字段的值，并在每个被修改的输入上派发 `change` 事件 |
| `reset`     | `() => void`                                  | 重置表单并清空所有已注册的输入                                     |
| `submit`    | `() => void`                                  | 触发一次程序化表单提交                                             |

#### Form.Submit

自动反映表单提交状态的提交按钮。在表单提交过程中会被禁用，并可渲染自定义加载图标。

| 属性          | 类型              | 默认值 | 描述                                               |
| ------------- | ----------------- | ------ | -------------------------------------------------- |
| `loadingIcon` | `React.ReactNode` | -      | 表单提交时显示的自定义图标，默认为旋转的 `Loader2` |
| `className`   | `string`          | -      | 自定义 CSS 类，与内置按钮样式合并                  |
| `children`    | `React.ReactNode` | -      | 按钮文案                                           |

支持其余所有原生 `<button>` 属性；`type` 被强制为 `submit`。

#### Form.Field

将标签、控件和辅助文字包装为单一可访问的字段。控件通过 render prop 提供。

| 属性          | 类型                                       | 默认值       | 描述                                                          |
| ------------- | ------------------------------------------ | ------------ | ------------------------------------------------------------- |
| `name`        | `string`                                   | -            | 字段名称，用于在表单中注册输入                                |
| `label`       | `React.ReactNode`                          | -            | 渲染在控件上方的标签内容                                      |
| `description` | `React.ReactNode`                          | -            | 渲染在控件下方的辅助文字，校验失败时会被错误信息替代          |
| `invalid`     | `React.ReactNode`                          | -            | 受控的错误信息。传入字符串时会渲染为错误并设置 `aria-invalid` |
| `direction`   | `"vertical" \| "horizontal"`               | `"vertical"` | 标签与控件的排列方向                                          |
| `inputId`     | `string`                                   | -            | 底层控件的自定义 id                                           |
| `className` | `ClassNameValue` | - | 自定义类名，作用于字段容器 |
| `style` | `React.CSSProperties` | - | 内联样式，作用于字段容器 |
| `classNames`  | `{ label?: ClassNameValue; hint?: ClassNameValue }` | - | 标签与提示文字的自定义类 |
| `styles`      | `{ label?: React.CSSProperties; hint?: React.CSSProperties }` | - | 标签与提示文字的内联样式 |
| `validConfig` | `{ validate?: (value: string) => string \| boolean \| null \| undefined \| Promise<string \| boolean \| null \| undefined>; trigger?: "onChange" \| "onBlur"; debounceMs?: number }` | - | 客户端校验配置，字段说明见下表 |
| `children`    | `(field: FormFieldArg) => React.ReactNode` | -            | 接收输入属性并渲染控件的 render prop                          |
| `...props`    | `React.ComponentProps<"div">`              | -            | 支持全部 div 原生属性（除 `children`、`className`、`style` 外），展开到字段容器 |

`validConfig` 字段说明：

| 字段         | 描述                                                                                            |
| ------------ | ------------------------------------------------------------------------------------------------- |
| `validate`   | 校验函数，接收字段当前的字符串值。返回字符串会作为错误信息展示；返回 `true` 则标记字段无效 |
| `trigger`    | 校验函数的触发时机                                                                                |
| `debounceMs` | 防抖延迟（毫秒），在 `trigger` 为 `"onChange"` 时生效                                             |

#### FormFieldArg

提供给 `Form.Field` 子元素的 render prop，其中 `FormElement = HTMLInputElement | HTMLSelectElement | HTMLTextAreaElement`。

| 属性               | Type                                                     | 描述                                                          |
| ------------------ | ---------------------------------------------------------- | --------------------------------------------------------------- |
| `id`               | `string`                                                   | 为底层输入生成的 id，转发到控件的 `id`                        |
| `name`             | `string`                                                   | 字段的 `name`，转发到控件的 `name`                            |
| `ref`              | `(el: FormElement \| null) => void`                        | 用于在表单中注册输入的 ref 回调                               |
| `onChange`         | `(e: React.ChangeEvent<FormElement>) => void`              | 变更处理器，当 `trigger` 为 `"onChange"` 时触发 `validConfig` |
| `onBlur`           | `(e: React.FocusEvent<HTMLElement>) => void`               | 失焦处理器，当 `trigger` 为 `"onBlur"` 时触发 `validConfig`   |
| `invalid`          | `boolean`                                                  | 字段当前是否处于无效状态                                      |
| `aria-describedby` | `string`                                                   | 描述文字或错误文字的 id，用于无障碍访问                       |

#### Form.Fieldset

将一组相关控件（如复选框组、单选组）包装为单一可注册的字段。`type="multi"`（默认）时组值为 `string[]`；`type="single"` 时为 `string`。

| 属性          | 类型                                            | 默认值    | 描述                                                                              |
| ------------- | ----------------------------------------------- | --------- | ------------------------------------------------------------------------------------ |
| `name`        | `string`                                        | -         | 分组名称，用于在表单中注册字段集的值                                                 |
| `type`        | `"single" \| "multi"`                           | `"multi"` | `"multi"` 以 `string[]` 收集值，`"single"` 以 `string` 收集                          |
| `legend`      | `React.ReactNode`                               | -         | 渲染在 fieldset `<legend>` 中的标题内容                                              |
| `description` | `React.ReactNode`                               | -         | 渲染在分组下方的辅助文字，校验失败时会被错误信息替代                                 |
| `invalid`     | `React.ReactNode`                               | -         | 受控的错误信息。传入字符串时会渲染为错误并设置 `aria-invalid`                        |
| `disabled`    | `boolean`                                       | `false`   | 禁用字段集内的所有控件                                                               |
| `className` | `ClassNameValue` | - | 自定义类名，作用于 fieldset 元素 |
| `style` | `React.CSSProperties` | - | 内联样式，作用于 fieldset 元素 |
| `classNames`  | `{ legend?: ClassNameValue; hint?: ClassNameValue }` | - | legend 与提示文字的自定义类 |
| `styles`      | `{ legend?: React.CSSProperties; hint?: React.CSSProperties }` | - | legend 与提示文字的内联样式 |
| `validConfig` | `{ validate?: (value: string[] \| string) => string \| boolean \| undefined \| Promise<string \| boolean \| undefined>; trigger?: "onChange" \| "onBlur"; debounceMs?: number }` | - | 客户端校验配置，与 `Form.Field` 的结构相同，但 `validate` 接收分组值 |
| `children`    | `(field: FieldsetRenderArg) => React.ReactNode` | -         | 接收分组值与处理函数的 render prop                                                   |
| `...props`    | `React.ComponentPropsWithRef<"fieldset">`       | -         | 支持全部 fieldset 原生属性（除 `children`、`className`、`style` 外），展开到 fieldset 元素 |

render prop 接收：

| 属性               | 类型                                          | 描述                                                                              |
| ------------------ | ----------------------------------------------- | ------------------------------------------------------------------------------------ |
| `id`               | `string`                                        | 为字段集生成的 id                                                                    |
| `name`             | `string`                                        | 字段集的 `name`                                                                      |
| `value`            | `string[] \| string \| undefined`               | 当前分组值 —— `type="multi"` 时为 `string[]`，`type="single"` 时为 `string`          |
| `onValueChange`    | `(value: string[] \| string) => void`           | 更新分组值，当 `trigger` 为 `"onChange"` 时触发 `validConfig`                        |
| `onBlur`           | `(e: React.FocusEvent<HTMLElement>) => void`    | 失焦处理器，当 `trigger` 为 `"onBlur"` 时触发 `validConfig`                          |
| `invalid`          | `boolean`                                       | 字段集当前是否处于无效状态                                                           |
| `aria-describedby` | `string`                                        | 描述文字或错误文字的 id，用于无障碍访问                                              |

### 可组合组件

#### FormLabel

字段标签，渲染为 `<label>`。

| 属性        | 类型             | 默认值 | 描述          |
| ----------- | ---------------- | ------ | ------------- |
| `className` | `ClassNameValue` | -      | 自定义 CSS 类 |

支持所有原生 `<label>` 属性。

#### FormHint

提示文字，渲染为 `<small>`。正常时显示描述文字，字段无效时显示错误信息（带 `role="alert"`）。

| 属性        | 类型             | 默认值 | 描述          |
| ----------- | ---------------- | ------ | ------------- |
| `className` | `ClassNameValue` | -      | 自定义 CSS 类 |

支持所有原生 `<small>` 属性。
