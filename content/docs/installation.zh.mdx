## 前提条件

Litefy 不提供脚手架工具。它假设你已经有一个可用的 React + Tailwind CSS 项目。

在继续之前，请确保你的项目满足以下条件：

- **React 19+**（Litefy 使用了 `props.ref` 等 React 19 特性，低于此版本会报错）
- **Tailwind CSS 4** 已配置（Tailwind CSS 3 未经过测试，不保证兼容）
- TypeScript 已启用
- `@/` 路径别名已配置（如 `@/ui` 指向 `src/ui`）

## 命令

### `init`

初始化 Litefy 配置文件。

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    ```bash 
    npx litefy@latest init
     ```
  </Tab>
  <Tab value="yarn">
  ```bash 
  yarn dlx litefy@latest init 
  ```
  </Tab>
  <Tab value="pnpm">
  ```bash 
  pnpm dlx litefy@latest init 
  ```
  </Tab>
  <Tab value="bun">
  ```bash 
  bunx --bun litefy@latest init 
  ```
  </Tab>
</Tabs>

> 如果未初始化，直接执行添加组件命令时会自动完成初始化。

- `-y, --yes`：跳过交互式提示，直接使用默认配置
- `--pm <npm|yarn|pnpm|bun>`：手动指定包管理器，跳过自动检测

---

### `add`

下载并添加组件到本地项目。

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    ```bash 
    npx litefy@latest add <components...>
    ```
  </Tab>
  <Tab value="yarn">
  ```bash 
  yarn dlx litefy@latest add <components...>
  ```
  </Tab>
  <Tab value="pnpm">
  ```bash 
  pnpm dlx litefy@latest add <components...>
  ```
  </Tab>
  <Tab value="bun">
  ```bash 
  bunx --bun litefy@latest add <components...>
  ```
  </Tab>
</Tabs>

- `-o, --overwrite`：强制覆盖本地已经存在的组件文件

### `rm`

移除已安装组件：删除本地组件文件，同步更新配置内已安装列表。

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    ```bash 
    npx litefy@latest rm <components...>
    ```
  </Tab>
  <Tab value="yarn">
  ```bash 
  yarn dlx litefy@latest rm <components...>
  ```
  </Tab>
  <Tab value="pnpm">
  ```bash 
  pnpm dlx litefy@latest rm <components...>
  ```
  </Tab>
  <Tab value="bun">
  ```bash 
  bunx --bun litefy@latest rm <components...>
  ```
  </Tab>
</Tabs>

## 主题变量

Litefy 不自动注入主题变量。请从 <Link to="/zh/docs/theming">主题</Link> 页面选择你需要的色板，手动复制到你的全局 CSS 文件中。
