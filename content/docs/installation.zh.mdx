## 前提条件

Litefy 不提供完整项目脚手架，请在已有 React 项目中使用。

项目需要满足：

- **React 19+**（依赖 React 19 新特性，低版本不兼容）
- 已开启 TypeScript
- 配置路径别名 `@/*` 指向项目源码根目录

> 组件模板内部使用 `@/lib` 导入 `cn` 工具函数，需要别名正常工作。使用 CLI 默认路径时，只需把 `@` 映射到源码目录即可，无需额外特殊配置。别名的具体配置方式请参考你的构建工具文档。

## 命令

### init

初始化项目，生成 `litefy.json` 配置文件，创建 `ui/litefy` 目录结构，拉取 `cn.ts`，安装所需依赖。未初始化直接执行 add，会自动触发初始化流程。

> ⚠️ 不要手动修改 `litefy.json` 中的路径字段。如果自行修改路径，你需要同步维护项目别名与导入语句，CLI 不会自动修复。

<Tabs items={["npm", "yarn", "pnpm", "bun"]}>
  <Tab value="npm">
    ```bash
    npx litefy@latest init
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    yarn dlx litefy@latest init
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm dlx litefy@latest init
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bunx --bun litefy@latest init
    ```
  </Tab>
</Tabs>

**参数**

- `-y, --yes`：跳过交互，使用全部默认配置
